频响与风格

  • 低频：延伸好、量感足（Sonarworks 称"低频延伸出色"，headphonecheck 称低频偏"胖"、上低频收敛；SOS 称低频突出）。[consensus，基于 Sonarworks 测量描述 + 2 篇听感]
  • 中频：Sonarworks 测到约 1 kHz 峰 + 2 kHz 凹，令中频有明显着色；headphonecheck 认为人声清晰度高、约 5 kHz 有明显回收。[measured（Sonarworks 文字描述，未取得曲线数值）]
  • 高频：比同价位贴耳竞品更亮，但约 14 kHz 以下提升仍算克制；SOS 称"较慷慨的高频强调"但不刺。[measured 描述 + consensus]
  • 风格：非中性、偏"讨喜/活泼"的轻 V 型；与 Harman / 扩散场目标的具体偏差数值证据不足。
  • 独立测量图（普洛影音網，台架未注明）：原始图上 500 Hz–1 kHz 是平台（≈95 dB），2 kHz 附近有凹陷，4–4.5 kHz 有最高峰（约高于 1 kHz 8 dB），8–9 kHz 有次峰，14 kHz 以上滚降；30–200 Hz 比中频低约 12–15 dB。"HEQ 补偿"图上 3–8 kHz 陷得很深（5 kHz 最低），8–10 kHz 回升。1 kHz 平台 / 2 kHz 凹这两点和 Sonarworks 的描述一致。低频明显偏低，这和 Sonarworks、SOS、headphonecheck 说的"低频足"相反。贴耳式在平板或低成本耦合器上容易漏气，所以更可能是台架密封的假象，不作为低频证据。[measured（图片，台架未知，低权重）]
  • 测量源：曲线库中未找到本型号的可复核曲线（见"原始曲线与来源"），因此没有台架或目标曲线对比。以上中频特征来自 Sonarworks 自有台架的文字描述（台架与目标未公开），属于间接测量。

技术素质

  • 解析：细节与中高频生动度获好评（2/3 评测）。[consensus]
  • 声场/纵深：headphonecheck 称纵深表现好；其余来源未涉及——证据不足。[consensus 1/3]
  • 分离、动态：官方宣称大冲程单元利于瞬态；独立评测未系统讨论，证据不足。[prior]

佩戴与做工

做工获一致高分（3/3）。贴耳舒适度分歧：SOS 认为比 Hi-X55 更舒服；Sonarworks 半数测试者觉得耳廓受压明显。[consensus，有分歧]

用途适配

  • 混音/挑错：多篇评测明确不推荐作为严格中性混音参考（需校正软件；Sonarworks 未校正 6.7/10，校正后 8/10）。适合录音监听、DJ/移动工作。
  • 听歌：调音友好，但贴耳佩戴因人而异。
  • 推力：25 Ω / 118 dB/V，手机即可轻松推动。

评分

  • 挑错度 55：高频略亮、细节可闻，但中频着色 + 低频偏多，更像通用监听而非挑错。
  • 音质 72：做工与单元素质好，但中频着色限制了绝对表现，约与 DT 770 Pro 同档。
  • 听歌适配 66：讨喜调音加分，贴耳压耳分歧减分。
  • 曲线重校：本轮没有找到原始数值曲线，三项分数都不变（55/72/66）。
  • 深挖重校（第四轮）：三项分数不变，仍为 55/72/66。原因：普洛影音網的图台架不明，低频很可能受漏气影响，只能印证中频有着色（1 kHz 平台、2 kHz 凹）和高频有峰（4–4.5 kHz、8–9 kHz），这些已经反映在现有分数里。
