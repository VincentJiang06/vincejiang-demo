Sennheiser HD 300 PROtect

结论：它是在 HD 300 Pro 上加了 ActiveGard 限幅，用来保护听力。调音偏暖、低频多，代理曲线（HD 300 PRO）显示高频不亮，佩戴稳，隔音强。适合广播和转播长时间监听，不以分析力见长。 Verdict: An HD 300 Pro with a switchable ActiveGard hearing-protection limiter. It sounds warm, balanced and non-fatiguing, fits securely and isolates strongly, which suits long broadcast shifts, but it is not an analytical reference.

频响与风格

测量来源：见上一节。唯一的数值曲线是 Listener 的 KB006x（711 类）曲线，测的是 HD 300 PRO。

关键特征（fr_analyze.py 对比 Harman OE 2018，500–1000 Hz 对齐；台架不匹配，只看趋势）：

  • 低频：20–60 Hz 多约 5.4 dB，60–200 Hz 多约 3.7 dB，150 Hz 附近有一个小鼓包。只要密封好，超低频延伸很好。Sonarworks 测到不同佩戴者之间低频差约 ±3 dB。低频失真偏高，200 Hz 以上失真低于 0.3%（Sonarworks）。
  • 中频：200–500 Hz 多约 2.3 dB，偏暖；1–3 kHz 比 Harman 少约 0.7 dB，人声不靠前。
  • 高频：3–6 kHz 少约 1.6 dB，6–10 kHz 基本持平（−0.6 dB），10 kHz 以上有峰有谷（9–13 kHz 凹、16 kHz 附近凸），总量不算亮。
  • 与图片来源的矛盾：上一轮根据 DIY-Audio-Heaven 的截图和文字写了“高频略抬、有锐度”。Listener 的数值曲线没有确认这一点，高频总量反而略少。两者台架都不标准；这次以唯一有数值的 Listener 曲线为准，DIY-AH 提到的锐度只作为“9 kHz 附近可能有窄峰、因人而异”保留。
  • 一致性：左右通道差不超过 2 dB（Sonarworks），DIY-Audio-Heaven 也评为“很好”。
  • 风格结论（曲线修正）：暖向、低频多。低频和超低频偏多，中频偏暖，存在感频段略少，高频不亮。不是上一轮写的“温和 U 形、高频略亮”。

技术素质（均为评测共识）

  • 解析：良好，但不是它的强项（2/2 篇一致）。
  • 声场：封闭式常见的中等偏小水平，证据不足。
  • 分离与动态：证据不足。
  • 瞬态：低频干净（headphonecheck）。

佩戴与做工

佩戴稳、不滑脱，压力适中，适合长时间工作（2/2 篇一致）。也有评测称赞它长时间佩戴舒适、不累。整体是专业耐用的塑料机身，本次没有专门检索做工口碑，这部分证据不足。

用途适配

  • 适合：广播、转播、长时间高声压的监听环境。ActiveGard 是它的核心价值，能削掉 110 dB 以上的峰值。
  • 混音或挑错：偏暖，不够“透明”，做挑错不是首选。
  • 听歌：低频足、高频不刺，隔音强，但夹得紧，适配度中等。
  • 推力：108 dB/V、64 Ω，手机能推响，但音量余量一般（measured spec）。

评分

  • 挑错度 52（不变）：曲线显示低频比 Harman 多约 4–5 dB、中频偏暖、存在感频段略少，本来会往下拉；但上一轮的 52 主要依据高频锐度，这次按曲线看高频不亮，两者抵消后仍放在 K371（45）和 DT 770 Pro（55）之间。与 HD 300 PRO（rank 17）的 52 保持一致。
  • 音质 68（不变）：低频延伸好、失真低、左右一致；150 Hz 鼓包、低频偏多、8 kHz 以上峰谷明显，平滑度一般。
  • 听歌适配 62（曲线重校：64→62，原因：曲线显示高频不刺，听感比“高频锐”好听，但 6 N 的夹持力限制长时间佩戴；与同声学的 HD 300 PRO 对齐）。

证据与置信度

  • 证据级别：proxy-measured，置信度中。唯一的数值曲线是 Listener 的 KB006x（711 类）曲线，测的是 HD 300 PRO，没有 PROtect 本身的数值，也没有 5128/GRAS 数据。
  • 矛盾点：DIY-Audio-Heaven 的截图和文字说高频略抬、有锐度；Listener 曲线显示高频总量略少。这次以有数值的曲线为准。
  • 曲线重校：风格从“温和 U 形、高频略亮”改为“暖向、低频多、高频不亮”；听歌适配 64→62；挑错度和音质不变。
  • 证据缺口：没有 5128/GRAS 数值曲线，没有第三方隔音测量，ActiveGard 开启后对音质的影响也缺少证据。
