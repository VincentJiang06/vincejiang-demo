频响与风格

  • 测量源：AutoEq 收录的 Innerfidelity 测量（Head Acoustics HMS II.3 台架，Innerfidelity 旧档案），raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/Innerfidelity/over-ear/Beyerdynamic%20DT%20240%20Pro/Beyerdynamic%20DT%20240%20Pro.csv 。对比目标是 AutoEq 换算到该台架的 Harman Over-Ear 2018 目标（CSV 自带的 target / error_smoothed 列）。另外用 fr_analyze.py 按 harman_oe_2018 算了一遍作交叉参考。台架不是 GRAS 43AG，这一遍只看趋势。
  • 低频：60–200 Hz 平均比目标高约 3.6 dB，最多的地方在 100–150 Hz 附近（约 +3.6 到 +4.5 dB）；20–60 Hz 只高约 0.8 dB，基本贴着目标。和 Stereophile 摘要里"低频宽鼓包"的说法一致，但测出来的抬升集中在中低频，不在超低频。
  • 中频：200–500 Hz 高约 1.7 dB，中频略厚；500 Hz–3 kHz 基本贴着目标（偏差不到 0.5 dB）。
  • 高频：原始曲线在 2–4 kHz 有凸起（3 kHz 附近约 +7 dB，相对 1 kHz），但这一段本来就是目标要求的耳道增益区，相对目标并不超量（3–4 kHz 约 −0.5 到 −0.8 dB）。5–7 kHz 有一个较深的凹陷（相对目标约 −7 到 −9 dB）。3–6 kHz 平均 −4.5 dB，6–10 kHz 平均 −5.2 dB，10 kHz 以上 −3.2 dB；8.6–10 kHz 附近有几个相对局部走势的窄峰，不过整体仍低于目标。
  • 风格（测量修正）：原先写的是"温暖偏 V、偏亮"。测量显示它是暖向、高频收敛的调音（fr_analyze 判定暖向倾斜，tilt 约 −7 dB）：中低频有鼓包，人声段中性，高频整体比 Harman 少，不是亮声。之前说的"3 kHz 峰值"是正常的耳道增益，不是过量。榜单写的"中性偏暖"比原稿更接近测量。注意这只是单一样本、单一台架的结果，headphonecheck 听到的 11 kHz 抬升在这条曲线里没有表现出来。

技术素质（review consensus only）

  • 解析：中等，有细节，但缺少锐利的精细度（headphonecheck、SoundGuys，2/3）。
  • 声场与分离：空间感尚可，但宽度和纵深分层达不到参考级（headphonecheck）；SoundGuys 认为清晰度和声场不如 ATH-M40x（2/3）。
  • 动态与瞬态：证据不足。

佩戴与做工

  • 轻，耳垫软，记忆头梁，长时间佩戴不累（2/3 一致）。
  • 金属头梁加铝制叉臂，线材加固，配件可换（SoundGuys）。

用途适配

  • 适合外出录音、播客、乐器跟踪，对挑错要求不高的场合。headphonecheck 明确说不适合声音关键的棚内工作。
  • 听歌：调音讨喜，佩戴轻松，可以当日常耳机用。
  • 推力：低阻高灵敏，手机直推就够。

评分

  • 挑错度 38（测量修正，原 50）：presence 段只是贴着目标，5 kHz 以上整体比目标少约 4–5 dB，中低频还多出 3–4 dB，按测量属于偏讨喜、偏整体的调音，和 ATH-M50x（≈40）差不多，甚至更暖一点。
  • 音质 60（原 62）：大部分频段平滑，但 5–7 kHz 的深凹陷和 9–10 kHz 的窄峰让高频不够平整；评测共识的解析、分层也只是中等。
  • 听歌适配 68（原 66）：暖、高频不刺、轻、好推，日常听歌比原先估计的更友好；高频延伸和空气感偏少。

证据与置信度

  • 曲线重校：本轮没有找到 5128 / GRAS 数值曲线，分数不变（挑错度 38、音质 60、听歌适配 68）；Stereophile 的文字描述（70 Hz 鼓包、5.5 kHz 深凹）支持现有结论。

  • 置信度：medium。官方规格齐全，有 Innerfidelity 的实测 FR（已量化），另有 3 篇评测；测量结论和原先的主观判断有冲突，以测量为准。

  • 曲线库补查：AutoEq 找到 Innerfidelity 的 DT 240 Pro 数据（已取 CSV 做量化）；AutoEq 里 oratory1990 的"DT 240"是旧款非 Pro，没有采用；RTINGS 没有这款（页面 404）。
  • 缺口：Stereophile 原文返回 403，只看到摘要；只有一个样本和一个非 GRAS 台架，没有失真和左右一致性数据；单元尺寸没有核实。
