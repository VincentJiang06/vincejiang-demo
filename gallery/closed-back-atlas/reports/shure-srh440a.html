频响与风格

测量源：oratory1990 实测（AutoEq 收录，https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Shure%20SRH440A ，raw CSV 已下载分析），台架为 GRAS 45BC KEMAR 耳-颊模拟器（oratory1990 常用台架）。对比目标曲线：Harman 头戴 2018（按 500–1000 Hz 对齐，用 vince-hifi-review 的 fr_analyze.py 计算）。AutoEq 中没有 crinacle、RTINGS 的 SRH440A 目录。DIY-Audio-Heaven 与 headphonecheck 的描述作为辅证。

  • 低频：20–60 Hz 比目标高约 2.2 dB，60–200 Hz 高约 4.6 dB，最多出现在 100–200 Hz（约 +4.5~5 dB）。低频量感明显偏多，与 DIY-Audio-Heaven 所说"约 150 Hz 抬升"一致。（measured）
  • 中频：200–500 Hz +0.7 dB，500–1000 Hz 中性，1–3 kHz 平均 -1.2 dB。相对低频和目标而言，中频并不"靠前"。
  • 高频：3–6 kHz 平均 -1.9 dB，其中约 4 kHz 有一处窄谷（比目标低约 5 dB）；6–10 kHz 基本贴合目标（+0.8 dB），约 9 kHz 没有尖峰（与目标相差不到 0.1 dB）；10–20 kHz 平均 +3.7 dB，约 13 kHz 有小峰，10.7 kHz 附近有小谷。
  • 曲线重校：本轮没有找到第二条 SRH440A 的原始数值，更没有 5128 曲线，所以上面的判断仍只依据一条 GRAS 曲线；没有出现相互矛盾的数值数据。
  • 整体风格（measured）：低频偏多的暖声，存在感区略收，高频大体平顺。测量修正：原报告"中频靠前"和"可能有 9 kHz 刺耳尖峰"都没有得到 oratory1990 数据支持。高频分歧暂按 oratory1990 的结果处理，DIY-Audio-Heaven 提到的尖峰可能与样本或佩戴有关。

技术素质

  • 解析：有限，明显不如 SRH840A。（consensus 2/2，headphonecheck、MusicTech 的比较）
  • 声场：宽度和深度都窄。（consensus，headphonecheck）
  • 分离、动态：headphonecheck 认为动态和层次有限。其他来源证据不足。
  • 瞬态：低频偏软（DIY-Audio-Heaven）。

佩戴与做工

记忆棉耳垫不容易出汗，头梁卡位调节方便，长时间佩戴舒适（consensus）。改款后做工比旧版 SRH440 好（DIY-Audio-Heaven）。

用途适配

  • 人声、播客、轻度混音：合适（TrustedReviews、headphonecheck）。
  • 高要求挑错：解析和声场都不够。
  • 听歌：低频暖而厚，舒适度好，是加分项。oratory1990 测量显示高频平顺、没有 9 kHz 尖峰，听久了也不容易累。
  • 推力：非常容易推。

评分

  • 挑错度 42（曲线重校：42→42，没有新曲线；上一轮测量修正：58→42）：中低频比 Harman 多约 4–5 dB，2–6 kHz 略收，4 kHz 有谷，9 kHz 没有尖峰，属于偏整体、偏暖的调音，与 ATH-M50x（≈40）同档。解析有限，也进一步限制了挑错能力。
  • 音质 60（曲线重校：60→60，不变）：测量整体较平顺，没有严重的尖峰，但低频量多、声场窄、解析一般，属于百元档的平均水平。
  • 听歌适配 70（曲线重校：70→70，不变；上一轮测量修正：66→70）：低频足、高频不刺，佩戴舒适、好推，适合听歌；声场窄、低频偏软是短板。
