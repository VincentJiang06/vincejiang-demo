Yamaha HPH-MT8

平直取向、细节量足、易推的平价封闭监听；声场紧凑、听感偏"硬"，更像工具而非享受。 A flat-leaning, detailed and easy-to-drive budget closed monitor; compact stage and a somewhat stiff presentation make it more tool than treat.

频响与风格

  • 测量（B&K 5128，对 5128 DF，500–1000 Hz 对齐）：超低频 +4.3 dB、中低频 +3.7 dB、低中频 −2.2 dB、中频 0、中高频 −2.6 dB、3–6 kHz −5.5 dB、6–10 kHz −1.7 dB、10–20 kHz −4.7 dB。5 位置平均几乎一样（+4.4/+4.0/−2.4/0/−2.4/−5.6/−1.7/−5.1）。
  • 怎么读：偏好中性的头戴通常低频比 DF 高约 4–6 dB、高频略低于 DF。按这个标准，MT8 的低频只是"中性量"，没有额外加厚；延伸很平，20–80 Hz 基本持平，不衰减。
  • 低中频：250–300 Hz 有一个比周围低约 4–8 dB 的凹陷（原始曲线 200 Hz ≈93.8、300 Hz ≈89.6、1 kHz ≈97.2 dB）。它让低频和中频"脱节"、声音显薄，与 ASR 上 solderdude 说的"200 Hz 附近小凹陷"、以及 ASR 楼主说的"thin"一致。
  • 中高频/高频：1–4 kHz 平缓上升；约 4.75 kHz 有一个窄而深的凹陷（残差 −7 dB），紧接着 5.5–6.5 kHz 抬起；13 kHz 附近有一个尖峰（残差 +7 dB），之后 15 kHz 以上下滑。band 平均算下来 3–6 kHz"偏少"，主要是那个窄凹陷拉低的，实际听感是"凹陷＋两侧尖峰"交替，高频不平整。
  • 风格（以 5128 为准）：中性量低频＋低中频凹陷＋锯齿状高频。算不上"平直"，也不偏亮；主观说的"细节多、偏硬"，更可能来自 6 kHz 和 13 kHz 的窄峰加上低中频凹陷，而不是整体高频抬升。
  • 矛盾点：主观共识（MusicTech 等）说"平直"，5128 曲线只支持"低频不加厚"，不支持"平直"；solderdude 说"低频偏少"，而 5128 上低频正好在中性偏好线附近——他的台架未注明，而且他也提到对密闭性敏感，所以以 5128 为准，只记为分歧。

技术素质

  • 解析：同价位出色，MusicTech 称细节接近其 £600 参考耳机；hatena 称信息量大 —— consensus 3/4（Soundsight 认为高频细节不及前代 MT220）。
  • 声场：分歧——hatena 称不宽、紧凑；Soundsight 称"很宽" —— consensus 冲突，1:1。
  • 分离/定位：良好（hatena、MusicTech 提到低中频分离）—— consensus 2/2。
  • 动态/瞬态：证据不足。
  • Frieve 聚合评分 3.0/5，认为性价比不如 MDR-7506 / ATH-M50x（偏规格导向，权重低）。

佩戴与做工

头梁软垫、耳垫质感优于 MT5，较舒适；耳垫深度一般，大耳者可能压耳；重量有感 —— consensus。做工扎实。

用途适配

  • 混音/审听：低频量中性、细节感足，能较快发现问题；但高频不平整（4.75 kHz 凹陷、13 kHz 尖峰），最好配合 EQ 使用，适合预算有限的混音与录音监听。
  • 听歌：hatena 指出声音偏"硬"、久听易疲劳，娱乐性一般。
  • 推力：37 Ω / 102 dB/mW，手机与接口均可轻松驱动。

评分

  • 挑错度 60（曲线重校：68→60。5128 显示高频没有整体抬升，低频是中性量；细节感主要来自低中频凹陷和 6 kHz、13 kHz 的窄峰，挑错能力不如整体上扬的 7506，和 DT 770 Pro 同档略高）。
  • 音质 68（曲线重校：70→68。低频延伸好，但 250–300 Hz 凹陷、4.75 kHz 深凹陷、13 kHz 尖峰让曲线不平整，对佩戴位置也比较敏感，低于 DT 770 Pro）。
  • 听歌适配 62（曲线重校：60→62。低频量达到中性偏好线、没有刺耳的整体高频，比原先估计的稍好；低中频偏薄、高频锯齿、声场紧凑仍然拖分）。
