AKG K175

可折叠的压耳式便携监听：德语原版评测说它低频偏多、高频偏少，2 kHz 附近中频突出，声音偏闷，整体暖而松弛；夹力大。四轮深挖仍未找到可信曲线，结论只能依据主观评测共识。 Foldable on-ear portable monitor. German reviews describe it as bass-leaning and treble-shy, with a pushy ~2 kHz midrange that sounds boxy, and warm, relaxed overall; strong clamp. Four rounds of searching found no credible FR measurement, so this rests on review consensus.

  • 共识（第四轮修订）：kopfhoerer.de（德语原版）说低频比高频多、高频略少，声场因此偏窄；2 kHz 附近中频强势，声音偏闷，瞬态偏收着。delamar.de 说低频非常强势、下潜深，中频和高频明显收敛，声音暖而松弛，没有齿音。What Hi-Fi? 摘要说声音有活力，但中频激进，容易疲劳。Noisegate 说均衡不染色，属于少数意见（dissent）。
  • 结论：大概率是低频偏多、高频偏暗、2 kHz 附近有凸起的暖闷型（低频偏多、高频偏少这一点 2/2 德语评测一致；2 kHz 凸起 1–2 家提到）。旧版"偏亮"的判断来自英文页的误译，本轮撤回。没有具体 dB 数值。

  • 动态、分离：证据不足。

佩戴与做工

铰链金属结构坚固，可折叠，便于携带（consensus）。压耳式设计，headphonecheck 实测夹力约 602.5 g（多头围平均），久戴会有明显压迫感；Noisegate 则认为舒适，存在分歧。

用途适配

适合便携跟踪、DJ、现场监听：隔音尚可，推力需求很低（32 Ω，114 dB SPL/V，手机直推即可）。按共识，它的中频偏前、声场窄，不适合做精细混音参考。听歌时有活力，但可能疲劳。

评分

曲线重校：无新曲线，三项分数不变（62 / 58 / 55）。

深挖重校（第四轮）：挑错度 62→48，音质 58→55，听歌适配 55→58。原因：德语原版评测纠正了英文页的误译，风格从"偏亮偏前"改判为"低频偏多、高频偏暗、2 kHz 凸起"的暖闷型。仍然没有测量。

  • 挑错度 48：低频偏多、高频偏暗、瞬态偏收着，不利于找出细节问题；2 kHz 凸起会让中频瑕疵稍微突出，所以比 M50x（≈40）略高，但低于 DT770（≈55）。
  • 音质 55：线性不佳（低频过多，2 kHz 附近偏闷），透明度低于同价位对手，声场窄、微动态一般，做工加一点分。
  • 听歌适配 58：暖、低频足、没有齿音，适合长时间放松听；但 2 kHz 附近偏闷，压耳夹力大，拉低了分数。
