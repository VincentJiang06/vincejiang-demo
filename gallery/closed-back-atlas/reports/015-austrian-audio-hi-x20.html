Austrian Audio Hi-X20

结论：149 美元档里很好推的封闭监听。B&K 5128 测量（Earphones Archive）显示它中低频很重、2.7–8 kHz 明显抬升，属于偏亮的 V 型，适合人声和内容检查；听歌时高频偏亮，需要适应。 Verdict: An easy-to-drive $149 closed monitor. B&K 5128 data (Earphones Archive) shows heavy mid-bass and a strong 2.7–8 kHz lift, a bright-leaning V shape that suits voice and content checking but can sound hot for music.

频响与风格

主曲线（B&K 5128，Earphones Archive，居中佩戴，L/R 平均），对照 5128 DF、以 500 Hz–1 kHz 对齐（fr_analyze.py）： - 分频段偏差：超低频 20–60 Hz +12.2 dB，中低频 60–200 Hz +9.3，200–500 Hz −0.5，1–3 kHz +0.6，3–5 kHz +5.1，5–10 kHz +4.7，10 kHz 以上 −2.7；脚本判为 V 形，tilt −8.4 dB（低频量压过了高频抬升）。 - 换算：偏好中性的头戴一般低频比 DF 高约 4–6 dB、高频略低于 DF。Hi-X20 的中低频多出偏好约 3–5 dB，3–10 kHz 则比 DF 还高约 5 dB，比偏好中性亮约 6–8 dB，是明确的“低频重 + 中高频亮”V 型。 - 特征点（相对 DF 的残差）：约 1.98 kHz 谷 −4.5（人声略退），约 2.7–2.95 kHz 峰 +5.3/+5.8（咬字靠前），约 8 kHz 峰 +3.8（齿音风险），约 18.7 kHz 深谷（听感影响小）。以 1 kHz 为 0 的原始值：3 kHz +17.5、6 kHz +14.4、8 kHz +13.3。 - 同台架对比（Earphones Archive 5128，同一分析）：HD 480 Pro 的 3–10 kHz 约 −3.4/−3.3，H200 约 −0.7/+1.0，SRH840A 约 +3.4/+5.4；Hi-X20 为 +5.1/+4.7，与 SRH840A 同属偏亮一档，中低频（+9.3）也与 SRH840A（+9.5）相当。 - 五个佩戴位置平均后结论不变；2–12 kHz 位置间最大差约 10 dB。左右声道 100 Hz–10 kHz 平均差 1.2 dB、最大 3.1 dB，一致性中等。 - 与 Kuulokenurkka 曲线对照：两者都显示低频偏多、2.7–6 kHz 明显抬升，方向一致，没有矛盾。上一轮根据 Kuulokenurkka 推断的“偏亮 V 型”得到 5128 确认；5128 上中低频更重（+9.3 dB），这一点以 5128 为准。 - 风格：中低频很重、2.7–8 kHz 明显抬升的偏亮 V 型（measured，B&K 5128 主曲线）。评测共识说的“中性偏亮、高频不刺”与测量不符，以测量为准。

技术素质（只来自评测共识）

  • 解析：好，细节充足（3 篇中 3 篇）。
  • 声场：对封闭式来说偏宽（3 篇中 3 篇）；headphonecheck 认为纵深也还可以。
  • 动态：古典乐的动态和纵深表现不错（1 篇，证据不足）。
  • 瞬态/分离：厂商宣称瞬态快，没有找到独立评测验证，证据不足。

佩戴与做工

金属头梁和金属转轴，耳杯可以旋转和倾斜，记忆棉耳垫柔软（consensus）。SoundStage! Solo 反映夹力稍大，耳杯高但不宽，耳朵大的人可能会觉得紧。可拆线（3 m，3.5 mm）。

用途适配

  • 混音/挑错：2.7–8 kHz 抬升，适合对白、人声和齿音检查，挑错力度中等偏上；中低频偏重，判断低频量时需留意。
  • 听歌：调音自然，佩戴舒适，SoundStage! Solo 认为比 MDR-7506 耐听。
  • 推力：25 Ω、113 dB/V，手机、笔记本和入门声卡都能轻松推动（prior + 规格）。

评分

  • 挑错度 66（曲线重校：68→66，5128 确认 3–10 kHz 比 DF 高约 5 dB、2.9 kHz 与 8 kHz 有峰，挑错倾向强；但中低频比 DF 高 9 dB，比 H200 多约 4.5 dB，会掩蔽中低频细节，所以略低于 Hi-X60 的 67）。
  • 音质 70（曲线重校：72→70，5128 显示 2 kHz 谷、2.9 kHz 峰、8 kHz 峰，高频起伏比 H200 大，中低频过量，左右一致性一般；解析和声场的评测共识仍不错）。
  • 听歌适配 66（曲线重校：68→66，低频量足但中高频比偏好中性亮 6–8 dB，长时间听容易疲劳）。

证据与置信度

  • 证据等级：measured。置信度：中高（上一轮为中）。现在有 B&K 5128 的双声道、五个佩戴位置数据，与 Kuulokenurkka 方向一致。
  • 证据缺口：没有失真数据；灵敏度的测试条件不明；隔音只有主观描述。
