频响与风格

  • 测量源（measured）：oratory1990 的测量，收录在 AutoEq 里（https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Beyerdynamic%20DT%20770%20M ；原始 CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/Beyerdynamic%20DT%20770%20M/Beyerdynamic%20DT%20770%20M.csv ）。台架：GRAS 45BC KEMAR（oratory1990 的包耳式台架）。目标曲线：Harman over-ear 2018。数据用 fr_analyze.py 分析，以 500–1k Hz 对齐。
  • 各频段相对 Harman OE 2018 的偏差：
  • 超低频（20–60 Hz）约 -8.6 dB，大幅不足；
  • 中低频（60–200 Hz）平均 +1.1 dB，但形状不平：约 70 Hz 有一个约 -6 dB 的凹陷，约 100 Hz 有一个约 +4 dB 的隆起；
  • 中下频（200–500 Hz）约 +2.7 dB，略厚；
  • 中频和中高频（0.5–3 kHz）基本贴合目标，偏差在 ±0.3 dB 以内；
  • 低高频（3–6 kHz）约 -6.8 dB，其中 3.6 kHz 附近的凹陷约 -9 dB；
  • 中高频（6–10 kHz）约 -4.1 dB；
  • 空气感频段接近目标，但 12.5 kHz 附近有一个约 +5 dB 的窄峰。
  • 结论：这是一条暗声、深低频不足的曲线，低频的量集中在 100 Hz 上下，中下频偏厚。这与 Head-Fi 和 Sweetwater 用户说的"发闷、两端延伸不足"一致。headphonecheck 说它"平衡、解析高"，这与测量不符。测量修正：原先只说"高频没有被刻意提亮"，实际上 3–10 kHz 明显偏少。
  • 测量的局限：只有 oratory1990 一个样本，没有左右声道一致性和失真数据。包耳式耳机的低频对佩戴密封很敏感。

技术素质

  • 解析、声场：headphonecheck 给了正面评价（纵深和定位"优秀"）；多名 Head-Fi 用户给了负面评价（糊、压缩）。1/3 份评测正面，共识不成立，置信度低。
  • 分离、动态、瞬态：证据不足。headphonecheck 提到它需要足够的推力才能发挥。

佩戴与做工

德国制造，耳垫可换，结构沿用 DT 770 家族，耐用性是公认的先验。6.5 N 的夹力是官方为了隔音特意定的，长时间戴会有压迫感。headphonecheck 认为长时间佩戴也舒适，这一点和"夹得紧"并存，因人而异。

用途适配

  • 最适合：打鼓监听、现场 FOH、嘈杂环境。线上音量旋钮很实用。
  • 混音或挑错：不推荐。测量显示 3–10 kHz 偏少，超低频不足。
  • 听歌：比同价的 DT 770 Pro 差。
  • 推力：80 Ω，手机能推响；想要余量最好配一台小耳放。

评分

  • 挑错度 35（测量修正，原为 45）：3–6 kHz 比目标低约 7 dB，6–10 kHz 低约 4 dB，整体偏暗，不会放大瑕疵。12.5 kHz 的窄峰只带来少量空气感和毛刺。
  • 音质 55（原为 60）：曲线不够平滑，有 70 Hz 的凹陷、100 Hz 的隆起、3.6 kHz 约 -9 dB 的凹陷和 12.5 kHz 的窄峰，深低频也延伸不足。用户说的"糊、闷"得到测量支持。
  • 听歌适配 50（原为 56）：声音偏暗，缺少超低频，夹力又大，讨喜程度有限。
  • 曲线重校（2026-09）：分数不变。原因是全网只找到 oratory1990 这一条原始曲线，没有 5128 数据或其他台架的数据可以修正结论。
