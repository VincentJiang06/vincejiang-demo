频响与风格

  • 主依据（B&K 5128，对比 5128 DF，500–1000 Hz 对齐）：
  • RTINGS：超低频 +4.0 dB，中低频 +2.1 dB，200 Hz–3 kHz 在 ±0.5 dB 以内；低高频（3–6 kHz）−2.3 dB，约 3.6 kHz 有凹陷（−6.6 dB）；中高频（6–10 kHz）+5.5 dB，约 8.7 kHz 有峰（+4.9 dB），约 13.7 kHz 有峰（+5.1 dB）。
  • Listener 5128 平均曲线：超低频 +1.7，中低频 +2.6，3.75 kHz 凹陷 −4.2，8.5 kHz 峰 +3.3，13 kHz 附近峰 +3.3，中高频 +4.1。和 RTINGS 形状一致，只是峰谷被多源平均抹平了一些。
  • 换算到偏好口径：5128 DF 是参考基线，不是偏好目标。偏好中性的头戴一般低频比 DF 高 4–6 dB、高频略低于 DF。按这个标准看：
  • DT 770 Pro 的低频只比 DF 高 2–4 dB，相对偏好中性是持平到略少，不是"低频多"。
  • 6–14 kHz 比 DF 高 4–5.5 dB，相对偏好中性约亮 5–7 dB，而且是 8.7 kHz 和 13.7 kHz 两个尖峰。
  • 3.5–4 kHz 的凹陷会让人声和乐器的存在感退后一点，同时让上面的峰显得更突出。
  • 其他台架（只作佐证）：oratory1990（GRAS，对比 Harman OE 2018）超低频 +3.4，3.8 kHz 凹陷 −5.5，6.4 kHz 峰 +3.2，极高频 +4.3。Harman OE 本身已经带低频架，所以这条也说明低频量在 Harman 附近、高频偏亮，与 5128 结论一致。HMS II.3 和其他未注明台架的曲线都显示高频偏亮（中高频 +2~+6，极高频 +2~+10）。低频量在不同版本和样品间差别很大（−9 到 +5 dB），应该是耳垫密封和版本差异造成的，不能据此断定"250Ω 更平直"。
  • 矛盾点：
  • 上一轮说"超低频略多（+3~4 dB），轻 V 型"，那是直接读 DF 偏差。换算到偏好口径后，低频只算中性，整体是高频偏亮、带两处尖峰的"亮向"调音，V 的低频那一侧并不成立。
  • GRAS 的峰在 6.4 kHz，5128 的峰在 8.7 kHz，属于台架耳道共振位置不同，以 5128 为准。
  • 换旧耳垫或 Dekoni 耳垫后低频会少 1–4 dB，高频峰变得更突出。
  • 风格：低频中性（相对偏好）、中频平直，3.5–4 kHz 凹陷，8.7 kHz 和 13.7 kHz 两处明显高频峰的亮向调音（measured，5128 两源一致）。

技术素质（只来自评测共识）

  • 解析：高频峰带来的表观细节多，但质感偏毛（2 篇中 2 篇）。
  • 声场：宽度不错，纵深层次一般（1 篇，headphonecheck）。
  • 动态：headphonecheck 认为略压缩、动态有限（1 篇）。
  • 低频质量：下潜深，但不够精致（1 篇）。

佩戴与做工

丝绒耳垫和较轻的机身，长时间佩戴舒适，戴眼镜也友好（consensus）。录音棚里的耐用口碑长期存在（prior）。直插线不可拆是一个短板。

用途适配

  • 混音/挑错：录音监听很合适（隔音好、舒适）；高频峰值有助于发现齿音，但会让高频判断失准。
  • 听歌：低频量中性、下潜好，高频偏亮加两处峰值可能耳疲劳，需要适应或 EQ。
  • 推力：250Ω / 约 101 dB/V，直插手机音量偏小，建议用耳放；32Ω 版适合移动设备（官方分档说明）。

评分

  • 挑错度 55（维持，也是锚点值）：5128 显示高频比偏好中性亮 5–7 dB，低频也不多，这些会让它更"挑"；但 3.5–4 kHz 凹陷会削弱对人声和主要乐器的判断，高频峰也让判断失准，所以不往上调。
  • 音质 72（维持，锚点值）：中频很平直、低频延伸好；但 8.7 kHz 和 13.7 kHz 两个约 +5 dB 的窄峰加上 3.6 kHz 凹陷，平滑度一般。
  • 听歌适配 70（维持，锚点值）：舒适；5128 显示低频并不偏多，高频偏亮，听歌主要靠佩戴和下潜加分，齿音风险减分。曲线重校后分数没有变，但扣分原因改成"高频偏亮"，不再是"低频讨喜"。

证据与置信度

  • 置信度：高。证据等级：measured。两条 B&K 5128 曲线（RTINGS、Listener 平均）形状一致，oratory1990 GRAS 和另外 11 条其他台架曲线的高频偏亮结论也一致。
  • 曲线重校：分数不变（55 / 72 / 70，本款是锚点）。风格从"轻 V 型、低频略多"改为"低频中性、高频偏亮带双峰"（原因：按 5128 DF 换算到偏好口径）。
  • 证据缺口：
  • RTINGS 和 Listener 两条 5128 曲线都没有注明阻抗版本。
  • 32/80/250Ω 三版的差异只能从不同台架、不同样品的数据里看，混着个体差异和耳垫密封差异，无法定论。
