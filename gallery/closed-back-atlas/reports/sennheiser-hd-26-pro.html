频响与风格

  • 测量源：Earphones Archive squig.link（B&K 5128 HATS），左右声道原始数据，测量日期 2025-11：https://earphonesarchive.squig.link/headphones/ （数据文件 data/Sennheiser HD26 Pro L.txt / R.txt）。这里把左右声道取平均，用 fr_analyze.py 对照 5128 DF 目标分析，以 500–1000 Hz 对齐。这是单一样本；贴耳式耳机在 HATS 上的密封通常比真人好。
  • 低频：对照 5128 DF，20–60 Hz 高 +8.7 dB，60–200 Hz 高 +6.5 dB，在约 80 Hz 附近形成低频鼓包，150 Hz 以上回落。DF 目标本身不含低频抬升，折算到 Harman 类目标时，这大约是持平到略多。测量修正：原先主观共识认为“低频薄”，台架上并不薄。主观上觉得薄，更可能是贴耳垫在真人头上漏气造成的（推断）。
  • 中频：200–500 Hz 为 −0.3 dB，1–3 kHz 为 +1.6 dB，2–4 kHz 相对 1 kHz 高约 +8 至 +9 dB，大体跟随 DF 的耳道增益并略多。这与“中频清楚、人声靠前”的评测一致。
  • 高频：3–6 kHz 为 −1.6 dB，6–10 kHz 为 −0.4 dB，但约 8.5 kHz 有 +7.8 dB、约 11.7 kHz 有 +7.4 dB 的窄峰，有齿音和刺感风险。12 kHz 以上急剧衰减，10–20 kHz 平均 −14.4 dB，15 kHz 相对 1 kHz 约为 −21 dB，与标称上限 18 kHz 一致。
  • 左右一致性：20 Hz–10 kHz 的平均差不超过 0.8 dB（最大 1.9 dB），一致性良好。10 kHz 以上最大差到 13 dB，属于高频定位差异，也可能是台架摆放造成的。
  • 风格：按对照 5128 DF 的倾斜（tilt −13.1 dB）判为暖向、低频量足。中频和上中频跟随目标，没有空气感，中高频有两个窄峰。这不是“偏中频的平淡”：人声清楚，但低频量感足，而且高频有窄峰。

技术素质

  • 解析：细节清楚但不刻意放大（Audio46 称其"detailed but not too revealing"，1/2 明确）。
  • 分离：单个音符分得开（1/2）。
  • 声场：贴耳封闭，预期较窄（prior，没有评测给出明确描述）。
  • 动态/瞬态：低频冲击弱（2/2）；ActiveGard 开启时会压缩大信号（厂商说明）。

佩戴与做工

塑料为主，模块化、易更换零件，耐用（consensus）。重量轻，耳垫软（厂商）；但贴耳式长时间佩戴有压耳问题，评测提示需要先接受贴耳设计（Audio46）。

用途适配

  • 挑错/监听：中频清楚，适合对白、人声和广播内容的判断；低频和高频信息不足，不适合完整混音。
  • 听歌：台架上低频不薄，但实际量感取决于贴耳密封；高频没有空气感，娱乐性一般。
  • 推力：100 Ω、105 dB/mW，手机可以推响，但音量余量不大；专业调音台或耳放更合适。

评分

  • 挑错度 58（原 68，测量修正）：上中频贴近 DF，8.5 和 11.7 kHz 的窄峰会让齿音显出来，保留一定挑错力。但台架上的低频量足，10 kHz 以上大幅衰减，整体偏暖，所以不如原先判断的那样挑错。
  • 音质 64（原 66）：左右一致性良好。但高频延伸差（12 kHz 以上急剧衰减），高频有两个 7 dB 以上的窄峰，平滑度一般。Earphones Archive 给的评级为 C。
  • 听歌适配 55（原 52）：台架显示低频不薄，人声清楚。但贴耳佩戴、高频没有空气感且有窄峰，仍以工作场景为主。
