频响与风格

  • 测量源：Sonarworks Reference 4 校准档 "SIH2 Wired Average"（私有台架、多样机平均、相对 Sonarworks 目标的偏差，仅图片；evidence: measured-image）。AutoEq、squig 系列、RTINGS、ASR 都没有数据。
  • 低频（measured-image）：约 100 Hz 有 +4～5 dB 的鼓包，50 Hz 以下滚降很快，20 Hz 约 −12 dB。这与 headphonecheck"100 Hz 处克制、缺超低频"的说法一致：底鼓有冲击，但没有下潜。
  • 中频（measured-image）：300 Hz–1 kHz 略低于目标，1.2 kHz 有小凸起，2.5–4 kHz 有约 −3 dB 的凹陷。人声不算靠前，整体不刺耳。
  • 高频（measured-image）：5–7 kHz 有约 +10 dB 的窄峰，是这条曲线最大的偏差，镲片和齿音会被突出，久听容易累（Reddit 上有用户说 12 小时录音"exhausting"）。10 kHz 以上骤降，空气感不足，这正是 headphonecheck 所说"10 kHz 以上收敛"和 Gearspace"偏暗"的来源。
  • 风格：低频鼓包、超低频不足，5–7 kHz 有尖峰，10 kHz 以上骤降，是一条起伏较大的"实用监听"曲线。深挖重校：之前"整体偏暗、平淡"的印象要修正，中高频其实有明显的亮点。
  • 说明：Sonarworks 的补偿目标和台架都不公开，6 kHz 附近的峰值有一部分可能来自台架与耳道的相互作用，所以幅度只作参考，形状可信度中等。

技术素质

解析、声场、分离、动态这几项，没有可靠评测做过细分描述，证据不足。headphonecheck 的定位是"不是 Hi-Fi，但很难挑毛病"，总评 3.9/5（1/1 评测）。

佩戴与做工

  • 重 309 g（不含线），平均夹力 1164 g，偏大（headphonecheck 实测）。
  • 耳垫是塑料皮材质，长时间戴容易出汗。夹力大是换取隔音的代价。

用途适配

适合鼓手练习、录音棚跟拍返听，以及在嘈杂环境里保护听力。不适合混音判断，也不适合长时间听歌。32 Ω、约 102 dB/mW，手机就能推响。

评分

深挖重校（依据 Sonarworks 平均频响图）： - 挑错度 40→48（深挖重校：40→48；原因：图上 5–7 kHz 有约 +10 dB 峰，镲片、齿音、瞬态细节会被放大，比"高频收敛"的旧判断更偏挑错；但 10 kHz 以上骤降、低频有鼓包，达不到 DT770 那种水平）。 - 音质 48→44（深挖重校：48→44；原因：曲线起伏大，有 5–7 kHz 窄峰、2.5–4 kHz 凹陷和 10 kHz 以上的深谷，超低频也不足，比 HD280（≈58）差一截；headphonecheck 的"干净"评价仍然成立，所以没有再往下压）。 - 听歌适配 42→38（深挖重校：42→38；原因：高频尖峰加超低频缺失，再加上夹力大、闷汗，长时间听歌容易疲劳）。
