Ultrasone Pro 480i

频响与风格

  • 测量结论（B&K 5128，measured）：以 500–1 kHz 对齐 5128 DF 后，偏差如下：20–60 Hz +5.1 dB，60–200 Hz +8.2 dB，200–500 Hz +3.2 dB，1–3 kHz −0.9 dB，3–6 kHz −2.9 dB，6–10 kHz −2.6 dB，10–20 kHz −3.4 dB；整体倾斜 −9.6 dB，属于暖向。
  • 换算成偏好口径（偏好中性的头戴一般低频比 DF 高 4–6 dB、高频略低于 DF）：超低频基本到位；中低频比偏好中性还多约 2–4 dB，是一个明显的中低频鼓包，下中频也略微偏厚；中频中性；高频整体略暗，但并不平滑。5.7 kHz 附近有约 +8 dB 的窄峰（有齿音风险），4.2 kHz 和 6.4 kHz 有凹陷，所以高频呈锯齿状，听起来会是"整体偏暗、个别地方刺"。
  • 声道一致性：左声道在 4.2 kHz 有一个深陷（比右声道低约 11 dB），5–8 kHz 两声道也相差 3–6 dB。这可能来自单体差异或佩戴位置，只有这一个样本，无法区分。
  • 与评测共识的矛盾：Major HiFi 描述它"中性偏冷、分析向、低频收着"，5128 曲线却显示中低频偏多、高频偏暗的暖调。按规则以 5128 为准。musicngear 汇总的用户评价"低频扎实、略暖"与测量一致。Earphones Archive 给这款的评级是 D+。
  • 榜单倾向值 5/10 与测量不符，测量更接近偏暖/偏娱乐的一侧。

技术素质

  • 解析与分离：细节，尤其是混响尾音，交代清楚，分离好（consensus 1/1）。
  • 声场：封闭式本身比较局促，但 S-Logic 偏置单元让声音有一点"像音箱在外面"的感觉（consensus 1/1；这是主观印象，不等于测量结论）。
  • 动态、瞬态：证据不足。

佩戴与做工

塑料机身轻而结实，但头梁偏硬、耳罩僵硬，舒适度差（consensus 1/1），附件比较简单。

用途适配

  • 可以用于录音跟踪和入门级监听，但低频偏多，不适合用来判断混音里的低频量；32 Ω 的负载手机就能带，但灵敏度单位不明，推力结论只是估计。
  • 暖调对听歌比较友好，但长时间佩戴不舒服，5.7 kHz 的峰也可能带来齿音。

评分

  • 挑错度 42（曲线重校：58→42）。原因：5128 曲线显示中低频鼓包、高频整体偏暗，并不是分析向；5.7 kHz 的窄峰会让齿音显得突出，所以没有再往下压。
  • 音质 50（曲线重校：56→50）。原因：中低频有溢出，高频呈锯齿状，左右声道在 4–8 kHz 不一致；分离感的正面评价仍参考了主观评测。
  • 听歌适配 54（曲线重校：50→54）。原因：暖调、低频扎实，比原先设想的冷调更适合日常听歌；但 5.7 kHz 峰和佩戴差仍然扣分。
