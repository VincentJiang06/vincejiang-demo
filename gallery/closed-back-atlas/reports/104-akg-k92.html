AKG K92

实测低频和中低频偏厚、1-5 kHz 大幅凹陷的暖闷型入门封闭耳机，佩戴舒适，但解析和人声清晰度不足。 Measured as warm and thick with a deep 1–5 kHz recession; very comfortable, but short on clarity and detail.

主要打分依据：oratory1990 的 GRAS 43AG-7 曲线，对比 Harman OE 2018。

频响与风格（measured，GRAS 43AG-7）

  • 测量源：oratory1990 的原始曲线，台架 GRAS 43AG-7。本轮用 fr_analyze 重新对比 Harman OE 2018，各频段结果如下：
频段 相对 Harman OE 2018
20–60 Hz +2.1 dB
60–200 Hz +3.1 dB
200–500 Hz +3.7 dB
500 Hz–1 kHz 0（对齐基准）
1–3 kHz −10.1 dB
3–6 kHz −5.0 dB
6–10 kHz +1.1 dB
10–20 kHz −2.7 dB
  • 上一轮的表格来自 AutoEq 的 error_smoothed，频段划分和对齐方式不同，数值有出入，但结论一致：中低频偏厚，1–5 kHz 大幅缺失。
  • 高频细节：约 6.8 kHz 有 +6.8 dB 的峰，约 8.5 kHz 有 +4.7 dB 的峰，约 9.8 kHz 和 11.7 kHz 各有一个凹陷。
  • 风格：暖、闷，presence 大幅缺失。fr_analyze 判定为“暖声”，倾斜 −4.8 dB。
  • 与评测的分歧（以测量为准）：
  • SoundGuys 说低频不足，与 oratory1990 的数据相反。
  • SoundGuys 描述的 1–4 kHz 凹陷与测量一致。
  • headphonecheck 说高频暗淡，也与测量相符。
  • 没有 5128 数据，不能按 5128 DF 复核。

技术素质（评测共识，3 份）

  • 解析和细节偏弱（2/3），人声和语音清晰度差（SoundGuys）。
  • 声像宽（headphonecheck，1/3 份）。
  • 动态、瞬态：证据不足。

佩戴与做工

自适应头梁加大耳罩、分量轻，舒适度好（3/3 份评测）。耳垫偏硬、不透气（Headphonesty）。全塑料机身，线不可拆。

用途适配

不适合挑错或混音：presence 缺了约 8 dB，失真和人声细节都会被掩盖。听歌方面，温暖、不刺耳，长时间佩戴舒适，但声音偏闷。113 dB/V、32 Ω，手机轻松推动。

评分

本轮曲线重校后分数不变：没有新的 5128 数据，主依据仍是同一条 GRAS 曲线，重新分析的结论与上一轮一致。

  • 挑错度 28：低频和中低频加量，2-5 kHz 大幅缺失，整体偏暖闷，不暴露瑕疵；6-8 kHz 的小峰略拉高一点分数。
  • 音质 50：中高频凹陷很深，频响不平滑，解析不足。
  • 听歌适配 58：佩戴舒适、不刺耳，但闷、人声不清晰。

证据与置信度

  • 证据等级：measured。置信度：high。依据是 oratory1990 的 GRAS 43AG-7 原始曲线，另有 3 份评测在中高频凹陷上与测量一致。
  • 缺少 5128 数据。Crinacle GRAS 和 ish.squig.link 的数值数据都无法下载，因此没有第二条原始曲线用于交叉核对。
