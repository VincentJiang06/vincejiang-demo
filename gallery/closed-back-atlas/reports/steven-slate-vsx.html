频响与风格

测量源：oratory1990 实测（经 AutoEq 收录，条目名 "Steven Slate Audio VSX (passive plugin inactive)"，即不开 VSX 软件的裸耳机状态）。CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/Steven%20Slate%20Audio%20VSX%20(passive%20plugin%20inactive))/Steven%20Slate%20Audio%20VSX%20(passive%20plugin%20inactive)).csv 。台架：GRAS 45BC KEMAR 类耳罩耦合台（oratory1990 的常用台架）。目标曲线：Harman Over-Ear 2018，以 500 Hz–1 kHz 对齐，用 fr_analyze.py 按频段平均计算。 - 低频：20–60 Hz 比 Harman 少约 5 dB，60–200 Hz 基本持平（+0.3 dB）。也就是说，中低频不缺，缺的是极低频的下潜和量感，与 SOS、headphonecheck 说的"偏瘦"一致（measured）。 - 中频：200–500 Hz 少约 1.7 dB；2–5 kHz 对照 AutoEq 目标列平均少约 2.8 dB，属于轻度凹陷，与"略带鼻音"的主观描述吻合（measured）。 - 高频：5–10 kHz 比 Harman 少 6–7 dB，最深的凹陷在 6.6 kHz 附近（相对目标约 -7.7 dB）；11 kHz 附近有一个小凹，13 kHz 附近有一个约 +4 dB 的窄峰。整体是暗声、偏暖的倾斜（measured）。 - 测量修正：原报告写"原始调音近中性"，这个说法不准确。测量显示，裸耳机在 5–10 kHz 明显偏暗，极低频也不足，所以它不会放大瑕疵。SOS 实测，打开 Systemwide EQ 后曲线明显变平，这也说明它的原始曲线本来就是为配合软件校正而设计的。

技术素质

  • 解析：不开软件时中频人声和原声乐器清楚（headphonecheck，1/2 评测提到）。
  • 声场：纵深有限，是封闭式的常见水平（1/2 评测提到）。开 VSX 房间模拟后空间感大幅提升，但这是软件做出来的效果，不算耳机本身的素质（consensus 2/2）。
  • 分离：headphonecheck 说频段和声道分离都不错（1/2 评测提到）。
  • 动态、瞬态：官方宣传铍振膜能减少拖尾，但这属于营销说法，没有评测佐证 → 证据不足。
  • headphonecheck 明确表示，单看硬件，它排不到 HD 660 S、NDH 30 那一档。

佩戴与做工

重量轻，长时间佩戴舒适。人造皮耳罩在天热时容易闷汗。椭圆耳罩尺寸宽裕，夹力中等（consensus 2/2）。外壳用铝合金，头梁是不锈钢（官方）。

用途适配

  • 混音：核心用途是用软件模拟录音棚、汽车、夜店等环境来检查混音。要用好它，使用者需要花时间学习和适应（consensus）。
  • 挑错：原始调音不追求放大瑕疵，属于中等挑错。
  • 听歌：单独听只算合格，而且需要装系统级 EQ 才能达到较好状态，不适合即插即用。
  • 推力：约 38Ω，手机或普通声卡大多推得动。灵敏度单位不明，这一点是先验判断。

评分

  • 挑错度 40（测量修正，原为 55）：oratory1990 的曲线显示，2–5 kHz 轻度凹陷，5–10 kHz 比 Harman 少 6–7 dB，高频收得很紧，不会主动暴露瑕疵。不过它的低频也不算饱满，所以分数没有压到"讨喜"那一档。
  • 音质 64（原为 66）：6.6 kHz 附近的深凹和 13 kHz 附近的窄峰让曲线不够平滑，不开软件时属于中游水平。开 EQ 后明显提升，但这里只给耳机本体打分。
  • 听歌适配 56（原为 58）：佩戴舒适，但声音偏暗、极低频不足、带点鼻音，想好听得靠软件或 EQ。
  • 曲线重校（2026-09-17）：三项分数都不变。本轮没有找到 5128 或其他新的数值曲线，重新用 GRAS 台架复算的频段偏差与上一轮一致（相对 Harman：20–60 Hz -5.2、60–200 Hz +0.3、3–6 kHz -6.3、6–10 kHz -7.1 dB）。
