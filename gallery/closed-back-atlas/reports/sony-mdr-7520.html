频响与风格

  • 测量源：见上一节。两条都是 HMS II.3 台架，Harman OE 2018 目标原本是按 GRAS 台架定义的，所以 5 kHz 以上的残差只能看趋势，不能逐 dB 解读。
  • 目标曲线：Harman over-ear 2018。用 fr_analyze.py 对齐 500–1k Hz 后计算各频段偏差。
  • 低频：60–200 Hz 比目标高约 +4.7 dB（RTINGS）/ +5.4 dB（Innerfidelity），属于偏多。20–60 Hz 与目标持平（RTINGS）或略少约 -2.7 dB（Innerfidelity）。这说明低频量感来自中低频鼓包，而不是超低频延伸。测量与主观共识"低频饱满"一致。
  • 中频：200 Hz–1 kHz 贴近目标。1–3 kHz 高约 +3 到 +3.7 dB，其中 2.1–3 kHz 区段高约 +4 到 +5 dB。
  • 高频：两条测量都显示约 3.9–5 kHz 有深凹陷，残差约 -8 到 -10 dB。8.4–9.8 kHz 有窄峰，残差约 +11 到 +12 dB；13–14 kHz 又有一处凹陷。整段 6–10 kHz 的均值，RTINGS 为 +5.3 dB，Innerfidelity 为 +1.0 dB，两者有差异。
  • 风格（测量修正）：更准确地说，是"中低频鼓包 + 上中频抬升 + 4–5k 凹陷 + 9k 附近尖峰"的起伏型曲线。低频偏暖；2–3k 的抬升和 8–10k 的尖峰会让人声边缘和齿音显得突出，所以细节听起来比实际更"多"。原稿写"高频不刺"与测量不完全相符：9k 附近的窄峰对齿音敏感的人来说可能偏刺。
  • 来源矛盾（曲线重校新增）：DIY-Audio-Heaven 的测量图和文字（只有图）同样显示 100 Hz 附近低频抬升和约 4 kHz 的宽深凹陷，这与两条 HMS 曲线一致；但作者说 5 kHz 以上整体略低，11 kHz 以上逐渐滚降，听感是"高频柔和、缺细节和空气感、不刺"，还认为它不适合混音。HMS II.3 的 8–10 kHz 窄峰没有在他的描述里出现。HMS 耳廓和其他台架在 8–10 kHz 本来就容易有差异，所以"9k 窄峰"应视为台架相关、证据不足的特征：4k 凹陷和中低频鼓包是可靠的，高频到底偏亮还是偏柔，暂无定论。
  • DIY-Audio-Heaven 实测阻抗约 23 Ω，效率约 103 dB/mW（119 dB/V），比官方标称 108 dB/mW 低，但仍然很好推。

技术素质（评测共识，非测量）

  • 解析：细节多，SOS 说细节多到"有点压迫" —— consensus 2/2（SOS、MusicRadar）。
  • 分离/定位：分离优秀，声像受控、精准 —— consensus 2/2。
  • 瞬态：全频段快而紧 —— consensus 1/2（SOS）。
  • 动态：MusicRadar 称力度惊人 —— consensus 1/2。
  • 声场：封闭式常见的"箱体感"，不算宽 —— consensus 1/2（SOS）。

佩戴与做工

镁合金外壳，重量轻，佩戴舒适、不夹头 —— consensus 2/2。缺点是卷线较笨重，而且已停产，耳垫等配件越来越难找 —— prior。

用途适配

  • 混音/审听：SOS 作者直接拿它做主力混音，认为混音拿到其他系统上表现一致；由于低频量感偏多，判断低频时要心里有数。
  • 听歌：低频饱满、细节丰富，适合流行和电子；细节密度高，长时间听可能疲劳。
  • 推力：24 Ω / 108 dB/mW，手机即可推响 —— prior（规格推断）。

评分

  • 挑错度 58（曲线重校：60→58，原因：DIY-Audio-Heaven 的测量和听感描述认为高频偏柔、清晰度不足，与 HMS 曲线上的 9k 窄峰相矛盾；没有 5128 或 GRAS 数据能裁决，所以只小幅下调）。依据仍然是 HMS 曲线：60–200 Hz 高约 +5 dB，偏向讨喜；2–3k 高约 +3–4 dB，可以带出人声边缘；4k 附近有深凹陷，会把一部分齿音和细节藏起来。挑错度介于 DT 770 和 MDR-M1 之间偏上，不如 7506 或 M70x。
  • 音质 74（不变）：共识里解析、分离、力度都强，但三条来源都显示 4k 深凹陷，HMS 曲线另有 9k 尖峰和 13–14k 凹陷，曲线起伏大，平滑度一般；DIY-Audio-Heaven 对高频质量评价偏低，这一项已经算在内。
  • 听歌适配 72（不变）：低频讨喜、佩戴轻、容易推；高频是偏刺还是偏柔，不同来源说法不一，而且已停产，配件难找。
