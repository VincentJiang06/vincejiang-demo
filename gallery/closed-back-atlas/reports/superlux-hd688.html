频响与风格

  • 测量源：DIY-Audio-Heaven（https://diyaudioheaven.wordpress.com/measurements/brand-superlux/hd688/）。台架是自制平板台架（flatbed），不是 IEC711 或 GRAS，也没有对应的标准目标曲线，所以只能截图读图 / 作者文字做定性判断，不给具体 dB 数值。
  • AutoEq（oratory1990 / crinacle / Rtings / Innerfidelity 等）里只有同厂的 HD668B、HD662F 等型号，没有 HD688。
  • 定性结论（measured，定性），参照标准是"中性"：
  • 超低频滚降；40 Hz 到 1.3 kHz 大致中性
  • 1.3-5 kHz 有明显凹陷（作者推测是为了压 4k 的共振）
  • 高频量明显偏多，有齿音风险；CSD 图上 4k 有短暂振铃，7k 附近的共振更明显
  • 风格：偏亮、偏薄（bright / lean）。刚听觉得"细节多"，但凹陷加上高频抬升，久听容易疲劳。
  • 用户评测（musicngear）说它"平直、清晰"，与测量方向部分一致，但忽略了高频偏多的问题。

技术素质

  • 解析：初听清晰（consensus 2/2），但 DIY-Audio-Heaven 认为 3k 凹陷让细微层次变少。
  • 声场：有用户评价"声场出色"（1 条，自评类，可信度低），证据不足。
  • 失真：低频失真属于价位正常水平，4k 以上干净（measured）。
  • 动态和瞬态：证据不足。

佩戴与做工

轻；初戴夹得很紧，可以掰松；头梁调节范围小，大头围的人戴着难受。可拆线的接头耐用性差，线材有摩擦噪声（consensus 2/2）。

用途适配

  • 挑错：高频亮，对齿音和嘶声敏感，有一定挑错能力；但 1.3-5k 凹陷，判断人声、中频不可靠。
  • 听歌：偏薄、偏亮，喜欢暖声的人不太合适。
  • 推力：好推，手机直推就行。

评分

  • 挑错度 65：高频抬升、有尖峰，低频偏少，属于偏挑错的方向；presence 段凹陷，所以没有给更高。
  • 音质 55：有凹陷和 7k 共振，失真属价位正常水平。
  • 听歌适配 50：偏亮、易累，佩戴也因人而异。
