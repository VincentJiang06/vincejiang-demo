频响与风格

  • 测量源 1（measured）：RTINGS，HMS II.3 头模，AutoEq 数据 results/Rtings/HMS II.3 over-ear/Shure SRH240。注意：这组数据标的型号是 SRH240，不是 240A，两者是否同一声学设计未经核实。我用 fr_analyze.py 对比 harman_oe_2018，与 Harman OE 2018 的偏差：超低频（20–60 Hz）约 −12.8 dB，中低频（60–200 Hz）约 −4.6 dB，低中频约 −3.6 dB。500 Hz–1 kHz 比目标高约 2 dB；3 kHz 附近接近目标；4–6 kHz 低约 3–4 dB。
  • 测量源 2（measured，只有 EQ 参数，拿不到 raw CSV）：Crinacle，GRAS 43AG-7，AutoEq 目录 results/crinacle/GRAS 43AG-7 over-ear/Shure SRH240A。按 Harman 目标生成的 EQ 包含：105 Hz 低架 +7.2 dB（74 Hz 处同时 −5.7 dB）、3.4 kHz +4.2 dB、1.3 kHz −2.1 dB。由此可以推断低频和 3–4 kHz 都低于目标，1 kHz 一带偏多，与 RTINGS 的结论方向一致（属于推断，不是读原始曲线）。
  • 测量源 3：DIY-Audio-Heaven 平板台架。低频可延伸到 30 Hz（该台架带低频修正），2 kHz 以上有凹陷，10 kHz 附近有峰，听感偏刺。
  • 测量源 4（新增，佐证）：Headphone.com Legacy，HMS II.3，型号同为 SRH240。跑 fr_analyze（对比 harman_oe_2018）的结果：超低频约 −21.6 dB，中低频约 −10.7 dB，低中频约 −4.2 dB，1–3 kHz 约 −1.6 dB；6.7 kHz 有深谷，10.3 kHz 有约 +11 dB 的峰。它和 RTINGS 方向一致，但低频缺得更多。这更可能是佩戴密封的差别，而不是版本差异，所以以 RTINGS 为主。RTINGS 曲线在 8.6 kHz 和 10.8 kHz 有小峰（+3.6 dB / +6.5 dB），14 kHz 有凹陷，工具给出的标签是“暗声、整体向亮倾斜”（低频缺得多）。
  • 结论：低频偏少，中频（约 1 kHz）靠前，presence 偏暗，10 kHz 附近有一个峰。这不是亮而挑错的调音，而是带点喊叫感、结像略显粗糙的中频型声音。

技术素质

可用评测只有 DAH 一篇（1/1）：中频不够清晰，质感粗、偏喊，高频质量差，立体声结像窄。其他技术素质属于证据不足，价位先验也是一般。

佩戴与做工

重量轻、夹力小。但耳罩浅（约 14 mm），耳廓容易碰到挡板，海绵偏硬，密封不容易做好（consensus 1/1）。机身为塑料，线材不可拆（prior）。

用途适配

38 Ω、107 dB/mW，手机就能轻松推动。能用来粗略监听和陪听。低频缺量、密封又依赖佩戴，所以不适合混音时判断低频；中频偏喊、高频粗糙，也不适合长时间听歌。
