  • fr_analyze（harman_oe_2018，按 GRAS 近似处理）的结果：
  • 中低频 +5.5 dB，低中频 +2.9 dB，中频 0 dB。
  • 高中频 −6.3 dB，低高频 −10.9 dB。
  • 签名为"低频猛"，倾斜 −7.4 dB（暖向）。
  • 4.4 kHz 有凹陷，6.7 kHz 有 +6.5 dB 尖峰（有齿音风险），8.8 kHz 有凹陷。
  • 与主观共识对照：headphonecheck 说低频主导、中频偏收、高频偏弱，测量证实了这一点（measured）。allthingsgear 说"意外地平直"，测量不支持。
  • 综合判断：中低频鼓包约 +5~8 dB，2–5 kHz 明显凹陷，属于暖、讨喜的调音。高频不平整，4 kHz 凹陷，紧接着 7 kHz 出现尖峰。
  • 深挖重校：风格方向不变，由 consensus 升级为 measured。

技术素质

  • 解析：一般，缺少高频细节（1/2，headphonecheck）。
  • 声场、分离、动态：证据不足。
  • 失真：没有取到 THD 数据，证据不足。
  • 左右一致性：灵敏度左右相差约 1.6 dB/V（RAA 实测）。这个差值偏大，属于廉价单元的正常水平（measured）。

佩戴与做工

  • 重量轻，夹力适中，长时间佩戴舒适（2/2 共识）。
  • 全塑料机身，线材不可拆（allthingsgear 指出线材不可拆是短板）。

用途适配

  • 混音、挑错：不推荐。低频偏多、高频偏暗，容易掩盖问题。
  • 听歌：适合嘻哈、R&B、流行和游戏，也适合当入门陪听耳机。
  • 推力需求：极低。

评分

  • 挑错度 30：中低频鼓包、存在感频段凹陷，细节容易被掩盖（measured）。
  • 音质 50：深挖重校，旧 52 → 新 50。原因是测量显示 4 kHz 凹陷约 −12 dB（相对 RAA 目标），紧接着 7 kHz 有尖峰，高频不平整；左右灵敏度差约 1.6 dB。
  • 听歌适配 62：暖调讨喜、佩戴舒适，但 7 kHz 尖峰可能带来少量齿音，分数不变。
