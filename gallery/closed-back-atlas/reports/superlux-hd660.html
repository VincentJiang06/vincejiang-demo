频响与风格（measured）

  • 测量源：oratory1990 测量，数据取自 AutoEq 收录的文件：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Superlux%20HD%20660
  • 台架：GRAS 43AG（oratory1990 的耳罩式台架）。目标曲线：Harman OE 2018。用 fr_analyze.py 分析 raw 曲线，以中频为对齐基准。分析脚本默认台架写的是 45CA，所以报了台架不匹配的警告；实际是 43AG 测量对 43AG 目标，这条警告可以不管。
  • 低频：20-60 Hz 比目标低 1.6 dB，60-200 Hz 低 1.2 dB。量感中性偏少，不算轰头。
  • 中频：200 Hz-2 kHz 与目标相差不到 ±1 dB，属于中性；2-4 kHz 高 1.6 dB，略多。3.9 kHz 附近有一个约 -6 dB 的凹陷。
  • 高频：6-10 kHz 平均高 6.9 dB，6.8 kHz 有 +6 dB 尖峰，有齿音风险；10.3 kHz 附近是凹陷；13 kHz 有 +6 dB 毛刺；10 kHz 以上整体高 3.7 dB。
  • 对照 HD660 Pro 150 Ω（oratory1990，同台架）：低频高 2.2 dB，6-10 kHz 只高 2.2 dB，tilt 0 dB，脚本判为均衡；6.4 kHz 仍有 +6.4 dB 峰，9.4 kHz 有 -7.7 dB 深谷。Pro 版明显更暖，不能拿它的听感评价套到原版上。
  • 结论：脚本判为"明亮 / 亮向"（tilt +4.7 dB）。榜单写的是"DT 770 外观"、倾向 6.0，实测比这个数更亮。

技术素质（consensus，可用评测少）

  • Audiophile ON 认为低频受控、不浑，中频扎实，高频偶尔过亮，封闭腔体的空间感比预期好。
  • Frieve、headphonecheck 测的是另一款 HD660 Pro，只能参考同一家族的倾向：高频峰谷超出 ±3 dB，高频显得粗糙。
  • 解析和分离只算入门水平。动态和瞬态没有找到可靠评述，这两项证据不足。Head-Fi 页面被验证墙挡住，没能读取。

佩戴与做工

塑料为主，有少量金属件，做工一般（评测 6.5/10）。夹力偏紧，久戴闷热（舒适 7.5/10）。耳垫可以换成 Beyerdynamic 的耳垫。属于 consensus，只有 1 篇评测，样本很少。

用途适配

  • 录音陪听或监听：隔音好、漏音少，7 kHz 附近的抬升容易暴露齿音和嘶声，适合用来挑错。
  • 日常听歌：高频偏刺，低频偏少，需要 EQ。AutoEq 给出的主要修正是 3.7 kHz +7 dB、7 kHz -6.8 dB。
  • 推力：150 Ω，推算约 104 dB/V。手机能推响，但余量一般，接声卡或小耳放更稳。

评分

曲线重校：没有找到 5128 数据，打分依据仍是 oratory1990 的原版曲线，三项分数维持原值（70 / 55 / 50）。

  • 挑错度 70：实测 6-10 kHz 高 6.9 dB 且有尖峰，低频略少，挑错倾向接近 Hi-X60，但峰值更粗糙。
  • 音质 55：高频峰谷明显，平滑度不佳；中频基本准，符合 45 美元的定位。
  • 听歌适配 50：偏亮、偏刺，夹得紧，听歌不算友好。

证据与置信度

  • 置信度：medium。频响有 oratory1990 的原版实测，但只有这一条原始数值曲线，没有 5128 或第二台架的交叉验证。技术素质只有 1 篇可读的评测，另有同家族型号的测量作参考。
