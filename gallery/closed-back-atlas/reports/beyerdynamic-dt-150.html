频响与风格

  • 测量源：AutoEq 收录的 Innerfidelity 数据 — https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Beyerdynamic%20DT%20150%20(250%20Ohm)（台架：Innerfidelity HATS，Head Acoustics 类仿真头，非 GRAS 43AG/5128）；另有 ASR（GRAS 45CA）、DIY-Audio-Heaven、RAA 曲线作交叉印证。
  • 目标曲线：Harman OE 2018（本地 fr_analyze.py，中频 500–1k 对齐）；同时参考 AutoEq 自带的 Innerfidelity 补偿 Harman 目标误差列。脚本提示台架/目标不完全匹配，dB 值作量级参考。
  • 分段偏差（fr_analyze）：20–60 Hz −2.0 dB（略少）；60–200 Hz +3.0 dB（略多）；200–500 Hz +0.9；500 Hz–3 kHz ≈0；3–6 kHz 0.0；6–10 kHz −2.3（略少）；10–20 kHz +4.1（偏多，含 16.7 kHz 约 −7 dB 凹陷）。AutoEq 误差列同向：60–200 Hz +1.9、5–10 kHz −1.5、10–16 kHz +2.4。
  • 关键特征：约 9.5 kHz 尖峰（残差约 +7 dB），两侧 6.6 kHz（约 −5.7）与 7.8–8 kHz（约 −4.5）凹陷 → 高频"锯齿状"，与 ASR / DIY-AH 结论一致。
  • 测量修正：Innerfidelity 数据下整体并不算"暗"——存在感区(2–5k)贴合目标，平均倾斜近中性；主要问题是中低频略鼓 + 高频峰谷交错。原装皮垫下 DIY-AH 所说"偏暗"更多来自 6–8 kHz 凹陷。量感：低 略多（超低略少）、中 平、高 不平（凹陷 + 9.5k 尖峰）。
  • 换 EDT 100T 丝绒耳垫后线性明显改善（DIY-AH 测量 + ASR 讨论区共识）。

技术素质

  • 分离/解析：复杂段落"糊"、分离与细腻度不足（DIY-AH）；ASR 称 EQ 能救音色但空间感无改善（2/2 一致偏负面）。
  • 声场：普通偏窄（prior + ASR 间接）。
  • 动态：低频冲击力足（DIY-AH，1/2）。
  • 失真：主要集中在低频，EQ 压低频可同时改善（ASR, measured）。

佩戴与做工

  • 做工：以极耐用、零件可替换著称（榜单先验 + 20 余年广播/录音场景口碑）。
  • 佩戴：ASR 称轻、舒适；DIY-AH 称夹力大、原装皮垫偏硬——存在分歧，可能与头型/新旧有关。

用途适配

  • 混音/挑错：不推荐（DIY-AH、Head-Fi 用户、ASR 均认为更适合跟踪录音/监听而非混音）。
  • 听歌：原装调音偏暗、低频多，素质一般；ASR 不推荐。
  • 推力：250 Ω、约 96–97 dB/mW，手机直推偏吃力，建议有电压余量的耳放/声卡（ASR、DIY-AH 共识）。

评分

  • 挑错度 46（测量修正，原 42）：中低频 +3 dB 偏厚、6–8k 凹陷压低细节，但 2–6k 贴合目标且 9.5k 有尖峰会放大齿音，故介于 M50x 与 K371 之间偏上。
  • 音质 58：测量偏差大、分离糊，但低频延伸与冲击尚可，约 HD 280 Pro 水平。
  • 听歌适配 55：暖厚低频有一定讨喜度，但高频假、分离弱、推力要求高、佩戴有争议。
