频响与风格

  • 测量源（主）：oratory1990 测量（GRAS 45BC KEMAR 类耳罩台架），AutoEq 数据 https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Audio-Technica%20ATH-M70x ；（辅）RTINGS 测量（HMS II.3 台架），https://github.com/jaakkopasanen/AutoEq/tree/master/results/Rtings/HMS%20II.3%20over-ear/Audio-Technica%20ATH-M70x 。Innerfidelity（HMS II.3）已补存并作佐证；crinacle 的 GRAS 数据在 graph.hangout.audio 上返回 403（付费受限），未取得。没有 5128 数据，按优先级以 GRAS 为准。
  • 分析方法：用 fr_analyze.py 对照 Harman over-ear 2018 目标，按 500–1000 Hz 对齐。
  • 分频段偏差（oratory1990 / RTINGS）：超低频 20–60 Hz -1.2 / -1.7 dB；中低频 60–200 Hz +1.4 / +1.4；低中频 200–500 Hz +2.1 / +2.4；中频 500–1k 0 / 0；中高频 1–3 kHz +2.5 / +3.6；低高频 3–6 kHz +4.2 / +5.6；中高频 6–10 kHz +2.5 / +6.8；空气感 10–20 kHz +2.3 / +5.5。整体倾斜 +2.9 / +6.1 dB，两份数据的分类都是"明亮"。
  • 关键特征：AutoEq 平滑误差显示，oratory1990 数据在约 5 kHz 处比目标高约 +2.3 dB，30 Hz 处低约 -3 dB；RTINGS 数据在 5 kHz、8 kHz 各约 +4.6 dB，8.65 kHz 有一个尖峰（残差约 +7.7 dB，有齿音风险），6.4 kHz、13.8 kHz 有凹陷。
  • Innerfidelity（HMS II.3，佐证）：1–6 kHz 同样偏多 +2.6~+2.8 dB，9–10.6 kHz 有 +7~+9 dB 的窄峰，6.7 kHz、13.8 kHz 有凹陷；整体倾斜只有 +0.8 dB（它的低频比另两份多，台架/耳垫泄漏差异所致）。三份数据都指向 1–10 kHz 偏多、8–10 kHz 附近有峰，但峰的位置和高度各不相同；按台架优先级，量级以 GRAS（oratory1990）为准，即 3–6 kHz 约 +4 dB、6–20 kHz 约 +2.5 dB，RTINGS 的 +5~+7 dB 偏高。
  • 风格结论：相对 Harman，低频没有目标要求的那么多（超低频略少），从 1 kHz 往上一路偏多，3–10 kHz 抬升最明显，所以是明亮、分析取向，和原判断一致。
  • 测量修正：原稿引用 TapeOp 的"900 Hz–3.6 kHz 约 -9 dB 挖空、10.5 kHz 约 +6 dB 峰"。这组数值很可能是相对平直线读的，没有考虑人耳/耳廓的增益；对照 Harman 时，oratory1990 和 RTINGS 都没有显示中频挖空（1–3 kHz 反而略多）。明亮感的主要来源应改为"3–10 kHz 整体抬升 + 约 5 kHz / 8–9 kHz 的峰"，不再使用"中频挖空"的说法。

技术素质

  • 解析：细节量高，属于同价位封闭耳机的上游（consensus 3/3，其中部分可能来自高频抬升）。
  • 声场与定位：MusicTech 认为左右定位清晰、包围感好（consensus 1 篇，置信度中低）。
  • 低频质量：干净、准确，比 M50x 更有控制力（consensus 2/2 + 失真测量）。
  • 动态、瞬态：证据不足。

佩戴与做工

TapeOp 和 MusicTech 都认为它比 M50x 更适合长时间佩戴（头梁更薄、贴合更好）。SoundGuys 提醒耳罩偏浅，大耳朵的人可能碰到单元。可换线。

用途适配

  • 挑错、审听：非常合适，高频和空间细节暴露得多。
  • 混音：要注意，3–10 kHz 偏多加高频峰会让人把人声推得过大、把高频压得过低，最好配合校正。
  • 听歌：高频容易疲劳，不算讨喜。
  • 推力：35 Ω、约 97 dB/mW，手机能推到一般音量，但余量不大。

评分

  • 挑错度 90（曲线重校：90→90，不变；无 5128，GRAS 结论与上一轮相同）：两份测量都显示 3–10 kHz 相对 Harman 抬升 4–7 dB，低频低于目标，是典型的放大瑕疵取向（与锚点一致）。
  • 音质 74（曲线重校：74→74，不变）：低频失真低、细节多、定位清楚；但高频有峰，而且不同测量之间差异较大（台架/样品不同），平滑度一般。
  • 听歌适配 48（曲线重校：48→48，不变）：高频疲劳是主要扣分项，低频量感也低于 Harman，舒适度还不错。
