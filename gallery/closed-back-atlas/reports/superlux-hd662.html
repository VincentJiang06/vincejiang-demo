频响与风格（proxy-measured，用同系列 HD662F 代替）

  • 测量源：没有找到原版 HD662 的测量。这里用 oratory1990 测的 HD662F（HD662 的可折叠版），数据取自 AutoEq：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Superlux%20HD%20662F
  • 台架：GRAS 45BC KEMAR。目标曲线：Harman OE 2018。用 fr_analyze.py 分析，以中频为对齐基准。脚本报的 45CA 台架不匹配警告可以不管，原因同 HD660。
  • 低频：20-60 Hz 比目标低 5.6 dB，偏少。60-200 Hz 低 1.1 dB，属于中性。
  • 中频：200 Hz-4 kHz 与目标相差不到 ±1.5 dB，属于中性。4.9 kHz 附近有一个 -4 dB 的小凹陷。
  • 高频：4-6 kHz 略少，但 5.75 kHz 有一个 +9.8 dB 的窄峰，是主要的齿音风险。11 kHz 附近凹陷 -9.4 dB，12.6 kHz 有 +7.8 dB 毛刺。
  • 结论：按频段平均，脚本判为"均衡"，tilt +2.5 dB，偏亮。但高频的窄峰和深谷明显，实际听感会比平均值更刺、更不平滑。
  • 换耳垫对照：同一台 HD662F 换 Brainwavz XL 皮耳垫后，20-60 Hz 回到中性（-0.1 dB），60-200 Hz 反而高 2.8 dB，5.75 kHz 的 +9.6 dB 峰仍在。说明原装耳垫的超低频缺口主要来自密封，低频量感对佩戴很敏感；高频峰来自单元或腔体，换垫去不掉。
  • 冲突：榜单的备注是"低频松"，EVO 版评测也说中低频有鼓包。这与 HD662F 实测的"超低频少、中低频中性"不一致。EVO 是改款，HD662F 也不等于原版，所以这一点记为未解决。换垫曲线显示密封一变中低频就会鼓起来，可能部分解释"低频松"的说法。

技术素质（consensus，样本主要是 EVO 或 F 版）

  • 评测多说声音近、高频有时毛躁，有轻微齿音。
  • 解析和分离属于入门水平。声场偏近。
  • 动态和瞬态没有找到针对原版的可靠评述，证据不足。

佩戴与做工

自适应头梁，重量轻，EVO 评测普遍觉得可以戴较久，但耳朵会被压到。Equipboard 汇总的用户反馈提到久戴闷热，头梁和耳垫材料会老化开裂。以上属于 consensus。

用途适配

  • 录音陪听：32 Ω、推算约 113 dB/V，手机或声卡都能轻松推。隔音中等。
  • 挑错：5.75 kHz 的窄峰会放大齿音，但低频下潜不足，判断低频不可靠。
  • 日常听歌：可以接受，但窄峰偏刺，适合用 EQ 压一下 5.7 kHz。

评分

曲线重校：本轮只多找到一条 HD662F 换垫曲线，结论不变，三项分数维持原值（58 / 50 / 55）。

  • 挑错度 58：频段平均接近中性，但低频缺量加上 5.75 kHz 的 +9.8 dB 尖峰，让它偏向挑错。
  • 音质 50：高频有深谷和尖峰，平滑度差，素质为入门级，与 HD662EVO 的锚点（60）相比略低。
  • 听歌适配 55：中频自然、好推、轻便，但高频偏刺，超低频不足。
