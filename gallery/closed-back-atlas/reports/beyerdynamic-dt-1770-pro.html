频响与风格

5128 曲线对照 5128 DF；其余台架的曲线以 Harman Over-Ear 2018（在 GRAS 45CA 上定义）为目标。两者都以 500 Hz–1 kHz 对齐，数值由 fr_analyze.py 算出。

MKII · B&K 5128（主依据）。以 5128 DF 为参考基线，以 500 Hz–1 kHz 对齐。解读前提：偏好中性的头戴，低频通常比 DF 高约 4–6 dB，高频略低于 DF。 - 绒布垫：20–60 Hz +8.1 dB，60–200 Hz +5.9 dB，200–500 Hz −1.9 dB（约 216 Hz 有 −5.8 dB 的凹陷），1–3 kHz −1.6 dB，3–6 kHz −1.5 dB，6–10 kHz +0.5 dB，10 kHz 以上 −2.5 dB，倾斜 −8.2 dB。工具判为"低频猛、暖向"。按偏好中性换算，超低频比偏好中性多约 2–4 dB，中低频大致处于偏好中性的上沿；中高频和高频整体大致在偏好中性附近，并不偏亮。约 7.0 kHz 有 −7.5 dB 的谷，紧接着约 7.9 kHz 有 +8.3 dB 的窄峰（齿音风险），15 kHz 附近另有 +5 dB 的小峰 —— measured（5128）。 - 皮垫：20–60 Hz +9.6 dB，60–200 Hz +5.2 dB，3–6 kHz −2.4 dB（约 4.4 kHz 有 −12 dB 的深谷），10 kHz 以上 −4.7 dB，倾斜 −9.7 dB，比绒布垫更暗、低频更多；约 7.9 kHz 的尖峰（+7.7 dB）依然存在 —— measured（5128，只有单声道）。 - 与其他台架的矛盾：GadgetryTech（KB006x）与 exound 对照 Harman OE 2018，给出的绒布垫低频只多 +2~3 dB、10 kHz 以上 +3 dB，属于"轻 V 型"。5128 的结果是低频更多、10 kHz 以上低于 DF，整体是暖向的低频型，而不是轻 V 型。以 5128 为准。 三个台架唯一一致的是 7–8 kHz 的谷峰结构（GadgetryTech 8.25 kHz +6.6 dB，5128 7.9 kHz +8.3 dB），所以这个尖峰可以确认是耳机本身的特性，不是台架共振。

MKII · 耳廓仿制件台架（佐证，原文保留）。测量源：GadgetryTech 的 squig 曲线库 https://gadgetrytech.squig.link/headsets/?share=beyerdynamic_DT_1770_Pro_MKII_(Velour_Pad) ，原始 L/R 文本已下载，取左右平均。台架：KB006x 耳廓仿制件（按该库 config 的 rig_description；耦合器没有注明，推测为 711 类，而非 GRAS），1/24 倍频程平滑。由于台架与目标不匹配，数值只作方向参考。 - 绒布垫：20–60 Hz +1.9 dB，60–200 Hz +2.2 dB（绝对值约 20 Hz 处 +6、100 Hz 处 +4 dB），约 200 Hz 有 −3.5 dB 的凹陷。1–3 kHz −0.6 dB，3–6 kHz −3.6 dB，6–10 kHz +0.3 dB，10 kHz 以上 +3.3 dB。约 7 kHz 有深谷（−7.9），约 8.2 kHz 有尖峰（+6.6，绝对值约 +9.5 dB），峰谷相邻、很尖锐 —— measured。 - 皮垫：60–200 Hz +5.6 dB，20–60 Hz +3.9 dB，低频明显更多；10 kHz 以上 +5.1 dB；8 kHz 附近同样有尖峰（+6.4） —— measured。换垫会改变调音，这与 SoundGuys 的结论一致。 - 左右一致性：100 Hz–5 kHz 平均左右差约 0.7 dB（绒布垫）和 1.1 dB（皮垫） —— measured。 - DIY-Audio-Heaven 的平面台架主观加测量（https://diyaudioheaven.wordpress.com/measurements/brands-a-i/dt-1770-pro-mkii/ ）：绒布垫低频明显抬升、略显膨胀，高频抬升且锐利，"并不中性" —— 与上面的曲线方向一致。 - 测量修正（上一轮）：上一版写的"MKII 高频比老款 Beyer 收敛"没有得到测量支持。MKII 仍然是低频抬升、200 Hz 凹陷、8 kHz 窄尖峰的轻 V 型 Beyer 调音，尖峰会放大齿音和镲片，挑错取向比上一版判断的更强。本轮 5128 修正：MKII 更准确的描述是"低频明显偏多的暖向调音，外加 8 kHz 的窄尖峰"，而不是"轻 V"。10 kHz 以上并不偏多。

初代（250 Ω，对照）。测量源：oratory1990（AutoEq）https://github.com/jaakkopasanen/AutoEq/tree/master/measurements/oratory1990/data/over-ear ，文件为 "Beyerdynamic DT 1770 (leatherette/velour earpads)"，台架为 GRAS 45BC KEMAR。另有 Rtings（HMS II.3，绒布垫）和 crinacle（graph.hangout.audio，"DT1770 Pro (Velour pads)"，仅确认已收录）。 - 皮垫：60–200 Hz +5.2 dB（约 100–150 Hz 绝对 +7 dB，即"中低频膨胀"），3–6 kHz −4.6 dB，约 4.4 kHz 有凹陷，约 8.4 kHz 峰 +3.7 dB、11 kHz 峰 +3.5 dB，15 kHz 以上滚降 —— measured，程度为"低频猛、偏暗"。 - 绒布垫：60–200 Hz +2.2 dB，约 200–300 Hz −1.4~−2.9 dB，6 kHz 附近 +5.3 dB、8.2 kHz 峰 +4.5 dB（残差）—— measured。Rtings 的 HMS II.3 数据中，8.7 kHz 峰 +6.5 dB。这印证了上一版的"6k/8.5k 峰、中低频膨胀"。

技术素质（评测共识，非测量）

  • 解析：初代是弱项（Headphones.com 认为不及同价开放式）；MKII 被称细节更好、瞬态更干净 —— consensus 2/3（MKII）。
  • 声场/定位：初代定位好；MKII 声场有更明显的高度与深度 —— consensus 2/2。
  • 分离：清楚但不算顶尖 —— consensus。
  • 动态/瞬态：MKII 单元失真更低、控制更好（Gearnews、Major HiFi）；低频冲击"有所克制" —— consensus 2/3。

佩戴与做工

全金属结构、耐用；重量较大但头梁厚、分压好，SoundGuys 认为可长时间佩戴；夹力偏紧，耳罩较浅，部分人耳朵会碰到垫子或单元。

用途适配

  • 混音/录音：隔音与漏音控制是核心优势（录音棚跟踪、嘈杂环境）；调音不算标准中性，做平衡决定需熟悉或配合校正。
  • 听歌：MKII 声场与动态讨喜，但重量、夹力和有争议的调音让它并非人人适合；建议试听。
  • 推力：MKII 30 Ω / 95 dB/mW，手机可以推响，但余量一般，建议接耳放或声卡耳放；初代 250 Ω 更依赖耳放。

评分（MKII）

  • 挑错度 57（曲线重校：62→57，依据 5128）：5128 显示低频比 DF 多 +6~8 dB，超过偏好中性约 2–4 dB；200 Hz 有凹陷，整体倾斜 −8 dB 偏暖；10 kHz 以上低于 DF，中高频也略少。这些都让它比上一轮判断的更宽松。唯一明显的"挑错"来源是 7.9 kHz 的 +8 dB 窄尖峰，它会放大齿音和镲片。综合下来与 DT 770 Pro 的锚点 55 接近，略高一点。
  • 音质 80（曲线重校：82→80，依据 5128）：左右一致性良好（约 0.7 dB），单元的动态和声场获得认可；但 5128 显示低频量感超出偏好中性、约 216 Hz 有 −5.8 dB 的凹陷、7 kHz 谷与 8 kHz 峰相邻（峰谷落差约 16 dB），平滑度一般；皮垫在 4.4 kHz 还有深谷。
  • 听歌适配 72（不变）：暖向和足量的低频本身讨喜，但 8 kHz 尖峰容易带来齿音和疲劳，再加上重量和较大的夹力，两方面大致抵消。
