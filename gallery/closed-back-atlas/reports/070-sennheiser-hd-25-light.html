Sennheiser HD 25 Light

2020 新版声音几乎等同 HD 25：低频冲击强、隔音好、轻便耐用，是 DJ 和外景的工具；做挑错监听，只能算"凑合可用"。 Sounds nearly identical to the HD 25, with punchy bass, strong isolation and a light build; it is a DJ and field tool, and only passable for critical monitoring.

频响与风格

  • 测量源：Light 本身没有曲线，以下全是家族代理数据（proxy-measured）。先用 fr_analyze.py 对 5128 DF 计算，再按 500–1000 Hz 对齐。要注意 5128 DF 是参考基线，不是偏好目标：偏好中性的头戴，低频通常比 DF 高 4–6 dB，高频略低于 DF。
  • 低频：RTINGS 5128 的结果是 20–60 Hz +0.1 dB、60–200 Hz +6.3 dB。按上面的换算，超低频比偏好中性少几 dB，中低频基本在偏好区的上沿。Earphones Archive 的 HD 25-1 II 更多（+6.6 / +8.9 dB），比偏好中性多约 2–4 dB。贴耳式结构对密封很敏感，两条曲线在低频上的差异应主要来自佩戴和版本不同。
  • 中低频：200–500 Hz 在 RTINGS 上是 +5.2 dB，偏好区在这个频段一般只比 DF 高 1–2 dB，所以约有 3 dB 的厚、闷感；EA 为 +1.8 dB。o90 的 GRAS 曲线也是 +2.4 dB（对 Harman）。
  • 中频：1–3 kHz 为 +0.5 到 +0.8 dB（5128），接近中性；o90 为 +2.5 dB，人声略靠前。
  • 高频：3–6 kHz 为 −1.3 / −2.4 dB，稍收；6–10 kHz 为 +3.9 / +1.6 dB，相对偏好（应略低于 DF）有凸起，对应 o90 在约 8 kHz 的尖峰；10 kHz 以上为 −7.0 / −6.3 dB，空气感不足。
  • 矛盾点：两条 5128 曲线的超低频差 6 dB 以上（RTINGS 0.1 dB，EA 6.6 dB），中低频的分布也不同。评分以 RTINGS 现款 HD 25 为准，因为它和 2020 版 Light 同代。
  • 整体：暖向，中低频偏厚，8 kHz 附近有尖峰，超高频滚降，不是中性监听曲线（家族代理，5128）。

技术素质

  • 解析：够用。headphonecheck 称赞瞬态干净、准确，但整体属于入门级（consensus 1–2 篇）。
  • 声场：贴耳式封闭结构，声场小（prior；评测基本没谈）。
  • 动态与瞬态：冲击力是强项（3/3）。
  • 分离：证据不足。

佩戴与做工

约 120 g，非常轻，耳罩可以旋转，适合单耳监听。夹力偏紧，2/3 篇认为长时间佩戴一般，可以换丝绒耳垫缓解。头梁垫看着廉价，但整机结构耐用，是 HD 25 家族的传统。

用途适配

  • 混音/挑错：能听出底噪和爆音，适合外景和现场监听；但中低频偏多，不宜作为混音参考。
  • 听歌：流行、电子节奏感好，但贴耳式的夹力和小声场会拉低舒适度。
  • 推力：阻抗约 60–70 Ω，手机能推响；灵敏度的具体数值证据不足。

评分

  • 挑错度 52（曲线重校：52→52，不变）：5128 代理曲线换算到偏好中性后，中低频（200–500 Hz）约多 3 dB，10 kHz 以上滚降，这两点会压低分析性。另一方面，6–10 kHz 的凸起会让齿音、底噪比较显眼，所以没有降到讨喜区。
  • 音质 62：同价位扎实，技术力属于入门到中档。
  • 听歌适配 62：节奏感讨喜，但贴耳式的舒适度和声场拖分。
