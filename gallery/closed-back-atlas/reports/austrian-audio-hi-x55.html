频响与风格

测量源：oratory1990 实测（AutoEq 收录，https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Austrian%20Audio%20Hi-X55），台架 GRAS 45BC KEMAR（耳罩式），对比目标 Harman OE 2018；用 AutoEq raw/error 数据按 500 Hz-1 kHz 对齐后分段计算（fr_analyze.py）。AutoEq 中只有这一份该型号测量。

  • 低频：20-60 Hz 比 Harman 少约 3 dB，60-200 Hz 多约 2 dB（100 Hz 附近约 +2.5 dB）。低频冲击有，但超低频下潜量感不足。（measured）
  • 中频：200-500 Hz 基本贴合目标；约 1 kHz 相对目标偏高约 3.5 dB，中频靠前。（measured）
  • 高频：2-3 kHz 比目标低约 5-6 dB（2-5 kHz 平均约 -5 dB），这是整条曲线最大的偏差；4-6 kHz 约 -2 到 -3 dB；7-12 kHz 基本贴合目标（±1 dB）。曲线上没有尖锐的高频峰。（measured）
  • 第二条曲线（Listener，仿制台架，只作佐证）：同样在 2.4 kHz 附近凹陷（相对目标约 -6.5 dB），和 GRAS 一致；但它在 3.6 kHz 有一个约 +7 dB 的窄峰，在 11 kHz 与 16-17 kHz 也有峰，6-20 kHz 整体比目标多 1-3 dB，超低频也比 GRAS 多约 5 dB。两条曲线的矛盾点在 3.5 kHz 以上和 60 Hz 以下。仿制耳廓对耳道共振和密闭的模拟与 GRAS 不同，所以数值以 GRAS 为准；不过 3.6 kHz 窄峰和偏多的高频，正好能解释主观评测里的“偏亮”，说明亮度对佩戴和头型比较敏感。（measured，两条曲线在高频不一致）
  • 风格：测量修正：上一轮根据评测共识判为“轻 V、偏亮”，oratory1990 曲线不支持这个结论。实测高频并不高于目标，反而是 presence 区明显下凹，加上 1 kHz 靠前、中低频略厚，整体是“中频前突、上中频凹”的染色调音。评测里的“亮”，可能来自 presence 凹陷后高频显得相对突出，或与个体、佩戴密封有关，这里以测量为准。榜单说的“中性”同样不成立。

技术素质

  • 解析：细节多、声音干净、失真低，被称为“有揭示力的分析工具”。（consensus 2/2）
  • 动态、瞬态：低频瞬态有力、有冲击。（1/1 headphonecheck）
  • 声场、分离：证据不足。日本评测提到纵深感强，但本轮没有核读原文，只作参考。
  • 测量上 2-3 kHz 凹陷约 5-6 dB，上中频的毛刺和齿音不容易被放大，挑错倾向比主观评测说的弱。（measured）

佩戴与做工

重量轻，关键部件用钢，只配软包。SOS 说耳根下方略有压迫；headphonecheck 说夹力偏低，更适合头大的用户。两者说法有出入。

用途适配

  • 审听低频、瞬态：强项。上中频（2-3 kHz）的问题容易被低估，审听人声齿音、吉他刺耳时需要留意。
  • 中性混音：SOS 明确说不如好的开放式耳机；实测偏差较大，需要校准曲线（AutoEq 有 oratory1990 的数据可用）。
  • 听歌：上中频收、高频不超目标、低频有劲，按测量看耐听度比上一轮估计的好；中频靠前，部分人声会显得略鼻。
  • 推力：标称 25 Ω / 102 dB/mW，手机就能推响；Headfonics 认为要配放大器才能发挥好。

评分

  • 挑错度 53（曲线重校：50→53。Listener 仿制台架曲线显示 3.6 kHz 窄峰和偏多的高频，与主观评测“偏亮”一致，所以略微上调；主依据 GRAS 仍是 presence 下凹、高频不超目标，所以只上调 3 分）。上一轮已由 68 按测量修正为 50。放大瑕疵的能力约和 DT 770 同档或稍低；解析好，所以不会再往下压。
  • 音质 76（原 78）：解析、动态好，但实测偏差较大（上中频凹陷、1 kHz 突出、超低频不足），染色比 Hi-X60 明显。
  • 听歌适配 72（测量修正，原 66）：实测不刺耳、低频有劲、佩戴轻；中频染色和超低频不足限制了上限。
