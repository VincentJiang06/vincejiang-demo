结论：声学上就是 HD 25，贴耳式、夹得紧、隔音好，低频有冲击、低中频偏厚（B&K 5128 上 60–500 Hz 比 DF 多 5–8 dB），8 kHz 附近有尖峰，好推。适合 DJ、外景和广播里的“快速监听”，不适合长时间舒服地听歌，也不能当作精确的混音参考。 Verdict: Acoustically the HD 25 (the Plus adds accessories): a punchy, forward, well-isolating and easy-to-drive on-ear monitor for DJ and field work. It clamps too hard for relaxed listening and is not a precise mixing reference.

频响与风格

  • 低频：60–200 Hz 比 DF 高 6–9 dB。偏好中性本来就比 DF 高 4–6 dB，所以换算后只多约 2–3 dB，属于“有冲击、略多”，不算轰。超低频很看密封：Earphones Archive 那条密封好，比 DF 多约 6.6 dB；另两条基本持平；oratory1990 另测的漏气曲线和 Elrics 的曲线都显示超低频明显下降。贴耳式的佩戴差异很大。
  • 中低频：RTINGS 和 headphonedatabase 的 200–500 Hz 都比 DF 多约 5 dB，比 GRAS 上的 +2.4 dB（相对 Harman）更明显。这是“厚、暖”听感的主要来源。Earphones Archive 这段只多 1.8 dB，说明不同样品或耳垫之间有差异。
  • 中频：1–3 kHz 大致贴着 DF（+0.5～+2.8 dB），2.5–4 kHz 相对 1 kHz 高 7–10 dB，和 DF 的耳道增益基本一致，所以人声不算靠前，也不算后退。
  • 高频：4–5 kHz 有一个小凹（−1.3～−2.5 dB）。6–10 kHz 高出 DF 1.6–5.4 dB，峰在 8 kHz 附近。偏好中性在这段本来应该略低于 DF，所以这个峰的实际听感比数字更突出，齿音和镲片会被放大。10 kHz 以上滚降明显（−6～−9 dB），空气感少。
  • 与其他台架对比：oratory1990（GRAS，相对 Harman OE 2018）是中低频 +4.6、200–500 Hz +2.4、3–6 kHz −0.5、6–10 kHz +4.7、10 kHz 以上 −2.7。Listener（711 类）显示 2.5–3 kHz 抬、8 kHz 尖峰、10 kHz 以上滚降。各台架的趋势一致，没有矛盾，只是 5128 上 200–500 Hz 更厚，GRAS 上 10 kHz 以上掉得少一些。
  • 风格结论：暖厚、带亮点。中低频和低中频加厚，4–5 kHz 小凹，8 kHz 附近有尖峰，10 kHz 以上滚降。它的“暴露问题”听感来自 8 kHz 峰，而不是整体中高频靠前。

技术素质（均为评测共识，不是测量结论）

  • 解析：中上，“从低到高都很能暴露问题”（2/3 篇一致）。
  • 声场：小，有的评测甚至说“几乎没有声场”（3/3 篇一致，贴耳式的通病）。
  • 分离和定位：一般，证据不足。
  • 动态与瞬态：低频干净、有冲击，节奏感好（3/3 篇一致）。

佩戴与做工

  • 做工：模块化，零件都能更换，耐用性口碑很好（consensus）。
  • 佩戴：初期夹得紧，贴耳压耳，长时间戴不舒服（3/3 篇一致）。换成丝绒耳垫、戴一段时间让头梁松一些后会好转。

用途适配

  • 适合：DJ 监听、外景录音、在嘈杂环境里做“有没有问题”式的检查。挑错能力偏强，但频响不平直，做混音参考要谨慎。
  • 听歌：节奏感好，但声场小、夹头紧，只能算一般。
  • 推力：约 120 dB/V，手机就能轻松推响（measured）。

评分

  • 挑错度 56（曲线重校：58→56，原因：三条 5128 曲线里有两条显示 200–500 Hz 比 DF 多约 5 dB，比 GRAS 上看到的更厚，会掩盖一些中频细节；8 kHz 峰仍在，所以不会低到 M50x 那档）。
  • 音质 70（不变）：5128 确认了 GRAS 上看到的问题（低中频加厚、4–5 kHz 凹、8 kHz 峰、10 kHz 以上滚降），平滑度一般；冲击力、耐用性口碑好，声场小。
  • 听歌适配 63（不变）：低频有劲，但 8 kHz 峰、夹得紧、声场小，长时间听会累。

证据与置信度

  • 证据级别：measured，置信度高。有三条独立的 B&K 5128 曲线（RTINGS、headphonedatabase、Earphones Archive），另有 oratory1990 的 GRAS 曲线、两条 711 类曲线和五条 HMS II.3 旧档，各台架的趋势一致。
  • 版本说明：这些曲线测的都是 HD 25、HD 25-1 II 或 Aluminium 版，没有 Plus 本身的数值（Crinacle 的 HD25 Plus 数据返回 403）。Plus 只多配件，按声学相同处理。
  • 矛盾点：各条曲线在超低频（密封）和 200–500 Hz 的量上有 3–7 dB 的差异，主要是佩戴和样品差异，趋势方向没有冲突。打分以 5128 为准。
  • 曲线重校：挑错度 58→56，音质、听歌适配不变。
  • 证据缺口：没有官方隔音 dB 值。失真和左右一致性这次没有核对（Elrics 那条 L/R 在 100 Hz–5 kHz 平均差 0.86 dB）。
