频响与风格

测量源：Kuulokenurkka（AutoEq 收录）https://github.com/jaakkopasanen/AutoEq/tree/master/results/Kuulokenurkka/over-ear/Sony%20MDR-M1 ，原始 L/R 曲线 https://kuulokenurkka.squig.link/ （MDR-M1 ）。台架：KB501x 耳廓 + IEC 711 耦合器（AutoEq name_index 标注 "KB501x + 711"）。目标：Harman Over-Ear 2018，以 500 Hz–1 kHz 对齐。注意**：Harman OE 2018 是按 GRAS 45CA 定义的，与 711 台架并不完全对应，以下偏差数值只作方向参考。数值由 fr_analyze.py 算出。

  • 低频：20–60 Hz 比目标高 +3.3 dB，60–200 Hz 高 +3.4 dB（绝对值约 50 Hz 处 +8.5 dB、100 Hz 处 +5.6 dB，相对 500–1k 均值），约 200 Hz 后回到中性（200–300 Hz 约 −1 至 −1.6 dB）。这印证了"低频有提升、下潜深、200 Hz 附近略少"的说法 —— measured。
  • 中频：200–500 Hz −0.4 dB，1–3 kHz +0.3 dB，基本贴合目标；2–3 kHz 绝对抬升约 +6~7 dB，耳增益并不欠缺。约 4 kHz 有一个 −4.7 dB 的凹陷 —— measured。测量修正：原文所说的"3 kHz 偏收"在这条曲线上没有出现，收敛的位置其实在 4 kHz 附近。
  • 高频：3–6 kHz 带均值比目标低 −5.1 dB，是全曲线最明显的缺量；6–10 kHz −1.1 dB（8 kHz 附近约 +3.9 dB，9–10 kHz 回落到 −2~−3.6 dB），10 kHz 以上 +2.2 dB，12.6 kHz 有一个窄峰（711 台架在这一频段本身就不可靠）。整体倾斜 −4.7 dB，属于暖向 —— measured。
  • 左右一致性：100 Hz–5 kHz 平均左右差约 0.6 dB，良好 —— measured（由 Kuulokenurkka 的 L/R 原始数据算出）。
  • 失真：整体很低，约 5 kHz 有窄峰，大音量时上升 —— measured（SoundGuys）。
  • 第二条曲线（GadgetryTech，KB006x）交叉验证：20–60 Hz +3.3 dB，60–200 Hz +3.2 dB，200–500 Hz −1.3 dB，1–3 kHz +0.9 dB，3–6 kHz −6.4 dB（约 3.95 kHz 凹陷 −6.1 dB），10 kHz 以上 +1.2 dB，倾斜 −5.2 dB，与 Kuulokenurkka 基本一致。差异在于：这条曲线在 8.1–8.4 kHz 有 +7 dB 的窄峰，11.8 kHz 还有 +6 dB，而 Kuulokenurkka 在 8 kHz 附近只有约 +3.9 dB。两家都用耳廓仿制件，这一频段受佩戴和台架影响很大，所以只能说 8 kHz 附近"可能有一个偏亮的窄峰"。Hu-Fi 只有单声道、台架不明，低频几乎平直，与两家耳廓台架的结果矛盾，不采信。
  • 结论：低频高出目标约 3 dB，中频贴合目标，4 kHz 附近收敛，没有尖锐的挑错峰。属于中性偏暖、听感宽松的监听调音，与 7506 那种亮而刺的风格明显不同。

佩戴与做工

轻量塑料结构，厚垫，长时间佩戴舒适（戴硬框眼镜会有压迫）；1–2 小时后易闷热。可拆线、3.5/6.3 转换，但螺纹母口让第三方换线不便（SoundGuys）。

用途适配

  • 混音/母带：适合作为主力监听或低频检查参考；3k 偏收与 200 Hz 凹陷需要心里有数。
  • 听歌：舒适、低频饱满，电子乐表现好；原声/空气感重的作品略欠。
  • 推力：50 Ω / 102 dB/mW，手机与笔电即可推动 —— prior（规格推断）。

评分

曲线重校：分数不变（50/79/80）。新增的 GadgetryTech 曲线证实了暖向的倾斜和 3–6 kHz 的缺量，它显示的 8 kHz 窄峰让挑错度不宜再往下调；由于没有 5128 数据，这次没有依据做更大的修正。

  • 挑错度 50：测量显示低频比 Harman 多约 +3 dB，3–6 kHz 比目标少 −5 dB，没有尖锐的高频峰，因此比锚点 MDR-M1≈55 略宽松（测量修正：收敛的位置在 4k 而不是 3k）。
  • 音质 79：失真低，左右一致性约 0.6 dB，低频延伸好；高频空气感与解析有保留。
  • 听歌适配 80：轻、舒适、低频讨喜，被"略闷"的评价小幅拉低。
