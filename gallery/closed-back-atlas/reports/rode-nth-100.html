  • 测量修正（沿用上一轮）：原稿写的"低频偏多、延伸到约 200 Hz、暖暗厚实"与三条曲线都不符。按 Harman OE 2018 算，中低频基本中性，超低频略少，低中频最多多 2 dB。
  • 风格：接近 Harman 的均衡调音，6–10 kHz 凹陷，12.5 kHz 有小峰，是"略暗的均衡"，不是"暖暗厚"。
  • 拆掉前阻尼后（Kuulokenurkka 改装曲线），6–10 kHz 缺量缩小到 −2.5 dB，说明凹陷主要来自出厂的阻尼设计。

技术素质

  • 解析：偏"蒙"、钝，细节少（Headphones.com；1/3 明确负面，其余评测未深谈）→ consensus 弱。
  • 失真：3 次、5 次谐波偏高，100 Hz 三次谐波约 2%（measured，Headphones.com / 另一测评）；headphonecheck 听感上指出大音量时齿音失真（2/2 一致）。
  • 声场、分离、动态、瞬态：证据不足。

佩戴与做工

佩戴与做工是最强项（3/3 评测一致）：轻、压力小、耐热，有左右彩色环、线可左右插。Headphones.com 提到三角形耳罩对大耳朵可能碰触。

用途适配

  • 挑错/混音：headphonecheck 认为更适合录音与监听而非关键混音；暗调与高频凹陷不利于判断齿音和空气感。适合播客、剪辑、长时间录音。
  • 听歌：均衡偏柔、不累，长时间舒适，但中高频缺量，空气感和齿音细节偏少。
  • 推力：32 Ω、110 dB/V（官方，偏保守），手机可推，响度一般够用。

评分

  • 挑错度 45（不变）：新增的 Exound 曲线同样显示 6–10 kHz 缺量，与 GRAS 结论一致。2–6 kHz 贴近 Harman，低频并不多，所以不算宽松的暖声；但 6–10 kHz 缺 4–9 dB，齿音和嘶声会被压低，挑错能力有限。与 K371 同档。
  • 音质 64（不变）：频响贴近 Harman，但有 7.7–9.8 kHz 凹陷和 12.5 kHz 峰；评测测得的谐波失真偏高（100 Hz 三次谐波约 2%）。缺少 5128 数据，无法进一步校准。
  • 听歌适配 72（不变）：调音偏柔，佩戴极好，适合长时间听；失真和高频缺量限制了上限。

证据与置信度

  • 置信度：中。没有 B&K 5128 数据；频响靠 GRAS（oratory1990）加 711 类（Kuulokenurkka）和未注明台架（Exound）三条曲线互相印证。失真只有评测数据，声场和分离缺少可靠来源。
  • 测量修正说明：原稿依据 Headphones.com 和 Sonarworks 的解读，认为"低频多、暖暗"；按 Harman 目标定量比对，低频基本中性，已据此改写。可能原因是那两家的参考目标不同（Sonarworks 用自家平直参考）。
  • 证据缺口：没有 5128 数据；官方灵敏度 110 dB/V 与第三方实测差 4–7 dB。
