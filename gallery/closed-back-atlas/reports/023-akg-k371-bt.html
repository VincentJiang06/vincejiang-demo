AKG K371-BT

结论：有线 K371 那套接近 Harman 的调音加上蓝牙（SBC/AAC）和 40 小时续航。平衡、低频饱满，听歌和一般检查都顺手，不适合对延迟敏感的录音返听。 Verdict: The K371's near-Harman tuning plus Bluetooth convenience. Balanced with a full low end, good for listening and casual checking, not for latency-critical tracking.

主要打分依据：Earphones Archive 测的有线 K371 B&K 5128 曲线（代理），与 5128 DF 对比。

频响与风格

  • 依据：有线 K371 的 5128 代理曲线，用 fr_analyze.py 对比 5128 DF，在 500–1k Hz 对齐。BT 版本身没有测量数据。
  • 低频：20–60 Hz 比 DF 高 13.2 dB，60–200 Hz 高 11.3 dB。偏好中性的头戴一般比 DF 高 4–6 dB，换算下来仍多出约 6 dB，属于明显的低频加强。200–500 Hz 高 2 dB，略厚。
  • 中频：500 Hz–1 kHz 是对齐基准。1–3 kHz 比 DF 低 2.2 dB，略收。
  • 高频：3–6 kHz 比 DF 高 1.1 dB（4.4 kHz 附近有一个 +3.5 dB 的峰），6–10 kHz 高 2.6 dB，所以并不暗。10 kHz 以上低 4.5 dB，15–19 kHz 有多个凹陷，极高频滚降。
  • 与其他台架的矛盾（以 5128 为准）：
  • oratory1990 的 GRAS 曲线显示低频基本贴着 Harman，3–6 kHz 比目标低约 2.3 dB。
  • 5128 显示低频量明显更多，3–10 kHz 也不暗。
  • RTINGS（HMS II.3）约 8.7 kHz 的窄峰，与 5128 上 6–10 kHz 略多的结果方向一致。
  • 整体：暖向、低频猛，中高频不暗，极高频收。原先"贴近 Harman 的平衡调音"这个判断需要修正为"低频加强的暖向讨喜调音"。
  • 蓝牙模式的频响是否与有线一致，没有测量证据；主观评测普遍认为差别很小。

技术素质

  • 解析：同价位中等偏上，偏平衡，不刻意突出细节（consensus 2/3）。
  • 声场：封闭式正常水平，不特别宽（prior，来自有线版口碑）。
  • 分离、动态、瞬态：没有 BT 版的专门评述，证据不足。
  • 以上都是评测共识或先验，不是测量结论。

佩戴与做工

  • 轻，耳垫偏硬但密封好，能连续戴几个小时（Tape Op 与 headphonecheck 都这么说，2/2）。
  • 耳罩上的触控操作方便，但蓝牙开关的位置被批评不顺手（headphonecheck）。
  • 可折叠，线材可拆，附三根线（Tape Op）。

用途适配

  • 听歌：强项。调音讨喜，还有无线的方便。
  • 混音/挑错：可以用来互相核对混音（mix check），但低频有抬升，不是"放大瑕疵"型。录音返听要用有线，蓝牙延迟没有公开数据，证据不足。
  • 推力：32 Ω、114 dB/V，手机或蓝牙都能轻松推动。

评分

  • 挑错度 43（曲线重校：45→43，原因与有线 K371 相同。5128 显示低频比偏好中性多约 6 dB，会掩盖低频和中低频的问题；3–10 kHz 不暗，所以只小幅下调）。
  • 音质 72（不变）：5128 上低频抬升偏多、极高频滚降。原分数本来就因为 BT 链路打过折，现在与有线 K371 重校后的 72 持平。
  • 听歌适配 80（不变）：暖向、低频加强的调音，加上舒适佩戴和无线便利。
