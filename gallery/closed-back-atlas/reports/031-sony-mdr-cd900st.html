Sony MDR-CD900ST

日本录音室的人声监听工具，中频直白、两端滚降，挑错能力强，但不适合当听歌耳机。 A vocal-centric Japanese studio tool: blunt mids, rolled-off extremes, very revealing, and a poor choice for casual listening.

频响与风格

测量源： 1. oratory1990 实测。台架为 GRAS 43AG-7（KEMAR 类耳廓），数据取自 AutoEq 的 CSV：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Sony%20MDR-CD900ST 2. crinacle 实测，同为 GRAS 43AG-7。AutoEq 只提供 EQ 参数，没有 CSV，这里用来交叉印证：https://github.com/jaakkopasanen/AutoEq/tree/master/results/crinacle/GRAS%2043AG-7%20over-ear/Sony%20MDR-CD900ST 3. ASR 测量帖（见文末）。

对比目标：Harman over-ear 2018。用 fr_analyze.py 计算，按 500–1000 Hz 对齐。

  • 低频：20–60 Hz 比目标低约 10 dB，属于大幅不足；60–200 Hz 低约 2 dB。结论是超低频明显缺量，这和 ASR 的"没低频、受密封影响"一致。（measured）
  • 中频：200–1000 Hz 基本贴合目标（±0.2 dB）；1–3 kHz 低约 3.8 dB。3.5 kHz 附近有一个窄峰，比周围高约 3 dB，属于咬字突出的类型。crinacle 的 EQ 在 3.6 kHz 做了 −3.5 dB 的衰减，同样印证了这个峰。（measured）
  • 高频：3–6 kHz 低约 3.5 dB，6–10 kHz 低约 5.7 dB，10 kHz 以上低约 7.9 dB。另有 10.7–11.8 kHz 的小峰（约 +3.5 dB）和 13.7 kHz 的凹陷。crinacle 的 EQ 在 8 kHz 补 +6 dB，在 10 kHz 用高架补 +5 dB，方向与此一致。
  • 风格结论（测量修正）：脚本判定为"暗声"，整体倾斜接近中性。它的"直白、干"并不来自高频抬升，而是三点共同作用：低频缺量、中频相对靠前、3.5 kHz 窄峰。原先写的"中频人声突出、两端滚降"方向正确，但"中频突出"更准确的说法是：中频相对两端靠前，而不是中频绝对高出目标。
  • B&K 5128 佐证（代理，MDR-CD900 标注）：对照 5128 DF，按 500–1000 Hz 对齐。20–60 Hz 为 −13.1 dB，60–200 Hz 为 −1.2 dB；偏好中性的头戴一般要比 DF 高 4–6 dB，按这个换算，中低频实际比偏好中性少约 5–7 dB。1–3 kHz 为 −3.5 dB，3–6 kHz 为 −5.0 dB，6–10 kHz 为 −3.6 dB，10 kHz 以上为 −9.9 dB；9.9–10.6 kHz 有约 +8.5 dB 的尖峰，14.3 kHz 有凹陷。脚本判定为"暗声"。与 GRAS 的结论一致：低频明显缺量，高频整体偏低，但 10 kHz 附近有尖峰。一处差异是：5128 上 3.5 kHz 窄峰不明显，3–6 kHz 反而更低（约 −5 dB）。所以"直白感"主要来自低频缺量，以及 10 kHz 附近的尖峰。
  • Super Review（台架未注明）的曲线也给出同样方向：20–60 Hz 为 −9.3 dB，10 kHz 以上为 −8.3 dB，另有 3.1 kHz 小峰和 8.7 kHz 峰（+6.4 dB）。
  • homestudiobasics 认为它"接近中性"，这一说法不被测量支持。

技术素质

  • 解析与分离：评价是"不错"（1/2 评测：homestudiobasics）。ASR 没有单独评价解析，只评了音色。
  • 声场：偏头中，表现随录音变化（1/2，consensus）。
  • 动态与瞬态：证据不足。
  • 失真：ASR 测得低频失真偏高，会限制 EQ 补低频的余地。（measured）

佩戴与做工

重量轻，但耳罩浅，戴约 1 小时后会闷热、出汗。仿皮耳垫大约一年会老化，好在属于易损件，容易更换。日本产，结构和 7506/V6 同源。线缆不可拆卸，机身不能折叠。（consensus，1–2 源）

用途适配

  • 适合：人声录音监听，在监听音箱之外做挑错补充。
  • 推力：灵敏度高、阻抗适中，手机也能推响。不过 ASR 提醒，如果要用 EQ 补低频，需要留出功率余量。
  • 听歌：低频少、中频突出、舒适度一般，不推荐。

评分

  • 挑错度 82（曲线重校：维持；5128 代理曲线与 GRAS 方向一致，10 kHz 尖峰加上低频缺量支撑高挑错度）（测量修正，原 88）：测量显示高频整体低于目标，没有明亮型的抬升。它的挑错感主要来自两点：超低频缺约 10 dB，没有低频掩蔽；3.5 kHz 有窄峰。所以比 M70x、7506 这类高频抬升的型号略温和，打在锚点 88 之下。
  • 音质 62（曲线重校：维持）：频响偏离大，超低频缺约 10 dB，高频缺 4–8 dB，ASR 还测到低频失真偏高；解析被评为不错。维持原分。
  • 听歌适配 42（曲线重校：维持）：低频少、偏暗偏干，佩戴容易闷热。维持原分。
