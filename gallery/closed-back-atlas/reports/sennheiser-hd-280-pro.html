频响与风格

测量源：oratory1990 实测（AutoEq 收录，https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Sennheiser%20HD%20280%20Pro ，raw CSV 已下载分析），台架为 GRAS 45BC KEMAR 耳-颊模拟器（oratory1990 常用台架）；辅证为 Innerfidelity 旧档（AutoEq results/Innerfidelity，Head Acoustics 台架，样本年份较早）。对比目标曲线：Harman 头戴 2018（按 500–1000 Hz 对齐，用 vince-hifi-review 的 fr_analyze.py 计算）。

  • 低频：oratory1990 数据中 20–60 Hz 比目标高约 4 dB（30 Hz 处约 +6 dB），60–200 Hz 基本中性（-0.7 dB），但约 100 Hz 附近比目标低约 1.5 dB，120–150 Hz 又有一处约 +2~3 dB 的小隆起。也就是"极低频有、中低频有小起伏"，不是整体缺低频。Innerfidelity 旧档则显示 20–200 Hz 比目标少 5–6 dB，与 oratory1990 差异大，可能是样本/耳垫密封/台架不同，本报告以 oratory1990 为准。
  • 中频：200–1000 Hz 与目标几乎重合（±0.1 dB），1–3 kHz 平均 -1.3 dB，中频平直的共识得到测量支持。
  • 高频：3–6 kHz 平均比目标低约 5.2 dB，其中约 4.2 kHz 有一个窄谷（比目标低约 6 dB）；约 6 kHz 有一个相对局部的小峰（残差 +3.7 dB）；6–10 kHz 平均 -4.2 dB，10–20 kHz 平均 -4.1 dB，约 12.6 kHz 有尖窄小峰。两份测量都判定为"暗声"。
  • 多曲线对照（都用 fr_analyze 对 Harman OE 2018 粗算；非 GRAS 台架有系统偏差，只看趋势）：3–6 kHz 的凹陷在 6 条原装耳垫曲线里都出现（−1.7 到 −5.5 dB，其中 5 条 ≤ −4 dB），这一点最可靠。低频分歧大：oratory1990 的 20–60 Hz 是 +4.0 dB，其余曲线从 −5.9 到 +0.8 dB；60–200 Hz 也只有 oratory1990 接近中性（−0.7），其余是 −2.2 到 −5.8 dB。HMS II.3 与 GRAS 目标本身不匹配，再加上这副耳机对密封很敏感，所以不能直接说哪边错。本报告仍以 GRAS 曲线为准，但把"低频量"视为因佩戴而变的量。换成绒面耳垫后（Filk）低频少约 10 dB，高频也明显下降。
  • 整体风格（measured）：中频平直、存在感区和高频明显不足的暗声，极低频略有余量。与原先主观判断"低频薄"相比，测量修正：oratory1990 数据中极低频并不少，只是 100 Hz 附近有小凹陷；"偏暗、4 kHz 窄谷"得到测量确认。

技术素质

  • 解析：中频细节交代得清楚，但高频收得早，整体解析只算入门到中等。评价有分歧：1/3 称"很能暴露问题"，2/3 称"偏闷、缺活力"。（consensus 2/3）
  • 声场：多数评测说窄（2/3），SoundGuys 则认为以封闭式来说算宽（1/3）。结论：偏窄。
  • 分离、动态、瞬态：证据不足，只有零星"适合跟踪录音"之类的描述。

佩戴与做工

耳垫厚，可戴眼镜。新耳机夹得紧，长时间戴会闷热。结构耐用，老牌录音棚常见型号。（consensus 3/3 提到夹力或闷热）

用途适配

  • 录音跟踪：隔音好、耐用，是它的强项。
  • 混音与挑错：中频可以参考，但低频凹陷、高频偏暗，看不清全频段的问题。
  • 听歌：低频薄、高频暗，偏无趣。
  • 推力：容易推。

评分

  • 挑错度 42（曲线重校：42→42，没有新的 5128 数据，多条曲线都确认 3–6 kHz 偏暗；更早一轮的测量修正：50→42）：2–10 kHz 整体比 Harman 低 4–5 dB，4 kHz 有窄谷，存在感区和高频都被压低，齿音、镲片的问题不容易被放大；中频平直可以作参考。整体比 DT 770 Pro（≈55）更不挑错，接近 ATH-M50x（≈40）一档。
  • 音质 58（曲线重校：58→58，不变）：测量中频平直，但高频不平（4 kHz 谷、6 kHz 与 12.6 kHz 小峰），不同样本/来源低频差异大，解析一般；与锚点 HD 280 Pro≈58 一致。
  • 听歌适配 55（曲线重校：55→55，不变）：极低频有量、高频不刺，但整体偏暗、中高频缺活力，夹力大、闷热，隔音强适合嘈杂环境。
