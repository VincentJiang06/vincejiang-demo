频响与风格

  • 依据是代理测量：Signature Master MkII 的 B&K 5128 曲线，两台样本。跟 5128 DF 比的偏差如下，第一个数是样本 1，第二个是样本 2。
  • 低频：20–60 Hz 为 +1.1 / +0.3 dB，60–200 Hz 为 +3.6 / +2.2 dB。偏好中性的头戴一般比 DF 高 4–6 dB，照这个换算，它的低频量感属于偏克制，这跟听感评测"低频克制"一致。
  • 中频：200–1000 Hz 基本贴着 DF；1–3 kHz 为 −3.2 / −4.0 dB，略少。
  • 高频：3–6 kHz 为 −8.6 / −10.2 dB，存在感区明显凹陷，4.5–5 kHz 附近有深谷。样本 1 在约 6.2 kHz 有一个 +9 dB 的窄峰，样本 2 的窄峰在约 3.6 kHz（+5.5 dB）。6–10 kHz 为 −2.2 / −3.5 dB，10–20 kHz 为 −6.6 / −7.0 dB，空气感偏少。
  • 风格：按曲线看，整体不算亮，更接近中频为主、存在感区下凹、带一个窄高频峰的"カマボコ"（中间鼓）型，sandalaudio 对初代的听感也是这样描述的。
  • 矛盾点：headphonecheck 和 HifiGuides 论坛把它形容为"偏亮 / 高频略刺"。曲线能解释的是"刺"，大概率来自 6 kHz 或 3.6 kHz 那个窄峰，窄峰在大片凹陷的背景上会显得更突出；但曲线不支持"整体偏亮"。按规则以 5128 为准；不过这是 MkII 的代理曲线，而且两台样本的峰位不一样，初代的实际高频形态仍然不确定。

技术素质

  • 解析：高（headphonecheck；另外 Ultrasone Pro 系列的高解析口碑可作 prior）。
  • 瞬态：快而准（1 篇，中置信）。
  • 声场与成像：立体声像宽；S-Logic 让声音有外化感，这点是厂商说法加评测描述，属 prior/consensus。
  • 动态：证据不足。
  • 评测数量少：只有 1 篇完整的独立听感评测，Frieve 是元分析，而且只批评它性价比低、缺少测量数据。

佩戴与做工

配件丰富：三根线加收纳盒。整体做工不错，但旋转结构是塑料的，显得廉价；哑光表面容易留汗渍；头梁垫偏宽。夹力高，所以隔音好，但戴久了会有压迫感（headphonecheck）。

用途适配

  • 混音 / 挑错：适合，尤其适合检查高频细节和瞬态。S-Logic 的声像特性需要时间适应（prior）。
  • 听歌：一般。高频刺、缺暖味，长时间听容易累。
  • 推力：约 97 dB/V、34 Ω，手机能推到够用的音量，但余量有限（依据 97 dB/V 推断）。

评分

  • 挑错度 62：曲线重校，72→62。5128 代理曲线显示存在感区下凹、空气感偏少，不是之前认为的整体偏亮；但窄高频峰会放大齿音，中频贴近 DF、低频克制，所以仍然偏监听向。
  • 音质 72：曲线重校，76→72。3–6 kHz 的深凹加上窄峰，均衡性不如预期，两台样本之间也有差异；解析和瞬态的口碑保留。
  • 听歌适配 60：曲线重校，58→60。整体没有想象中亮，刺激主要集中在窄峰；但低频偏少、夹力高，听歌仍然一般。
