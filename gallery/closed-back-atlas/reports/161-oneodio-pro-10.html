OneOdio Pro-10

低频量大、中低频偏厚的平价 DJ 耳机，好推、隔音够用；6 kHz 附近有一个尖峰，可能带齿音。依据是 SupOrSalad 的一条单声道 DIY 台架曲线，没有 5128 数据，置信度低。 A bass-heavy budget DJ headphone with a thick lower midrange and a sharp ~6 kHz peak; easy to drive. Based on one single-channel DIY-rig measurement (SupOrSalad), no 5128 data, so confidence stays low.

频响与风格

  • 测量源：SupOrSalad 的单声道曲线（见上表），对照 Harman OE 2018，以 500–1000 Hz 对齐。
  • 低频：20–60 Hz +1.1 dB（基本中性）；60–200 Hz +5.6 dB（偏多）。这和"低频量大"的评测共识一致。
  • 中低频：200–500 Hz +4.8 dB，偏厚、偏浑。以前评测说"中低频偏薄"，曲线不支持这个说法；这里以曲线为准。
  • 中高频：1–3 kHz 平均 −3.5 dB，人声往后退一点。曲线在约 3.1 kHz 有个峰，比 1 kHz 高约 14 dB。
  • 高频：约 4.5 kHz 有个凹陷（残差 −10.7 dB），约 6.1 kHz 有个尖峰（+12.6 dB，可能带齿音），约 8.1 kHz 又凹下去（−9.6 dB），10 kHz 以上偏少（−1.7 dB）。评测说"高频收敛、不刺耳"，这与 6 kHz 尖峰有出入。DIY 耳廓在 6–8 kHz 的形态受台架影响大，所以这个尖峰只作中等可信的参考。
  • 总体：低频偏重、偏暖（倾斜 −3.9 dB），属于低频猛的消费型调音，再加上一个窄的 6 kHz 峰。

技术素质

  • 解析、分离、声场：评测里基本没提（证据不足），入门动圈的先验是一般水平。
  • 动态：音量开得很大时会失真（consensus 1/2，soundandgo）。
  • 另一篇评测的总体评价是"就价位而言还不错"（techbuzzireland）。

佩戴与做工

  • 耳垫柔软，有评测说很舒服（techbuzzireland）；但也有评测指出，头梁拉到最长时耳罩仍盖不全耳朵，头大的人可能不合适（soundandgo，并提到多名用户反馈）。
  • 结构还算结实，不过耳垫和头梁不能换（soundandgo）。

用途适配

  • 混音 / 挑错：不适合。低频偏重、高频收敛，暴露不了问题。
  • 听歌 / DJ / 陪听：可以当低成本的低频型耳机用。32 Ω 手机就能推响，不需要耳放。

评分

  • 挑错度 30（曲线重校：30→30，不变）：低频和中低频多出 5 dB 左右，中高频退后，整体讨喜；6 kHz 尖峰会让细节听起来多一点，但不是均衡的解析。
  • 音质 38（曲线重校：40→38，原因：曲线显示中低频偏厚、4–8 kHz 起伏很大）。
  • 听歌适配 48（曲线重校：50→48，原因：6 kHz 尖峰可能带齿音，削弱长时间听的舒适度）：低频讨喜、好推；佩戴尺寸有争议。

证据与置信度

  • 置信度：低；证据级别：measured（只有一条非 5128 曲线：DIY 711 仿制台架，单声道）。
  • 曲线和评测的矛盾：评测说中低频偏薄、高频收敛；曲线显示中低频偏厚，6 kHz 有尖峰。按规则以曲线为准，但因为台架是 DIY、只有一个声道，高频结论保留余地。
