频响与风格

  • 与 RAA 目标的差值（HDM-X，L/R 汇总，150 Ω 版）：
  • 20-60 Hz：+1 ~ +2 dB，基本中性。
  • 80-500 Hz：+4 ~ +8.5 dB，峰值在 180-240 Hz 附近。这是上低频到下中频的一个宽鼓包，不是超低频下潜。
  • 0.9-1.2 kHz：大致回到目标附近。
  • 1.2-5 kHz：-3 ~ -12 dB，其中 1.6-2.2 kHz 约 -9 dB，3.7-5 kHz 约 -10 ~ -12 dB。临场感这一段明显凹陷。
  • 6.5 kHz 附近：一个窄峰，基本回到目标水平（-1 dB）；绝对电平上比 3-5 kHz 高出约 8 dB。
  • 8-20 kHz：-3 ~ -6 dB，14 kHz 以上继续滚降。
  • DAH 两张图（仅图片，佐证）：100-500 Hz 平台最高，1.5-5 kHz 深谷，7-13 kHz 有几个窄而高的峰，与 RAA 的趋势一致。HD330 Pro 版的 6-8 kHz 峰比 150 Ω 版更突出。
  • 修正旧结论：旧版写的"2-3k 有存在感"，数值曲线不支持——2-3 kHz 恰恰在凹陷区里（HDM-X 上只有 2.7 kHz 附近一个小突起）。风格应改为：暖厚的下中频 + 凹陷的临场感 + 6-8 kHz 附近的窄亮峰。这是"暖而带刺"的 U/V 形：人声偏厚、偏远，齿音和镲片会从窄峰里冒出来。HSB 说的"6-7k 金属感"与曲线一致；headphonecheck 说"高频亮"，对应的是这个窄峰，而不是整体偏亮。
  • 注意：HDM-X 不是标准台架，这里的读法依赖 RAA 自家目标，结论只能到定性和粗略的 dB 量级为止。

技术素质

  • 解析、清晰度：3/3 份评测都说"超出价位"（consensus）。
  • 声场、分离：HSB 说半开放下声场宽敞、分离好（1/3，证据不足）。
  • 动态、瞬态：证据不足。

佩戴与做工

HSB 说佩戴非常舒适，可比 HD600（1 份评测）。做工方面，HSB 评价金属件扎实；headphonecheck 挑出线材焊死、头梁有缝隙的问题。

用途适配

  • 混音/挑错：6-7k 偏亮，能暴露齿音，但低频抬升和半开放漏音让它不适合录音棚里做跟踪监听。
  • 听歌：调音讨喜、价格低、舒适。高频敏感的人需要注意。
  • 推力：150 Ω 版手机能推响，但余量一般。32 Ω 版更好推。

评分

  • 挑错度 45（曲线重校：55→45）：1.2-5 kHz 凹陷约 10 dB，下中频又抬了 6-8 dB，人声和乐器的细节会被遮住；6-8 kHz 的窄峰能把齿音放大，但只在这一个频段有"挑错"效果。整体接近 ATH-M50x / K371 一档，而不是 DT 770 一档。
  • 音质 56（曲线重校：60→56）：临场感凹陷明显，高频是几个窄峰而不是平顺的延伸，音色准确度一般；以它的价位，解析力仍然超值（consensus）。
  • 听歌适配 62（不变）：暖厚、低频足、舒适，多数流行乐讨喜；但 6-8 kHz 的窄峰对齿音敏感的人不友好，半开放结构隔音也差。

证据与置信度

  • 置信度：中低（medium），证据级别 measured（数值曲线来自 RAA 自家 HDM-X 台架，从页面 canvas 解码得到；DAH 的两张图作为佐证）。没有 5128 或 GRAS 数据。
  • 曲线之间的矛盾：没有数值曲线互相冲突。与旧版评测共识的冲突在于"2-3k 存在感"这一条，以测量为准。headphonecheck 说"低频内敛"，测的是 32 Ω Pro 版，与 150 Ω 版的曲线对不上，版本差异仍未解决。
  • RAA 标出的灵敏度是 117.77 dB/V、113.36 dB/mW，平均阻抗 362 Ω，与厂商的 150 Ω / 96 dB 相差很大（可能是批次或版本不同，也可能是测量设置不同），所以没有替换规格表里的数值，只在这里记录。
