Shure SRH940

低频偏薄（相对 Harman）、细节极多的挑错型封闭监听，但 9kHz 附近明显的高频峰让它长听刺耳，头梁铰链易裂是硬伤，且已停产。 A detail-forward closed monitor with clean, flat bass but lean bass and a sharp ~9–10 kHz treble peak and notoriously fragile hinges; discontinued.

频响与风格

主测量：Earphones Archive B&K 5128（L/R 平均），fr_analyze.py 对比 5128 DF（中频锚定）。5128 DF 只是参考基线，偏好中性的头戴一般低频比 DF 多 4–6 dB、高频略低于 DF，下面按这个换算。

  • 低频（measured，5128）：20–60 Hz 比 DF 高 1.0 dB，60–200 Hz 高 2.4 dB。按偏好中性换算，大约还差 2–4 dB，属于偏薄、没有低频架；相对 1 kHz，20 Hz 处约 −7 dB，超低频有滚降。
  • 中频（measured，5128）：200 Hz–3 kHz 与 DF 的偏差都在 ±1 dB 以内，中频干净平直。
  • 高频（measured，5128）：3–6 kHz 比 DF 高 1.5 dB，6–10 kHz 高 2.4 dB，10 kHz 以上与 DF 持平（−0.5 dB）；15 kHz 左右有 +4.7 dB 的窄峰，17–18 kHz 有凹陷。按偏好中性（高频略低于 DF）换算，3–11 kHz 整段大约多出 3–4 dB，是一整片偏亮的平台，而不是单个尖峰。
  • 风格：脚本按 DF 判为"均衡"（tilt −0.6 dB），换算到偏好中性后是偏薄、偏亮的分析型：低频少、中高频到高频整体多。
  • 与 HMS II.3 数据的矛盾（以 5128 为准）：Innerfidelity 与 Headphone.com Legacy 在 9–10 kHz 显示 +7~+9 dB 的尖锐大峰，14 kHz 还有次峰；5128 上 6–11 kHz 是较宽的抬升平台，没有这么突出的单峰，高频超量也只有约 3–4 dB。两台架对"偏亮、低频偏薄"的方向判断一致，差的是峰的形状和幅度。

技术素质

  • 解析：非常高，"细节怪兽"（3/3：Headfonia、DIY-Audio-Heaven、Sound On Sound 共识）。部分观感来自高频峰的强调，不完全等于真实解析力。
  • 动态：好（1/3，DIY-Audio-Heaven）。
  • 声场/定位：日文评测称定位准确（1/3），证据有限。
  • 失真：90dB 时 3 次谐波约 2%，80dB 可接受（measured）。

佩戴与做工

塑料做工偏廉价；头梁铰链/伸缩臂开裂是多方共识（Head-Fi、DIY-Audio-Heaven、日文评测 3/3）。头梁受力集中于头顶一点，久戴有压迫。夹力不大。

用途适配

  • 混音/挑错：强项，齿音和高频问题会被放大，但需注意峰值导致的高频误判，建议 EQ 压 9kHz。
  • 听歌：长时间听易疲劳，不推荐不 EQ 直接听。
  • 推力：约 100–103 dB/mW、30–40Ω，手机可推。

评分

  • 挑错度 82（曲线重校：85→82，5128 上高频是宽平台、超量约 3–4 dB，没有 HMS 数据里那么尖的 9–10 kHz 峰；但低频偏薄加中高频偏多，仍是很强的挑错取向）。
  • 音质 72（曲线重校：70→72，5128 上中频平直、高频峰谷比 HMS 数据平缓；超低频滚降和 90 dB 时约 2% 的三次谐波仍然扣分）。
  • 听歌适配 50（曲线重校：48→50，高频刺激没有旧数据显示的那么尖；但偏薄偏亮、头梁压顶且容易坏，长听仍会疲劳，建议 EQ）。

证据与置信度

  • 置信度：中高（有 B&K 5128 原始曲线作主依据，另有两份 HMS II.3 曲线，三者方向一致；隔音缺数据；单一样本）。
  • 曲线库补查：Earphones Archive 5128 库找到本型号（L/R）；AutoEq 找到 Innerfidelity、Headphone.com Legacy；未找到 oratory1990、Crinacle、RTINGS、headphones.com 数据。
  • 台架矛盾：HMS II.3 的 9–10 kHz 尖峰（+7~+9 dB）在 5128 上表现为较宽、较温和的抬升平台，按 5128 修正。
  • 测量修正：原稿"低频延伸好、平直"与 HMS II.3 数据不符，改为"相对 Harman 超低频约 -8 dB"；DIY-Audio-Heaven 的低频结论记为 dissent。
  • 证据缺口：隔音量化；官方与实测阻抗不一致（42 vs 33Ω），以官方为名义值。
