Fostex TH-7

便宜、好推的 Fostex 封闭耳机。实测低频下潜弱，100 Hz 到 1 kHz 比目标多出约 2 dB，2–3 kHz 有凹陷，5 kHz 附近有一个尖峰。整体偏中性略暖、中频靠前，谈不上挑错利器。 A cheap, reasonably easy-to-drive closed Fostex. Measurements show weak sub-bass, mids about 2 dB above target, a 2–3 kHz dip and a sharp ~5 kHz peak. The result is neutral-warm and mid-forward, not a true fault-finder.

频响与风格

  • 测量源：AutoEq 仓库中 crinacle 的数据，页面为 https://github.com/jaakkopasanen/AutoEq/tree/master/results/crinacle/GRAS%2043AG-7%20over-ear/Fostex%20TH7 。台架是 GRAS 43AG-7（耳罩式耳机专用）；目标曲线是 AutoEq 给 crinacle 耳罩数据配的 Harman over-ear 类目标。AutoEq 只公开了 PNG 图和 EQ 文件，拿不到原始 CSV，所以下面是截图读图的定性结论，没有运行 fr_analyze.py。
  • 低频（measured）：40 Hz 以下明显滚降，20 Hz 处比目标低约 10 dB。AutoEq 的 EQ 在 31 Hz 补了 +6.9 dB。80–200 Hz 大体贴着目标，底部显得偏薄，冲击力不足。评测说"低频欠冲击"（consensus），与测量一致。
  • 中频（measured）：约 150 Hz–1 kHz 比目标高约 +2 dB，人声和乐器的中段偏厚、偏靠前。
  • 高频（measured）：2–3 kHz 比目标低约 −4.5 dB，存在感频段收着。约 5 kHz 有一个窄而尖的峰，原始曲线约 +6 dBr。约 10 kHz 有一个深谷。headphonecheck 说"中高频到高频的过渡可以更收敛"，这可能就是 5 kHz 峰的听感表现（consensus 与测量吻合）。
  • 风格结论：中性偏暖、中频靠前、下潜不足，另有一个 5 kHz 尖峰。低频缺量会让它显得偏清瘦，但存在感频段的凹陷又抵消了挑错感，所以挑错度中等。

技术素质（仅评测共识）

  • 解析：3 篇评测中有 2 篇认为这个价位细节不错、"分层清楚"（headphonecheck、Major HiFi）。
  • 声场：封闭式常见的中等尺度，证据不足。
  • 动态与瞬态：1/3 评测说低频冲击不足；另有 1/3 认为加耳放后低频"更有力"。
  • 失真与左右一致性：证据不足。

佩戴与做工

重量中等，夹力适中。人造皮耳罩久戴容易闷汗（headphonecheck）。线材不可拆，这一点属于先验，未核实。

用途适配

适合入门日常听音、陪听和通勤。5 kHz 尖峰和低频下潜不足会影响判断，不宜当主力混音参考。低频量感也不适合电子乐重度用户，虽然 headphonecheck 的推荐恰好相反。手机能推，用耳放更好。

评分

  • 挑错度 52：下潜不足、有 5 kHz 尖峰，偏向挑错；2–3 kHz 凹陷、中频偏厚，又往回拉。
  • 音质 58：曲线在 5k 和 10k 附近不够平滑，评测认可它在这个价位的解析力，整体属入门水准。
  • 听歌适配 60：中频耐听，但底部偏薄、耳罩闷热，有耐听性上的扣分。
