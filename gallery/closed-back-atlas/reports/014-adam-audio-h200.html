Adam Audio H200

结论：测量显示，H200 的超低频明显抬升，约 2.8 kHz 前倾，6–8 kHz 有小峰，10 kHz 以上下滑。配套 Sonnox 校正插件，是一只务实的封闭式工作耳机。主要短板是高频延伸和夹力偏紧。 Verdict: A neutral-leaning, mid-forward closed monitor with deep, controlled bass and smooth, slightly rolled-off treble. It is a sensible, easy-to-drive studio workhorse.

频响与风格

主曲线（B&K 5128，Earphones Archive，居中佩戴，L/R 平均），对照 5128 DF、以 500 Hz–1 kHz 对齐（fr_analyze.py）： - 分频段偏差：超低频 20–60 Hz +11.1 dB，中低频 60–200 Hz +4.7，200–500 Hz +0.8，1–3 kHz +1.2，3–5 kHz −0.7，5–10 kHz +1.0，10 kHz 以上 −5.8；tilt −9.7 dB。 - 换算：偏好中性的头戴一般低频比 DF 高约 4–6 dB、高频略低于 DF。H200 的中低频（+4.7）正好在这个范围，超低频（+11）多出约 5 dB，属于“下潜深、量感足但不渗入中频”；3–10 kHz 大致贴着 DF，比偏好中性略亮。同台架对比 HD 480 Pro（低频 +8.9/+3.8，3–10 kHz 约 −3.4/−3.3），H200 低频量相近，高频多 3–4 dB。 - 特征点（相对 DF 的残差）：约 3.0 kHz 峰 +3.4（咬字靠前），约 5.0 kHz 谷 −3.9，约 6.6 kHz 峰 +6.8（齿音风险），约 12 kHz 谷 −5.9。以 1 kHz 为 0 的原始值：3 kHz +13.4、7 kHz +12.0、12 kHz −8.5。 - 五个佩戴位置平均后结论不变（+10.8 / +4.6 / … / 10 kHz 以上 −7.2）；2–12 kHz 位置间最大差 11 dB，高频受佩戴影响大。左右声道 100 Hz–10 kHz 平均差 0.6 dB、最大 2.8 dB，一致性良好。 - 与其他台架对照：GRAS 43AG-4（unheardlab，右声道）给出的 2.8 kHz 前倾、6.6/8.4 kHz 小峰、10 kHz 以上凹陷，与 5128 结果一致，没有矛盾。唯一差别是强度：5128 上 6.6 kHz 峰更突出（+6.8 对 +5.0）。 - 风格：低频深而足、3 kHz 前倾、6–7 kHz 有峰、12 kHz 附近下滑的暖向偏中性监听（measured，B&K 5128 主曲线，GRAS 佐证）。原报告“高频偏收、没有明显齿音”只对 10 kHz 以上成立；5128 显示 6–7 kHz 峰会带来轻度齿音。

技术素质

  • 解析与清晰度：好（3/4）。DIY-Audio-Heaven 认为高频下滑削弱了精致感。
  • 声场：多篇说宽，佩戴密封良好时有近似开放式的感觉（2/4）。
  • 低频控制和冲击：好（3/4）。
  • 动态：高音量时变得粗糙（1 源，DIY-Audio-Heaven）。
  • 分离度：证据不足。

佩戴与做工

铝制轭架，耳罩长圆形且有倾角，耳垫和头梁垫可更换。夹力意见不一：SOS 和 Major HiFi 认为偏紧，proaudio.tech 认为没有过大压力。SOS 还指出头梁会传导触碰噪音。

用途适配

  • 混音：中频准确、隔音好，适合录音和混音。配套插件提供 Pure 与 Uniform Natural Response 两种声音，并有外化（Externalisation）功能。插件没有系统级版本。
  • 挑错：3 kHz 和 6.6 kHz 有峰，咬字和齿音容易听出；12 kHz 以上下滑，极高频瑕疵不易察觉。
  • 听歌：低频有劲，高频不刺，比较耐听；夹力是扣分项。
  • 推力：32 Ω、97.5 dB/mW，几乎任何音源都能推。

评分

  • 挑错度 62（曲线重校：60→62，5128 显示 3–10 kHz 贴近 DF，比 HD 480 Pro 高 3–4 dB，3 kHz 和 6.6 kHz 两个峰让咬字和齿音更容易听出来；超低频多约 5 dB、12 kHz 附近下滑，所以仍低于 Hi-X60 的 67）。
  • 音质 74（维持）：低频量大但不渗入中频，左右一致性好；扣分在 3 kHz / 6.6 kHz 峰、5 kHz 谷和 12 kHz 凹陷，高频不够平滑，以及大音量下变粗（DIY-Audio-Heaven）。
  • 听歌适配 70（维持）：低频下潜讨喜，但 3 kHz 和 6.6 kHz 两个峰带来轻度齿音和前倾；夹力偏紧也扣分。

证据与置信度

  • 证据等级：measured。置信度：中高（上一轮为中）。现在有 B&K 5128 的双声道、五个佩戴位置数据，和 GRAS 43AG-4 结果一致；仍缺独立失真数据（THD 厂商数值两处转述不一致），隔音 40 dB 为厂商数据，榜单价格与市场价冲突。
