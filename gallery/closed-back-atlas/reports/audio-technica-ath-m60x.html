频响与风格

测量源： 1. oratory1990 实测。台架为 GRAS 43AG，数据取自 AutoEq 的 CSV：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Audio-Technica%20ATH-M60x 2. RTINGS 实测。台架为 HMS II.3，数据同样取自 AutoEq 的 CSV：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Rtings/HMS%20II.3%20over-ear/Audio-Technica%20ATH-M60x

对比目标：Harman over-ear 2018。用 fr_analyze.py 计算，按 500–1000 Hz 对齐。

  • 低频：20–60 Hz 比目标低约 2 dB（两家分别为 −2.4 和 −1.8 dB）；60–200 Hz 高约 1–1.5 dB。低频量感接近 Harman，只是超低频略少，属于"收敛但不缺"。（measured，2/2）
  • 中频：200–500 Hz 低约 2 dB，两家一致，RTINGS 在 430 Hz 附近还有一个小凹。1–3 kHz 两家有分歧：oratory1990 测得高约 1.9 dB，RTINGS 测得约 +0.2 dB。3–6 kHz 分别为 0 和 −2.2 dB。
  • 高频：两家都在 6.9–7.3 kHz 测到一个窄峰，高出约 4–6 dB，有齿音风险；9–12 kHz 都有凹陷，达 −6 到 −9 dB。10 kHz 以上的读数受台架影响较大，oratory1990 为 −0.9 dB，RTINGS 为 +3.9 dB，13–15 kHz 另有尖峰。
  • 风格结论（测量修正）：脚本判定 oratory1990 的数据为"中频前倾"，RTINGS 的数据为"均衡"。两家的测量都不支持"整体偏亮"或"从较低频段起大幅抬升"的说法。Sound On Sound 说的"刺、亮"，更可能来自 7 kHz 窄峰，以及 oratory1990 测到的 1–3 kHz 轻微前倾。整体属于接近 Harman 的、略偏中频的平直调音，比 M50x 更平。

技术素质

  • 解析与细节：细节清楚，中频细节好（1/2，headphonecheck）。
  • 动态：直接、有冲击感（1/2）。
  • 声场与分离：贴耳结构本来就不利于声场，评测没有给出一致描述，证据不足。
  • 瞬态：证据不足。

佩戴与做工

耳罩是长圆形，轻压在外耳上，不会夹紧，长时间佩戴也比较舒适（2/2 评测一致）。但 headphonecheck 认为佩戴偏松，不太适合移动中使用。耳垫可以更换，做工耐用。

用途适配

  • 适合：外景录音、现场扩声、DJ，以及需要便携的快速检查。
  • 混音：Sound On Sound 表示"不会是混音首选"，headphonecheck 也认为混音有更中性的选择。
  • 推力：低阻、灵敏度中高，手机可以直推。
  • 听歌：佩戴轻松，但偏亮、隔音一般，属于中等水平。

评分

  • 挑错度 58（曲线重校：维持，没有新增 5128 数据）（测量修正，原 70）：频响接近 Harman，低频不缺，presence 段没有系统性抬升，所以挑错倾向没有原先判断的强。7 kHz 窄峰和轻微的中频前倾让它比 M50x（40）更直接，但离 Hi-X60（70）还有距离。
  • 音质 70（曲线重校：维持）（原 68）：两家测量都显示整体贴合目标，主要瑕疵是 7 kHz 峰和 9–12 kHz 凹陷。解析被评为清楚。略高于 M50x。
  • 听歌适配 64（曲线重校：维持）（原 60）：调音比原先判断的更平衡，因此上调。但贴耳佩戴、隔音一般、7 kHz 齿音风险仍然扣分。
