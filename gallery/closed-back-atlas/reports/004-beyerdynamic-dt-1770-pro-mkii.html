Beyerdynamic DT 1770 Pro MkII

做工顶级、低频饱满、细节锐利的封闭监听，但调音不中性：低频抬升，presence 退后，齿音区有尖峰，更像"高解析的趣味监听"。 Superbly built closed monitor with full bass and sharp detail, but not neutral: elevated bass, recessed presence and a sibilance-region peak make it more "detailed and fun" than reference-flat.

频响与风格

5128 结果（MkII，实测减 5128 DF，dB，500 Hz–1 kHz 对齐） - 天鹅绒耳垫：20–60 Hz +8.1；60–200 Hz +5.9；200–500 Hz −1.9；1–3 kHz −1.6；3–6 kHz −1.5；6–10 kHz +0.5；10 kHz 以上 −2.5。约 216 Hz 凹陷 −5.8 dB；约 7.0 kHz 凹陷 −7.5 dB，紧接着约 7.9 kHz 峰 +8.4 dB；约 15 kHz 峰 +5.0 dB。 - 皮质耳垫（仅 R 声道）：20–60 Hz +9.6；60–200 Hz +5.2；1–3 kHz −1.2；3–6 kHz −2.4（约 4.4 kHz 凹陷 −12 dB，单声道数据，可能含佩戴因素）；约 7.9 kHz 峰 +7.7 dB；约 16 kHz 峰 +6.1 dB。

按偏好中性换算（偏好中性的头戴通常低频比 DF 高 4–6 dB、高频略低于 DF）： - 低频：超低频比偏好中性再多约 2–5 dB，皮质耳垫更多；中低频在偏好中性的上沿。整体是低频偏多，比上一版按 MkI 推测的"高 3–5 dB"略重。约 216 Hz 的凹陷把低频和中频分开，和 MkI 的 245 Hz 凹陷位置相近。 - 中频：200 Hz–3 kHz 比 DF 低 1–2 dB，属于中性略退。 - 高频：3–6 kHz 略低于 DF，presence 略退后；7.9 kHz 有 +8 dB 左右的窄峰，前面紧挨一个凹陷，是明显的齿音风险点。MkII 并没有"驯服"MkI 的 8 kHz 峰，这支持 DIY-Audio-Heaven 说它仍然尖锐的判断。

与其他台架的对照： - GadgetryTech（KB006x 仿制耳廓，对照 Harman）也测到约 8.1–8.3 kHz 的 +6～7 dB 峰和约 7.1 kHz 的凹陷，3–6 kHz 低约 3.6 dB，与 5128 一致。 - 分歧在低频：GadgetryTech 的天鹅绒耳垫只比 Harman 高约 2 dB，5128 则比偏好中性多约 2–5 dB。以 5128 为准，并注明低频量感受贴合和台架影响较大。两份数据都显示皮质耳垫低频更多。 - MkI（oratory1990）"低频厚、presence 退后、约 8 kHz 窄峰"的结论，在 MkII 的 5128 数据上基本重现，只是 MkII 的超低频更多。

结论：低频偏多的暖调，中频略退，约 8 kHz 有强窄峰，属于"低频厚 + 齿音区尖峰"的 V/U 形调音。

技术素质

  • 解析 / 细节：强（consensus，3/4 篇评测）。
  • 声场 / 定位：对封闭耳机来说较宽、有立体感，定位准（consensus，2/3 篇评测）。
  • 低频控制：多篇评测称比前代更好；DIY-Audio-Heaven 则说低频略松（意见分歧）。
  • 动态 / 瞬态：证据不足。

佩戴与做工

钢制骨架，零件标准化、便于维修，附硬壳收纳盒和两根线（consensus）。SoundGuys 连续戴几小时也不累；DIY-Audio-Heaven 测得夹力偏高（4.5–5 N），戴眼镜的人可能会有压迫感。

用途适配

  • 混音 / 挑错：可以用于审听细节，但低频抬升会影响低频判断，需要熟悉它的调音后再用。
  • 听歌：适合喜欢低频量感、又要高解析的人；对高频敏感的人会觉得不够顺滑。SoundGuys 总评 6.9/10，建议先试听。
  • 推力：30 Ω，手机也能推响。但 DIY-Audio-Heaven 指出，输出阻抗较高的放大器会改变音色，建议前端输出阻抗低于 10 Ω。

评分

  • 挑错度 57：5128 显示低频比偏好中性多 2–5 dB、presence 略退，整体偏暖；分析感几乎全来自约 8 kHz 的 +8 dB 窄峰，和 DT 770 Pro（≈55）的情况相似。曲线重校：60→57（MkII 本身的 5128 数据显示低频比按 MkI 推测的更重）。
  • 音质 81：解析、声场、做工一线；但 MkII 的 5128 数据确认了 8 kHz 强窄峰、前面紧挨的凹陷，以及超低频过量，平滑度不如 Hi-X60。曲线重校：84→81（频响不平滑的问题在 MkII 上得到直接确认）。
  • 听歌适配 72：低频饱满，presence 退后，听感不累，适合喜欢低频量感的人；8 kHz 峰对齿音敏感的人不友好；夹力和重量有争议。曲线重校：72→72（不变）。
