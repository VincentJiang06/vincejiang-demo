频响与风格

方法：主曲线用 fr_analyze.py 对比 5128 DF（--target bk5128_df --rig bk5128），以 500 Hz–1 kHz 对齐。5128 DF 是参考基线，不是偏好目标：大多数人觉得"中性"的头戴，低频比 DF 高约 4–6 dB，高频略低于 DF。下面按这个换算来解读。

B&K 5128 主曲线（Earphones Archive，相对 5128 DF） - 超低频 20–60 Hz +13.2 dB，中低频 60–200 Hz +11.3 dB。扣掉偏好中性约 4–6 dB 的抬升后，低频仍多出约 6–7 dB，属于明显加强的低频。 - 200–500 Hz +2.0 dB，略厚。1–3 kHz −2.2 dB，上中频略收。 - 3–6 kHz +1.1 dB，6–10 kHz +2.6 dB，都略高于 DF，也就比偏好中性的高频亮约 2–4 dB。约 4.4 kHz 有一个 +3.5 dB 的小峰。 - 10 kHz 以上 −4.5 dB，15–19 kHz 有多处凹陷，空气感偏少。 - 脚本判定："低频猛"，整体暖向（倾斜 −12.5 dB）。 - Listener 的 5128 合成平均（三方测量的平均）低频较少（+7.8 / +2.8 dB），3–10 kHz 为 −2.5 / −1.7 dB。它混入了未必来自 5128 的数据，只作参考。

其他台架（佐证，对比 Harman OE 2018） - oratory1990（GRAS）：超低频 +1.7，中低频 +0.6，3–6 kHz −2.3，10 kHz 以上 −2.6；约 3.9 kHz 有凹陷；判定"均衡"。 - GadgetryTech（711 仿制）：超低频 +6.1，中低频 +3.9，3–6 kHz −3.3，6–10 kHz +1.8；约 3.8 kHz 有凹陷，约 8.4 / 9.9 kHz 有小峰；判定"低频猛"。 - RTINGS（HMS II.3）：各频段相对 RTINGS 自家目标都在 ±1 dB 内，约 3.8 kHz 和 5.5 kHz 各有约 −3.5 dB 的小谷。

矛盾点（以 5128 为准）：oratory1990 的数据显示低频只比 Harman 多约 1–2 dB，而 5128 主曲线和 GadgetryTech 都显示低频明显更多。5128 五个佩戴位的低频相差不到 1 dB，所以低频量更可能接近 5128 的结果。差异可能来自个体差异，或各台架的密封条件不同。3–6 kHz 的判断也不一致：GRAS 和 711 显示约 3.8–3.9 kHz 有凹陷、该段偏少，5128 显示该段与 DF 持平或略多。

风格（曲线重校后）：暖向、低频加强的讨喜调音。低频比偏好中性多约 6 dB，上中频略收，3–10 kHz 不暗，10 kHz 以上滚降。原结论"很贴近 Harman 的中性"来自 oratory1990 的 GRAS 数据；按 5128 修正为"低频明显偏多的暖向讨喜"。 - 低频对密封敏感，要戴好才有完整低频（consensus）。

技术素质

  • 解析：同价位够用，中频略"颗粒"，高频细节与 M50x 相当（1/1 详评）。
  • 声场：封闭中较宽，约等于 HD 58X，宽于 M50x、窄于 DT 770（2/2 一致）。
  • 定位：称职，略逊 DT 770（1/1）。
  • 动态/冲击：偏弱，"slam" 不突出（1/1）。

佩戴与做工

轻量塑料机身，舒适度获好评，戴眼镜也友好（consensus 2/2）；初期夹力偏紧、一两天后放松。隐忧：橡胶头梁与伸缩机构耐久性（1 源）。

用途适配

  • 混音：适合作"消费者参考"式监听，但哈曼低频抬升需心里有数；不是挑错放大镜。
  • 听歌：强项——均衡讨喜、舒适、便携。
  • 推力：极易推，手机直推足够（measured）。

评分

  • 挑错度 43（曲线重校：45→43，因为 5128 显示低频比偏好中性多约 6 dB，暖向更明显，会掩盖低频和中低频的问题；3–10 kHz 不暗，所以只小幅下调）：偏讨喜、偏整体。
  • 音质 72（曲线重校：74→72，因为 5128 显示低频抬升超出偏好范围，10 kHz 以上滚降；原分数依据的"贴近 Harman"在 5128 上不成立）：解析与动态仍是同价位水准。
  • 听歌适配 80（不变）：低频加强、暖向调音加上舒适易推，对多数流行和电子音乐是加分项。
