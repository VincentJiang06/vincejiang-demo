Yamaha HPH-MT220

Innerfidelity 实测：中频略靠前，2–8 kHz 低于 Harman 目标，9 kHz 和 12 kHz 各有一个窄峰。它能帮人听出齿音，但并不平直，佩戴也偏硬。 Measured (Innerfidelity): mid-forward, recessed 2-8 kHz vs Harman, with narrow 9k/12k peaks; uneven rather than neutral.

频响与风格

  • 测量源 1（主锚点）：Innerfidelity 旧档案，经 AutoEq 收录。https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Yamaha%20HPH-MT220 ，raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/Innerfidelity/over-ear/Yamaha%20HPH-MT220/Yamaha%20HPH-MT220.csv 。台架为 Head Acoustics HMS II.3。对比目标是 AutoEq 为该台架换算的 Harman over-ear 2018。
  • 测量源 2（参考）：DIY-Audio-Heaven 自制台架的实测，没有经过 Harman 补偿，只用作定性对照。
  • 按 Innerfidelity 数据，与目标曲线的偏差（error 列，以 500 Hz–1 kHz 为基准，读 CSV 得出）：
  • 低频：20–200 Hz 与目标大致持平，只略少约 1 dB，没有明显的低频加量。
  • 中频：500 Hz–1 kHz 比目标高约 3 dB（1 kHz 附近最高约 +4 dB），中频略靠前。
  • 临场区：2–5 kHz 平均比目标低约 3 dB，相对中频基准就是约 -6 dB；2.5 kHz 附近最低约 -6 dB。
  • 高频：5–8 kHz 低约 4–5 dB；9 kHz 和 12 kHz 各有一个窄峰，分别比目标高约 +4 dB 和 +5.5 dB；14 kHz 附近有一个约 -10 dB 的深谷。HMS II.3 在 8 kHz 以上的读数可靠性有限。
  • 测量修正：上一版依据 DIY-Audio-Heaven，写成"中频下沉约 5 dB、7–14 kHz 宽幅约 +5 dB 的 V 型"。按 Harman 口径的 Innerfidelity 数据，更准确的描述是：中频略靠前，2–8 kHz 整体收敛；毛刺感主要来自 9 kHz 和 12 kHz 两个窄峰，而不是一整段宽的高频抬升。两台架对中频的读法相反，本报告以 Harman 口径的数据为准，同时保留"高频不平滑、有尖峰"这一点，因为两份测量在这点上一致。
  • 评测分歧：Audio Appraisal 说它"平直、极其准确"。两份测量都显示高频起伏明显，不支持"平直"。

技术素质（评测共识）

  • 解析 / 细节：细节丰富（2/2 一致）。这一印象有一部分来自高频峰的"突显效应"。
  • 声场：Audio Appraisal 称声场出色（1/2）；另一篇没有评价。证据不足。
  • 分离 / 动态：DIY-Audio-Heaven 认为动态好、分离可以，但不够顺滑（1/2）。
  • 瞬态：低频收得紧（1/2）。

佩戴与做工

耳垫较薄，驱动单元的硬塑料护盖会顶到耳朵，长时间佩戴不舒服（1 篇）。线材固定、不可更换。Reference Audio Analyzer 也有这款的测量，本次没有展开。

用途适配

  • 监听 / 挑错：高频峰和良好隔音适合录音跟踪、查齿音。不过中频下沉，拿来判断混音平衡不太可靠。
  • 听歌：两篇评测都认为它不适合放松听音乐，录音质量差的曲目会发亮、发刺。
  • 推力：37 Ω、99 dB/mW，手机或声卡耳放就能推响。

评分

  • 挑错度 52（测量修正，原 60）：临场区和中高频都低于 Harman 目标，从这一点看并不刺激；9 kHz 和 12 kHz 的窄峰会放大齿音和镲片瑕疵。两方面综合，接近 MDR-M1 / DT 770 档而略低。
  • 音质 62（原 64）：8 kHz 以上峰谷交错，高频不平滑；动态和细节的口碑尚可。整体略低于 ATH-M50x。
  • 听歌适配 58（原 55）：临场区收敛，比原先判断的耐听一些；但有窄峰，佩戴也偏硬，仍属中下水平。
