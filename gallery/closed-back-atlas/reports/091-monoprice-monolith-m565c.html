Monoprice Monolith M565C

平价封闭平板，听感柔和、人声靠前、不刺激；没有原始数值曲线，只有一张 Wirecutter 测量图：低频不厚、上中频前移、3–8 kHz 收敛。 A soft, mid-forward, non-fatiguing budget closed planar. No raw FR data exists; one Wirecutter graph (rig unstated) shows lean-ish bass, a 2 kHz lift and recessed 3–8 kHz.

频响与风格

没有原始数值曲线。 唯一能看到的测量是 Wirecutter 的图片（第四轮核实为 GRAS 43AG + KB5000），只能读出大致走向，不能当精确数值用：

  • 低频：20–200 Hz 基本平直，比 Wirecutter 图里的"Harman"低约 1–2 dB；这条"Harman"本身又比真正的 OE 2018 低约 3 dB，折算下来 低频比 Harman 少约 4–5 dB，不属于低频厚重型。ASR 上一位用户的听感也一样："不是低音炮，低频少于 Harman OE"。
  • 中频：约 1.5–2 kHz 提前抬起，峰值约 +7 dB（图中读数）。这很可能就是"人声靠前"的原因，也有用户说中频"有点不对劲"。
  • 高频：3–8 kHz 明显低于目标，7–8 kHz 附近还有一个凹陷，10 kHz 附近有回升。这和"不刺激、耐听"的共识一致。
  • 矛盾点：旧版共识写的"低频温暖、量感足"和图片不符。图上的温暖感更可能来自 3–8 kHz 收敛，而不是低频量感大。
  • 整体：低频中性偏少、上中频前移、存在感和齿音区收敛，偏柔和耐听，不是亮声挑错型。以上都来自一张图片加少量主观反馈，置信度有限。
  • 旁证（第四轮）：开放版 M565 的 ASR GRAS 测量也是"低频平、约 5 kHz 凹陷"，Wirecutter 正文也说 M565C 的中频存在感不如理想。这些都支持"3–8 kHz 收敛、不亮"的判断，只是 1.5–2 kHz 的前移幅度仍然只能从图上读。

技术素质

  • 解析和速度：平板的快速、细节好，评价较一致（2/3，consensus）。
  • 分离度：被称赞"分离出色"（1–2/3）。
  • 声场：有评测说对封闭耳机来说开阔（1/3，偏主观印象）。
  • 动态和失真：证据不足（找不到失真测量）。

佩戴与做工

木头加金属，做工被普遍认可。反复出现的缺点有：原装线有线噪（microphonic），插头要用力才能插到位；耳垫偏小，耳朵大的人可能压耳；机身 389 g，不算轻。

用途适配

适合听歌和轻度监听，不适合严格挑错。18 Ω / 96 dB/mW 的平板，手机能推响，但想要足够余量最好配小尾巴或台式放大器。
