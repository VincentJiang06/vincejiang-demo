频响与风格

5128 结果（实测减 5128 DF，dB，500 Hz–1 kHz 对齐）：20–60 Hz +6.8；60–200 Hz +4.4；200–500 Hz −1.4；1–3 kHz −1.8；3–6 kHz −1.1；6–10 kHz +2.1；10 kHz 以上 −4.7。窄峰：约 2.85 kHz +5.2 dB，约 6.8 kHz +4.1 dB，约 13.8 kHz +3.9 dB；17 kHz 以上下滑（5128 在这个频段对佩戴很敏感，参考价值低）。

按偏好中性换算：偏好中性的头戴通常低频比 5128 DF 高 4–6 dB、高频略低于 DF。据此： - 低频：+4～+7 dB，正好落在偏好中性区间，超低频只多约 1 dB。和 oratory1990 的结论一致（低频贴合 Harman，高约 1 dB）。 - 中频：200 Hz–3 kHz 在 DF 下方 1–2 dB，整体中性。2.85 kHz 有一个窄峰，oratory1990 在 2.6 kHz 也测到了，位置基本一致。 - 高频：6–10 kHz 比 DF 高约 2 dB，而偏好中性一般略低于 DF，所以这一段比偏好中性略亮，并带有 6.8 kHz 的窄峰。ASR、DIY-Audio-Heaven 说它"偏亮"，这条 5128 曲线部分支持这个说法。

与其他台架的矛盾： - 超低频：Filk（711 仿制）比 Harman 少约 4 dB，5128 与 oratory1990 都没有这个缺口。以 5128 为准，Filk 的缺口多半是贴合或漏气造成。 - 中高频：Filk 的 1–3 kHz 比 Harman 高 3.5 dB，Super Review 整体呈 V 形（16.5 kHz 有 +9 dB 峰），这两条都与 5128 和 GRAS 的结论不一致，只作参考。 - 6–10 kHz：oratory1990（GRAS）基本贴合 Harman，5128 则略高于偏好中性。以 5128 为准，结论改为"中性，6–7 kHz 一带略亮"。

结论：低频和中频都接近偏好中性，6–7 kHz 一带略亮，有几个窄峰。在这一组封闭监听里算是相当平直的调音，榜单"最平直"的说法基本成立。

技术素质

  • 失真：极低（measured，2/2）。ASR 另外提到低高频区有少量共振和失真尖峰。
  • 解析 / 细节：偏强，高频抬升有助于听出录音问题（consensus，3/4 篇评测；Audiophile Heaven 称它为 detail extractor）。
  • 声场：闭声场中等。Headfonics 说它比前代更宽，ASR 说几乎没有空间感，两方意见不一致。
  • 动态 / 瞬态：证据不足；ASR 提到群延迟很干净（measured）。

佩戴与做工

意见分歧：Headphones.com 的标题就叫 "Comfort Creature"，认为它是最舒适的封闭耳机之一，耳罩空间大；DIY-Audio-Heaven 实测夹力偏高（约 5 N），长时间佩戴有轻微头痛，线材有麦克风效应（线噪）。做工扎实，适合录音棚使用（consensus）。

用途适配

  • 混音 / 挑错：适合。抬高的高频加上低失真，能暴露录音瑕疵；但 100 Hz 鼓包会让人低估低频，需要留意。
  • 听歌：一般。DIY-Audio-Heaven 认为不做 EQ 不太适合享受音乐；ASR 加 EQ 后约七成曲目听感改善。
  • 推力：25 Ω、灵敏度高，手机或普通小尾巴就能推好。

评分

  • 挑错度 67：5128 显示整体接近偏好中性，6–10 kHz 略高于偏好中性，2.85 kHz、6.8 kHz 有窄峰，再加上失真极低，细节容易听出来，偏分析取向。曲线重校：67→67（5128 与原判断一致，不变）。
  • 音质 82：失真极低，主要频段平滑；扣分在于几个窄峰和 6–7 kHz 的轻微偏亮。曲线重校：82→82（不变）。
  • 听歌适配 72：低频量感合适，调音接近偏好中性，好推；高频略亮、夹力评价有分歧。曲线重校：72→72（不变）。
