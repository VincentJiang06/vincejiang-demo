频响与风格

  • 主测量（B&K 5128）：Earphones Archive，fr_analyze.py 对 5128 DF（以 500 Hz–1 kHz 对齐）。注意 5128 DF 是参考基线，偏好中性的头戴一般低频比 DF 高约 4–6 dB、高频略低于 DF。
  • 低频：20–60 Hz +4.8 dB、60–200 Hz +5.3 dB。换算成偏好口径，大约是"中性偏足"，不算额外抬升 —— measured。
  • 中低频：200–500 Hz +2.4 dB，略厚，带一点暖 —— measured。
  • 中频：1–3 kHz −5.1 dB，明显凹陷，人声和军鼓往后退 —— measured。GRAS 结果（−4.7 dB）与此一致。
  • 高频：3–6 kHz +2.2 dB，其中约 3.3 kHz 有 +7.3 dB 的窄峰（咬字和齿音被推前）；6–10 kHz −4.7 dB；约 10.5 kHz 有 +6 dB 窄峰；10 kHz 以上约 −10 dB，空气感明显偏少（5128 在这一段对佩戴位置敏感，只看大趋势）—— measured。
  • 风格：tilt −9.2 dB，脚本判为"低频猛/暖向"；按偏好口径换算，实际是"低频足、中低略厚、上中频凹、3.3 kHz 有峰、顶端暗"的暖向调音。
  • GRAS 佐证：oratory1990（Harman OE 2018）低频 +2.2~2.4 dB、1–3 kHz −4.7 dB、约 3.4 kHz 峰、约 8.5 kHz +7 dB 窄峰、10 kHz 以上 −3.6 dB，同为暖向下倾（tilt −4.2 dB）。
  • 矛盾点：两条曲线的高频窄峰位置不同（5128 在约 10.5 kHz，GRAS 在约 8.5 kHz），这类窄峰受耳道模拟器和佩戴影响大，以 5128 为准，但只当作"6–11 kHz 有一处窄峰"来理解。Auriculares Argentina（台架未注明）显示 3–6 kHz +3.9 dB、10 kHz 以上 +5.9 dB，判为 V 形，和前两条都不符，不采用。另外 5128 样本左右差偏大（约 2.3 dB），可能是单体差异或佩戴问题。
  • 结论：5128 与 GRAS 大方向一致：暖向、上中频凹、3.3 kHz 附近有峰。5128 显示顶端比 GRAS 更暗，3.3 kHz 峰更突出。与榜单"中性略暖"相比更偏暖。

技术素质

  • 失真/解析：SOS 给出全频 THD < 0.6%，暴露混音里的共振、浑浊与齿音能力强 —— measured（THD）+ consensus 3/3。
  • 声场/结像：偏窄、有限（headphonecheck）；SOS 未提 —— consensus 1/1，证据不足。
  • 瞬态/动态：有力，但精度不及同价位期待（headphonecheck）—— consensus 1/1。
  • 分离：证据不足。

佩戴与做工

做工、材料与可维修性获一致好评（可换线、零件可现场更换）。主要短板是夹力大，SOS 明确指出耳下方压迫感；重量偏重 —— consensus。

用途适配

  • 混音/挑错：适合中低频与齿音检查、录音现场监听（隔音强）；上中频凹陷会让部分人声/军鼓存在感判断偏差，需留意。
  • 听歌：暖厚低频讨喜，但声场窄、夹力大，长时间聆听不佳。
  • 推力：150 Ω 但 114 dB/V，对大多数输出（含手机/接口）都是轻负载。

评分

  • 挑错度 50（曲线重校：52→50，5128 显示 10 kHz 以上比 GRAS 更暗）：低频足、中低略厚、1–3 kHz 凹约 5 dB、顶端偏暗，整体偏向"整体听感"一侧；3.3 kHz 的 +7 dB 窄峰和极低 THD 让它仍能暴露齿音与共振，大致和 MDR-M1 同档，略低于 DT 770。
  • 音质 78（不变）：THD 极低、做工一流；两套台架都显示上中频凹陷和多处窄峰，平滑度一般，声场偏窄。
  • 听歌适配 68（不变）：暖厚低频和暗顶端本来讨喜，但上中频凹、3.3 kHz 峰偶有咬字发硬，加上夹力大、声场窄。
