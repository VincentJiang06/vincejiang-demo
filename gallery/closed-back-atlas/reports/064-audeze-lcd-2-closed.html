Audeze LCD-2 Closed

平面振膜封闭式里的高素质选手：低频干净、结实，失真几乎为零，声场开阔得不像封闭式；高频偏柔，612 g 的重量是主要代价。 A high-caliber closed planar: clean, taut bass, near-zero distortion and an unusually open stage for a closed-back. The treble is soft, and the 612 g weight is the main cost.

频响与风格

测量源： oratory1990 测量，AutoEq 归档 https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Audeze%20LCD-2%20Closed%20Back （raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/Audeze%20LCD-2%20Closed%20Back/Audeze%20LCD-2%20Closed%20Back.csv）。台架：GRAS 43AG-7。目标曲线：Harman Over-Ear 2018。分析：fr_analyze.py，以 500 Hz–1 kHz 为 0 dB 对齐。Crinacle 的曲线无法下载（403）。Super Review 的 711 仿制曲线已下载，作为佐证，见上一节。

  • 低频：20–60 Hz −3.8 dB，60–200 Hz 0.0 dB。中低频和 Harman 持平；超低频相对 Harman 的搁架略少，不是"低频抬升"型。〔measured, oratory1990〕
  • 中频：200–500 Hz −0.3 dB，1–4 kHz +0.5 dB，基本中性。〔measured〕
  • 高频：4–8 kHz −1.4 dB，8–12 kHz −2.3 dB，12 kHz 以上 +4.2 dB。均值接近中性，但曲线不平：约 6 kHz 有一个 +5 dB 的峰，约 9 kHz 有一个 −8 dB 的深谷，约 11.7 kHz 还有一个 +3 dB 的峰。〔measured, oratory1990〕
  • 风格判定（测量）：整体接近 Harman 的均衡曲线，向亮倾斜 +2.1 dB，主要由超低频略少、极高频略多造成。
  • 测量修正：上一版写的"比多数大平板多一两 dB 低频""高频圆润偏柔"来自 SoundStage 的描述和主观评测，与 oratory1990 的数据不完全一致。按 oratory1990 的数据，它低频中性、超低频略少，高频均值中性，但在 6 kHz 和 9 kHz 有明显的峰谷。主观上的"柔"可能来自 9 kHz 的深谷，也可能是单体或耳垫差异造成的，这里存疑。
  • 与 711 仿制曲线对照（佐证）：Super Review 的曲线同样没有低频搁架（20–60 Hz −1.0 dB，60–200 Hz +2.4 dB），整体属于均衡型，向亮倾斜 +2.3 dB。它在 8 kHz 附近有峰、在 9.8 kHz 和 12.9 kHz 附近有谷，也说明高频有明显峰谷，但峰谷的具体位置和 oratory1990 不同。它的 1–3 kHz 为 +3.4 dB，12 kHz 以上为 +9 dB，这两处差异更可能来自 711 仿制耦合器的共振和校准方式，因此以 oratory1990 的 GRAS 数据为准。两条曲线的共同结论是：低频不抬升，高频均值不暗，但峰谷明显。
  • 输出阻抗敏感：用高输出阻抗的源时，1.5–3 kHz 会抬高 1–1.5 dB。〔measured, SoundStage〕

技术素质

  • 失真：THD 接近测量底噪。〔measured, SoundStage〕
  • 瞬态衰减：2–6 kHz 有轻微梳状滤波，但阻尼远好于常见封闭式。〔measured, SoundStage〕
  • 声场：以封闭式来说宽阔、立体、有纵深。〔consensus 3/3〕
  • 解析与分离：细节丰富、透明。〔consensus 2/3〕
  • 动态：低频有力；其他方面证据不足。

佩戴与做工

  • 重 612 g，但重量分布好，多数人认为仍然舒适。〔consensus 2/3〕
  • headphonecheck 提到调节机构偏紧，头部活动时耳机不够稳。

用途适配

  • 混音/挑错：实测接近 Harman，没有低频抬升；有 6 kHz 峰和 9 kHz 谷，属于中性、耐听的参考，不是刺耳的挑错型。（测量修正）
  • 听歌：素质高、调音讨喜；重量是最大门槛。
  • 推力：101 dB/mW、70 Ω，按官方值换算约 112 dB/V。手机能推响，但实测灵敏度更低（97.5 dB），建议配一台小耳放，而且输出阻抗要低。

评分

  • 挑错度 50（测量修正，原 45）：频响接近 Harman，没有低频抬升；约 6 kHz 的 +5 dB 峰会让细节更显眼，但 9 kHz 的深谷又把它往回拉。整体处在中性区，略高于 K371，与 DT 770 相比稍低一点。
  • 音质 84：失真极低、声场突出，频响均值接近目标；6 kHz 和 9 kHz 的峰谷影响了平滑度，略低于 LCD-XC。
  • 听歌适配 77：接近 Harman，素质高；612 g 的重量和超低频略少是主要减分项。
  • 曲线重校（2026-09）：分数不变。原因是没有找到 5128 数据；新增的 711 仿制曲线和 oratory1990 的 GRAS 曲线结论一致。
