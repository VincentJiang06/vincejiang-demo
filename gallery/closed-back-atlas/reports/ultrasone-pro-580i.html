频响与风格

  • 主测量（B&K 5128，代理 HFI-580）：用 fr_analyze.py --target bk5128_df --rig bk5128 分析（以 500-1000 Hz 对齐）。相对 5128 DF：超低频 +7.0 dB、中低频 +8.7 dB、低中频 +1.4 dB、中频 0、上中频 +0.5 dB、lower treble +1.5 dB（约 4.4 kHz 有一个 -5 dB 凹陷）、6-10 kHz +3.7 dB、air -2.4 dB；约 13.5 kHz 有 +8.5 dB 的尖峰，12 kHz 与 18 kHz 各有凹陷。
  • 换算到偏好：偏好中性的头戴一般低频比 DF 高约 4-6 dB、高频略低于 DF。按这个换算，它的低频仍比偏好中性多约 2-4 dB（量足但不算轰头），中频平直，6-10 kHz 比偏好多出约 4-5 dB，13.5 kHz 有毛刺。整体是低频量足、中高频带亮点的 V 型，并不是上一轮判断的"低频缺量的亮向"。
  • 换 K371 耳垫后（佐证）：低频少 2-3 dB，1-6 kHz 与 6-10 kHz 各多约 2 dB，变成更亮的 V 型，说明这款耳机的音色对耳垫很敏感。
  • 曲线矛盾：Headphone.com 旧台架的 HFI-580 曲线（对 Harman OE 2018）显示超低频 -4.6 dB、中低频 -2.1 dB、3-4 kHz 有 +6 dB 左右的峰、整体倾斜 +5.5 dB（亮向）。旧台架的低频密闭性与耳廓模型都和 5128 不同，这里以 5128 为准；上一轮"超低频缺量、3-4 kHz 明显峰值"的结论据此撤回。两台架共同指向的是 6-10 kHz 一带偏多、超高频不平滑。
  • consensus（Head-Fi 等 2-3 处用户评测）：低频快、紧、有控制，中频偏凹，约 6 kHz 附近偶尔扎耳；5128 曲线在 6-9 kHz 偏多，与"6 kHz 附近扎耳"的主观描述大体一致。换丝绒耳垫后中频回升、尖峰减轻。
  • 结论：V 型监听，挑错感主要来自 6-10 kHz 的亮点与 13-14 kHz 毛刺，presence 段并不突出；低频量足，会掩盖一部分细节。

技术素质

  • 解析：中上，高频亮带来的"细节感"偏多（2/3 评测）。
  • 声场：S-Logic 让它在封闭耳机里显得更宽（3/3 厂商及零售文案，评测部分认同）。
  • 分离、动态：低频瞬态快、收得干净（2/3 评测）；没有找到失真实测数据。

佩戴与做工

约 295 g，佩戴舒适度评价正面；线材不可拆是主要槽点；原装耳垫为皮质，可换丝绒耳垫调整声音（consensus）。

用途适配

  • 挑错/录音监听：6-10 kHz 偏亮，齿音和刺耳问题容易听出，但峰值会夸大这些问题；低频量足，不适合用来判断低频平衡。
  • 听歌：低频量足的 V 型，流行、电子比较合适；对齿音敏感的人长时间听会累。
  • 推力：32 Ω、灵敏度偏高，手机/笔记本即可推动。

评分

  • 挑错度 60（曲线重校：72→60。5128 代理曲线显示 1-6 kHz 基本平直、低频比偏好多 2-4 dB，挑错感只来自 6-10 kHz 与 13.5 kHz 的亮点；旧台架显示的 3-4 kHz 大峰在 5128 上不存在）。大致介于 MDR-M1（≈50）与 DT 770 Pro（≈55）之上、Hi-X60（≈67）之下。
  • 音质 62（曲线重校：64→62。中频干净，但低频过量、6-10 kHz 偏多、12-18 kHz 高低起伏，平滑度一般；而且是前代型号的代理测量）。
  • 听歌适配 64（曲线重校：60→64。低频量足、presence 不突出，比原先判断的"亮向、超低频缺"更容易听歌；6-10 kHz 的亮点仍会让齿音敏感的人听久了累）。
