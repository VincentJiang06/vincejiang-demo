频响与风格

测量源： oratory1990 测量，AutoEq 归档 https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/V-MODA%20M-200 （raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/V-MODA%20M-200/V-MODA%20M-200.csv）。台架：GRAS 45BC KEMAR（oratory1990 耳罩式台架）。目标曲线：Harman Over-Ear 2018。分析：fr_analyze.py，以 500 Hz–1 kHz 为 0 dB 对齐，下列 dB 为各频段相对目标的平均偏差。

  • 低频：20–60 Hz 为 −6.4 dB，60–200 Hz 为 −4.6 dB。延伸本身不差，但相对 Harman 的低频搁架明显偏少，属于"平直低频"。〔measured, oratory1990〕
  • 中频：200–500 Hz −0.9 dB，基本中性；以 AutoEq 的原始误差看，约 250 Hz–2 kHz 整段比目标高出 2.5–4 dB，最高点在 1 kHz 附近（约 +4 dB）。这和 Sonarworks 说的"150 Hz–1.5 kHz 宽幅抬升"一致。〔measured, 两家互证〕
  • 中高频/高频：1–4 kHz −3.1 dB，4–8 kHz −10.4 dB，8–12 kHz −9.4 dB，12 kHz 以上 −6.6 dB。整体暗，3.9 kHz 附近有约 −5 dB 的凹陷；5.2 kHz 附近有一个 +6 dB 的窄峰（有齿音风险），12.8 kHz 附近还有一个 +4 dB 的小峰。〔measured, oratory1990〕
  • 风格判定（测量）：以中频为中心、暗声，整体向暖倾斜（tilt −3.3 dB）。
  • 测量修正：上一版把它写成"中频前倾、细节直给"，并按偏挑错打分。实测显示存在感区（2–5 kHz）和高频整体明显缺量，所以它实际上不是挑错型耳机。中频靠前确实会让中频的问题更容易被听到，但高频细节会被压住。MusicRadar 说的"平直准确"与两份测量都不符。
  • 一致性：Sonarworks 测到 200 Hz 以下左右声道差约 3 dB，频响对佩戴密封敏感；ASR 也报告低频声道无法匹配（图片），两家互证。oratory1990 的归档数据只有一条曲线，无法验证这一点。
  • ASR 佐证（图片）：中频贴合、低频和高频双双不足，与 oratory1990 的数值结论一致，没有矛盾。

技术素质

  • 失真：推到 90 dB SPL 仍然很干净。〔measured, Sonarworks〕
  • 解析：MusicRadar 认为细节丰富，能暴露混音问题〔consensus 1/2〕；Sonarworks 没有给出正面评价。整体证据不足。
  • 声场：典型封闭式的"包围"感，没有特别之处。〔consensus 1/2，证据不足〕
  • 动态、瞬态：证据不足。

佩戴与做工

  • 以塑料为主，铰链是金属，整体结实；耳垫磁吸，更换方便。〔consensus 2/2〕
  • 舒适度两家说法相反：MusicRadar 说舒适，Sonarworks 嫌夹力大、不适合长时间使用。

用途适配

  • 混音/挑错：曲线中频抬升、高频整体偏暗（oratory1990 实测），Sonarworks 明确说它不适合当参考监听；更适合录音跟踪（tracking），因为隔音好。
  • 听歌：人声、中频突出，喜欢这种风格的人会接受；夹力是主要减分项。
  • 推力：30 Ω、101.5 dB/mW，手机直推没问题。

评分

  • 挑错度 48（测量修正，原 62）：存在感区和高频相对 Harman 分别少约 3 dB 和约 10 dB，整体暗声，按测量应放在偏整体的一侧；1 kHz 附近的中频抬升和 5 kHz 的窄峰让它不至于太松，所以放在 K371（45）和 DT 770（55）之间。
  • 音质 68：失真低、结构扎实；但高频有深谷和窄峰，Sonarworks 还测到低频声道差，平滑度和一致性一般，与 ATH-M50x 同档。
  • 听歌适配 60：低频相对 Harman 偏少、高频暗，风格小众，加上夹力大，适合的人群比较窄。

置信度：中。 频响有三家测量（oratory1990 数值曲线，ASR、Sonarworks 图片），结论一致；缺 5128 数据。 证据缺口： 缺 squig.link / RTINGS 的原始曲线；解析和动态的共识样本太少；官方规格没有逐项核对。

曲线库补查（2026-09）： 找到 oratory1990 测量（GRAS 45BC KEMAR，AutoEq 归档，链接见"频响与风格"），它和 Sonarworks 的"中频宽幅抬升"结论互相印证。AutoEq 索引中只有 oratory1990 这一个来源，没有 crinacle、Rtings 或 Innerfidelity 的数据。现在有两家独立测量，频响风格的置信度升为中高；整体置信度仍记为中，原因是声道一致性只有一家测到，舒适度评价也有分歧。

曲线重校（2026-09）： 没有找到 5128 曲线，打分依据仍是 oratory1990 GRAS 45BC KEMAR。新增 ASR 图片佐证，它和数值曲线一致，也确认了低频声道失配。三项分数不变（挑错度 48、音质 68、听歌 60）。
