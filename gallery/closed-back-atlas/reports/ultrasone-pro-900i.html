频响与风格

AutoEq、oratory1990、squig/crinacle、RTINGS 都没有 Pro 900i 本身的测量。AutoEq 里只有老款 Pro 900 的两份数据，本节用它们作代理测量。900i 和 900 的调音是否一致没有得到官方确认，下文数值只能作参考： - Innerfidelity（Head Acoustics HMS II.3，AutoEq 补偿到 Harman 类目标）：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Ultrasone%20PRO%20900 - Headphone.com Legacy（AutoEq 没有注明台架，对比 Harman 类目标）：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Headphone.com%20Legacy/over-ear/Ultrasone%20PRO%20900

下文的 dB 值是 AutoEq error 列（测量值减目标值）的频段平均或峰值。

  • 低频（Pro 900 代理）：60–200 Hz 比目标高约 +4.5 dB（Innerfidelity）和 +1.8 dB（Headphone.com），属于明显加量，这和评测里说的"约 60 Hz 抬升、量大下潜深"一致。
  • 中频：200 Hz–2 kHz 比目标低约 −2 到 −3.6 dB，2 kHz 附近还有约 −5 到 −7 dB 的凹陷，中频凹是实测特征。
  • 中高频/高频：3–4 kHz 比目标高约 +5 到 +7 dB，6.5 kHz 附近有约 +7 到 +9 dB 的尖峰，8–9.6 kHz 有约 −5 到 −12 dB 的深凹，12–15 kHz 又高出约 +8 到 +13 dB。整体是典型的 V 型，高频多处尖锐峰谷，和评测里"4.7/6 kHz 抬升、9 kHz 凹、10–11.5 kHz 抬"的描述大体吻合（频点有偏移）。
  • fr_analyze 复核（harman_oe_2018，台架不匹配，只看趋势）：Innerfidelity 判为 V 形，中低频 +6.6 dB，10–20 kHz +10.2 dB，6.5 kHz 有 +8.6 dB 的齿音峰；Headphone.com 判为"明亮"，3–6 kHz +7.2 dB，10–20 kHz +11.8 dB，9.7 kHz 有 −14 dB 的深凹。两条曲线在超低频上不一致（+4.5 dB 对 −2.6 dB），可能是耳垫密封或样品不同造成的；在高频抬升、峰谷尖锐这一点上两者一致。
  • 结论：代理测量支持原稿"V 型、高频突出且不平顺"的判断，而且高频峰谷比原稿写的更尖锐，所以音质略下调。

技术素质

  • 声场：在封闭耳机里算宽，纵深和高度感都不错（consensus 2/2，可能和 S-Logic 有关）。
  • 解析：高频抬升让细节显得多，但这里面有"亮"造成的错觉（consensus 2/2）。
  • 分离、动态、瞬态：没有一致的评测结论，证据不足。

佩戴与做工

机身以塑料为主，带金属饰件，关节顺滑；丝绒耳垫柔软，密封好。夹力中等偏紧，耳罩大，戴眼镜的人可能不舒服（Audio46）。Major HiFi 则认为它非常舒适。线材是螺口固定。

用途适配

  • 混音/审听：高频突出，有利于发现齿音和亮部问题；但低频加量、中频下凹，拿来判断整体平衡不可靠。
  • 听歌：适合电子乐、电影这类重低频内容；对高频敏感的人不建议。
  • 推力：40 Ω，手机就能推；灵敏度单位不明，具体余量无法算，证据不足。

评分

曲线重校：本轮没有找到 5128 或 GRAS 数据，分数不变（65 / 66 / 58）。

  • 挑错度 65（原 60，按代理测量上调）：3–4 kHz 和 6.5 kHz 实测明显抬升，齿音和亮部问题容易被放大；但低频 +4.5 dB、中频凹，所以它作为"尺子"并不可信。
  • 音质 66（原 70，按代理测量下调）：高频峰谷落差超过 15 dB，不平顺；声场和低频延伸是加分项。
  • 听歌适配 58（原 62）：低频和空间感讨喜，但 6.5 kHz 和 12 kHz 以上的尖峰容易刺耳，夹力也偏紧。
