频响与风格

测量源：Innerfidelity（Tyll Hertsens）旧档对 Status Audio SM-CB1（即 CB-1 的产品编号）的测量，经 AutoEq 收录。原始 CSV 为 https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/measurements/Innerfidelity/data/over-ear/Status%20Audio%20SM-CB1.csv ，索引页为 https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Status%20Audio%20SM-CB1 。台架是 Head Acoustics HMS II.3。对比目标为 Harman OE 2018，用 fr_analyze.py 以 500–1000 Hz 对齐。脚本提示：HMS II.3 与 Harman 所用的 GRAS 43AG 不能直接互换，所以 dB 值只作方向参考。measured

  • 低频：20–60 Hz 比 Harman 少 4.5 dB，60–200 Hz 多 1.0 dB，接近中性。HMS 台架上的超低频结果受耳罩密封影响较大；DIY-Audio-Heaven 测到 -3 dB 点约在 15 Hz。两者合起来看：超低频延伸没问题，只是相对 Harman 的低频架子量感不足。measured
  • 中频：200 Hz–3 kHz 与目标的偏差都在 ±1 dB 以内，属中性。原始曲线在 1.5–2 kHz 有小幅抬升，与 DIY-Audio-Heaven 的结论一致。measured
  • 高频：3–6 kHz 少 2.2 dB，6–10 kHz 少 1.7 dB，10 kHz 以上少 1.6 dB，整体略暗。但有几处窄峰：约 3.5 kHz 高出 4.5 dB，约 9.1 kHz 高出 7.2 dB，约 14.4 kHz 高出 4.4 dB。约 16 kHz 有一个 -9 dB 的凹陷。这正是 ASR 所说的"高频共振/不平整"：均值偏暗，却带尖锐窄峰，个别曲目会显出齿音或毛刺。measured（Innerfidelity，与 ASR 方向一致）
  • 结论：中低频准中性，高频均值略暗但有几处尖峰。原稿写"8 kHz 以上滚降"大体成立，现补充 9 kHz 窄峰这一点（测量修正）。

技术素质

  • 失真：90 dB SPL 以上仍 <1%，低频三次谐波很低（DIY-Audio-Heaven，measured）；ASR 认为 94 dB 下尚可，但高频区有共振。
  • 解析/分离：2/3 评测（DIY-Audio-Heaven、Tom's Guide）认为在价位内干净自然；ASR 认为开箱平淡。consensus，低置信。
  • 声场：属于封闭式常见的小声场；各评测基本不提，证据不足。
  • 动态/瞬态：证据不足。

佩戴与做工

轻，但耳罩小，会压到耳朵上缘，而且闷热；需要密封好，戴眼镜的人不友好（ASR）。塑料机身，结实程度一般（prior）。

用途适配

  • 混音/挑错：调音大体中性、低频延伸真实，可作入门参考；高频滚降与共振会影响细节判断。
  • 听歌：平衡耐听，但舒适度扣分。
  • 推力：极易推，手机直推即可。

评分

曲线重校：分数不变。本轮没有找到 5128 或 GRAS 台架的数值数据，打分依据仍是 HMS II.3。

  • 挑错度 48：测量显示中频中性，presence 和高频均值比 Harman 低约 2 dB，本应偏整体取向；但 3.5 kHz 和 9 kHz 两处窄峰会暴露部分齿音，所以只比 50 略低（测量修正：50→48）。
  • 音质 58：失真低、低频延伸好，被曲线起伏拖累，与 HD 280 Pro 同级。
  • 听歌适配 60：声音耐听，小耳罩和闷热拉低分数。
