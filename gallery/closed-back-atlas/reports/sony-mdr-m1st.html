频响与风格

  • 主测量：Earphones Archive，B&K 5128，原装耳垫，L/R 平均；fr_analyze 以 5128 DF 为基线，在 500–1000 Hz 对齐。要注意 5128 DF 只是参考基线，不是偏好目标：大家偏好的中性头戴，低频通常比 DF 高 4–6 dB，高频略低于 DF。下面的解读已经按这个换算。
  • 低频：20–60 Hz 比 DF 低 5.8 dB，60–200 Hz 比 DF 高 1.0 dB。换算到偏好口径，超低频大约少 10 dB，中低频大约少 3–5 dB。结论是低频偏瘦，超低频明显不足，比之前读 GRAS 截图时判断的"中低频不缺"要更瘦。
  • 中频：200–500 Hz −1.0 dB，500 Hz–1 kHz 为对齐基准，1–3 kHz −1.8 dB。整体平直，但低频偏瘦，所以听感上中频靠前。
  • 高频：3–6 kHz −8.1 dB，6–10 kHz −5.6 dB，10 kHz 以上 −16.4 dB。7.5 kHz 有一个约 +7.8 dB 的窄峰（相对于平滑后的走势），9.2 kHz 附近约 +6 dB；11.5 kHz 以上有深谷。即使按"高频略低于 DF"来换算，3–6 kHz 仍明显收敛，超高频也很早衰减。
  • 样品和批次差异：中期批次第二个样品为 −5.2 / +1.5 / −6.5 / −4.7 / −15.6 dB（依次为超低频、中低频、3–6 kHz、6–10 kHz、10 kHz 以上），早期批次为 −4.8 / +0.7 / −5.4 / −3.6 / −14.0 dB，走势一致；早期批次的高频略多 2–3 dB。换装羊皮耳垫后，中低频变成 +4.4 dB、超低频变成 −0.8 dB，低频明显增加，所以耳垫对低频影响很大。
  • 与 GRAS 测量对照：Crinacle 的 GRAS 43AG-7 截图显示 5–7 kHz 凹陷、8 kHz 窄峰、10 kHz 以上急降、超低频滚降，与 5128 一致。唯一的差异在中低频：GRAS 读图约 +2～3 dB（对 Harman），5128 换算后偏少。以 5128 为准，判定低频偏瘦。
  • 风格（曲线重校）：中频前置、低频偏瘦、3–6 kHz 和超高频收敛，7.5 kHz 有窄峰的监听调音。整体听感偏暗，但 7.5 kHz 的窄峰会在齿音和镲片上带出一点锐利感。

技术素质

  • 解析（3/3 共识）：高，能听清细节，而且乐器各自的音色更容易分辨。
  • 声场（1/3）：以封闭式而言不窄，人声、吉他的定位偏近。
  • 分离、定位（1/3）：各乐器清楚可辨，便于混音时判断。
  • 瞬态（prior + 1/3）：CCAW 音圈、响应快；CD900ST 以起音快见长，M1ST 基本延续了这一点。
  • 动态（证据不足）。

佩戴与做工

头梁垫更厚，夹持比 900ST 稳（AV Watch）；约 215 g，较轻。在日本大分工厂组装，属于维修体系成熟的专业产品，但维修收费，也基本只在日本销售（Frieve）。

用途适配

  • 混音/挑错：适合编曲、混音前段的制作；有评测认为人声录音时 900ST 更顺手，混音前段则 M1ST 更好用。
  • 听歌：比 900ST 讨喜，但仍是明亮清晰的监听调音。
  • 推力：24 Ω、103 dB/mW，手机或小尾巴就能推到足够音量。

评分

  • 挑错度 62（曲线重校：62→62，维持）：5128 显示低频偏瘦、中频裸露，有利于听清中频细节；7.5 kHz 的窄峰会暴露齿音。但 3–6 kHz 下凹约 8 dB，10 kHz 以上也衰减得早，对高频瑕疵的放大明显弱于 CD900ST 和 MDR-7506（80），因此仍高于 MDR-M1（50）、低于 Hi-X60（67）。
  • 音质 71（曲线重校：74→71，5128 显示低频比偏好口径少约 3–10 dB，而且 3–6 kHz 凹陷、7.5 kHz 窄峰、超高频早衰三处问题同时存在）：80 Hz–3 kHz 走势平顺，评测也认可它的解析；但频响的完整度不如 DT 770 Pro（72）一档。
  • 听歌适配 63（曲线重校：66→63，低频比之前判断的更瘦，氛围感和冲击力不足）：高频不刺、佩戴好，是加分项；换装更厚的耳垫可以补回低频。
