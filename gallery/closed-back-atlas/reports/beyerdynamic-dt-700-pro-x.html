频响与风格

测量源：没有 5128 数据，按 GRAS 为主。oratory1990（GRAS 45BC KEMAR）对 Harman OE 2018，fr_analyze.py 以 500 Hz–1 kHz 对齐。

  • 低频：20–60 Hz −1.5 dB，60–200 Hz +0.6 dB（100 Hz 附近约 +2.5 dB）。低频量接近目标，略带中低频加强。（measured）
  • 中频：200–500 Hz −2.5 dB，约 250 Hz 有约 −3 dB 小凹，和 DIY-AH 结果一致；1–3 kHz +0.7 dB，基本贴合。（measured）
  • 高频：约 3.9 kHz 有一个窄而深的凹陷（约 −9 dB，Q 高，听感影响小），拉低了 3–6 kHz 均值（−2.8 dB）；约 6.2 kHz 有 +4.7 dB 的小峰；6–10 kHz −1.6 dB，约 9.4 kHz 有小凹；10 kHz 以上 +0.2 dB。没有拜亚传统的尖锐大峰。（measured）
  • 风格：脚本判为"均衡"（tilt −1.0 dB），接近 Harman 的中性调音。
  • 交叉核对：Kuulokenurkka（711 仿制台架）结果几乎相同：250 Hz 凹 −2.8 dB、3.9 kHz 凹 −11 dB、约 6.1 kHz 峰，判为"均衡"。RTINGS（HMS II.3）低频更少（−3.3 dB）、6–10 kHz +6.2 dB、约 8.6 kHz 峰，偏亮；但 HMS 台架与 Harman OE（GRAS 目标）不能直接比，结论以 GRAS 为准。几条曲线的共同点是：约 4 kHz 窄凹、250 Hz 小凹、6 kHz 附近有小峰。SOS 听到的低中频膨胀在三条曲线上都看不出来。

技术素质

  • 解析：清晰度好，“真实自然”。（consensus 3/3：SOS、DIY-AH、SoundGuys）
  • 声场：封闭结构，声场比 DT 900 Pro X 窄。（consensus 1/1，证据较弱）
  • 分离：低频和中频之间略脱节，对乐器分离有一点影响。（1/1）
  • 动态、瞬态：证据不足。实测失真低，只能间接支持。

佩戴与做工

多为金属结构，欧洲制造，零件可更换，做工扎实（SOS）。丝绒耳垫柔软，戴眼镜也比较友好。缺点是出厂夹力偏大、重量约 350 g，有用户反馈头梁垫几个月后会变形。

用途适配

  • 录音/跟踪：很合适，隔音好、不漏音。
  • 混音/挑错：可以用，但 SOS 提醒低中频膨胀可能影响判断，精细混音更推荐开放版 900。
  • 听歌：调音讨喜、高频不累，适配度高。
  • 推力：48 Ω、约 103 dB/mW，手机和声卡都能推响。

评分

曲线重校：无变化。本轮没有找到 5128 数据，三条非 5128 曲线结论一致，分数维持。

  • 挑错度 55：接近中性，但低频有抬升、高频偏收，放大瑕疵的能力一般，和 DT 770 大致同档。
  • 音质 80：实测平衡、失真低，高频处理在拜亚里很突出，但低频与中频衔接不算完美。
  • 听歌适配 80：调音耐听、好推，佩戴只是夹力偏紧。
