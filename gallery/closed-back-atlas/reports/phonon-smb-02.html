频响与风格

  • 测量源：Innerfidelity 旧档案，经 AutoEq 收录，条目名为"Phonon SMB2"。https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Phonon%20SMB2 ，raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/Innerfidelity/over-ear/Phonon%20SMB2/Phonon%20SMB2.csv 。台架为 Head Acoustics HMS II.3。对比目标是 AutoEq 为该台架换算的 Harman over-ear 2018。Innerfidelity 在 2018 年前停止更新，而 SMB-02G 是后来才出的，所以这份数据应该是原版 SMB-02（推断）。
  • 与目标曲线的偏差（error 列，读 CSV 得出）：
  • 超低频：40 Hz 以下开始衰减，20–60 Hz 平均比目标低约 2.4 dB，30 Hz 约 -3 dB。
  • 中低频：60–500 Hz 比目标高约 2–3.5 dB（200 Hz 附近约 +3.5 dB），属于暖、厚的中低频。
  • 中频：500 Hz–2 kHz 基本贴合目标，偏差在 0 到 +2 dB 之间。
  • 临场区：2.5–4 kHz 比目标低约 2–4 dB，略收；5 kHz 处有一个很窄的深谷（约 -14 dB）。
  • 高频：6–8 kHz 低约 3.5 dB；9–12 kHz 高约 2–3 dB，带一点空气感；14 kHz 以上低约 3–4 dB。
  • 风格结论（measured）：中低频饱满、临场区略收、高频有少量亮点，是偏暖、偏耐听的混音监听调音。这和日文评测"中低频饱满但沉稳、高频细腻"的描述基本一致。测量不支持"声音往前靠"的说法，因为临场区是收的；5 kHz 的窄谷也可能让人声显得偏后。
  • 风格（consensus，2 篇日文评测 + 厂商描述）：评测说它空间感好、信息密度高。厂商说由母带工程师熊野功调音（厂商说法，prior）。

  • 空间 / 定位：两篇都说声场开阔、定位清楚（2/2，厂商也这样宣传）。
  • 解析：信息量大，好录音和差录音的差别一听就出来（1/2）。

  • 说明：以上都是日文用户、店铺类的主观评测，属于印象型来源，有偏正面的倾向。

佩戴与做工

耳垫厚度适中，戴眼镜也不难受，连续戴 2 小时不累（2 篇）。标配 3 m 四芯独立地线和可翻转的 6.3/3.5 mm 插头。

用途适配

  • 混音 / 挑错：在日本电子乐和混音圈有口碑，评测反映低频和空间判断比较可靠。不过缺少测量，无法确认它的中性程度。
  • 听歌：评测普遍认为耐听、有冲击力，适配度中上。
  • 推力：40 Ω、100 dB/mW，手机可以推响。

评分

  • 挑错度 45（测量修正，原 55）：中低频比 Harman 多约 2–3 dB，临场区收约 2–4 dB，除 5 kHz 窄谷外没有尖锐的高频峰，偏整体混音取向，与 AKG K371 同档。
  • 音质 72：除了 5 kHz 窄谷，整条曲线起伏不大，评测对空间感的口碑也一致，维持在 DT 770 档。
  • 听歌适配 72（原 70）：暖而不刺，佩戴舒适，测量支持"耐听"这一评价；隔音和佩戴形式仍然存疑。
