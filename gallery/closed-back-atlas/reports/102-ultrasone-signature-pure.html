Ultrasone Signature Pure

低频加强的暖色调封闭耳机，presence 到位，5.7k 有深凹陷、8k 有窄峰，隔音强，适合娱乐听歌，不适合做挑错监听。 A bass-boosted, warm closed-back with a deep ~5.7 kHz notch and an ~8 kHz peak. Strong isolation; a fun listener, not an analytical monitor.

频响与风格

  • 主依据：B&K 5128（EarphonesArchive），对比 5128 DF，结果为 measured。DF 只是参考基线，不是偏好目标：偏好中性的头戴，低频通常比 DF 高约 4–6 dB，高频略低于 DF。按这个换算后逐段看：
  • 超低频 +9.9 dB、中低频 +7.8 dB：换算后仍比偏好中性多约 4 dB，属于明确的低频加强型。
  • 中低频 −1.1 dB，中频 0 dB：基本中性。
  • 1–3 kHz −1.5 dB：presence 没有缺失。
  • 3–6 kHz −5.5 dB：主要被一个很深的窄凹陷拉低。
  • 6–10 kHz 与 DF 持平。
  • 10 kHz 以上 −7.2 dB，空气感偏少。
  • 整体倾斜 −13.1 dB，自动判定为“低频猛 / 暖向”。
  • 形状细节（5128，以 1 kHz 为 0 dB）：
  • 3–3.5 kHz 为 +8~+9 dB，与 DF 的耳道增益基本同高，不算异常尖峰。
  • 约 5.7 kHz 有一个很深的窄凹陷，相对目标残差约 −24 dB。它的深度可能部分来自 5128 的耦合，但 GRAS 43AG-4 曲线上同一位置也有约 −10 dB 的凹陷，所以凹陷本身可信。
  • 约 8.2 kHz 有 +8 dB 的窄峰，三条曲线都有（GRAS +9 dB，kr0mka +5.6 dB），有齿音和刺感风险。
  • 12 kHz 以上下降约 7 dB。
  • 曲线之间的矛盾（以 5128 为准）：
  • 上一轮只用 kr0mka 对比 Harman，把 3 kHz 写成“明显尖峰”。三条曲线在 3 kHz 处其实同样高出 1 kHz 约 8–10 dB，在 5128 DF 下这属于正常耳道增益。修正为“presence 基本到位，不算尖峰”。
  • kr0mka 的凹陷在 4.5 kHz，5128 与 GRAS 的凹陷在 5.7 kHz，位置不同，可能来自台架或佩戴差异。
  • kr0mka 在 7.5 kHz 有 −8 dB 的凹陷，5128 上没有。
  • 与共识一致：评测也说它低频为核心、高音不累（1/1）。5128 的数据支持“低频强、10 kHz 以上偏暗”，但中频并不明显后退。

技术素质（评测共识，N=1，另有一个聚合站）

  • 解析、声场、分离：Audiophile Heaven 评价高于同价位（1/1，属于印象型来源，按规则降权）。
  • 动态、瞬态：证据不足。
  • Frieve 聚合站总分 2.8/5，偏保守，理由之一是缺少独立测量。

佩戴与做工

  • 夹力很大，需要把头梁拉到接近最大。
  • 新版耳垫和头梁垫都更厚（Audiophile Heaven）。
  • 耐用性方面没有多来源证据。

用途适配

  • 混音/挑错：不理想。低频比偏好中性多约 4 dB，5.7k 深凹陷、8k 窄峰和 12k 以上滚降会误导判断（依据 5128）。
  • 听歌：适合电子、说唱、金属，也适合通勤隔音；不适合古典或追求中性的听法。
  • 推力：规格上是 32 Ω、114 dB，看起来好推，但评测说要大推力才好听。规格和评测说法冲突，折中处理。

评分

  • 挑错度 40。曲线重校：35→40（5128 显示 1–3 kHz 没有缺失，8.2 kHz 的峰会暴露齿音）。低频比偏好中性多约 4 dB，10 kHz 以上偏暗，5.7 kHz 有深凹陷，所以仍然偏娱乐向，不适合做主力挑错。
  • 音质 60（不变）。5128 证实中高频是锯齿状：5.7 kHz 深凹陷、8.2 kHz 峰、12 kHz 以上滚降，低频也偏多。技术力方面只有单一正面评测支撑。
  • 听歌适配 64（不变）。低频饱满、隔音强，但夹力大，8 kHz 峰可能带来疲劳。

证据与置信度

  • 证据等级：measured。有 B&K 5128 的 L/R 数据，另有 GRAS 43AG-4 和 kr0mka 两条曲线佐证。
  • 置信度：中。
  • 5128 测的是 White 配色版，与标准版声学结构相同这一点没有官方文件证实。
  • 价格和单元规格（40 mm 对 50 mm）存在冲突。
  • 技术力方面只有单一评测。
