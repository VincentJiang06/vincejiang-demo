12 kHz 以上 明显滚降，这一段受台架影响大，不作结论

fr_analyze（harman_oe_2018 目标；台架不匹配，只看趋势）给出的结果是"暗声、暖向"，倾斜 −4.2 dB。左右声道在 100 Hz 相差约 2.4 dB，1 kHz 以上基本一致。

  • 低频：40–150 Hz 比 DF 高约 4–5 dB，正好落在偏好中性的头戴常见的低频加量范围内；20 Hz 附近略有衰减。这和评测里"punchy、有冲击"的说法一致。
  • 中频：300 Hz–1 kHz 平直；1–4 kHz 比 DF 低 3–4 dB，人声和乐器的前冲感稍收。这与 Home DJ Studio "中频略收"的描述相符。
  • 高频：4–9 kHz 比 DF 低约 10 dB，低于偏好中性头戴通常只比 DF 低几 dB 的水平，整体偏暗、偏柔。8 kHz 附近的窄峰可能就是 Pocket-lint 说的"fizzing"质感。
  • 与旧结论的矛盾：上一轮根据评测共识推断为"高频偏亮的轻 V 型"。实测只支持"低频加量"这一半，高频整体偏少，不算亮。按本轮规则以测量为准，风格改判为低频加量、高频收敛的暖暗型 DJ 调音。由于没有 5128 或 GRAS 数据，而仿制台架的高频本身不确定性较大，"偏暗"的幅度应打折看待。

技术素质

  • 解析：中上（3/4 篇评测称清晰度好）。
  • 声场：Home DJ Studio 认为比一般 DJ 耳机宽；OnTheDex 认为不如 X10 开阔（1 篇支持、1 篇反对）。
  • 动态：大音量下不失真、不发散，这是共识强项（3/4 篇）。
  • 分离、瞬态：证据不足。

佩戴与做工

做工和耐用性口碑很好，属于强共识。夹力明显偏大，Home DJ Studio 和 Pocket-lint 都提到长时间佩戴有压迫感，但耳垫柔软（consensus，2 篇）。

用途适配

主要面向 DJ 现场监听和对拍，不适合做混音或挑错参考。阻抗约 32–36 Ω、额定灵敏度 102–106 dB，手机能推响，但要开到 DJ 现场的音量，最好接专业输出。

评分

  • 挑错度 36（曲线重校：42→36）：实测高频明显偏少、低频加量，属于讨喜的暖声调音，暴露细节的能力比原先推断的"偏亮 V 型"更弱。
  • 音质 58（曲线重校：60→58）：低频和中频比较平顺，但 4–9 kHz 凹陷很深，还有 8 kHz 窄峰；再加上 100 Hz 处约 2.4 dB 的左右差，技术面扣分。
  • 听歌适配 62（曲线重校：60→62）：暖声、低频有量，适合长时间听流行和电子乐，也不刺耳；但夹力偏大，所以只小幅上调。
