频响与风格

  • 测量源：oratory1990 测量（AutoEq 收录，raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/AKG%20K271%20MKII/AKG%20K271%20MKII.csv ）。台架为 GRAS 45BC KEMAR 耳模拟器。对比目标：Harman OE 2018，以 500–1000 Hz 对齐，用 fr_analyze.py 分析。交叉参考：AutoEq 另收有 Innerfidelity（Head Acoustics HMS II.3）和 Headphone.com Legacy 的数据，本节不作主依据。
  • 低频：20–60 Hz 比目标低约 14.8 dB，60–200 Hz 低约 7.5 dB，属于大幅缺量，比 Harman 类目标薄很多。[measured]
  • 中频：200–3000 Hz 基本贴合目标（−0.7 至 0 dB）。上一版引用 Frieve 转述的"200–630 Hz 抬升 +7~+9 dB"，与本测量不符，测量修正：中频不算突出，只是低频缺量让中频显得靠前。[measured]
  • 高频：3–6 kHz 平均比目标低约 5.5 dB（5.2 kHz 附近有凹陷），7.4 kHz 和 8.3 kHz 有窄峰（残差约 +4.5 dB，齿音风险），6–10 kHz 平均 +0.9 dB。12.6 kHz 有约 +6.6 dB 的尖峰，15.4 kHz 附近凹陷，10 kHz 以上平均 −4.2 dB。[measured]
  • 风格：低频大幅缺量，整体明显向亮倾斜（分析器给出的 tilt 为 +8.2 dB，属于亮向）。存在感频段（3–6 kHz）凹陷，高频由 7–8 kHz 和 12.6 kHz 的窄峰构成，所以听感是"清楚、带齿音、偏薄"，而不是存在感频段刺耳。这与评测共识"中高频清晰、低频少"一致。

技术素质

  • 解析与细节：2/3 篇评测称中高频细节好，人声和弦乐清晰（MusicRadar、Headphone Day）。[consensus]
  • 声场：在封闭式里算"不错"，定位够用（1/3）。[consensus，弱]
  • 分离、动态、瞬态：证据不足。

佩戴与做工

轻，夹力适中，适合长时间佩戴（MusicRadar）；机身多为塑料，不能折叠，不附收纳包。自带两套耳垫、可换线，还有取下即静音的功能，录音棚和广播场景很实用。

用途适配

  • 混音/挑错：适合检查人声、原声乐器和齿音；低频判断不可靠，需要配合音箱或其他耳机。
  • 听歌：低频少、高频偏亮，听流行和电子乐吸引力一般。
  • 推力：55 Ω / 104 dB/V，手机直推就够。

评分

  • 挑错度 68：测量上低频严重缺量，7–8 kHz 和 12.6 kHz 有窄峰，容易暴露齿音和高频毛刺，所以挑错度偏高。但 3–6 kHz 凹陷，存在感频段不放大，因此仍低于 MDR-7506/M70x（测量校正 +2）。
  • 音质 60：高频峰谷多、不平滑，低频延伸差，老设计的特征明显；中频贴合目标是加分项（测量校正 −2）。
  • 曲线重校：分数不变（没有 5128 曲线；HMS II.3 的佐证曲线与 GRAS 结论一致）。
  • 听歌适配 53：佩戴舒适，这点加分；低频比 Harman 少 7–15 dB，高频有窄峰，这点减分。
