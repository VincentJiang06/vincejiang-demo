FiiO FT1

木壳、60mm 单元的平价封闭耳机，调音偏暖，低频厚，中频自然，适合听歌；高频不够平顺，定位一般，不适合挑错。 Warm, bass-rich wooden closed-back with natural mids — a strong-value music headphone, but uneven treble and soft imaging rule it out for critical monitoring.

频响与风格

主依据：B&K 5128（EarphonesArchive，居中佩戴）。fr_analyze.py 的目标为 bk5128_df，以 500–1000 Hz 对齐。5128 DF 只是参考基线，偏好中性的头戴一般低频比 DF 高约 4–6 dB、高频略低于 DF，下面的解读已按这个换算。 - 低频：20–60 Hz 比 DF 高 +10.5 dB，60–200 Hz 高 +7.0 dB。扣掉偏好中性应有的 4–6 dB 后，超低频仍多约 5 dB，中低频多约 1–3 dB。所以它的低频是明显加量、偏超低频的暖声，比 GRAS 数据看起来还要多一点。5 种佩戴位置的读数几乎一样（±0.1 dB），低频密封很稳。 - 中频：200–500 Hz 为 +1.7 dB，略厚；500 Hz–3 kHz 与 DF 相差不到 ±0.3 dB，线性、自然。 - 高频：3–6 kHz 为 -0.9 dB，6–10 kHz 为 -1.2 dB，10 kHz 以上为 -0.7 dB。平均正好落在"略低于 DF"这一偏好区间，不算暗。形态是锯齿状：约 5.9 kHz 有峰（残差 +4.6 dB，有齿音风险），约 9 kHz 有谷，约 14–15 kHz 和 17.5 kHz 有窄峰（+4–5 dB）。高频细节随佩戴位置变化明显：前移时 15 kHz 峰达 +12 dB、12 kHz 出现 -7 dB 谷，上移时 9.5 kHz 谷为 -5.5 dB。 - 整体：工具判定"低频猛 / 暖向"，倾斜约 -9.7 dB（相对 DF）。换算后可以概括为：中性偏好曲线上再加约 5 dB 超低频，中频平直，高频平均量合适但不平顺。

佐证（GRAS 与 711 类台架，目标 Harman OE 2018）： - 低频：五份测量都比 Harman 多约 3–5 dB（oratory1990 +3.3/+3.1，Sai +3.4/+3.1，Kuulokenurkka +4.7/+3.3，GadgetryTech +4.2/+3.8，Super Review +3.7/+2.8），与 5128 的结论一致。 - 高频：GRAS/711 类数据中 6–10 kHz 普遍比 Harman 少 3–4 dB（oratory1990 -4.2），而 5128 在同一频段只比 DF 少约 1 dB。这是矛盾点，以 5128 为准：6–10 kHz 并不明显偏少，主要问题是峰谷不平，而不是整体偏暗。 - 约 5–6 kHz 的峰和约 14 kHz 的窄峰在各台架上都能看到，属于稳定的形态特征。

技术素质

  • 解析：尚可，但不以微细节取胜，重在动态和投入感（consensus，2/3 篇评测）。
  • 声场：在封闭耳机里算开阔，没有闷罐感（Kuulokenurkka）；但 Audio46 认为声音"抱团"，听起来比实际窄。两者存在分歧。
  • 分离与定位：定位一般（Audio46，1/3 篇评测）。
  • 动态：较好（consensus）。
  • 瞬态：证据不足。

佩戴与做工

  • 夹力和贴合都好，头梁垫虽薄但舒适（consensus）。
  • 头梁的金属边缘偏锐利。
  • 线材和布面耳垫有摩擦噪声。
  • 耳罩偏大，头小的用户可能密封不好。

用途适配

  • 主要适合听歌，混音或挑错时只能做参考。
  • 推力要求低，手机小尾巴就能推，接更好的放大器还会有提升。

评分

  • 挑错度 35（曲线重校：35→35，不变）：5128 显示低频加量比 GRAS 数据更多（超低频比偏好中性多约 5 dB），整体更偏讨喜；但 6–10 kHz 并不像 GRAS 数据那样偏少，5.9 kHz 与 14–15 kHz 的窄峰会带来局部的亮点。两方面相互抵消，分数维持不变。
  • 音质 70（曲线重校：70→70，不变）：中频在 5128 上与 DF 相差不到 ±0.3 dB，线性很好；扣分来自超低频加量偏多、高频锯齿（且随佩戴位置变化大），以及定位一般。
  • 听歌适配 78（不变）：中性偏好曲线加上约 5 dB 超低频，本身就很适合流行和电子音乐；加上好推、舒适，性价比高。
