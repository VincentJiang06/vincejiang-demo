频响与风格

  • 测量源：oratory1990 的 Takstar Pro 82 测量，经 AutoEq 收录，https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Takstar%20Pro%2082 （raw CSV）。台架为 GRAS 45BC KEMAR 类耳罩式人头台架（oratory1990 的标准台架）。低频拨杆档位数据页未注明，按默认档理解。
  • 分析方法：用 fr_analyze.py 对比 Harman OE 2018 目标曲线，按 500–1000 Hz 对齐。AutoEq 的 error 列（相对 oratory1990 目标）作交叉核对。
  • 低频：20–60 Hz 比 Harman 少约 1.6 dB；60–200 Hz 高约 0.7 dB，100 Hz 附近约 +3 dB。整体接近 Harman 的低频搁架量，并不“偏薄”；开 +3/+6 dB 档后会高于 Harman（每档约 +3 dB，Frieve/RAA 实测）。
  • 中频：200–500 Hz 约 −1.1 dB，基本中性；1–3 kHz 约 +2.0 dB（原始曲线在 2–3 kHz 明显隆起）。人声和吉他会显得偏前。
  • 高频：3–6 kHz 比目标少约 2.9 dB，AutoEq error 在 4 kHz 约 −4.6 dB；6–10 kHz 约 −1.2 dB，其中 8 kHz 附近有 +4 dB 窄峰（齿音风险），9.2 kHz、10.9 kHz 各有约 −6.6 dB 和 −4.2 dB 的凹陷；10 kHz 以上的 air 段约 +5.1 dB，14.7 kHz、16 kHz 有尖峰。
  • 第二台架佐证（Sai，GRAS 43AG-4，只有 R 声道）：bass-1 档对比 Harman 的结果为 1–3 kHz +1.4 dB，3–6 kHz −2.5 dB，air 段 +4.5 dB；8.5 kHz 有 +6.9 dB 窄峰，9.5 kHz 有 −8.3 dB 凹陷。这些与 oratory1990 的结论一致：上中频前倾，8 kHz 附近有齿音峰，超高频偏多。低频方面，bass-1 档的 20–60 Hz 为 −3.2 dB，60–200 Hz 为 −1.5 dB；bass-2 档分别为 +1.7 dB 和 +4.7 dB；bass-3 档再往上加。oratory1990 的低频量（+0.7 dB）落在 bass-1 与 bass-2 之间，更接近 bass-1，所以推测它测的是最低档或接近最低档。两台架之间没有实质矛盾。
  • 小结（测量修正）：原先按主观评测写成“默认档偏亮的 U 型”，测量不支持。实际是低频接近 Harman、2–3 kHz 上中频前倾、4–6 kHz 回收的形态，工具判定为“中频前倾”（mid-forward）。主观上的“亮、有劲”主要来自 2–3 kHz 抬升、8 kHz 窄峰和超高频 air 峰，而不是整个高频段都偏多。

技术素质

  • 解析：细节感强，一部分来自偏亮的高频（consensus）。
  • 声场：不算宽，但定位准确、连贯（SoundGearLab，1 篇）。
  • 分离、动态、瞬态：证据不足。

佩戴与做工

  • 轻、软，长时间佩戴舒适，是被反复称赞的强项（consensus）；天热时耳罩闷热。
  • 做工以价位看不错。可靠性警示：Frieve 引用 DIY-Audio-Heaven，称约 1.6 V（约 80 mW）持续输入 30 秒后音圈烧毁，并提到声道不平衡和品控波动。这只是单一来源，未能交叉核实，所以可靠性分只作参考。

用途适配

适合练习、跟听，也适合作为入门听歌耳机；混音时高频偏亮、中频偏后，需要对照其他设备。实测约 100 dB/mW，手机直推很轻松，但不要长时间大功率驱动。

评分

曲线重校：分数不变。本轮没有找到 5128 数据；新增的 Sai 43AG-4 曲线与 oratory1990 的结论一致。

  • 挑错度 55：测量上 1–3 kHz 抬升约 2 dB，8 kHz 有窄峰，air 段偏多，能凸显人声、吉他和齿音；但低频接近 Harman，4–6 kHz 回收，整体不刺耳，所以维持中位，算不上严格的挑错耳机。
  • 音质 57：频响有多处 ±4–6 dB 的窄峰窄谷，Frieve 汇总的低频失真超过 1%，左右一致性也有品控疑问，限制了上限。
  • 听歌适配 64：低频量接近 Harman、可以上调，佩戴舒适，讨喜度较高；上中频前倾和 8 kHz 峰会带来一些疲劳，扣分。
