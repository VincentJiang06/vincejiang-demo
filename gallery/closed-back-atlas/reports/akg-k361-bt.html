频响与风格

  • 主依据（B&K 5128，RTINGS，有线 K361）： 以 5128 DF 为基线，500–1000 Hz 对齐。
  • 与 DF 的偏差：超低频 +9.8 dB，中低频 +5.5 dB，低中频 −0.2 dB，上中频 −1.0 dB，低高频 −3.0 dB，中高频 −0.7 dB，空气感 −6.9 dB。
  • 偏好中性的头戴通常低频比 DF 高 4–6 dB、高频略低于 DF。按这个标准换算：中低频基本在"偏好中性"范围内，超低频再多约 4–5 dB，属于低频略足、延伸好。上中频贴近中性；低高频和空气感比偏好中性略暗。
  • 分析器的原始判定是"低频猛 / 暖向（tilt −11.2 dB）"。这个判定是相对 DF 做的，换算到偏好基线后应读作温和偏暖，不算重低音。
  • 窄带特征：约 9.3 kHz 有尖峰（残差 +8.8 dB，齿音和毛刺的主要来源）；约 3.1 kHz 有小峰（+4.2 dB）；12.7 kHz、16.7 kHz、17.9 kHz 有深谷（−7 至 −9 dB）。
  • 佐证（其他台架，对比 Harman OE 2018）：
  • oratory1990（GRAS）：低频 +2.8 dB / +2.1 dB，约 3.9 kHz 有凹陷，8.8 kHz 和 13 kHz 有尖峰。
  • Listener（KB006x 仿制台架，3 次佩戴平均）：超低频 +4.6 dB，低高频 −6.2 dB。
  • Kuulokenurkka（KB501x + 711）：低频 +4.4 dB / +4.1 dB，低高频 −1.7 dB。
  • 四个台架都显示低频略多于中性、中频平直、9 kHz 附近有峰、高频起伏大。
  • 矛盾点： 3–4 kHz 区域各台架结果不一致。RTINGS 5128 在 3.1 kHz 有小峰，oratory1990 在 3.9 kHz 有凹陷，Listener 的低高频整体偏少。本报告以 5128 为准：presence 区不存在明显凹陷，但整体略偏暗，不刺耳。
  • 风格： 温和偏暖的中性监听取向。低频足、中频平直，高频整体略收，但 9 kHz 有尖峰。
  • K361 与 K371（oratory1990，同一台架）： K371 高频更顺，没有 9 kHz 峰。
  • 蓝牙模式（consensus，1 篇）： MusicRadar 认为无线时声音单薄、中频有鼓包，有线时更暖、更清晰。没有测量数据。

技术素质

  • 解析：测量显示高频有共振峰，DIY-Audio-Heaven 认为精致度不如同级。
  • 声场：2 篇对比评测都认为 K371 声场更开阔，K361 较紧凑（consensus）。
  • 分离、动态、瞬态：证据不足。
  • 失真：没有找到独立数据。

佩戴与做工

夹力较小，重量轻（塑料伸缩臂），耳垫很软，适合长时间佩戴（2 篇评测）。代价是做工观感偏"玩具"，不如 K371 扎实。卡口可拆线是加分项。

用途适配

  • 混音与挑错：有线使用时，中低频的平直度对检查低频平衡有用；高频不平滑，会影响对齿音和细节的判断。
  • 听歌：蓝牙方便，但音质打折扣；MusicRadar 认为中等音量下也可能疲劳。
  • 推力：114 dB/V、32 Ω，手机直推没有压力。

评分

  • 挑错度 50（曲线重校：52→50。5128 曲线换算到偏好基线后，低频略足，高频和空气感整体略暗，只有 9 kHz 峰会凸显齿音，整体比先前判断更暖。与 MDR-M1 同档）。
  • 音质 66（曲线重校：不变。5128 曲线同样显示 9 kHz 峰和 12–18 kHz 深谷）：中低频平直、延伸好；高频有尖峰与深谷交替，两个台架结果一致，平滑度一般；蓝牙模式另外扣分。
  • 听歌适配 70（曲线重校：不变）：轻、舒适、有蓝牙，低频量感足够；9 kHz 峰和蓝牙音质限制了听歌体验。
