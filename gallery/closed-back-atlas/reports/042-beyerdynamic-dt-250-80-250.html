Beyerdynamic DT 250 (80/250 Ω)

中文结论：实测接近平直的轻量封闭监听，均衡耐用、隔音中等；高频略粗糙，夹力偏大，属于老派广播监听工具。 One-line verdict: A light closed-back broadcast monitor that measures close to flat. It is balanced and durable, with only moderate treble refinement and fairly high clamping force.

频响与风格

测量源（主锚点）：oratory1990，DT 250（250 Ω），GRAS 43AG 类耳罩台架。数值化 CSV 来自 AutoEq：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Beyerdynamic%20DT%20250%20(250%20Ohm) 。旁证：Innerfidelity 250 Ω（AutoEq results/Innerfidelity，同为 GRAS 类台架）；oratory1990 80 Ω（AutoEq results/oratory1990）；DIY-Audio-Heaven 实测。 对比目标：Harman over-ear 2018。用 fr_analyze.py 处理，以中频对齐；分析脚本提示台架/目标型号不完全匹配，所以各频段偏差按约 ±1 dB 的精度来读。

  • 整体（measured）：脚本判定为均衡 / neutral，倾斜 +2.5 dB，主要来自极高频。
  • 低频（measured）：相对 Harman，超低频 −2.3 dB，中低频 −3.6 dB，比 Harman 略少。Innerfidelity 样本的超低频滚降更明显，约 −7 dB。测量修正：原报告说低频"量感正确"，改为"平直偏瘦，比 Harman 少 2–4 dB"。
  • 中频（measured）：200 Hz–5 kHz 基本贴合目标，低中频 −1.5 dB，中央和上中频约 0 dB，人声自然。
  • 高频（measured）：低高频约 −3.3 dB，3.7 kHz 附近有一个凹陷；约 8.9 kHz 有 +4 dB 的窄峰，有齿音风险；13.4 kHz 有 +4 dB 峰，15.6 kHz 有 −7.6 dB 凹陷。5–10 kHz 平均值接近目标（oratory 为 −0.8 dB），但峰谷不平整，这和"高频略粗"的主观描述一致。
  • 80 Ω 版（measured，oratory1990）：低频更少（超低频 −6.8 dB），6–10 kHz 明显凹陷（约 −8.7 dB），比 250 Ω 版更暗。样本差异和版本差异都不能排除。
  • 风格：中性平直、低频偏瘦的广播监听。presence 区没有抬升，所以不属于刺激型挑错耳机；挑错能力主要来自低频不加料，以及 9 kHz 一带的窄峰。

技术素质

  • 解析：够用、诚实，但不算细腻（consensus 2/3）。
  • 声场与分离：封闭式常见水平；证据不足。
  • 动态和瞬态：证据不足。

佩戴与做工

轻、丝绒耳垫舒适，但夹力大，长时间戴会累（measured 4.5 N + consensus）。结构模块化，结实耐用，德国制造，适合专业环境（consensus）。

用途适配

  • 广播、影视、录音监听：平直、耐用、隔音中等，很合适。
  • 挑错：中性诚实，2–5 kHz 没有抬升，挑错度中等偏上（measured）。
  • 听歌：均衡耐听，缺一点讨喜的味道和精致感。
  • 推力：250 Ω 版 107 dB/V，手机能推响，但余量有限，建议接声卡或耳放；80 Ω 版更好推（prior）。

评分

  • 挑错度 60（测量支撑）：2–5 kHz 没有抬升，5–10 kHz 平均值贴合目标，但有 9 kHz 窄峰，低频比 Harman 少 2–4 dB，放在 DT 770 与 Hi-X60 之间。
  • 音质 68：中频贴合目标，这是加分项；高频有 9 kHz 和 13 kHz 的峰，再加 15.6 kHz 的凹陷，不够平滑，两台架样本之间也有差异。
  • 听歌适配 63（测量修正，原为 65）：均衡耐听，但低频比 Harman 偏瘦、有齿音风险，夹力也大。
