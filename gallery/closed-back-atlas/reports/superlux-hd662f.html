频响与风格（measured）

  • 测量源：oratory1990 测量，经 AutoEq 整理：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Superlux%20HD%20662F（原始 CSV 已下载，并用 fr_analyze.py 分析）。
  • 测量台架：GRAS 45BC KEMAR。本轮改用 --rig gras_43ag 重新分析，台架与目标匹配，没有警告。
  • 对比目标：Harman OE 2018，以 500 Hz–1 kHz 为基准对齐。
  • 各频段结果：超低频（20–60 Hz）约 −5.6 dB，偏少；中低频、低中频、中频、高中频都在 ±1.5 dB 以内，基本中性；低高频和中高频的均值分别为 −1.8 和 −2.0 dB。
  • 关键特征：5.75 kHz 有约 +10 dB 的尖锐窄峰，AutoEq 给出的修正是 Q≈5、−14.9 dB 的滤波器；约 5 kHz 处有 −4 dB 凹陷；11 kHz 凹陷约 −9 dB，12.6 kHz 又有约 +8 dB 的尖峰。整体向高频倾斜约 +2.5 dB。
  • 换耳垫版本（佐证）：换 Brainwavz XL 耳垫后，超低频补到与目标持平（−0.1 dB），中低频 +2.8 dB，空气感 +4.9 dB；但 5.75 kHz 的 +9.6 dB 窄峰和 12.7 kHz 的尖峰依然存在。这说明窄峰来自单元或腔体本身，换耳垫去不掉。
  • 结论：频段均值看起来"均衡"，但窄峰很尖，实际听感偏亮、偏干。这和榜单"削低频，偏挑错"的先验一致，而且高频的问题比先验说的更突出。

技术素质（consensus，样本少）

  • 高频：2 条来源（Head-Fi 评测、论坛）都说高频亮、有尖峰，带颗粒感，有齿音，久听容易累。这与测量到的 5.7k 和 12.6k 尖峰吻合。
  • 中频：1 条来源认为中频略低于中性、偏干，人声缺少生气。
  • 低频：1 条来源认为低频比同门开放款更有细节。
  • 声场：头中声场小（1 条来源）。
  • 动态：有评测说适合节奏快、能量足的音乐，摇滚表现好。
  • 解析、分离：证据不足，按价位推断属于入门水平（prior）。

佩戴与做工

耳垫小，偏贴耳式，oratory1990 还专门测了换 Brainwavz 圆形 XL 耳垫后的版本，说明原装耳垫是常被吐槽的短板。做工属于入门塑料机身（prior）。关于舒适度，没有找到详细共识，证据不足。

用途适配

  • 挑错：可以用来暴露齿音和 5–6 kHz 的问题，但尖峰本身会误导判断。
  • 混音：不建议做主力监听。
  • 听歌：高频刺，建议配合 EQ 使用。
  • 推力：32 Ω、98 dB/mW，手机可以直接推。

评分

  • 挑错度 72：测量显示超低频缺量，5.7k 和 12.6k 有尖锐窄峰，属于高亮挑错取向；中频平直，所以没有到 7506 那一档。
  • 音质 50：窄峰多、有颗粒感，但中频平直，属于入门级的技术力。
  • 听歌适配 42：易疲劳，佩戴一般，需要 EQ 才耐听。
  • 曲线重校：分数不变（没有 5128 数据；以 GRAS 为依据的结论与上一轮一致）。

证据与置信度

  • 证据等级：measured（频响）+ consensus（技术素质，样本少）。
  • 置信度：medium。频响来自单一测量者的 GRAS 数据，两个耳垫版本在窄峰上互相印证；没有 5128 或第二家测量可以交叉验证。
