Focal Listen Professional

中文：舒适易推、低频与高频都有抬升的 W 型封闭耳机，细节感明显但带染色，更适合兼顾欣赏而非严格混音。 English: A comfortable, easy-to-drive closed headphone with a W-shaped tuning; detailed-sounding but colored, better as a hybrid listen/monitor can than a strict mixing reference.

频响与风格

测量源（均为 AutoEq 收录的原始数据，用 CSV 自带的 target 列即 AutoEq 为该来源配的 Harman over-ear 2018 系目标计算偏差，以 500–1k Hz 对齐；另用 fr_analyze.py 按 harman_oe_2018 复核，结论一致）： - A. Auriculares Argentina，Focal Listen Professional：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Auriculares%20Argentina/over-ear/Focal%20Listen%20Professional（台架 AutoEq 未注明，属非标准台架，定量只作参考） - B. Innerfidelity，Focal Listen（消费版，与 Pro 同平台但耳垫/调音可能不同）：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Focal%20Listen（Head Acoustics HMS II.3 台架） - crinacle 的 GRAS 43AG-7 测量在 AutoEq 索引与 graph.hangout.audio 中有条目，但原始数据当前无法取得（404/403），未使用。

相对目标的频段偏差（A / B，dB）： - 低频 20–60 Hz：−4.6 / −3.8；60–200 Hz：−4.5 / −4.2。即相对 Harman 的低频搁架偏少约 4 dB，量感接近"平直"，并非明显抬升。 - 下中频 200–500 Hz：+2.4 / +1.4，略厚。 - 1–3 kHz：−3.6 / −1.7；3–5 kHz：−5.8 / −4.3。presence 区明显回收。 - 5–10 kHz：−0.3 / −4.6；10–20 kHz：+8.5 / −1.4。两份样本高频差异大：A 在约 15 kHz 有尖锐峰（残差约 +9 dB）、约 4.9 kHz 小峰；B 在约 8.8–9.5 kHz 有尖峰（残差约 +6～+8 dB，齿音风险）。 - 曲线重校（本轮）：两条曲线用 fr_analyze.py 按 harman_oe_2018 复算，结果为 A 低频 −4.6/−4.6 dB、下中频 +2.2 dB；B 低频 −3.7/−4.3 dB、下中频 +1.2 dB，与上轮一致。仍然没有 5128 或 GRAS 数据可以裁决高频分歧，A 的台架是 711 仿制，它在 10 kHz 以上的峰值可信度有限。 - 风格（测量修正）：原报告据 Sonarworks 文字描述写的"低频与高频抬升的 W 型"与测量不完全吻合。测量更接近"下中频略厚、presence 凹陷、高频有窄峰"的形态；低频相对 Harman 偏少而非偏多。高频的"细节感"主要来自窄峰，不是整体亮。主观评测提到的齿音偶尖，与 8–9 kHz 或 15 kHz 峰对得上。

技术素质

  • 解析/细节：headphonecheck 评为出色，Sonarworks 认为部分是高频抬升造成的"感知细节"。[consensus 2/3，有分歧]
  • 声场/定位：headphonecheck 称"合格"，封闭腔体但不闷；其他来源未涉及。[consensus 1/3]
  • 动态、瞬态：官方宣称钛振膜瞬态快；独立证据不足。[prior]

佩戴与做工

记忆海绵耳垫柔软，长时间无明显压点（Sonarworks）；headphonecheck 认为夹力偏高、部分人会在意；大耳朵用户需注意耳垫偏小。可折叠、附件齐全，便携性好。[consensus]

用途适配

  • 混音/挑错：未校正不宜做严格参考（Sonarworks 未校正 6.6/10，校正后 8.4/10）；headphonecheck 则给出 4.8/5 并认可其监听用途，存在分歧。
  • 听歌：低频饱满 + 高频亮，听感有活力，属"制作兼欣赏"。
  • 推力：32 Ω / 122 dB/V，手机轻松驱动。

评分

  • 挑错度 50（测量修正，原 55）：2–5 kHz 回收 4–6 dB，削弱了对人声和咬字瑕疵的暴露；高频窄峰带来"感知细节"，但不是可靠的挑错依据。
  • 音质 65（原 67）：高频窄峰明显，两份样本高频形态差异大，可能是单体差异或佩戴敏感；低频延伸与下中频尚可。
  • 听歌适配 66（原 70）：低频比原判断少，高频峰有刺感风险。耳垫舒适加分。
  • 曲线重校：三项分数不变（50 / 65 / 66）。本轮没有找到比现有曲线更可信的台架数据。
