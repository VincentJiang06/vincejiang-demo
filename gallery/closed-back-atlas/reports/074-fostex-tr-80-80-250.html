Fostex TR-80 (80/250Ω)

中低频鼓包明显、超低频不足、4 kHz 存在感凹陷，另有一个 5.6 kHz 窄峰的封闭监听（crinacle 测量）；并非整体偏亮，但窄峰可能带来刺感；两种阻抗版本都需要一定推力。 A mildly V-shaped closed monitor: natural punchy bass, a lower-mid dip and forward, borderline-fatiguing upper mids and treble; both versions want some amplification.

频响与风格

  • 测量源：crinacle 的测量，收录于 AutoEq（https://github.com/jaakkopasanen/AutoEq/tree/master/results/crinacle/GRAS%2043AG-7%20over-ear/Fostex%20TR-80 ，图为 Fostex TR-80.png，并附 ParametricEQ/GraphicEQ）。台架为 GRAS 43AG-7（crinacle 头戴式台架）；对比的目标曲线是 AutoEq 在 crinacle GRAS 数据上默认使用的 Harman over-ear 系目标。测量没有注明是 80 Ω 还是 250 Ω 版。AutoEq 没有公开原始 CSV，以下数值是读截图估出来的，另参考 AutoEq 自动生成的 EQ 滤波器。
  • 低频（测量修正）：主要特点是中低频鼓包，而不是"自然"的低频。约 100–200 Hz 比目标高出约 5–6 dB（AutoEq 在 160 Hz 给出约 −11 dB、Q 0.45 的宽幅衰减）；超低频滚降明显，50 Hz 约比目标低 3 dB，20 Hz 约低 9 dB。
  • 中频：约 400 Hz–3 kHz 大致比目标低 1–1.5 dB，基本平直。所谓"600 Hz 凹陷"在测量里只是一段浅而宽的偏低；主观上的"中频下凹"主要来自中低频鼓包的反衬。
  • 中高频与高频（测量修正）：测量不支持"整体偏亮"。约 4.1 kHz 有一个约 −5 dB 的凹陷，存在感不足。约 5.6 kHz 有一个很窄的尖峰（原始曲线上突起明显，比目标高约 3 dB），容易带来齿音或刺感，可以解释 SOS 的"疲劳"评价。6–9 kHz 比目标低约 2 dB，10–12 kHz 低约 3–6 dB。14 kHz 以上有几个锯齿状的窄峰，比目标高约 5–8 dB（这一段台架误差较大，仅供参考）。
  • 总结：属于"中低频偏厚、超低频不足、存在感凹陷加一个 5.6 kHz 窄峰"的不平整调音，不是经典的亮 V 形。
  • 主观补充：SOS 认为有疲劳感、MajorHiFi 认为不刺耳，这个分歧与 5.6 kHz 窄峰对耳道位置和佩戴很敏感相吻合。

技术素质

  • 解析：尚可但不突出（2/2）。
  • 分离：复杂编曲中乐器容易糊在一起（MajorHiFi，1/2）。
  • 声场：证据不足。
  • 动态：MajorHiFi 认为加放大后细节和反差会明显提升（1/2）。

佩戴与做工

做工扎实，模块化设计便于维修。舒适度两家评测意见相左：SOS 认为长时间佩戴不太舒服，MajorHiFi 认为头梁和耳垫都很舒适。

用途适配

  • 挑错与混音：中低频鼓包会掩盖细节，4 kHz 凹陷也削弱了存在感，挑刺能力有限，只有 5.6 kHz 窄峰会放大齿音；不适合做中性的混音参考。
  • 听歌：适合摇滚、嘻哈，古典乐分离不足。需要耳放或接口驱动，手机直推会显得松散。

评分

曲线重校：本轮未找到原始数值曲线（含 5128），各项分数不变，仍以 GRAS 截图读图为锚点。 - 挑错度 48（测量修正，原为 58）：测量显示中低频比目标高约 5–6 dB、4 kHz 凹约 5 dB，整体偏厚而不亮，只有 5.6 kHz 窄峰带来一些挑刺倾向。 - 音质 60（原为 62）：曲线不平整，中低频鼓包会造成分离变糊（与 MajorHiFi 的描述一致），高频有窄峰、呈锯齿状；解析尚可。 - 听歌适配 58（原为 57）：中低频饱满，整体不亮，适合流行、摇滚、嘻哈；但超低频不足、有窄峰刺感、需要耳放，舒适度也存在争议。
