频响与风格

主依据：B&K 5128（Earphones Archive，5 个佩戴位置，均为 L/R 平均）。用 fr_analyze.py 对照 5128 DF，以 500 Hz–1 kHz 对齐。注意 DF 是参考基线，不是偏好目标：偏好中性的头戴一般低频比 DF 高约 4–6 dB，高频略低于 DF。

居中位置相对 DF 的频段偏差：20–60 Hz +9.1、60–200 Hz +10.1、200–500 Hz +3.2、1–3 kHz +0.1、3–6 kHz +1.1、6–10 kHz +1.8、10–20 kHz -3.9 dB。5 个位置之间，低频差异不到 0.5 dB，1–10 kHz 差异在 ±1 dB 以内，说明它对佩戴位置不敏感。 - 低频：比 DF 高约 9–10 dB，换算后比偏好中性多约 4–5 dB，中低频（60–200 Hz）是抬升的重点。和 GRAS（+5.1）、HMS（+3.3 到 +5.1）的结论一致（measured 4/4）。同一数据库里，Hi-X60 这一段只有 +4.4 dB，HD 480 Pro 是 +3.8 到 +5.1 dB，SRH1540 明显更厚，和 K371 相近（+11.3 dB）。 - 中频：200–500 Hz 比 DF 高约 3 dB，属于轻度增厚。1–3 kHz 与 DF 持平。偏好中性在这一段一般也在 DF 附近，所以上中频不缺。人声显得靠后，主要是低频和中低频抬升造成的相对效果（measured）。 - 高频：3–10 kHz 比 DF 高 1–2 dB。偏好中性一般略低于 DF，换算后这一段比偏好中性略亮约 2 dB。10 kHz 以上比 DF 少约 4 dB，14 kHz 和 18 kHz 附近有凹陷，16 kHz 附近有一个小峰。整体是"低频厚、高频有存在感但不尖"（measured）。 - 与其他台架的矛盾：GRAS（oratory1990）和 HMS 两条曲线显示 5–10 kHz 与 Harman 基本持平（-0.4 到 +0.7 dB），5128 换算后略亮约 2 dB。差异不大，以 5128 为准：SRH1540 的高频并不暗。Innerfidelity 数据里 9.5 kHz 附近的窄峰，在 5128 上没有对应的明显峰，应当是台架差异。oratory1990 数据在 4.6 kHz 附近有一个约 -3 dB 的小凹，5128 上 3–6 kHz 反而略高于 DF，两者不一致，这里以 5128 为准。 - 风格结论：低频明显抬升的暖向调音，高频保持清楚。它不是"暖又暗"的类型，整体偏暖主要来自低频和中低频。这和"温暖宽松、但细节不闷"的主观共识一致。

技术素质

  • 解析：同价位里属于中上，但因为调音温和，细节不会被推到眼前（consensus 3/4）。
  • 声场：以封闭式来说比较开阔（consensus）。
  • 分离、动态：表现良好，低频冲击力足，但速度不算快（consensus）。
  • 瞬态：低频略松，这一点和实测的低频表现吻合（measured + consensus）。

佩戴与做工

轻量化的碳纤维加铝合金结构，配 Alcantara 耳罩，长时间佩戴舒适度很高，多篇评测给出一致好评（consensus 4/4）。附带两对耳罩和两条线材。

用途适配

  • 混音或长时间制作：耳朵不容易累，适合长时间工作，但暖色调音需要使用者心里有数。
  • 挑错：不适合。低频和中低频偏厚，会掩盖部分瑕疵；不过 5128 显示高频略亮，细节并不闷。
  • 听歌：非常合适。
  • 推力：46Ω、约 99 dB/mW，用手机或入门声卡就能推到足够的音量。

评分

  • 挑错度 25（曲线重校：25→25，不变）：5128 显示低频比偏好中性多约 4–5 dB，中低频也偏厚，暴露瑕疵的能力会被低频量感盖住，所以仍属暖向、讨喜。但 3–10 kHz 比偏好中性略亮约 2 dB，高频细节不会被藏起来。单看曲线，它可以比锚点再高几分，但 SRH1540 本身就是挑错度锚点（≈25），分数保持不变。
  • 音质 78（曲线重校：78→78，不变）：5128 在 1–10 kHz 没有尖锐峰值，5 个佩戴位置高度一致；四条曲线（三个台架）结论相同。扣分项：中低频抬升约 5 dB，200–500 Hz 偏厚，低频略松；10 kHz 以上有几个凹陷。
  • 听歌适配 85（曲线重校：85→85，不变）：低频饱满、高频清楚，再加上顶级的佩戴舒适度，适合长时间听。这也是该项的锚点。
