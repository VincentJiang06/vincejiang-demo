Dan Clark Audio Aeon 2 Closed

中文：解析与做工都很强的折叠式平板封闭耳机，调音接近 Harman（低频加、上中频收、6k/8.5k 有窄峰）；技术力高，但动态偏软，而且吃推力。 English: A highly resolving, beautifully built folding closed planar with a near-Harman tuning (bass lift, upper-mid recession, narrow 6k/8.5k peaks). Technically strong, but dynamics are soft and it needs a real amp.

频响与风格

  • 测量源：见上一节，主曲线是 oratory1990 的 GRAS 43AG-7（原版、默认垫片）。
  • 目标曲线：Harman over-ear 2018。用 fr_analyze.py 对齐 500–1k Hz 后计算偏差。
  • 低频：20–60 Hz 约 -1.1 dB，60–200 Hz 约 +1.1 dB，基本贴合 Harman 的低频搁架。这是"跟目标一样多"，不是在目标之上再抬升。
  • 中频：200 Hz–1 kHz 贴近目标。从 1.5 kHz 开始逐渐下沉，2.7–3 kHz 约 -4 dB，3.5–3.9 kHz 最深，约 -7 到 -8 dB。1–3k 均值约 -1.9 dB，3–6k 均值约 -4.5 dB。
  • 高频：约 5.9 kHz 有一处小峰（残差约 +4.8 dB），但整体仍接近目标。7–10 kHz 低于目标约 -3 dB，10 kHz 附近有凹陷。12–15 kHz 高于目标约 +1.5 到 +4.7 dB（10–20k 均值约 +3.6 dB）。

  • 风格（测量修正）：大致是"低频贴 Harman + 临场感明显后退 + 顶端空气感略多"的柔和偏暗中频曲线。与 Headphones.com 描述的"1.5–5k 凹陷、6k 附近有峰"方向一致，但 oratory1990 的凹陷更深（最深约 -8 dB，不是 3–4 dB）；8.5k 在这条曲线上不是明显的峰。临场感后退，也与主观上"动态、冲击偏软"的共识相符。

  • 佐证曲线（曲线重校新增）：

  • 5128 代理（Noire，对比 5128 DF）：20–60 Hz 约 +9 dB，60–200 Hz 约 +6 dB，1–3k 约 -2 dB，3–6k 约 -2 到 -3.6 dB，6–10k 大致持平（1 格垫片 +0.1、不放垫片 +2.5）。偏好中性的头戴一般低频比 DF 高 4–6 dB、高频略低于 DF；换算后，Noire 属于"低频比中性略多一点、临场感略收"的暖向近中性曲线，和原版 GRAS 曲线的方向一致（临场感收），但凹陷没有原版那么深。原因是 Noire 的穿孔耳垫会把上中频补回来（oratory1990 穿孔耳垫版的 1–3k 为 +1.1 dB、3–6k 为 +1.9 dB，而原装垫分别是 -1.9 / -4.5 dB）。所以 Noire 的 5128 曲线不能直接代表原版的临场感深度。
  • HypetheSonics（台架未注明，对比 Harman OE 2018）：低频基本贴目标，约 3.8k 凹陷（-4.5 dB），3–6k 为 -3.7 dB，与 oratory1990 一致；但 10–20k 为 +7.2 dB，约 13.8k 有 +11 dB 的窄峰，顶端比 oratory1990 更亮。极高频本来就受台架和佩戴影响，这一处差异不改变"临场感后退、顶端有空气感"的判断。
  • 各曲线之间没有与主结论冲突的矛盾：三条原版测量都显示 3.5–4k 凹陷；差异主要在 10k 以上的幅度，以及换垫后的变化。

技术素质（评测共识，非测量）

  • 解析：同价位优秀，中频和高频都比 Open 版更干净 —— consensus 2/2。
  • 分离：好 —— consensus 1/2（Headphone Corner）。
  • 声场：不宽，中央定位准，左右偏窄 —— consensus 1/2。
  • 动态/冲击：偏弱，两篇都提到力度和冲击感不足，Headphone Corner 批评尤重 —— consensus 2/2。
  • 低频：清楚但体感冲击不足 —— consensus 1/2。

佩戴与做工

两篇都称赞做工，Headphones.com 更评为"spectacular"；舒适度评价好，但夹力偏紧 —— consensus 2/2。Headphone Corner 指出头梁不能掰弯调节，耳垫会压到下颌 —— 1/2。

用途适配

  • 混音/挑错：曲线接近目标、解析高，适合做参考；但 3k 区偏收、高频有峰，动态偏软，不是冷峻挑错型。
  • 听歌：调音讨喜、细节好，隔音好，还能折叠带走；喜欢冲击力的人会觉得偏"平静"。
  • 推力：13 Ω / 92 dB/mW，偏吃电流。两篇都建议配有力的台式功放，手机直推不理想 —— consensus 2/2。

评分

  • 挑错度 45（不变）：oratory1990 原版曲线显示 2–5k 比 Harman 低约 4–8 dB，7–10k 也略低，低频不缺量，因此偏放松、讨喜；只有顶端空气感和高解析补回一些细节感。HypetheSonics 的 3.8k 凹陷与之一致；5128 Noire 代理曲线显示的临场感后退较轻，但那是换垫后的另一版调音，不改变原版的分数。
  • 音质 84（不变）：除临场感凹陷外，曲线比较平滑；两条原版测量在 10k 以上的幅度不同（+3.6 / +7.2 dB），但没有中频段的尖峰。同价位封闭平板中解析和分离出色，动态偏软被扣分。
  • 听歌适配 78（不变）：调音讨喜、做工好，隔音好；夹力、偏软的动态和推力需求拉低分数。
