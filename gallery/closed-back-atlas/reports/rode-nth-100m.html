频响与风格

测量源（AutoEq 原始 CSV，经 fr_analyze.py 对比 Harman OE 2018，中频锚定对齐）： - oratory1990（NTH-100，GRAS 45BC-10）：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/R%C3%98DE%20NTH-100 - Rtings（NTH-100M 本体，HEAD acoustics HMS II.3）：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Rtings/HMS%20II.3%20over-ear/R%C3%98DE%20NTH-100M - 本轮补跑 Filk（NTH-100M，KB006x + 711）：超低频 −6.1、中低频 −0.2、低中频 +2.1、上中频 −1.5、3–6 kHz −2.1、6–10 kHz −4.9、10 kHz 以上 −6.0 dB，7.7 kHz 凹陷、10.1 kHz 峰；分析器判为"暗声"。它的高频比 GRAS 和 RTINGS 更少，但 711 类台架在高频误差大，按规则以 GRAS 为准。 - 矛盾点：6–10 kHz 缺量，GRAS −4.0、RTINGS −2.3、Filk −4.9、Kuulokenurkka −7.0、Exound −9.1 dB，方向一致、幅度不同；10 kHz 以上 RTINGS 只少 1.2 dB，Filk 少 6 dB。实际听感可能比 GRAS 结论更暗一点。

  • 低频（measured）：两台架一致，60–200Hz 与 Harman 基本持平（+1.0 / -0.1 dB），20–60Hz 超低频略少（-3.9 / -6.3 dB）。不是"低频偏多"。
  • 中低频（measured）：200–500Hz 高出目标约 +2.0 / +2.4 dB，带来轻微温暖、偏厚感，这是"厚"的真实来源。
  • 中频/presence（measured）：1–5kHz 相对目标基本中性（upper mids -1.4 / -0.6 dB）；Rtings 在约 3kHz 有 +3.3 dB 小峰。测量修正：原先"700Hz–3kHz 下倾约 6 dB、人声偏后"与两份 AutoEq 数据不符，已删除。
  • 高频（measured）：5–10kHz 偏少（-4.0 / -2.3 dB），约 7–8kHz 有 -3.4~-6 dB 凹陷；约 12kHz 有 +4~+7 dB 窄峰，14kHz 以上滚降（16kHz 约 -4.5 dB 相对目标）。
  • 风格（测量修正）：脚本判定整体"均衡/中性倾斜"（tilt -0.7 / +1.9 dB）——接近 Harman 的中性偏暖，而非"暗厚"。主观评测里的"thick/veiled"主要来自 200–500Hz 的微量堆积和 7–8kHz 凹陷，量级温和。与榜单先验 tuning_x 5.5 基本一致。

技术素质

  • 解析：偏弱，细节被掩盖（2/2 评测：Headphones.com、DIY-Audio-Heaven）。
  • 声场/分离：声场亲密、分离一般，有一定糊（1/2，Headphones.com）。
  • 动态：可接受但冲击力一般（1/2）。
  • 瞬态：证据不足。
  • 其他：DIY-Audio-Heaven 提到不用的插孔需塞橡胶塞，否则可能出现声道不平衡。

佩戴与做工

做工被多家评为同价位最好之一，锁定结构、耐用材料（consensus 2/2）。三角形耳垫对大耳朵可能有轻微接触；重量适中，长时间佩戴舒适。非折叠，便携性一般。

用途适配

  • 混音/挑错：可粗听，但 7–8kHz 凹陷会让人低估齿音。
  • 听歌：调音接近 Harman、不刺耳，适合大多数人，但同价位 AKG K371 声音更好（Headphones.com）。
  • 口播/直播/视频剪辑：主场景，话筒一体化是卖点。
  • 推力：32Ω、约 95 dB/mW，手机可推。

评分

本轮补查没有 5128 数据；新增的 Filk 曲线与主曲线方向一致，分数不变（曲线重校：无变化）。

  • 挑错度 45（测量修正，原 35）：整体接近 Harman、presence 中性，但 7–8kHz 凹陷让齿音暴露不足，属中性略偏讨喜。
  • 音质 65（原 62）：两台架频响都较平滑、偏差小；主观解析偏弱、声场亲密，仍低于 K371。
  • 听歌适配 70（原 66）：调音接近 Harman 且不刺，佩戴做工好；超低频略缺、略厚。

证据与置信度

  • 置信度：中高（oratory1990 + Rtings 两份原始 FR 已跑脚本，结论一致；技术素质仅 2 篇评测，故结构化字段仍记 medium）。
  • 曲线库补查：已保存 oratory1990、RTINGS、Filk、Kuulokenurkka、Exound 五条曲线；没有 5128 数据（RTINGS 这款仍是 v1.5 / HMS II.3）；crinacle 库没有本机。RTINGS 图表需会员，隔音、失真未量化。
  • 测量修正：原稿"中频下倾 6 dB、低频偏多、偏暗"被测量否定，改为"中性偏暖、7–8kHz 凹陷"。
  • 证据缺口：M 版话筒外壳是否影响声学未核实（默认与 NTH-100 相同，prior）。
