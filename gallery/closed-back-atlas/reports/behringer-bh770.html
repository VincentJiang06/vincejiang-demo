频响与风格

  • 测量源：webstudius.com 的 REW 图（第四轮找到，只有图片，台架未知、未补偿）。没有数值，所以没法和 5128 DF 或 Harman OE 2018 做量化对比，只能看形状。
  • 图上的形状：低频到中频大致平直（相对 Harman 常见的低频抬升来说偏少）；4 kHz 附近有深谷；7-8 kHz 有很高的尖峰；16 kHz 以后滚降。7-8 kHz 的尖峰正好对应评测说的齿音尖锐、偏亮；低频没有抬升也和"低频偏薄"一致。4 kHz 的深谷说明亮感主要来自齿音区，而不是 2-4 kHz 的临场区；因为台架未知（没有耳道共振时，这一段本来就会偏低），谷的实际深度不能照图读取。
  • 下面的结论都来自评测共识（consensus，2/2 条来源一致：ear-phone-review 详评，加上 Sweetwater/zZounds 用户评价）：
  • 低频：量少、偏薄。电贝司发虚，底鼓缺少重量，和"extended bass"的宣传相反。
  • 中频：有人说中频有一处不讨喜的鼓包；整体缺少纵深，音色表现一般。
  • 高频：明显突出，延伸不错，但齿音（ch/th）尖锐，容易疲劳。
  • 按共识归类为亮、偏 V/上扬的挑错型。
  • 补充：ear-phone-review 还提到定位不自然；有用户反映漏音明显，但也有用户说录人声时串音很少，两种说法矛盾，隔音维持"中等"的推断。

技术素质

高频抬升带来"细节多"的错觉，但评测认为实际解析一般，声音"平、没有纵深"（consensus 1/1 详评）。声场、分离、动态和瞬态没有可靠评述，证据不足。

佩戴与做工

评测说贴合度不错，可以和 DT 990 相比；用户评价普遍认为做工对得起价格（consensus）。编织线是单边入线，附 6.35 mm 转接头。

用途适配

  • 混音/挑错：适合查齿音和高频瑕疵；不适合判断低频。
  • 听歌：偏亮、低频薄，不耐听。
  • 推力：80 Ω、约 107 dB/V，手机能推响，但音量余量一般。

评分

  • 挑错度 72：共识一致认为高频突出、低频偏少。第四轮找到的独立图（7-8 kHz 尖峰、低频不抬升）印证了这一点，但 4 kHz 深谷会削弱临场区的挑错能力，台架也不明，所以维持 72。深挖重校：72→72（新证据与共识一致，不改分）。
  • 音质和听歌适配：深挖重校 42→42、42→42（图上的 4 kHz 深谷加 8 kHz 尖峰属于明显的不平直，与评测对音色的负面评价一致）。
  • 音质 42：评测对解析和纵深评价偏低，属于价位的正常水平。
  • 听歌适配 42：疲劳感强、低频薄，只有佩戴还算不错。
