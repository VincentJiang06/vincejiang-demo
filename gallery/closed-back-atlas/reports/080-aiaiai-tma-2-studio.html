AIAIAI TMA-2 Studio

轻巧的模块化封闭耳机：低频和中低频紧实有力，12 kHz 以上略收，声场小而近。它更像电子乐制作和 DJ 的顺手工具，不是严格挑错的监听。 A light, modular closed headphone with tight low and low-mid punch, a slightly reserved top octave and a compact stage. It is a friendly production and DJ tool rather than a strict analytical monitor.

只有图、没有数值的来源： - headphonecheck.com 的 TMA-2 Studio 评测：实测 83.4 Ω。它另有一篇“Studio Preset”评测，测的是 S03 + E04 组合，实测 36.4 Ω，没有曲线。两篇都没有可下载的数据。 - Headphonesty 的 TMA-2 Studio Wireless+ 评测：miniDSP EARS 曲线图，页面返回 403，没有数值。 - Sonarworks 的 TMA-2 HD Studio 评测：只有文字和图。

查过的库：AutoEq measurements（Rtings / oratory1990 / Innerfidelity，其中 Innerfidelity 只有 TMA-1 和 TMA-1 Studio，是另一代产品，没有采用）；graph.hangout.audio 头戴库的 phone_book；squig.link、kr0mka、timmyv、hbb、precog、bedrock、sai、achoreviews、jaytiss、doltonius、recode 等 squig 站点的 phone_book；RTINGS（只测过 TMA-2 DJ）；网页搜索。

两条代理曲线的 fr_analyze 结果： - RTINGS 5128 上的 TMA-2 DJ，对比 5128 DF：20–60 Hz +6.6 dB，60–200 Hz +7.7 dB，200–500 Hz +5.9 dB，1–3 kHz −9.2 dB，3–6 kHz −9.5 dB，10 kHz 以上 −11 dB。换算成“中性头戴通常比 DF 低频高 4–6 dB”的标准，它仍然低频偏多、中高频和高频明显不足，是很暗的 DJ 调音。 - oratory1990 GRAS 上的 TMA-2 HD Wireless，对比 Harman OE 2018：60–500 Hz 约 +5 dB，1–10 kHz 约 −2 dB，整体偏暖。 - 两条曲线的暗度差别很大，说明 TMA-2 的声音主要由单元和耳垫组合决定，所以两条都不能直接拿来给 Studio 预设打分。

主要打分依据：headphonecheck 与 Attack Magazine 对 Studio 预设的主观共识；两条代理曲线只用来确认 TMA-2 家族“低频和中低频偏多、中高频偏收”的大方向。

频响与风格

  • 没有找到 RTINGS / oratory1990 / squig 对 Studio 预设的曲线（RTINGS 只测过 TMA-2 DJ）。Frieve 汇总说偏离 Harman 约 ±2–3 dB，但它是二手聚合，低权重。
  • 低频：Attack 说低频能下潜到超低频，约 35 Hz 以下开始衰减，但量不过多；headphonecheck 说低频紧、有冲击，不轰（2/2 consensus）。量感中性偏多。
  • 中频：headphonecheck 说中低频突出、听感像“把俱乐部放进脑袋里”；Attack 说中频细节好，中高频有轻微抬升。
  • 高频：headphonecheck 说 12 kHz 以上略收；Attack 说高频通透。两篇有分歧，取中性、顶端略收。
  • 整体风格：中性偏暖、偏有冲击力（consensus）。
  • 曲线旁证（2026-09 重查）：同平台两条代理曲线（RTINGS 5128 的 TMA-2 DJ、oratory1990 的 TMA-2 HD Wireless）都是低频和中低频偏多、中高频偏收，方向与上面的主观判断一致。但 DJ 预设比 Studio 暗得多，因为单元和耳垫不同，所以不按它下调 Studio 的高频判断。

技术素质

  • 解析：Attack 认为中频细节优于它对比的 Beyerdynamic 型号（1/2）；headphonecheck 认为高频空气感不足（1/2）。评价中等偏上。
  • 声场：headphonecheck 说偏小、偏近（1/2），Attack 没有提到。
  • 分离：Attack 说分离好（1/2）。
  • 动态与瞬态：两篇都说低频冲击力好（2/2）。

佩戴与做工

重量轻（206 g），Alcantara 耳罩和记忆棉头梁都很舒适（2/2）。模块化设计可以更换耳罩、线材和单元，维修性好。有一篇汇总提到部分个体低频左右声道相差约 2.5 dB（来源等级低，仅作提示）。

用途适配

  • 混音、挑错：可以用作参考，尤其适合电子乐制作；但高频顶端略收、声场偏近，不适合细抠混响尾音和空间感。
  • 听歌：佩戴舒适，声音有冲击力，适合日常听。
  • 推力：按 113 dB/mW 和 32 Ω 算，手机直推很轻松；如果实际阻抗是 83 Ω，推力需求会略高，但仍属易推（prior）。

评分

  • 挑错度 45：中低频有冲击、高频顶端略收，定位接近 K371 这类“能用的讨喜监听”。
  • 音质 68：频响大体平稳，解析中上，声场偏小，与 M50x 同档。
  • 听歌适配 72：轻巧舒适，声音讨喜，分数与 M50x 相当。
  • 曲线重校：三项分数均不变。原因是没有 Studio 预设本身的曲线，代理曲线只能确认大方向。
