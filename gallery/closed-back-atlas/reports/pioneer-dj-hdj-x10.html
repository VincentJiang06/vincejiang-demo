频响与风格

  • 证据：iXBT 的 B&K 4153 独立测量图（measured，只有图片），加上 Sonarworks SoundID 校准曲线的用户转述。两者在两点上一致：低频抬升、5 kHz 附近凹陷。
  • 低频：中低频宽幅抬升。Sonarworks 补偿后，50–300 Hz 约 +3 dB。4153 原始图上 80–120 Hz 的峰更大，是平板密封夸大所致。主观评测（MajorHiFi 听到 80/100 Hz 抬升，headphonecheck、kopfhoerer.de 说"强调但不掩盖"）与此一致。
  • 中频：300 Hz–1 kHz 平直，人声基底完整。
  • 上中频 / 低高频：从 2 kHz 起缓降，5 kHz 附近明显凹陷（Sonarworks 补偿后约 −6 dB）。所以它不刺、耐听，但齿音和质感会被收一点。这一点修正了前几轮"1 kHz / 4 kHz 存在感峰"的主观描述：测量不支持 4 kHz 有峰。
  • 高频：8 kHz 附近回升；8 kHz 以上大体回到平直 ±3 dB 以内。MajorHiFi 说的 12 kHz "脆亮"，可能对应 5 kHz 凹陷之后的相对回升。
  • 风格：偏暖、低频加重、中高频（约 5 kHz）凹陷的 DJ 调音。它更接近"温和 L 形 / 浅 V"，而不是高频突出的 V 形。跟 Harman 类目标比，主要偏差是中低频多约 3 dB，5 kHz 一带少约 6 dB（依据 Sonarworks 的文字转述，属近似值）。

技术素质

  • 解析：中上。2/3 篇认为中高频细节可以（consensus，中置信）。
  • 声场与定位：左右定位准确，但声场偏近（1 篇，低置信）。
  • 分离：中低频的延伸会让中频略显拥挤（依据 1 篇的描述推断，低置信）。
  • 动态与瞬态：大音量下瞬态清楚、不失真；低频"紧、有冲击"（2/3 篇）。

佩戴与做工

做工是这款耳机的强项：金属骨架，耳罩有防汗纳米涂层且可更换，附卷线和直线两根线，外加硬壳包。夹力偏紧，大耳朵用户可能嫌耳罩小（headphonecheck）。MajorHiFi 则认为松紧合适。长时间佩戴总体尚可。

用途适配

  • 混音 / 挑错：不合适。低频加重，headphonecheck 明确指出它不适合需要线性的录音室工作。
  • 听歌：适合电子、嘻哈这类重低音曲风；吉他类音乐表现一般（MajorHiFi）。
  • 推力：32 Ω、高灵敏度，手机直推就够。
