  • 和 DIY-Audio-Heaven 截图的一致与矛盾：
  • 一致：低频抬升明显（两者都是超低频比 1 kHz 高 7–11 dB）；约 140–150 Hz 都有鼓包，80–110 Hz 都有小凹；中频偏暖。
  • 矛盾：DIY-AH 图上是 5–6.5 kHz 深谷加 9 kHz、12 kHz 尖峰。KB006x 曲线的 3–6 kHz 是平滑的耳增益（+5~6.5 dB，比 Harman 略少），9 kHz、11 kHz、13.6 kHz 反而是凹陷。
  • 8 kHz 以上各种台架的差异本来就大，两个都不是标准台架，没有 5128 或 GRAS 数据可以裁决。所以只保留两者都支持的结论：高频有窄峰窄谷、不平滑。"高频锐"的说法降级为"作者主观 + 单一 DIY 台架"。
  • 风格结论（曲线重校）：低频明显偏多（超低频约高 5 dB、150 Hz 有鼓包），中频偏暖；2–6 kHz 存在感略低于 Harman；8 kHz 以上峰谷交替，总量不亮。它是偏暖、低频量足的调音，不是之前说的"高频锐的 V 形"。榜单说的"中性略暖"只对中频成立。

技术素质

  • 解析：细节量偏多，部分来自高频抬升（consensus 2/3）。
  • 声场：有评测说它不像典型封闭耳机那样闷，比较"开阔"（consensus 1–2 篇，置信度低）。
  • 动态与失真：200 Hz 以上失真 <0.3%，但 80 dB SPL 以上开始出现压缩，300 Hz 以下有共振（measured, DIY-Audio-Heaven）。
  • 分离、瞬态：证据不足。

佩戴与做工

夹紧力大是最一致的批评：Sonarworks 舒适度只给 5/10，测试者都不认为适合长时间混音；Head-Fi 用户说适应后会好一些（consensus 3/3 认为夹得紧）。夹得紧的好处是密封好、隔音强。

用途适配

  • 录音跟踪、现场、便携制作：很合适，隔音强、推力小，用手机也能驱动（dB/V 灵敏度高）。
  • 混音：低频偏多，需要心里有数或 EQ；佩戴也限制长时间使用。
  • 听歌：低频量足、偏暖，可以听；主要短板是夹头。

评分

  • 挑错度 52（曲线重校：62→52）：KB006x 曲线显示低频比 Harman 多约 4–5 dB、中频偏暖、存在感频段略少、高频总量不亮，挑错取向应该低于 DT 770 Pro（55）。隔音强、左右一致性好，仍然适合跟踪时听细节。之前的 62 是依据 DIY-AH 截图上的 9–12 kHz 尖峰，这个特征没有被第二条曲线确认。
  • 音质 68（维持）：低频延伸好、失真低、L/R 一致；但 150 Hz 鼓包、低频量偏多、8 kHz 以上峰谷明显，而且 80 dB SPL 以上开始压缩，平滑度一般。
  • 听歌适配 62（曲线重校：58→62）：低频量足、中频偏暖、高频不刺，比之前估的更好听；4.5–5 N 的夹紧力仍然限制长时间佩戴。

证据与置信度

  • 置信度：中。证据等级：measured。有一条非标准台架（KB006x 仿制）的数值曲线，加上一份 DIY 台架截图；两者低频和中频一致，8 kHz 以上互相矛盾；没有 5128 或 GRAS 数据。
  • 曲线重校：挑错度 62→52，听歌适配 58→62，音质维持 68。风格从"高频锐的 V 形"改为"偏暖、低频量足"。
  • 规格补充：DIY-Audio-Heaven 实测约 53 Ω、114 dB/V（101 dB/mW），与官方 64 Ω / 108 dB/V 有差异；结构化数据仍用官方值，两种数值都属于手机易推。夹紧力实测 4.5–5 N。
  • 缺口：没有标准台架数据；声场、分离的评测样本少。
