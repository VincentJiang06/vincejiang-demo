频响与风格

  • 测量源（代理）：STS 本体在 AutoEq、squig.link 各库（graph.hangout.audio、Earphones Archive 等）和 RTINGS 中都没有独立数据。多个来源称 STS 的耳罩和单元与 M50x 相同，因此这里用 M50x 的测量作代理，标为 proxy-measured。
  • oratory1990（GRAS 45BC KEMAR 类台架），经 AutoEq 收录：https://github.com/jaakkopasanen/AutoEq/tree/master/results/oratory1990/over-ear/Audio-Technica%20ATH-M50x ，目标曲线为 Harman OE 2018。
  • Rtings（B&K 5128），经 AutoEq 收录：https://github.com/jaakkopasanen/AutoEq/tree/master/results/Rtings/Bruel%20&%20Kjaer%205128%20over-ear/Audio-Technica%20ATH-M50x ，目标曲线为 5128 DF。
  • 分析工具为 fr_analyze.py，以 500–1000 Hz 对齐。
  • 低频：5128 DF 只是参考基线，偏好中性的头戴一般比它低频高 4–6 dB。M50x 的 5128 曲线在 60–200 Hz 比 DF 高 +5.3 dB，正好落在这个范围的上沿，即"略多"而不是"很多"。对照 Harman OE 2018（oratory1990），中低频（60–200 Hz）高约 +2.6 dB，超低频基本持平。对照 5128 DF（Rtings），60–200 Hz 高 +5.3 dB，20–60 Hz 高 +3.9 dB。DF 目标本身不含低频抬升，所以这个量大致落在 Harman 类目标附近，略多一点。
  • 中频：200–500 Hz 为 −1.1 至 −1.4 dB，1–3 kHz 在 ±1 dB 以内。测量修正：中频并没有明显后撤。
  • 高频：3–10 kHz 的平均偏差很小（−1.5 至 +0.7 dB），但曲线起伏大。oratory1990 的数据在约 8 kHz 有 +3.1 dB 的窄峰，在约 14.5 kHz 有 +3.9 dB 的窄峰；Rtings 的数据在约 4.3 kHz 和 7.8 kHz 各有 +4.7 dB 的峰，约 6.2 kHz 有 −6.4 dB 的谷。齿音和颗粒感主要来自这些窄峰，而不是整体高频偏多。
  • 风格：测量修正。它不是明显的 V 形，而是接近 Harman 的轻度低频抬升，高频为锯齿状，有 4–8 kHz 的窄峰。评测里说的“讨喜 V 形”主要来自低频量感和这些窄峰。

技术素质

  • 解析：同价位中等水平，细节够用但不突出（约 3/4 家评测共识，基于 M50x）。
  • 声场：窄，封闭式典型表现（3/4 共识）。
  • 分离：中等；中低频的量感会让复杂编曲略糊（2/4）。
  • 动态/瞬态：低频冲击力好，速度一般（2/4）。
  • STS 专属：HiFiReport、TechRadar 均认为声音与 M50x 等同，差异在话筒。

佩戴与做工

塑料为主，结构耐用（consensus）。夹力偏紧，耳罩内径对一般耳朵偏小，1–2 小时后不适（HiFiReport）；另有评测认为夹力尚可。吊杆话筒增加一点重量。

用途适配

  • 混音/挑错：低频略多，高频有窄峰，不适合做精确判断，只能作参考。
  • 听歌：讨喜，但佩戴限制长时间使用。
  • 推力：38 Ω、约 99 dB/mW，手机或声卡直推即可。
  • 真正的定位是直播和播客耳麦：话筒质量是主要卖点。

评分

  • 曲线重校：分数不变（40 / 68 / 70）；证据等级从 measured 改为 proxy-measured，因为全部曲线都来自 M50x。
  • 挑错度 40：与锚点 M50x 相同。测量显示中高频没有整体抬升，只有窄峰，低频略多，所以不以挑错为目标。
  • 音质 68：发声部分与 M50x 等同，直接对齐锚点。高频起伏限制了平滑度。
  • 听歌适配 70：调音接近 Harman 且低频略多，听感讨喜。但耳罩小、夹力紧，吊杆话筒对纯听歌是累赘，所以比 M50x 略低。
