Tascam TH-02

25 美元级的暗色封闭耳机：3–5 kHz 大坑、8 kHz 尖峰，听感松弛但不准，佩戴与隔音都一般。 A dark-tilted $25 closed-back with a deep 3–5 kHz hole and an 8 kHz spike: relaxed, not accurate, with mediocre comfort and isolation.

频响与风格

  • 测量源：RTINGS 测量，数据取自 AutoEq 收录的版本：results/Rtings/HMS II.3 over-ear/Tascam TH-02（https://github.com/jaakkopasanen/AutoEq/tree/master/results/Rtings ）。台架为 HEAD acoustics HMS II.3。先对照 AutoEq 按这个台架给出的目标看误差，再用 fr_analyze 与 Harman OE 2018 对比。严格说两者台架不同，Harman 这一组只作参考。
  • 低频（measured）：20–60 Hz 比 Harman 少约 7 dB，60–200 Hz 少约 3 dB。200 Hz 附近比 AutoEq 目标高约 3 dB，略带浑感。RTINGS 文字说低频"偏多、会渗进中频"，这和曲线上的超低频缺量对不上，原因可能是佩戴密封不同。结论：量感偏少到中性，中低频稍厚。
  • 中频（measured）：500 Hz–2 kHz 基本中性。3 kHz 起开始下陷。
  • 高频（measured）：4–5 kHz 比目标低约 11–13 dB，是很深的凹陷。8.3 kHz 有一个约 +7~9 dB 的窄峰，有齿音风险。12 kHz 以上滚降。
  • 风格：fr_analyze 判为"暗声、暖向"（tilt -2.3 dB）。存在感频段大幅缺失，主观上偏松弛、不刺激，但 8 kHz 尖峰会偶尔带出嘶声。

技术素质（评测共识，2 篇左右）

  • 解析与分离：一般。RTINGS 认为声音"适度均衡"，但低频有些浑（1/2）。
  • 声场：RTINGS 称"尚可"，对封闭耳机来说不差（1/1，证据不足）。
  • 动态、瞬态：证据不足。

佩戴与做工

耳罩小，不能完全包住耳朵，长时间佩戴不舒适，还会影响密封（RTINGS）。塑料机身轻、可折叠。线材 3 m，不可拆。

用途适配

3–5 kHz 缺得这么多，人声齿音和军鼓边沿都会被压下去，不适合挑错或混音。适合作入门陪听或录音时的监听。阻抗 32 Ω，手机就能推动。

评分

  • 挑错度 35：存在感频段大幅凹陷、整体偏暗，只有 8 kHz 单峰会带出一点嘶声（measured）。
  • 音质 42：曲线起伏大（深坑加窄峰），低频浑，素质属于入门档（measured + consensus）。
  • 听歌适配 50：听感松弛、不累耳，但佩戴一般，隔音也弱。

证据与置信度

  • 曲线重校：2026-09 重新检索了 5128 与 GRAS 数据库，仍然没有找到更高优先级台架的曲线。重跑 fr_analyze，结果与原结论一致，分数不变。

  • 证据等级：measured（只有 RTINGS 一条曲线），置信度 medium。
