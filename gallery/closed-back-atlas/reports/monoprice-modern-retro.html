频响与风格（measured）

  • 测量源：oratory1990，经 AutoEq 收录的原始数据：measurements/oratory1990/data/over-ear/Monoprice Modern Retro.csv（https://github.com/jaakkopasanen/AutoEq）。台架：GRAS 45BC KEMAR（oratory1990 头戴测量的标准台架）。目标曲线：Harman OE 2018，用 fr_analyze.py 以 500–1k Hz 对齐。
  • 低频：20–60 Hz 比目标高 +7.4 dB，60–200 Hz 高 +8.1 dB。注意 Harman 目标本身已经带低频架，所以这是在它之上再多约 8 dB，属于明显的低频猛（measured）。
  • 中频：200–500 Hz 高 +3.0 dB，带出一些浑厚感；1–3 kHz 基本贴着目标（-0.9 dB）。3.5 kHz 附近有约 -6 dB 的凹陷，人声前沿会退后一点（measured）。
  • 高频：2–6 kHz 与 6–10 kHz 两段整体分别比目标低 -4.0 / -3.2 dB，但 5.3 kHz 和 6.5 kHz 各有约 +7 dB 的窄峰，9 kHz 和 11 kHz 各有约 -6/-7 dB 的凹陷。所以整体偏暗，个别音源上仍可能有齿音（measured）。
  • 换 Dekoni Elite Hybrid 耳垫后（同一台架）风格变化很大：低频只比目标高约 +3.5 dB，1–10 kHz 比目标高约 +4.5 dB，10 kHz 以上高 +8.5 dB，5.3 kHz 有 +9 dB 峰，变成亮向的 V 形。所以本报告的结论只适用于原装耳垫（measured）。
  • 整体倾斜 -10.3 dB，暖向。主观评测对"V 型、高频偏亮"的说法（Head-Fi 用户）和"高频顺滑"的说法（Sonic Elevation）互相矛盾；以测量为准，高频整体并不亮，只有窄峰。

技术素质（consensus，2 篇来源，样本少）

  • 声场：2/2 认为以封闭耳机而言意外地开阔（Sonic Elevation、Head-Fi 用户评测）。
  • 解析与纵深：1/2 说纵深不及更贵的型号；证据有限。
  • 动态与低频质量：低频扎实、不破音（Sonic Elevation）。
  • 分离与瞬态：证据不足。低频超量这么多，按常识推测会有一定掩蔽（prior）。

佩戴与做工

全塑料机身，实用但不高档；夹力轻；原装蛋白皮耳垫偏薄，适合 2 小时以内的使用，社区常见做法是换 Dekoni 等耳垫（oratory1990 也单独测过 Dekoni Elite Hybrid 耳垫版本）。线材不可拆。

用途适配

  • 混音/挑错：不适合。+8 dB 的低频和凹陷的中高频会让混音在低频上判断失准。
  • 听歌：流行、电子、嘻哈这类重低音曲风听起来讨喜。
  • 推力：32 Ω，手机直推没有问题。

评分

  • 挑错度 28：低频大幅超量，中高频整体收敛，只有窄峰 / Bass-heavy and warm per measurement.
  • 音质 52：低频量很足，但频响起伏大（多个 ±6–7 dB 的峰谷），做工和耳垫都是入门级。
  • 听歌适配 60：好推、讨喜，声场口碑不错；不过低频过量，原装耳垫也一般。

证据与置信度

  • 置信度：中。风格有 oratory1990 的测量作锚点，可信；技术素质的评测样本少。
  • 曲线重校（本轮）：没有找到 5128 或其他新的原始数据，仍以 oratory1990 GRAS 曲线为准，三项分数不变（28 / 52 / 60）。
