频响与风格

以 B&K 5128 为主，对比目标是 5128 扩散场（bk5128_df），中频 500–1000 Hz 对齐。5128 DF 是参考基线，不是偏好目标：偏好中性的头戴通常低频比 DF 高约 4–6 dB，高频略低于 DF。

  • 按偏好换算后：偏好中性的头戴在 5128 上低频本来就高 4–6 dB。RTINGS 的中低频 +6.3 只比这个多 1–2 dB，但低中频 +5.2 是实打实的厚。Earphones Archive 那副的低频比偏好多约 3–5 dB，还往超低频延伸，低中频反而只多 1.8。两条 5128 曲线的共同点是：低频到低中频偏厚，整体暖。
  • 高频：偏好中性的头戴在 6–10 kHz 应略低于 DF，而两条 5128 曲线都高出 DF 1.6–3.9 dB，尖峰都在 8.5 kHz 附近，所以这里是相对偏亮、有齿音风险的一段。10 kHz 以上两条都缺 6–7 dB，15 kHz 以上明显滚降。
  • 风格：暖厚的低频加上 8.5 kHz 尖峰、顶端滚降，是暖向 U 型。GRAS、HMS 和 squig 曲线在"低频鼓包 + 8–9 kHz 峰 + 顶端滚降"上与此一致，没有和 5128 矛盾的结论。
  • 两条 5128 的差异：超低频差 6.5 dB，低中频差 3.4 dB。原因可能是版本不同（现款对 HD25-1 II），也可能是贴耳密封不同。oratory1990 的"密封不良"曲线超低频掉 13 dB；Exound 的松、紧两次佩戴超低频差 8.5 dB。所以这副耳机的低频量主要取决于贴合，不是固定值。
  • HMS II.3 的几条老曲线（Innerfidelity、Headphone.com）超低频从 −13 到 +3.5 dB 不等，一样是密封差异造成的，没有用来打分。

技术素质

  • 解析/清晰度：DJ 与现场环境下"听得清"是共识（3/3 DJ 向评测；consensus，场景偏向）。
  • 声场：贴耳封闭，声场小（prior + 共识倾向，证据不足以量化）。
  • 分离、动态、瞬态：缺乏可靠评测，证据不足。
  • 一致性：Sonarworks 称批次一致性很好（measured）。

佩戴与做工

模块化、零件可换、耐摔，是长期口碑（consensus）。夹力偏紧，短时舒适，长时间贴耳压迫感见仁见智（2/3 评测提到 "slightly tight"）。

用途适配

  • 挑错/混音：Sonarworks 认为未校正不适合关键混音；8 kHz 峰对查齿音/底噪有用。更适合跟踪、监听、DJ cue、外景录音。
  • 听歌：低频有冲击、隔音好，便携通勤可用，但高频峰和贴耳压迫限制长时间聆听。
  • 推力：70 Ω、高效率铝音圈，手机直推足够响（prior + 官方"high sensitivity"）。

评分

  • 挑错度 56（曲线重校：58→56，第二条 5128 显示低频比偏好多 3–5 dB，更暖）：8.5 kHz 尖峰在两条 5128 曲线上都出现，会放大齿音和嘶声，这是它能"听出毛病"的原因；但低频到低中频比偏好中性多出 1–5 dB，顶端又缺 6–7 dB，整体偏暖厚，不适合作严格的挑错工具。位置在 DT 770 Pro（55）附近。
  • 音质 64（不变）：两条 5128 和 GRAS 在主要特征上一致，频响起伏明显（低中频鼓包、8.5 k 尖峰、13 k 窄峰、15 k 以上滚降），而且低频量很依赖密封；失真、声场等技术素质仍缺多源测量。
  • 听歌适配 62（不变）：低频有劲、隔音好，但 8.5 k 峰、低中频偏浑和贴耳压迫拖分。

证据与置信度

  • 置信度：中。频响方面证据很足：两条 B&K 5128（RTINGS 现款、Earphones Archive 的 HD25-1 II）加 GRAS 和多条 HMS/squig 曲线，主要特征互相印证。技术素质（失真、声场）仍缺多源测量，所以总体不升为高。
  • 版本说明：Earphones Archive 与 oratory1990 测的是 HD25-1 II，Innerfidelity/Headphone.com 有初代、Aluminium 和 SP，Exound 是 75 周年版，Hu-Fi 换了 Yaxi 耳垫。现款的主依据是 RTINGS。
  • 证据缺口：官方没有给出带单位的灵敏度；crinacle 的 GRAS 数据抓取被拒；RTINGS 的失真和隔音页没有逐项核对。
