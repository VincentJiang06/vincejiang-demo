中频比较平，中低频有鼓包，超低频比 M50x 少。8 kHz 有尖峰，10 kHz 以上偏亮（oratory1990 实测）。夹得偏紧。适合当入门监听，长时间听歌不算舒服。 Flat mids with a mid-bass bump, less sub-bass than the M50x and a peaky, bright top end (oratory1990 data); a capable budget monitor, but its clamp makes it a so-so everyday listen.

频响与风格

  • 测量源：oratory1990 实测，经 AutoEq 收录（https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/Audio-Technica%20ATH-M40x/Audio-Technica%20ATH-M40x.csv）。台架：GRAS 45BC KEMAR 耳模拟器 + KEMAR 耳廓（oratory1990 标准台架）。目标曲线：Harman over-ear 2018。分析工具：fr_analyze.py，以 500 Hz-1 kHz 对齐。另有 DIY-Audio-Heaven 和 Sonarworks 的测量作为补充。
  • 低频：60-200 Hz 比 Harman 多约 +4 dB（100-150 Hz 的残差为 +3~+4 dB）。超低频反而缺一点，30 Hz 约 -2.4 dB。所以它不是"低频收"，而是中低频有鼓包、下潜稍弱。
  • 中频：200-500 Hz 为 +0.3 dB，500 Hz-1 kHz 为 0 dB，1-3 kHz 为 +1.0 dB，都接近目标。300 Hz 附近只有约 -1.3 dB 的浅凹，不算明显的"中频凹陷"。
  • 临场/高频：3-6 kHz 比目标少约 0.6 dB，5 kHz 附近的凹陷约 -3.6 dB。6-10 kHz 多约 +3.4 dB，8.3 kHz 有约 +4.6 dB 的尖峰（齿音风险）。10 kHz 以上多约 +6.3 dB，11.8 kHz 有凹陷，15 kHz 附近有毛刺峰。高频抬升是这款耳机最主要的偏离。
  • 与 M50x 比（同一测量者、同一台架）：两者中低频鼓包的量差不多（M40x +4.0 dB，M50x +2.6 dB）。M40x 的超低频更少，8 kHz 和 10 kHz 以上明显更亮（mid_treble 为 +3.4 dB 对 -1.5 dB，air 为 +6.3 dB 对 +3.3 dB）。
  • 其他台架佐证：RTINGS（HMS II.3）同样显示 60-200 Hz +4.2 dB、6-10 kHz +4.5 dB（8.6 kHz 峰 +5.7 dB）、10 kHz 以上 +8.1 dB，与 GRAS 结论一致，只是高频量更大。Auriculares Argentina（台架未注明）中低频只多 +1.3 dB、200-500 Hz 反而 -1.5 dB，但 10 kHz 以上多约 +9.9 dB（14.8 kHz 峰）。三份数据的共同点是 10 kHz 以上明显偏多；中低频鼓包的大小有分歧，以 GRAS 为准（+4 dB）。另：GRAS 数据的超低频段均值为 -0.4 dB（30 Hz 单点约 -2.4 dB），下潜只是略弱。
  • 风格：中低频略厚，外加 8 kHz 和极高频的尖峰。整体接近 Harman，但高频偏亮、偏尖。
  • 测量修正：上一版说"低频收"和"200 Hz-1 kHz 凹陷"，oratory1990 的数据都不支持。改为：中低频与 M50x 相当，超低频更少，中频基本平，偏离主要在 8 kHz 以上。

技术素质

  • 解析：抬高的高频会凸显泛音，这是染色带来的"解析感"，不是真正的细节（1/2 评测明确提到，另 1 篇说高频"顺但假"）。
  • 声场、分离、动态、瞬态：本次来源里没有可靠的一致意见，证据不足。先验判断：属于封闭式入门的常见水平。

佩戴与做工

Sonarworks 说它夹得紧、头梁硬，几小时后会不适，皮质耳罩闷汗。DIY-Audio-Heaven 也说耳罩偏闷（consensus 2/2）。做工扎实，可折叠、可换线（官方加 prior）。

用途适配

  • 混音/挑错：中频基本平，但中低频鼓包和抬高的高频（8 kHz 峰、10 kHz 以上偏多）会误导判断。Sonarworks 给 6/10，校准后 7.4/10。用来做跟踪录音、粗略监听够用。
  • 听歌：音色偏淡，佩戴也一般。
  • 推力：35 Ω、约 98 dB/mW，手机直推没问题。

评分

  • 挑错度 62（曲线重校：62→62，不变；无 5128，GRAS 结论与上一轮相同，另两份曲线同样显示高频偏多）：临场段没有抬升，但 8 kHz 尖峰和 10 kHz 以上约 +6 dB 会放大齿音和空气感，超低频也偏少，所以比 M50x（40）更挑错。中低频鼓包又让它挑不到 Hi-X60（70）的程度。
  • 音质 63（曲线重校：63→63，不变）：中频平直是优点，但高频有多处尖峰和凹陷，平滑度不如 M50x（68）。失真和素质都属于入门监听水平。
  • 听歌适配 60（曲线重校：60→60，不变）：高频偏亮偏尖，夹得紧，不如 M50x（72）。
