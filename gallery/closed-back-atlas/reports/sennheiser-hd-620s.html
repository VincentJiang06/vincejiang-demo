频响与风格

以三条 B&K 5128 原厂垫曲线为主（fr_analyze.py，对比 5128 DF 基线，以 500 Hz–1 kHz 对齐）。5128 DF 是参考基线，不是偏好目标：偏好中性的头戴一般低频比 DF 高约 4–6 dB，高频略低于 DF。下面的 dB 值依次为 EarphonesArchive 样品 1 / 样品 2 / RTINGS 相对 DF 的频段平均偏差。

  • 低频：20–60 Hz +2.3 / +2.7 / +3.8 dB，60–200 Hz +4.9 / +4.5 / +4.0 dB。换算到偏好中性，大致落在区间内，中低频略靠上限、超低频略欠。所以是"温和、够量"的低频，不是低频猛的耳机（脚本自动标签"低频猛"是按 DF 算的，换算后不成立）。
  • 中频：200 Hz–1 kHz 在 ±1 dB 内，贴合；1–3 kHz 低 1.8 / 2.7 / 1.1 dB，人声和乐器的"前沿感"略退后。
  • 中高频/存在感：3–6 kHz 低 4.3 / 3.7 / 2.5 dB，比"略低于 DF"更暗；三条 5128 曲线都在约 3.85 kHz 有深而窄的凹陷（残差约 −9 到 −11 dB），oratory1990 GRAS 同样测到（约 3.9 kHz）。这是它耐听、不刺的主要原因，也是挑错能力偏弱的主要原因。
  • 高频：EarphonesArchive 两个样品都在约 8.4 kHz 有 +8 到 +9 dB 的窄峰，紧接着约 10.5 kHz 有凹陷；RTINGS 的窄峰位置在 13.4 kHz（+7 dB），6–10 kHz 平均接近 DF（+0.5 dB）。10 kHz 以上三条都低于 DF（−3 到 −7 dB），空气感偏少。
  • 矛盾与处理：oratory1990 GRAS 曲线在约 9.5 kHz 是凹陷而不是峰，air 段反而高于 Harman（+2.5 dB）；以 5128 为准，判定为"8–9 kHz 附近有一个窄峰、10 kHz 以上滚降"。高频窄峰的位置在不同样品、不同台架间移动，说明它受佩戴和耳垫影响大。换 HD 560S 耳垫后中低频降到 +2 dB，属于改装，不计分。
  • 风格结论（曲线重校）：整体是"暖、放松"的调音。低频在偏好中性范围内，1–6 kHz 系统性偏低，3.9 kHz 有深凹陷，8.4 kHz 有一个窄峰会带出一点齿音，超高频滚降。上一轮的"略放松的准 Harman"大方向不变，但存在感比上一轮（GRAS 数据，2–5 kHz 只低约 0.5 dB）判断的更暗，暖度更明显。

技术素质

  • 失真：1 kHz / 90 dB SPL 时 THD < 0.05%（measured）。
  • 声场与定位：斜置单元让深度和空间感比一般封闭更好，评测普遍把这当作卖点（consensus 3/3）。
  • 解析与分离：够得上"中端 600 系"水准，但没有评测认为它明显强过同价位（consensus 2/3）。
  • 动态与瞬态：没有专门讨论，证据不足。

佩戴与做工

耳罩内腔更宽更深，不压耳；头梁用记忆棉。侧向夹力偏紧，延续 600 系的特点。合成皮耳垫比较闷热。耳罩有钢件加固，转动时外壳会有少许形变（consensus）。

用途适配

  • 听歌：自然中频加足量低频，适合日常长时间听。
  • 挑错/混音：5128 测得 1–6 kHz 整体偏低、3.9 kHz 有深凹陷，高频 10 kHz 以上滚降，所以挑错偏弱；它不是严格的监听调音，只能兼作审听，用来检查整体平衡。
  • 推力：灵敏度约 112 dB/V，用手机或小尾巴能推到够用音量；阻抗较高，换成放大器会更从容。

评分

  • 挑错度 40（曲线重校：42→40，原因：5128 三条曲线显示 1–6 kHz 系统性低于 DF 2–4 dB，存在感比 GRAS 数据显示的更暗；8.4 kHz 窄峰只提供有限的齿音提示，不足以抵消）。低于 M50x（≈40）同档、略低于 K371（≈45）。
  • 音质 76（不变）：低中频贴合、失真低、斜置单元带来空间感；扣分在 3.9 kHz 深凹陷、8.4 kHz 窄峰和超高频滚降，样品间高频也有差异。整体没到 DT 1770 / HD 480 Pro 那一档。
  • 听歌适配 78（不变）：5128 曲线确认是暖而不刺的调音，低频量在偏好范围内，适合长时间听；扣分在夹力、皮垫闷热，以及略欠的空气感。
