结论：DT 770 家族的低阻、可换线版本。V 型调音（测量确认），低频有力、高频锐利，细节感强；约 6.3 kHz 的齿音峰和 11–12 kHz 的亮峰是主要短板。适合监听和找高频问题，长时间听歌可能疲劳。 Verdict: A punchy, treble-forward V-shaped 48 Ω DT 770. It shows detail well and is easy to drive, but its sibilance-prone treble limits relaxed listening.

测量源（三条独立测量，结论一致；前两条如下，第三条见下文）： - oratory1990（AutoEq 收录）：https://github.com/jaakkopasanen/AutoEq/blob/master/measurements/oratory1990/data/over-ear/Beyerdynamic%20DT770%20Pro%20X%20Limited%20Edition.csv ，台架 GRAS 45BC KEMAR - Kuulokenurkka（AutoEq 收录）：https://github.com/jaakkopasanen/AutoEq/blob/master/measurements/Kuulokenurkka/data/over-ear/Beyerdynamic%20DT770%20Pro%20X%20Limited%20Edition.csv ，台架未单独核实（AutoEq 将其与 GRAS 系数据同样处理） - 对比目标：Harman Over-Ear 2018（GRAS 45CA），以 500 Hz–1 kHz 对齐；分析脚本 fr_analyze.py

关键特征（两条测量的数值依次为 oratory1990 / Kuulokenurkka，单位 dB，数值相对目标）： - 低频：20–60 Hz 比目标高 +4.8 / +4.7，60–200 Hz 高 +3.3 / +3.2，量感明显偏多、下潜充分；200–500 Hz 低 −3.1 / −3.3，约 240 Hz 有凹陷（残差约 −5）。这与“低频厚、和中频略脱节”的主观描述一致。 - 中频：1–3 kHz 与目标基本持平（+0.8 / +0.2），中频不前倾，也不凹。 - 高频：3–5 kHz 为 +0.8 / +1.8；5–10 kHz 为 +4.6 / +5.2，10 kHz 以上为 +5.3 / +6.6。主峰约 6.2–6.4 kHz，残差 +5.4 / +6.2，有齿音风险；约 11–12 kHz 另有一个亮峰，残差 +4.4 / +9.4；约 9 kHz 和 14–15 kHz 有凹陷。 - 第三条曲线（GadgetryTech，711 仿制，对比 Harman OE 2018）：超低频 +4.1，中低频 +2.7，200–500 Hz −2.8，3–5 kHz −1.1，5–10 kHz +5.1，10 kHz 以上 +6.4；约 6.6 kHz 峰 +6.4，约 11.8 kHz 峰 +6.1，约 9 kHz 和 13.8 kHz 有凹陷。三条曲线的方向和峰谷位置一致，没有矛盾。 - 没有 B&K 5128 数据，所以风格判断按 GRAS 为准。 - 风格：V 型，整体倾斜中性。测量修正：原报告说齿音峰“约 8 kHz”，测量显示主峰在约 6.3 kHz；8 kHz 附近仍处在抬升区，但不是峰顶。

技术素质

  • 解析与细节感强（3/3）。其中一部分来自高频抬升，不完全是真实的分辨力。
  • 声场：在封闭式里算大，纵深不错（1/3 明确提到，其余未反对）。
  • 瞬态：headphonecheck 评价为“exemplary”，结实、干净（1/3）。
  • 分离度和动态：没有足够的一致评价，证据不足。

佩戴与做工

headphonecheck 认为舒适度高：绒面耳垫柔软，头梁自动调节，夹力适中。可换线和 DT 系列的可维修性是加分项（prior）。

用途适配

  • 混音/挑错：高频放大了齿音和镲片问题，适合查高频瑕疵，但判断高频平衡时需要留出余量。
  • 听歌：低频讨喜，不过高频容易疲劳；DIY-Audio-Heaven 认为不加 EQ 听歌时高频“过多”。
  • 推力：48 Ω、98 dB/mW，手机或小尾巴就能推。

评分

  • 挑错度 65（本轮曲线重校未变；上一轮由 62 上调）：5–10 kHz 比 Harman 高约 5 dB，10 kHz 以上约高 5–7 dB，6.3 kHz 和 11–12 kHz 有尖峰，高频瑕疵会被放大。低频比目标多约 3–5 dB，抵消了一部分挑错感，所以仍低于 Hi-X60（约 70）。
  • 音质 75（本轮未变；上一轮由 76 下调）：三条独立测量高度一致，说明声学表现和批次比较稳定；下潜、瞬态和声场在价位内不错。扣分在 6 kHz / 11 kHz 尖峰和约 240 Hz 的中低频凹陷。
  • 听歌适配 68（本轮未变；上一轮由 70 下调）：佩戴舒适、低频有劲，但测量确认高频整体偏多，长时间听歌容易疲劳。
