Fostex TH-610

木壳大动圈的"氛围型"封闭耳机：低频量足、人声靠前、声场偏近，推力很轻；是 Hi-Fi 听歌用的，拿来挑错并不合适。 A walnut-cup, bass-rich closed headphone with intimate mids that is very easy to drive; it is a musical Hi-Fi can rather than a critical monitor.

频响与风格

  • 测量源（曲线库补查）：AutoEq 收录的 Innerfidelity 测量 Fostex TH610（https://github.com/jaakkopasanen/AutoEq/tree/master/results/Innerfidelity/over-ear/Fostex%20TH610 ，raw：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/measurements/Innerfidelity/data/over-ear/Fostex%20TH610.csv ）。台架为 Innerfidelity 的 Head Acoustics HMS II.3（不是 GRAS 45CA），目标曲线用 Harman over-ear 2018，按 500–1000 Hz 对齐后用 fr_analyze.py 计算。台架和目标不配套，下面的 dB 只作量级参考。oratory1990 只有换 Dekoni 羊皮耳垫的版本（原装耳垫版未收录），没有采用。
  • 低频：20–60 Hz 相对 Harman 约 +0.7 dB，属于中性；60–200 Hz 约 +3.4 dB，200–500 Hz 约 +3.1 dB，都是略多。Harman 本身已经带低频架，所以这是在它上面再加 3 dB 的中低频，暖、厚的听感由此而来。这与"量足"的多数评测一致，MajorHifi 说"克制"的判断不成立。
  • 中频：1–3 kHz 约 −1.5 dB，略少。人声的厚度主要来自 200–500 Hz 的抬升，不是靠 presence 往前推。
  • 高频：3–6 kHz 约 −0.9 dB，6–10 kHz 约 −1.9 dB，整体收敛；但 ~9.6 kHz 有约 +5 dB 的窄峰，~8.2 kHz 有约 −7 dB 的凹陷，10–20 kHz 均值 +4.5 dB（含 ~12.4 kHz 的毛刺）。这个窄峰能解释 MajorHifi 听到的齿音，所以高频评价出现分歧。
  • 与 GRAS 换垫曲线的矛盾：oratory1990 的 GRAS 43AG-7 曲线（Dekoni 开孔羊皮耳垫）对照 Harman OE 2018 为：20–60 Hz −4.1 dB、60–500 Hz 约 −1～−0.5 dB、3–6 kHz +4.4 dB（~5.2 kHz 峰 +5.7 dB）、6–10 kHz −2.4 dB（~7.6 kHz 谷 −6.1 dB）、10–20 kHz +6.6 dB，脚本判为"明亮"。开孔耳垫一般会减低频、抬中高频，所以这条曲线不代表原装状态，不能用来推翻 HMS 曲线的暖向结论。两条曲线一致的地方是单元在 5–10 kHz 一带峰谷不平（约 7.6–8.2 kHz 深谷，两侧有窄峰），这支持"高频不平、偶有齿音"的判断。
  • 整体：低中频偏暖偏厚，presence 和中高频略收，带几处窄峰；是暖向讨喜调音，不是平直监听曲线（measured，单一台架）。

技术素质

  • 解析：尚可，但 2/3 篇指出空气感和细节不如更贵的型号或开放式（consensus）。
  • 声场：3/3 认为偏小、偏近，没有开阔感（consensus）。
  • 分离与定位：人声居中很近，乐器稍往后退（Headphone Guru）。
  • 动态与瞬态：冲击力不错，但低频衰减偏慢，不算紧（Audio Primate，1 篇）。

佩戴与做工

黑胡桃木壳，每只纹理各不相同；2-pin 接头镀铑，可拆线。夹力适中，2/2 篇认为能长时间佩戴。蛋白皮耳垫和头梁用料一般；木壳不耐磕，不适合外带。

用途适配

  • 混音/挑错：不推荐。低频偏多、中频有染色、声场近，都会误导判断。
  • 听歌：适合人声、流行、电子，氛围感好。
  • 推力：阻抗 25 Ω，1 V 就能到 118 dB SPL（RAA），手机也能推响。

评分

  • 挑错度 30：测量显示 60–500 Hz 比 Harman 多约 3 dB，2–10 kHz 略收，是暖厚的讨喜型；只有约 9.6 kHz 的窄峰会带出一点齿音，所以只比 SRH1540 略偏分析（测量确认，曲线重校后维持原分：GRAS 曲线是开孔换垫版，不改变对原装状态的判断）。
  • 音质 74：质感和冲击都不错，但声场和空气感被多篇评测点名。
  • 听歌适配 76：讨喜，佩戴也可以；扣分在于 375 g 偏重、声场近，高频评价也有分歧。
