频响与风格

  • 测量源：oratory1990 的 Fostex T40RP Mk3 测量（AutoEq 收录，raw CSV：https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/oratory1990/over-ear/Fostex%20T40RP%20Mk3/Fostex%20T40RP%20Mk3.csv ）。台架为 GRAS 45BC-10（GRAS 耳道，AutoEq 索引标注；上一版误写为 43AG）。按规则，没有 5128 数据时以 GRAS 曲线为主。对比目标：Harman OE 2018，以 500–1000 Hz 对齐，用 fr_analyze.py 分析。交叉参考：Innerfidelity 的 Mk3 测量（Head Acoustics HMS II.3，https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/Innerfidelity/over-ear/Fostex%20T40RP%20Mk3/Fostex%20T40RP%20Mk3.csv ）。注意：测量对象是 Mk3，不是榜单写的"mk4"。
  • 低频：oratory1990 数据中，20–60 Hz 比目标低约 2.2 dB，60–200 Hz 高约 1.1 dB，基本贴合 Harman 低频架。Innerfidelity 数据中，20–60 Hz 低约 11 dB，60–200 Hz 低约 2.2 dB，超低频延伸不如 oratory 数据。两台架差异较大，可能与耳垫密封有关。测量修正：上一版说"低频弱"，这只在超低频和密封不良时成立，中低频的量并不少。[measured]
  • 中频：200–1000 Hz 贴合目标；1–3 kHz 比目标低约 4.2 dB，上中频凹陷。[measured]
  • 高频：3–6 kHz 低约 4.2 dB，6–10 kHz 低约 1.9 dB，10 kHz 以上低约 2.6 dB。8.4 kHz 有一个约 +3.2 dB 的小峰，13.4 kHz 附近有 +3.6 dB 的窄峰，11.9 kHz 和 15.4 kHz 附近凹陷。[measured]
  • 风格：分析器判为"暗声"，tilt 为 −2.3 dB（暖向）。上中频到存在感频段整体下沉约 4 dB，低频贴合目标，所以听感偏暗、偏柔、不刺耳。这与评测里"偏暗、平淡"的印象一致；"低频弱"主要来自超低频滚降和耳垫密封问题。

佩戴与做工

原厂舒适度差：耳垫薄，头梁缺乏衬垫，长时间佩戴普遍建议换垫、加悬挂带。做工偏实用，零件方便更换和改装。

用途适配

  • 混音/挑错：声音偏暗、偏平，不会刻意放大齿音，中频判断尚可；低频少，需要 EQ 或参考其他设备。
  • 听歌：原厂声音平淡，佩戴一般，适合愿意改装或调 EQ 的用户。
  • 推力：标称 91 dB/mW 偏低，平面振膜建议配独立耳放；手机直推会显得乏力。

评分

本轮补查没有找到 5128 或新的数值曲线，分数不变（曲线重校：无变化）。

  • 挑错度 45（测量修正，原 62）：1–6 kHz 比 Harman 低约 4 dB，高频只有小峰，整体暗而柔，不会放大齿音和瑕疵，偏向"整体/宽容"一侧，接近 K371 的位置。
  • 音质 65：oratory 数据在中低频很平滑，峰谷幅度较小；平面振膜的细节和结像是加分项；原厂佩戴和推力需求是减分项。两台架的低频差异说明，耳垫对声音一致性影响较大。
  • 听歌适配 55（原 50）：测量上低频量足、高频不刺，调音比主观印象更容易接受；但原厂佩戴差，也需要耳放，所以分数有限。
