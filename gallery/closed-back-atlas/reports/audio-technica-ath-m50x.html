频响与风格

  • 主曲线：RTINGS 的 B&K 5128 曲线，用 fr_analyze.py 对照 5128 DF 分析，以 500 Hz–1 kHz 对齐。注意，5128 DF 是参考基线，不是偏好目标。偏好中性的头戴一般低频比 DF 高约 4–6 dB，高频略低于 DF。下面的解读都按这个标准换算。
  • 低频：20–60 Hz 比 DF 高 +3.9 dB，60–200 Hz 高 +5.3 dB。换算到偏好中性，大致是"中性到略多"。58 Hz 附近有一个约 -4 dB 的窄凹，其余部分延伸完整。
  • 中频：200–500 Hz 为 -1.1 dB，1–3 kHz 为 +0.8 dB，都算中性。
  • 临场/高频：3–6 kHz 为 +0.7 dB，6–10 kHz 为 -0.9 dB，10 kHz 以上为 +0.4 dB。偏好中性的头戴，这一段通常略低于 DF，所以 M50x 实际上比偏好中性略亮一点。窄峰在 4.3 kHz 和 7.8 kHz（残差都是 +4.7 dB），6.2 kHz 有 -6.4 dB 的窄凹。
  • 风格：脚本判为"低频猛"，倾斜 -4.5 dB（暖向）。按偏好换算后，实际形态是"低频中性偏多 + 临场窄峰"的温和 U 型。
  • 与 GRAS 曲线的矛盾：oratory1990 的 GRAS 曲线对照 Harman 2018，3–6 kHz 为 -0.9 dB，窄峰在 8 kHz 和 14.5 kHz。5128 上的峰落在 4.3 kHz 和 7.8 kHz，临场段也略高于偏好。两者低频结论一致，都是中低频有 3–5 dB 富余。本文以 5128 为准：临场段略亮，有咬字和齿音的窄峰。

技术素质

  • 失真：中频以上失真很低（ASR measured）。这是它素质的底子。
  • 解析、分离：峰值会带来"亮感"，但不等于真解析（prior 加测量推断）。
  • 声场：封闭式常见的偏窄（prior，本次没有核实到评测共识）。
  • 动态、瞬态：低频冲击感强，有评测形容为"雷鸣般"（1 篇）。其余证据不足。

佩戴与做工

ASR 评价佩戴与同级封闭式差不多，耳罩会蹭到耳朵，样机耳罩有老化（1/1）。耳罩掉皮是长期用户里很常见的抱怨（prior）。配件和可换线生态最丰富（榜单加 prior）。

用途适配

  • 听歌、录音监听：讨喜，推力需求低，场景通吃。
  • 混音/挑错：ASR 只推荐加 EQ 使用。高频峰会误导齿音处理的判断。
  • 推力：38 Ω、约 99-100 dB/mW，手机就能推响。

评分

  • 挑错度 42（曲线重校：40→42。5128 显示 4.3 kHz 和 7.8 kHz 有窄峰，临场段略高于偏好中性，比 GRAS 读出的更亮一点。低频富余仍然明显，所以只上调 2 分）。
  • 音质 68（不变）：失真低（ASR），5128 上各频段都在 DF 附近，只有几个窄峰窄凹算轻度染色。
  • 听歌适配 72（不变）：低频饱满，好推。临场窄峰可能让个别录音的齿音偏重，但整体不刺。
