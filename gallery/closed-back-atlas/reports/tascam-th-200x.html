频响与风格

有一条仿制台架的测量（Listener，KB006x 仿制耳廓），结论和之前的口碑相反。 以 1 kHz 为 0 dB，6 次测量平均后的读数如下：

  • 低频：20 Hz +4.9、50 Hz +7.3、100 Hz +6.7、150 Hz +7.3、200 Hz +6.3、300 Hz +3.3 dB。中低频相对 Harman OE 2018 多约 7 dB，200–500 Hz 也多约 4 dB。所以低频是偏多、偏暖，不是之前口碑说的"偏瘦"。L 声道低频比 R 多 2–4 dB，但 3 次佩戴的结果都一致，不像是漏气造成的。
  • 中频：500 Hz 附近有个约 -2.5 dB 的小凹，1–3 kHz 在 +0.5~+2.8 dB，耳增益比 Harman 少约 2 dB，人声略靠后。
  • 高频：4 kHz 有个约 -11 dB 的深谷，6–8 kHz 回到 +3~+4 dB，9 kHz 和 12 kHz 又有 -11~-17 dB 的深谷，20 kHz 以上衰减明显。脚本判为"低频猛、暖向"（tilt -11 dB）。4 kHz 和 9 kHz 的深谷可能有一部分是仿制耦合器的共振伪影，具体深度不可全信，但高频整体偏少、起伏大，这个方向比较可信。6–8 kHz 相对两侧谷底凸出，可能会有一点齿音。
  • 和口碑的矛盾：之前的弱共识说"低频瘦、中频清楚"，测量显示低频偏多。以测量为准；口碑的差异可能来自头型、佩戴密封或样本差异。

用途适配

32 Ω、灵敏度约 95 dB，手机和声卡都能直接推（prior）。测量显示低频偏多、高频偏少，适合录音时陪听，不适合混音校准，否则混出来的低频容易偏少。听歌时低频量感够，高频偏暗。
