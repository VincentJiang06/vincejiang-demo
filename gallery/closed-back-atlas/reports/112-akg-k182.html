AKG K182

低频明显偏多（5128 实测）、上中频凹、高频有几处窄峰的平价封闭监听耳机，适合 DJ、鼓手和电子乐制作，不适合做精细混音。 A bass-heavy budget closed monitor (B&K 5128 measured) with recessed upper mids and a few narrow treble peaks: good for DJs, drummers and EDM, not for precise mixing.

频响与风格

  • 测量（B&K 5128，对照 5128 DF，以 500-1000 Hz 对齐）：
  • 低频：20-200 Hz 整段比 DF 高约 +9~10 dB，是一个从超低频到中低频的平直抬升，200 Hz 以后迅速回落。偏好中性的头戴一般比 DF 高 4-6 dB，所以换算下来低频仍多出约 4-5 dB，属于明确的低频重。超低频延伸完整、没有滚降，这一点和"超低频一般"的主观共识不一致：从曲线看量是够的，主观上说的薄或糊更可能是质感和失真问题，这台架测不出来。
  • 中频：200-1000 Hz 基本贴 DF（300 Hz 附近有一个小凹）；1-2.5 kHz 比 DF 低约 4 dB，人声和乐器的上中频偏后。这和"中频略靠后"的共识一致。
  • 高频：约 3.1 kHz 有一个窄而尖的峰（残差 +8.5 dB），4.4 kHz 紧跟一个深谷（-8 dB），6 kHz 与 8.4 kHz 又各有一个峰（+5 dB 左右），10 kHz 以上下滑，18-20 kHz 明显衰减。3-6 kHz 平均值比 DF 低 2.5 dB，但峰谷起伏很大，这正对应"brash、偏干偏亮"的描述，也解释了齿音评价为什么有分歧：8 kHz 的峰对某些录音和耳道会刺，4.4 kHz 的谷又把一部分齿音压了下去。空气感不足（10-20 kHz 比 DF 低 3.4 dB）。
  • 风格：低频猛、暖向（整体倾斜 -11.9 dB），高频是锯齿状的峰谷，而不是平滑的抬升。 旧版写的"U 形、高频前段稍亮"方向基本对，但曲线显示上中频凹得比设想的深，高频亮感来自几个窄峰，不是整段抬高。榜单先验"低频重"得到测量证实。

技术素质

声场偏小、结像一般，在封闭式里属于价位的正常水平（Headfonics）。解析和分离中等。动态和冲击是强项，headphonecheck 的原话是"pace and punch"。瞬态没有专门评述，证据不足。

佩戴与做工

全塑料机身但结实，headphonecheck 评价为"incredibly robust"。Headfonics 则提到握持时有塑料异响、夹紧力偏大。255 g 算轻；耳垫一两个小时后会闷热（consensus 2/2）。

用途适配

  • 混音/挑错：headphonecheck 认为它不适合精确的分析型混音；做监听、跟拍、DJ 够用。
  • 听歌：流行和电子乐有冲击力，比较讨喜。
  • 推力：32 Ω、112 dB/V，手机很容易推。

评分

  • 挑错度 40（曲线重校：42→40。原因：5128 显示低频比中性偏好多约 4-5 dB、1-2.5 kHz 凹陷，会掩盖中低频和人声的问题；3 kHz 和 8 kHz 的窄峰只会让个别频段夸张，不能当成均衡的细节还原）。和 M50x 同一档，略低于 K371。
  • 音质 56（曲线重校：58→56。原因：高频峰谷起伏大（3.1 kHz +8.5 / 4.4 kHz -8 dB），空气感不足，L/R 在高频最多差 5.7 dB；低频延伸是加分项，但整体仍低于 HD 280 Pro 那一档的平顺程度）。
  • 听歌适配 60（曲线重校：62→60。原因：低频量足、暖，流行和电子乐讨喜；但 3 kHz 与 8 kHz 的尖峰在音量大时容易刺耳，再加上夹紧力和闷热）。

证据与置信度

  • 证据等级：measured（旧：consensus）；置信度：medium。有一条 B&K 5128 实测，但只有一个样本、一个测量者，没有第二条曲线交叉验证，所以置信度不升到 high。
