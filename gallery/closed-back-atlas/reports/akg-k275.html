频响与风格

  • 结论来自实测（measured，B&K 5128）。对 5128 DF 分析的结果是"低频猛 / 暖向"，整体倾斜 −12.8 dB。
  • 低频：20–200 Hz 比 DF 高约 10 dB，从 200 Hz 一直平直延伸到 20 Hz，下潜很足。偏好中性的头戴通常比 DF 高 4–6 dB，所以 K275 仍然多出约 4–6 dB，属于明显的重低频。
  • 中低频：200–500 Hz 比 DF 高 4.6 dB，300–500 Hz 才开始回落，因此会有厚、闷的感觉（与 SOS 描述的"闷"一致）。
  • 中高频：1–3 kHz 比 DF 高 2.7 dB，2–3 kHz 平台偏高，3.6 kHz 有一个窄凹陷（残差约 −7 dB），4.5–6 kHz 又回升。1.5–3 kHz 的突出可以解释主观评测里的"鼻音 / 存在感偏多"。
  • 高频：3–10 kHz 比 DF 低约 1.5–2 dB，大致落在偏好中性的范围内；10 kHz 和 12.6 kHz 各有一个小峰；12.5 kHz 以上滚降明显（空气感比 DF 少约 5 dB）。"比 AKG 旧型号暗"的说法主要来自超高频滚降和偏重的低频。
  • 与旧结论的关系：旧版 consensus 判断的"低频多、高频收敛、中高频鼻音"得到曲线证实，但低频过量的程度比原来估计的更大。测量者给出的评级是 D+。

技术素质

  • 解析：中等，headphonecheck 认为缺少 AKG 应有的清晰度（2/2 认为弱于 K371 或同级）。
  • 声场与分离：证据不足，只有 SOS 提到带有封闭式常见的"闷"感。
  • 动态与瞬态：headphonecheck 认为不适合喜欢瞬态锐利声音的用户（1/2）。

佩戴与做工

headphonecheck 认为耳垫大、压力分布均匀，佩戴舒适；SOS 则认为自调节头带弹力偏弱、在头上不稳，因头型而异，两家评测意见相左。外观和做工整体获好评。

用途适配

  • 挑错与混音：可以用于录音跟听（隔音好、漏音少），但低频不够准、中频有染色，不宜作为混音参考。
  • 听歌：调音温和、偏重低频，适合日常听歌；手机直推没有问题（32 Ω、109 dB/V）。

评分

  • 挑错度 38（曲线重校：42→38。5128 曲线显示低频比偏好中性高出约 4–6 dB，200–500 Hz 也偏厚，会掩盖低频和中低频的细节；1–3 kHz 突出、有 3.6 kHz 凹陷，中频判断有染色）。
  • 音质 57（曲线重校：60→57。低频和中低频明显过量，3.6 kHz 有凹陷，超高频滚降；低频下潜和延伸则是优点。测量者评级 D+）。
  • 听歌适配 63（曲线重校：64→63。暖而重低频的调音适合流行、电子音乐，高频不刺激；但中低频浑厚、中高频有鼻音，低频量对偏好中性的人来说偏多）。
