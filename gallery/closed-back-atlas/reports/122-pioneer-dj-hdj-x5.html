Pioneer DJ HDJ-X5

入门级 DJ 耳机：中低频厚实有冲击，2–5 kHz 明显下凹，做工耐用。第三方测量（listener，711 + 仿制 KB006x 耳廓）显示 presence 段明显下凹，整体偏暗。 An entry DJ headphone with thick, punchy mid-bass and a recessed 2–5 kHz region, built to take abuse. A third-party 711-coupler measurement (listener) shows a deep presence dip and a dark overall tilt.

频响与风格

  • measured（listener，711 + 仿制 KB006x；以 1 kHz 归一，并与站点自带的 KEMAR DF 目标比较）：
  • 低频：60–100 Hz 比 DF 高约 +8 dB，20 Hz 回落到约 +2 dB。中低频有明显的鼓包，超低频下潜一般。
  • 中频：200–700 Hz 比 DF 高 +1~+3 dB，基本平直。
  • 中高频：2–4 kHz 比 DF 低约 −9~−10 dB，4.8 kHz 附近还有一个窄凹陷（约 −12 dB）。presence 段明显缺失。
  • 高频：6–8 kHz 有一个相对峰（按 Harman 残差算约 +5 dB，有齿音风险），10 kHz 和 14 kHz 附近又有凹陷，高频整体偏暗、不平。
  • fr_analyze（harman_oe_2018，按 gras_43ag 近似处理）：sub_bass −3.5、mid_bass +2.2、lower_mids −0.6、upper_mids −4.0、lower_treble −9.1、mid_treble −3.2、air −0.9；签名为"暗声"，tilt −3.8 dB，属暖向。
  • 与共识对照： Audio46 说 1.5–3.5 kHz 凹陷、低频冲击，都被测量证实。Audio46 说的"5.5 kHz 抬起"，在测量里对应的是 4.8 kHz 凹陷之后、6–8 kHz 的一个相对峰，而不是整体性的提升。
  • 结论：这是低中频鼓包、presence 段大幅下凹的暗暖 L 型 / 浅 V 型 DJ 调音，比旧稿写的"人声靠前"更暗。

技术素质

  • 解析：够用，人声清晰（consensus，2/3）。
  • 结像：Major HiFi 说现场录音的结像不错（1/3）。
  • 声场、分离、动态：证据不足。
  • DDJT 认为音质明显不如 X7/X10（1/3）。

佩戴与做工

  • 做工：耐用、可折叠、线可拆，这一点三篇一致（3/3）。
  • 耳垫：Audio46 说耳垫薄，耳朵会碰到腔体，长时间佩戴会疲劳。Major HiFi 却说戴眼镜也舒适。DDJT 觉得耳垫手感廉价，但整机轻。佩戴评价存在分歧。

用途适配

适合 DJ 监听和节拍对拍，也适合听嘻哈、电子、流行这类重低音、人声为主的音乐。中频有凹陷，不适合混音或挑错。推力需求很低。
