频响与风格

测量源：Reference Audio Analyzer（RAA）HPH-MT5 报告 https://reference-audio-analyzer.pro/en/report/hp/yamaha-mt-5.php ，台架 RAA HDM-X（入耳道口双耳麦克风，无耳道共振，不等同 GRAS 45CA / B&K 5128），左右声道合并曲线，对比目标为 RAA Target v1 @ HDM-X（1 kHz 以下按 Harman 2018 低频修正）。本条为截图读图（页面为 canvas 绘制，未取得原始数据），dB 为按 6 dB 网格估读的近似值。

  • 低频：20–70 Hz 基本贴合目标；约 100–250 Hz 有一个中低频鼓包，比目标高约 5–7 dB，70–80 Hz 附近有一个小凹。这与 higherhz 所说"快节奏曲目低频略糊"一致。
  • 中频：约 300–350 Hz 有个低于目标约 3 dB 的凹陷，500 Hz–1.5 kHz 大致贴近目标。
  • 中高频（2–5 kHz）：明显低于目标，2–5 kHz 比目标低约 5–10 dB，5 kHz 前后最深。这一段决定了它不锐、不挑错。
  • 高频：约 6 kHz 有个回到目标附近的小峰，8–9 kHz 有凹陷，约 10–11 kHz 大致贴近目标，15 kHz 以上滚降。整体听感平滑偏暗（与 SonicScoop"比 MT8 更暗"一致）。
  • 测量修正：原稿写"中频靠前"，测量显示的是中低频偏厚、中高频（2–5 kHz）缺量的暖暗取向，"中频靠前"只可能指 0.5–1.5 kHz 相对 2–5 kHz 的凸出感；higherhz 所说"人声偏薄偏冷"与这条曲线不太吻合，可能来自 300 Hz 凹陷或个体/佩戴差异（推断）。
  • 注意：没有 GRAS/5128 数据（AutoEq、squig 均无此型号），HDM-X 与 Harman 台架的高频不可直接对照，2 kHz 以上的判断只作定性参考。

  • 解析、分离：中等；没有评测特别称赞（0/3 正面，prior）。
  • 瞬态：底鼓瞬态不够清楚（1/3，higherhz）。
  • 声场：封闭式常见的窄声场，证据不足。

  • Frieve 综合评分 2.6/5，认为缺乏独立测量，性价比不如 ATH-M20x（一家的观点）。

佩戴与做工

长时间录音不累（SonicScoop，超过 1 小时）；做工比 MT8 更耐摔，适合公用录音棚（consensus 1–2 篇）。

用途适配

  • 混音/挑错：能作录音跟踪、陪听参考用，但 higherhz 认为不适合做关键监听的首选。
  • 听歌：低频有量、高频不刺，听感比较讨喜，但素质一般。
  • 推力：约 107 dB/mW、约 52 Ω，手机就能推动。

评分

  • 挑错度 42（测量修正，原 55）：RAA 曲线 2–5 kHz 明显低于目标、中低频有鼓包，这种暖暗取向会盖住不少瑕疵，挑错度比 ATH-M50x（约 40）略高一点，远低于 7506。
  • 音质 58（原 60）：100–250 Hz 鼓包、300 Hz 凹和 2–5 kHz 缺口让曲线不算平滑；左右声道相位与阻抗一致性良好（RAA），但整体素质与 HD 280 Pro 同一档或略低。
  • 听歌适配 62：低频饱满、高频不刺，佩戴不累、易推；低频偏糊和素质一般限制上限。
