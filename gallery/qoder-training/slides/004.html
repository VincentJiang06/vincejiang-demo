Qoder 产品家族地图

从个人入口到团队级云端代理：一个 Qoder，贯通本地、IDE 与企业协作。

01

Desktop

主控台入口，聚合项目、会话、文件与任务调度。

02

QoderWork

多智能体工作台，把需求拆成可追踪的交付流。

03

QoderWake

QoderWake 是公开产品入口，平台支持 macOS 13+ / Windows 10+ / Linux 安装脚本；能力边界以官方文档为准，本培训不推测未公开能力。

04

CLI

命令行入口，面向脚本、仓库与自动化流水线。

05

Cloud Agents

云端执行层，承接长任务、并行任务与远程环境。

06

JetBrains Plugin

IDE 内嵌入口，把代理能力带进代码上下文。

07

Mobile / Web

轻量访问面，查看进度、接管决策与移动协作。

08

Enterprise

组织级治理，统一权限、审计、安全与部署策略。

同一代理内核，八个入口协同：本地 / IDE / 云端 / 企业治理 Qoder Product Family
