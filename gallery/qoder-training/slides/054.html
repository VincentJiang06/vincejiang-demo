CLOUD AGENTS / 产品矩阵

Cloud Agents 是什么

Cloud Agents 是产品矩阵中的云端 Agent 执行入口：把任务委派给云端的 Agent 自主执行，不占用本地会话，异步运行、结果回传。

01
云端执行入口
任务不再占用本地会话，直接交给云端 Agent 自主执行，是矩阵中面向云端的统一入口。
02
异步并行运行
Agent 在云端长时间自主运行，可同时并行推进多个任务，完成后回传结果与产物。
03
与本地互补
本地 IDE Agent 负责交互式编码，Cloud Agents 承接批量、后台与长周期任务。
定位
本地 · IDE Agent交互式编码
云端 · Cloud Agents批量与后台执行
