何时推荐插件，何时推荐 Desktop

Recommend
Plugin

客户已有 JetBrains 标准

开发者日常入口已经固定，优先让 Qoder 进入现有 IDE 工作流。

目标是低摩擦试点

强调安装快、学习成本低、对既有工程习惯改动最小。

采购关注兼容性

把价值锚定在现有 IDE 标准内的补强，而不是替换桌面环境。

Recommend
Desktop

需要完整 Agent 桌面

客户要一个统一入口来承接规划、执行、审查与上下文管理。

长任务与跨文件推进

需求包含多步骤任务、持续运行、自动改动与可追踪的交付过程。

销售场景要展示上限

用 Desktop 演示端到端能力，更容易讲清 Qoder 的 Agent 差异化。

If JetBrains is the standard

先推荐 Plugin，降低切换成本

Sales and CS rule

入口跟随客户的任务复杂度

If full agent work is needed

推荐 Desktop，承接长任务
