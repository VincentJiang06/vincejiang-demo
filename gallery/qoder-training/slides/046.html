JetBrains Plugin 是什么

给已经在 IntelliJ IDEA、PyCharm、WebStorm 等 JetBrains IDE 中工作的开发者，一个不离开编辑器的 Qoder 能力入口。

01

来自 JetBrains Marketplace

像安装其他 IDE 插件一样获取与更新，面向已有 JetBrains 用户自然分发。

INSTALL PATH
02

保留原有 IDE 习惯

项目结构、快捷键、调试方式与代码上下文都留在熟悉的 JetBrains 工作流中。

NO CONTEXT SWITCH
03

嵌入式 AI 能力入口

把问答、代码理解、生成与改写能力嵌进当前项目，而不是切到另一个工具。

AI INSIDE IDE
