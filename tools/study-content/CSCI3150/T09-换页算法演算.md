### p.4–5：每种策略保留的历史不同

> **p.5** Recap:
>
> Remove the items that are used least frequently to make room for new items.
>
> The LFU algorithm is based on the idea that items accessed less frequently in the past are less likely to be needed in the future.

FIFO看入驻先后，LRU看最近一次访问，LFU看频次，OPT看未来最远下一次访问。OPT可作已知序列的离线比较下界，在线系统不能预知任意未来。FIFO可能出现增加容量反而更多缺失的Belady异常；本例没有给FIFO容量对比，不能把其他表当其证明。

LFU可能保住过去常用但现在不再用的项；还必须约定同频怎么选以及被淘汰后计数是否保留。

**表（p.4）：课件完整字段与状态。** 下表保留原页术语和数值；读写轨迹的同一格按原页由上到下排列，空格以“—”表示。

| Algorithm | Logic | Pro / Con |
|---|---|---|
| FIFO | Oldest page in memory is replaced first. | Simple to implement / Suffers from Belady’s Anomaly. |
| LRU (Least Recently Used) | Replaces the page that hasn't been used for the longest time. | Highly efficient / Requires hardware support (counters/stacks). |
| Optimal (OPT) | Replaces the page that will not be used for the longest period in the future. | Lowest miss rate (requires future knowledge). |
| LFU (Least Frequently Used) | Replaces the page with the smallest reference count. | Focuses on frequency, no-longer-used pages. |

### p.6–7：LFU完整题面与同频规则

> **p.6** Consider the need to access the following addresses in order and there are 5 cache lines in the cache：
>
> 0x1A2B, 0x3C4D, 0x1A2B, 0x5E6F, 0x7A8B, 0x9A8B, 0x7A9F, 0x7A8B, 0x7CAB, 0x1A2B, 0x3C4D

> **p.7** 1. Checking for Cache Hit:
>
> Iterates through each cache line to check for a hit.
>
> On Hit: Increments the line’s frequency counter. Outputs a cache hit message.
>
> 2. Handling Cache Miss: If no matching line is found, it’s a cache miss. Proceed to find a suitable line to store the new data.
>
> Finding a Replacement Line:
>
> Search for Empty Line. First preference is to find an empty line.
>
> If no empty line is available, searches for the line with the lowest frequency.
>
> Set the the new line’s frequency counter to 1. Output a cache miss message.

### p.8–10：LRU时间戳在命中时也刷新

> **p.8** Recap
>
> Least Recently Used (LRU) algorithm is a Greedy algorithm where least recently used pages are to be replaced.
>
> The LRU algorithm is based on the idea that the pages that have been used the least recently are the ones that are least likely to be used again in the near future.

> **p.10** Each access increments the global time by one.
>
> 1. Checking for Cache Hit:
>
> Iterates through each cache line to check for a hit.
>
> On Hit: Updates the last access time of the cache line to the current global time. Outputs a cache hit message.
>
> 2. Handling Cache Miss: If no matching line is found, it’s a cache miss. Proceeds to find a suitable line to store the new data.
>
> Search for Empty Line. First preference is to find an empty line.
>
> If no empty line is available, searches for the line with the smallest last access time.
>
> Set the new line's last access time to the current global time. Output a cache miss message.

沿用完整同一序列与容量，时间从1逐次加1，命中更新最近访问时间。第7步淘汰时间2的3C4D；第8步7A8B命中更新时间8；第9步淘汰时间3的1A2B；第10步再访问1A2B已miss，淘汰时间4的5E6F；第11步淘汰时间6的9A8B。

只有第3、8步命中，2hit、9miss，命中率18.18%。该序列LFU更好不代表LFU普遍优于LRU；它们对未来的估计依据不同。[逐步全表](#lru)。

**补充：用同一次命中看清三种历史。** 原序列第8步再次访问7A8B，LFU把它的累计频次从1变2，LRU把最后访问时间改成8，CLOCK只把引用位置1。三个字段都叫“最近用过的信息”，但保存粒度完全不同：LFU计多次，LRU保留精确最近次序，CLOCK只记自上次清位以来是否又用过。

因此CLOCK见1清0并不是淘汰，也不是把这一页的数据清零；它是在收回一次“再给机会”的标记。接着继续扫描，真正遇到0才替换。做表时把“数据标签、引用位、扫描指针”写在不同列，能防止误把指针经过当作一次用户访问。

:::hint 自测：本例CLOCK与LRU都是9次miss，是否可把二者中间表格互换？

不可以。第7步LRU淘汰3C4D，CLOCK淘汰1A2B，缓存内容已不同。总次数相等只是对这条有限序列的统计巧合；若后续再访问其中一个刚被不同策略保留的标签，命中情况便可能分叉。

:::endhint

### p.11–13：CLOCK让近期访问者再获一次机会

> **p.11** Recap
>
> An approximation of the Least Recently Used (LRU) algorithm. Requires less overhead than true LRU implementations because it doesn’t need to keep a detailed history of page accesses.
>
> Easy to implement with small hardware requirements (only a use bit).

> **p.13** Cache Hit Scenario:
>
> The Clock Pointer will not be moved forward
>
> If the requested data is found, update the reference bit to 1. No replacement occurs.
>
> Cache Miss Scenario:
>
> Search for empty line. First preference is to find an empty line.
>
> If no empty line.
>
> Iterates the cache lines and set the reference bit from 1 to 0.
>
> Replace the first line whose reference bit is 0.  Set the reference bit of the new line to 1.
>
> Move clock pointer to the next line for future accesses.

原规则命中置引用位1但不移动指针；miss先用空槽，满后从指针开始扫描：见1清0继续，见0替换，新项置1，指针移到下一槽。这里初始指针槽0，装空槽后也向前，和图一致。

第7步所有位原为1，扫描一整圈清0后淘汰槽0的1A2B，装7A9F，指针1；第8步7A8B命中把槽3位重新置1，指针仍1。第9步换槽1的3C4D；第10步换槽2的5E6F；第11步从槽3见1清0，再到槽4见0，淘汰9A8B。结果2hit、9miss，与本例LRU总数相同，但第7步牺牲者已不同，不能说算法相同。[逐步全表](#clock)。
