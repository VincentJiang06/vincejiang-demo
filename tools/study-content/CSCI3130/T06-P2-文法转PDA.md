### 栈保存尚未匹配的句型（p.5–6）【已会】

题面块（T06 · Problem 2 · PDF p.6；公式按讲义重排）：

> **p.6** Construct a pda that accepts the language defined by the grammar $S\to aSbS\mid bSaS\mid\lambda$

栈顶在左。用初态q0、展开匹配态q、终态qf，初始栈Z。全部转移如下，未列无动作：

| 输入/栈顶 | 当前态→新态 | 替换栈顶 |
|---|---|---|
| λ/Z | q0→q | SZ |
| λ/S | q→q | aSbS 或 bSaS 或 λ |
| a/a | q→q | λ |
| b/b | q→q | λ |
| λ/Z | q→qf | Z |

读到变量就非确定选一条产生式，读到终结符就与输入头匹配并弹栈。只有读完整串并消完所有待推导符号，才可留在qf接受；若提前展开完而仍有输入，qf无读字符边，该分支失败。

**算一遍**：输入ab，从(q0,ab,Z)到(q,ab,SZ)，展开aSbS得到(q,ab,aSbSZ)，读a后(q,b,SbSZ)，第一个S取λ变(q,b,bSZ)，读b后(q,λ,SZ)，第二个S取λ，再到qf。输入λ可让初始S直接取λ。输入a不能让所有待匹配符号消失后又正确耗尽。

每次变量替换模拟一个最左推导步骤，每次终结符匹配核对推导的下一个字符，因此文法成功推导与PDA接受路径一一对应于相同的规则选择。文法描述全部a、b计数相等的串，但PDA正确性直接来自模拟，不需要先额外证明该语言刻画。

### 连接“已经读过的前缀”与“栈里待做的事”（补充）

设输入为 $ur$，机器已经消耗 u，尚余 r，栈为 $\alpha Z$。对这份模拟构造，沿每条尚未失败的推导分支都有 $S\Rightarrow^*u\alpha$：读变量时按规则替换栈顶，正好替换该句型里最左侧未完成变量；读终结符时只在它等于输入头时弹出，等于把已确定的字符从 α 移入 u。若最终 α 为空且 r 也为空，就得到了 $S\Rightarrow^*u$，因此接受串确实由文法生成。

逆向则从任意最左推导出发，依次采用同样的 λ 展开，并在终结符来到栈顶时匹配输入。虽然一些其他选择会卡住，甚至可以不断展开而不结束，但只要存在这条有限成功分支就足以接受。不能因此把 NPDA 当成“所有分支都要结束”的算法；本题证明的是识别语言相同。

:::hint 自检：展开 S→aSbS 时能否把 bSaS 压在栈顶？

先固定本篇栈顶写在左侧的记法，再看下一个待匹配字符。

:::hint 展开推理与答案

不能。左侧为栈顶时必须把 aSbS 原顺序替换 S，使下一个读到 a。若使用逐个 push 的实现，实际 push 操作要从右向左执行；实现操作顺序与写出的最终栈串顺序不是一回事。

:::endhint
:::endhint
