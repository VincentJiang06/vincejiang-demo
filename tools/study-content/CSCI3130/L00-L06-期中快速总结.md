## L00 课程导论与计算模型

<a name="q00"></a>**要掌握什么**：区分模型能力与效率，理解有限状态怎样概括历史。[完整解释](L00-L06-期中全面复习.md#l00)。出处：L00 p.14–64。

| 概念 | 核心内容 | 辨析 |
|---|---|---|
| 可计算性 computability | 是否存在符合模型规则的算法解决问题 | 自己没想出算法，不等于不可计算 |
| 复杂性 complexity | 求解所需时间与空间如何增长 | 很慢与不可判定不同 |
| 四类记忆 | 输入、输出、程序、中间结果 | 是用途分类，不一定是四块独立硬件 |
| FA | 只有有限控制状态，没有无界额外工作空间 | 有限状态本身就能保留信息 |
| PDA | 有限控制加后进先出的栈 | 本范围只作导论；正式转移构造在 L07 |
| TM | 一般算法的抽象计算模型 | 导论 RAM 示意不是标准单带转移定义 |
| generator | 生成符号串，无外部输入串 | 文法是生成式描述 |
| acceptor | 接收串并判断接受/拒绝 | “无输出”指无额外输出串 |
| transducer | 有输入也有输出串 | 编译器作为整体是转换器 |

**记住三个例子**：立方计算先存平方 4，再算出 8；20 元售货机用 0、5、10、15、20 五个金额状态，15 再投 10 要退 5；最短路求源点到各点最短路径，TSP 要访问每城一次并返回起点，任务不同。

**效率对照**：最短路例列 $O(\lvert V\rvert^2)$ 与 $O(\lvert E\rvert+\lvert V\rvert\log\lvert V\rvert)$；TSP 例列 $O(n!)$ 与 $O(n^{2}2^{n})$。这些是增长量级，不是确切秒数。课件的 TSP 图红线成本 25，已有伴读枚举的最小值为 23。

**背景线索**：形式语言/文法描述合法串；自动机描述离散动态行为；存储程序把程序也当作信息；Kleene 连接 RE 与 FA；BNF 是程序文法记法。Hilbert、Gödel、自指、Turing 是理论边界的导论脉络，不把概要措辞当成无条件定理。

## L01 数学基础、语言与文法

<a name="q01"></a>**要掌握什么**：对象类型、集合与语言运算、量词、证明和文法生成。[完整解释](L00-L06-期中全面复习.md#l01)。出处：L01 p.3–89。

### 1. 集合、函数、关系与增长界（p.3–24）

| 内容 | 一句话记忆 |
|---|---|
| 子集与成员 | a 属于 A；{a} 可为 A 的子集，两个层次不能混用 |
| 基数 | 不同成员的数量；集合忽略重复和列举顺序 |
| 幂集 | 全部子集组成的集合；n 元集有 2 的 n 次方个子集 |
| 笛卡尔积 | 有序对；大小为两集合基数乘积，次序重要 |
| 划分 | 块非空、两两不交、合起来覆盖原集合 |
| 函数 | 每个实际定义的输入有唯一输出；全函数覆盖声明的定义域 |
| 关系 | 有序对集合，可一对多 |
| 等价关系 | 自反、对称、传递；等价类构成划分 |

德摩根律（同一全集）：

$$
\overline{A\cup B}=\overline A\cap\overline B,
\qquad
\overline{A\cap B}=\overline A\cup\overline B.
$$

**渐近界**：对所有足够大的 n，$f(n)=O(g(n))$ 要有固定常数 c>0 使 $0\le f(n)\le cg(n)$；Ω 反向，Θ 同时有上下界。$3n^2+n$ 是 Θ(n²)，也可以是 O(n³)，却不是 O(n)。O 不是“恰好同阶”。

### 2. 图、树与证明（p.25–54）

- 本课 walk：相邻边序列；path：不重复边；simple path：不重复顶点。cycle 回到起点；simple cycle 除首尾外不重复顶点；loop 为自身边。
- Euler tour 每条边一次；Hamiltonian cycle 每个顶点一次再回起点。前者可以重复点，后者不用经过每条边。
- 树的根深度为 0，高度数边。二叉树高度 n 的叶数最多 $2^n$。
- 直接证明：由定义与前提推出结论；构造性证明给出具体对象或构造。
- 归纳证明：基例、归纳假设、归纳步骤；强归纳可使用全部更小规模。
- 递归是定义/计算，归纳是证明。直线最大分区数为 $n(n+1)/2+1$，须无平行线、无三线共点。
- 反证法：否定目标，推出矛盾。证明根号 2 无理时，要先约分至最简，最后“两数都偶”才矛盾。

### 3. 串与语言的运算（p.57–78）

| 对象或操作 | 定义 / 关键边界 |
|---|---|
| 字母表 Σ | 有限符号集合 |
| 串 w | 有限符号序列；顺序重要 |
| 语言 L | Σ 星闭包的任意子集；不要求有限 |
| 空串 λ | 长度 0；与 w 连接仍是 w |
| 空语言 ∅ | 0 个成员 |
| {λ} | 1 个成员，那个成员长度为 0 |
| 子串 | 连续位置，不能跳着取 |
| 前缀/后缀 | 从开头/末尾取；含空串及自身 |
| 串幂 | 同一个串重复 n 次；零次为空串 |
| 语言幂 | 每份可独立选不同成员；零次为 {λ} |

$$
\lvert uv\rvert=\lvert u\rvert+\lvert v\rvert,
\qquad (uv)^R=v^Ru^R.
$$

$$
L_1L_2=\{xy:x\in L_1,y\in L_2\},\quad
L^{\ast}=\bigcup_{n\ge0}L^n,\quad L^+=\bigcup_{n\ge1}L^n.
$$

**空串边界**：$L^{\ast}=L^+\cup\{\lambda\}$ 总成立；只有当 λ 不属于 L 时，才能写 $L^+=L^{\ast}-\{\lambda\}$。空语言的星闭包为 {λ}，正闭包为空。语言连接的结果可能重复，基数不一定是两基数乘积。

### 4. 文法（p.79–89）

$G=(V,T,S,P)$：变量、终结符、起点、产生式。一步推导用 ⇒；零步或多步用 ⇒ 的星号。**句型可以含变量；语言成员必须只含终结符。**

| 目标语言 | 可用文法 | 为什么 |
|---|---|---|
| 先 a 后 b，等量 | S→aSb 或 λ | 每轮两端各添一个 |
| b 比 a 多一个，仍分段 | S→Ab；A→aAb 或 λ | 先固定尾部一个 b |
| 任意顺序，a/b 等量 | S→SS 或 aSb 或 bSa 或 λ | 外包平衡对，或串接平衡块 |

文法等价只比较生成语言，不比较变量名、规则数或推导步数。构造证明要同时说明“没有生成非法串”和“每个合法串都能生成”。

## L02 DFA、NFA、确定化与最小化

<a name="q02"></a>**要掌握什么**：把有限记忆写成状态；会完整构造、运行、转换与合并。[完整解释](L00-L06-期中全面复习.md#l02)。出处：`lec2.pdf` p.3–206。

### 1. DFA 与 NFA 的定义（p.28–50、135–153）

共同为五元组 $M=(Q,\Sigma,\delta,q_0,F)$。Q 有限，q0 是一个初态，F 是终态集合。

| 项目 | DFA | 本课允许空边的 NFA |
|---|---|---|
| 一步转移类型 | $Q\times\Sigma\to Q$ | $Q\times(\Sigma\cup\{\lambda\})\to2^Q$ |
| 后继 | 恰一个 | 0 个、1 个或多个 |
| 空边 | 不允许 | 允许，不消费输入 |
| 接受 | 完整读完后在 F 内 | 存在完整读完并到 F 的有限路径 |
| 拒绝 | 唯一运行结束于非终态 | 所有可能运行均不能成功 |

DFA 的扩展转移：

$$
\delta^{\ast}(q,\lambda)=q,\qquad
\delta^{\ast}(q,wa)=\delta(\delta^{\ast}(q,w),a).
$$

DFA 接受条件为 $\delta^{\ast}(q_0,w)\in F$。NFA 扩展转移返回全部可达状态，接受条件为 $\delta^{\ast}(q_0,w)\cap F\ne\varnothing$。

**注意**：NFA 不是随机选路；某条分支失败不代表整体拒绝。输入耗尽后仍可沿空边到终态。单步 λ 转移与零步或多步 λ 闭包不同，闭包包含出发状态自身。

### 2. 设计状态的常用模板（p.52–74、157–158）

| 约束 | 应记的信息 |
|---|---|
| 恰 k 个 0 | 0…k，再加超额陷阱；1 不改变计数 |
| 至少 k 个 1 | 0…k−1、至少 k；达到门槛后饱和 |
| 长度模 k | k 个余数状态；每个字符都加 1 取模 |
| 两个计数模数 | 状态对；各字符只更新对应分量 |
| 二进制数模 k | 读位 b 后余数变为 $(2r+b)\bmod k$ |
| 固定前缀 | 匹配成功后可接受任意后缀；早期失败不可挽回 |
| 固定后缀 | 当前末尾与模式前缀匹配的最长长度 |
| 包含某模式 | 匹配到后保持“已出现” |
| 禁止某模式 | 匹配到即永久拒绝 |
| 每个 00 后立即跟 1 | 增加“刚见 00，欠一个 1”的非终态；尾部停在此也拒绝 |
| 每个奇数位置为 1 | 记下一个位置奇偶；奇数位读 0 入陷阱；空串合法 |

“以 a 开头、以 a 结尾”若题目形如 awa，最短长度为 2，单独 a 不算。模数比较也不能替换成原始计数比较。

### 3. 子集构造（p.166–197）

设 C(S) 表示集合 S 的空闭包。新 DFA 初态为 $C(\{q_0\})$，转移为

$$
\Delta(S,a)=C\left(\bigcup_{q\in S}\delta(q,a)\right).
$$

**步骤**：登记初态集合；每次取未处理集合，对每个字母计算后继、闭包；新集合加入表；直到所有行处理完。含旧终态的集合才是新终态。空集若可达，要保留为自环陷阱。

n 态 NFA 至多对应 $2^n$ 个子集，只列可达的即可。正确性不变式：读完任意前缀，新 DFA 当前集合恰好等于旧 NFA 全部可能位置。由此得 DFA 与 NFA 接受相同的正则语言类。

**单终态 NFA**：新加 f，旧终态空边到 f，取消旧终态资格，保留旧转移，f 无出边。旧 F 为空时只加不可达 f。

### 4. 最小化（p.203–206）

1. 去掉从初态不可达的状态。
2. 分终态与非终态两个块。
3. 按每个字母的目标块细分，直到稳定。
4. 一块合成一个状态。

等价状态：对所有相同后缀，接受性一致。**可区分只需一个后缀**；一终一非终用 λ 即可区分。陷阱即使不能到接受状态，只要可达，也不能直接漏掉它的完整转移。

## L03 正则表达式、自动机与正则文法

<a name="q03"></a>**要掌握什么**：解释 RE、构造 RE、双向转换，区分线性与正则文法。[完整解释](L00-L06-期中全面复习.md#l03)。出处：L03 p.3–104。

### 1. RE 的语法与语义（p.3–25）

基本表达式是 ∅、λ、字母；用并、连接、星和括号有限次构造。**星优先于连接，连接优先于并**。L(r) 才是表达式表示的语言。

$$
L(\varnothing)=\varnothing,\quad L(\lambda)=\{\lambda\},\quad L(a)=\{a\}.
$$

$$
r+\varnothing\equiv r,\quad r\lambda\equiv r,\quad r\varnothing\equiv\varnothing,\quad\varnothing^{\ast}\equiv\lambda.
$$

最后一行是语言等价，不是字符串字面相同。不要将连接当作交换运算。

| 语言 | RE 模板 |
|---|---|
| 含至少一处 00 | $(0+1)^{\ast}00(0+1)^{\ast}$ |
| 不含 00 | $(1+01)^{\ast}(0+\lambda)$ |
| 偶数长度 | $((0+1)(0+1))^{\ast}$ |
| 不以 01 结尾 | $\lambda+0+1+(0+1)^{\ast}(00+10+11)$ |
| 0 的个数为奇数 | $1^{\ast}01^{\ast}(01^{\ast}01^{\ast})^{\ast}$ |
| a/b/c 上恰一个 a | $(b+c)^{\ast}a(b+c)^{\ast}$ |
| a 段至少 3，b 段奇数个 | $aaa\,a^{\ast}b(bb)^{\ast}$ |
| a 段后接 b 段，总长度奇数 | $a(aa)^{\ast}(bb)^{\ast}+(aa)^{\ast}b(bb)^{\ast}$ |

最后一项有段序限制，不能换成任意奇数长串。总是检查 λ、长度 1、最短合法串。

### 2. RE 与 FA 的等价（p.27–54）

**RE→NFA**：对表达式结构归纳。并用新起点空分叉；连接用前出口空接后入口；星用回路重复模块，并加入口到出口的零次通路。各模块先用不相交状态名。

**FA→RE**：转成边标 RE 的 GTG，平行边取并，缺边标 ∅。消去 k 时，对每对保留点同时使用旧标签更新：

$$
r'_{pq}=r_{pq}+r_{pk}r_{kk}^{\ast}r_{kq}.
$$

先保留旧边，再加入“进去—循环—出来”，最后删 k。若用两状态公式，左自环 r1、左到右 r2、右到左 r3、右自环 r4，且只有左初态、右终态，则

$$
r=r_1^{\ast}r_2(r_4+r_3r_1^{\ast}r_2)^{\ast}.
$$

初终重合或多终态时，先加统一的新初终态，不直接套这个前提不同的公式。

### 3. 正则文法（p.58–104）

| 文法形式 | 判定条件 |
|---|---|
| 线性 | 每条右侧至多一个变量，可以夹在中间 |
| 右线性 | A→xB 或 A→x，x 为终结符串 |
| 左线性 | A→Bx 或 A→x |
| 正则文法 | 整份文法统一右线性或统一左线性 |

**反例**：S→aSb 或 λ 是线性 CFG，生成非正则的等量分段语言。每条规则分别看似左线性/右线性的混合，也不能据此称整份文法正则。

- 文法→NFA：变量作状态；x 作逐字路径；无尾变量就走向新终态；x 为空时使用空边。
- NFA→右线性文法：边 q— a →p 对应 q→ap；空边对应单位规则；每个终态加 q→λ。
- 左线性→右线性：A→Bv 变 A→反转(v)B，得到原语言的反转；再用反转封闭性回原语言。
- 奇偶与饱和计数文法：先造有限状态机，再逐边翻译；接受状态加空规则。例如 a 偶且 b 至少 4 用 2×5 个状态；a/b 双偶用 2×2 个状态。

**总关系**：DFA、NFA、RE、RG 恰好刻画正则语言。某文法形式不是正则，不自动说明其语言非正则。

## L04 正则语言的性质与非正则证明

<a name="q04"></a>**要掌握什么**：用封闭性构造，用有限图判定，用泵引理反证。[完整解释](L00-L06-期中全面复习.md#l04)。出处：L04 p.3–103。

### 1. 封闭性（p.3–32）

正则语言对有限并、连接、星、反转、补、交、差、同态像封闭。前提是输入语言正则，补集必须说明共同字母表。

| 运算 | 构造 |
|---|---|
| 并、连接、星 | NFA 模块接线 |
| 反转 | 反向全部边，新初态空边进入旧终态，旧初态变终态 |
| 补 | 完整 DFA 交换终/非终态，不能直接翻转 NFA |
| 交、并、差、对称差 | 两 DFA 同步乘积，只改变终态判定 |
| 同态 | 每个字母固定替换成一个串，允许空串；RE 结构不变 |

乘积转移：

$$
\delta((p,q),a)=(\delta_1(p,a),\delta_2(q,a)).
$$

交：两者都接受；并：至少一者；差：第一接受且第二拒绝；对称差：恰一者接受。h(uv)=h(u)h(v)，h(λ)=λ；替换多字母块后再加星时注意括号。

### 2. 判定问题（p.34–44）

| 问题 | 有限算法 |
|---|---|
| w 是否属于 L | 运行自动机，读完判终态 |
| L 是否为空 | 从初态搜索能否到终态，含零步路径 |
| L 是否无限 | 在 DFA 中查是否有初态可达且能到终态的环 |
| L1 是否等于 L2 | 对称差是否为空；非空时路径标签为反例 |

不能以一个串被拒绝推出空语言；纯空转移环不能证明无限；两个语言的有限试串一致不能证明等价。

### 3. 正则泵引理（p.45–100）

如果 L 正则，则存在 p≥1，使每个长度至少 p 的成员 w 都能写成 xyz，满足

$$
\lvert xy\rvert\le p,\qquad\lvert y\rvert\ge1,\qquad
xy^iz\in L\quad\text{for all integers }i\ge0.
$$

**原因**：p 状态 DFA 的前 p 步共有 p+1 次状态访问，所以出现重复；y 是非空环，删掉或多绕都能接原来的 z 到终态。

**反证顺序**：任意泵长 p → 我选合法长串 → 任意合法分割 → 我选 i → 泵后离开语言。不能指定 y；i 可以依赖 y。引理不能反向用来证明正则。

### 4. 选串与泵次数速查（p.77–103）

以下 k 表示非空泵段长度，通常满足 1≤k≤p；同一行中的指数参数独立于其他行。每行的完整证明见全面稿。

| 目标约束 | 见证串 | 破坏方法 |
|---|---|---|
| a、b 等量且分段 | $a^pb^p$ | y 全是 a，泵 2 次打破等量 |
| 偶数回文（至少两字母） | $a^pb^{2p}a^p$ | 只增加最左 a 段，两端不对称 |
| a 比 b 少 | $a^pb^{p+1}$ | 泵 2 次后 a 至少与 b 同多 |
| 平方长度 | $a^{p^2}$ | 泵 2 次后长度在相邻平方之间 |
| a、b 总数等于 c | $a^pb^pc^{2p}$ | 删掉左 a 段，c 数不变 |
| 分段 a、b 数不等 | $a^{p!}b^{(p+1)!}$ | 泵次数为 1 加 p·p! 除以 k，强制两指数相等 |
| 素数长度 | $a^q$，q 为不小于 p 的素数 | 泵 q+1 次，长度为 q(k+1)，是合数 |
| a 数 / b 数为整数 | $a^{p+1}b^{p+1}$ | 删 y 后比例严格在 0、1 之间 |
| a 数≤b 数≤2a 数 | $a^pb^{p+1}$ | 泵 3 次后 a 数超过 b 数 |
| 交替块数大于尾部 a 数 | $(ab)^{p+1}a^p$ | 删奇数长 y 破坏交替；删偶数长 y 使块数不足 |

**封闭性捷径**：若 L 为有序的不等量串，假设其正则，则“补 L 再交 a 星 b 星”得到等量串语言，与非正则矛盾。必须加交集，补集中还有乱序串。

## L05 CFG、解析与歧义

<a name="q05"></a>**要掌握什么**：用规则生成嵌套结构，读写树与推导，区分三种“唯一性”。[完整解释](L00-L06-期中全面复习.md#l05)。出处：L05 p.6–89。

### 1. CFG 的构造（p.6–21）

CFG 每条规则左侧恰为一个变量，右侧为任意变量/终结符串；不依赖该变量的左右邻居。存在这样的文法恰好生成 L，则 L 是 CFL。正则文法是 CFG 的特例，但 CFL 可非正则。

| 结构 | 典型规则 |
|---|---|
| 分段等量 | S→aSb 或 λ |
| 偶数回文 | S→aSa 或 bSb 或 λ |
| 合法括号（a 开、b 关） | S→aSb 或 SS 或 λ |
| 分段不等量 | S→AU 或 UB；U→aUb 或 λ；A→aA 或 a；B→bB 或 b |

括号合法要有**总数相等＋所有前缀 a 数≥b 数**。ba 不合法；abab 合法但不能只用 S→aSb 或 λ 生成。文法构造要证两个包含方向，不仅举推导例子。

### 2. 推导、树和解析（p.22–56）

- 最左推导：每步展开最左变量；最右同理。不同展开次序可以对应同一棵树。
- 推导树根为 S；内部节点是变量，其有序孩子是一条产生式右侧；完整树终结叶从左到右是 yield。
- 部分树可以保留变量叶子，所得是句型；变量不能算作最终输出。
- 解析从目标串反推规则或树。朴素广度穷举可找到成功路径，但无停止界时不能判断失败。
- 无空规则、无单位规则后，长度 n 的成功推导有不超过 2n 的安全步数界；固定最左展开时，分支数仍可能指数增长。
- s-grammar：每条 $A\to aV_1\cdots V_k$，且同一 A/a 组合最多一条。下一输入符号决定规则，固定文法下按最左解析可用线性时间。

### 3. 歧义与优先级（p.57–79）

**文法歧义**：存在某成员有两棵不同推导树；等价于两条不同最左推导或两条不同最右推导。仅两条一般推导不够。

表达式文法 E→E+E 或 E∗E 或 (E) 或 a 对 a+a∗a 有两个根结构。令 a=2，会得到 6 或 8。用层次规则规定乘法优先、同级左结合：

$$
E\to E+T\mid T,\quad T\to T\ast F\mid F,\quad F\to(E)\mid a.
$$

E 管加法，T 管乘法，F 管原子/括号。嵌套 if 的单个 else 可以绑定内层或外层，也会引起结构歧义。

**固有歧义**：一个 CFL 的所有生成文法都歧义。证明某一份文法两支重叠，只能证明那份文法歧义；不能代替“所有文法”的证明。课件列出的经典固有歧义语言是两类三段串的并：前两段等量，或后两段等量。

### 4. 程序语言应用（p.81–89）

字符源文件→lexer→token 流→parser→树→codegen→目标代码。词法划分记号，语法确定嵌套结构，语义还需检查类型/含义。`10+2*5` 的加法根、乘法右子树给先乘后加，结果 20。BNF 是规则记法；LL/LR 是受限解析框架，不能推出任意 CFG 都可线性解析。

## L06 文法清理、范式与 CYK

<a name="q06"></a>**要掌握什么**：会写每个中间文法并说明保留语言的原因；会逐格填 CYK。[完整解释](L00-L06-期中全面复习.md#l06)。出处：L06 p.3–64。

### 1. 清理（p.3–31）

| 操作 | 方法 | 易漏点 |
|---|---|---|
| 代入 | A 右侧含 B 时，把 B 的全部右侧代入 | 只代一条就删原规则会漏语言；两侧上下文不能丢 |
| 消空 | 求 nullable 闭包，对每个可空出现位置独立选保留/删除 | 不是只看直接空规则；重复变量按位置处理 |
| 消单位 | 求单位可达闭包，把全部非单位出口复制给起点，再删单位规则 | A→a 不是单位规则；循环用闭包处理 |
| 去无用 | 先删不能生成终结串者，再在剩余文法删不可达者 | 单有可达性不够，原图先查可达可能误留变量 |

**固定顺序**：消 λ → 消单位 → 去无用。消 λ 可能制造单位规则，所以顺序有原因。要保留空串可设从不出现在右侧的新起点，保留它的空规则；随后清理其单位出口。严格无空规则文法不能生成空串。

### 2. CNF 与 GNF（p.33–52）

| 项目 | CNF | GNF |
|---|---|---|
| 合法右侧 | 恰两个变量，或恰一个终结符 | 一个首终结符，后接任意多个变量 |
| 形式 | $A\to BC$ 或 $A\to a$ | $A\to aV_1\cdots V_k$，k≥0 |
| 用途 | 二叉推导结构、CYK | 每个最左步骤生成一个新的终结符 |
| 非空串长度 n 的步数 | 2n−1（补充推论） | n |
| 不合法例子 | aB、ab、BCD、单位变量 | Ba、abB、λ（除约定例外） |

**CNF 转换**：先清理；长右侧的终结符用代理变量替换；将超过两个变量的右侧二叉化。A→a 本来合法，不要改成 A→Ta 制造单位规则。长为 m 的变量链可用 m−2 个新变量二叉化。

**GNF 局部转换**：首位若是变量，代入其所有规则；首位以后的终结符改成代理变量。一般含左递归的转换不能只靠一次代入。本讲给存在性与局部例子，不将其扩充成未讲的通用算法。GNF 不要求 A/a 组合唯一，所以不等于 s-grammar。

### 3. 一道完整 CNF 转换压缩版（p.63–64）

**题面转引**（L06-文法变换与范式-资料包.pdf · Quiz · p.63；引文来自现有伴读，公式重排）：

> **p.63** Convert the grammar
>
> $S\to AB\mid aB,\quad A\to abb\mid\lambda,\quad B\to bbA$
>
> into Chomsky normal form.

仅 A 可空。删空并补规则：S→AB、B、aB；A→abb；B→bbA、bb。消单位 S→B：将 bbA、bb 复制给 S。

**等价的 CNF 写法**（辅助变量命名为本稿整理）：Ta→a，Tb→b，X→TbTb；S→AB 或 TaB 或 XA 或 TbTb；A→TaX；B→XA 或 TbTb。每条都是两个变量或一个终结符。原语言不含 λ，不另加空规则。最短串 bb 由 S→TbTb 产生，检查了消空分支没有漏掉。

### 4. CYK（p.54–62）

前提：非空输入和 CNF。$V_{i,j}$ 存能生成位置 i 至 j 子串的**所有变量**，不是一个状态。

1. 一字符格：收所有 A→该字符的 A。
2. 按长度递增；对每个子串试每个切点 k。
3. 左格含 B、右格含 C 且有 A→BC，就把 A 加入当前格。
4. 所有切点结果取并；整串格含开始变量 S 才接受。

**题面转引**（L06 原件 · Input example · p.57；引文来自现有伴读，公式重排）：

> **p.57** Grammar G: $S\to AB,\quad A\to BB\mid a,\quad B\to AB\mid b$.
>
> String w: aabbb

| 子串长度 | 从左至右的变量集合 |
|---|---|
| 1 | {A}；{A}；{B}；{B}；{B} |
| 2 | ∅；{S,B}；{A}；{A} |
| 3 | {S,B}；{A}；{S,B} |
| 4 | {A}；{S,B} |
| 5 | {S,B} |

例如 abb：a·bb 对应 AA，无规则；ab·b 可用 BB，得 A。顶格含 S，所以接受。固定文法时间 $O(n^3)$；补充：直接扫描规则时 $O(\lvert P\rvert n^3)$，集合空间 $O(\lvert V\rvert n^2)$。保存规则与切点才能回溯树。空输入另外判断起点是否可空。
