### 截断为零的减法（p.110）

**题面**（本讲 · Short Quiz · p.110；公式按讲义重排）

> **p.110** Design a TM that can compute proper subtraction. That is m–n.
>
> m–n if m > n
>
> m–n = 0 if m < n

原页没有单列m=n；按proper subtraction通常含义，本解明确补上等号结果0，即 $\max(m-n,0)$。采用本讲一元编码，输入 $1^m01^n$，输出 $1^{\max(m-n,0)}0$，其中最后0是结果结束符，故零结果编码为单个0。

构造分三阶段。第一，在右数找一个未标1并标Y，再回左数找一个未标1标X；找得到则继续下一轮，找不到说明n尚有需求但m已耗尽，转“结果0”清理。第二，若右数已无未标1，所有n次抵消完成，左数剩余未标1的个数就是m−n；如也无剩则结果0。第三，擦去分隔符、X、Y工作痕迹，将剩余1搬到连续输出区，尾端写0，头回左端停机。每个阶段的左右扫描以分隔符或边界标记结束，有限符号与阶段可编码成有限控制状态。

**补充算例**（数字为演示自取）：m=5,n=3，三轮后左数为XXX11、右数YYY，剩两个1，整理得110，表示2；m=2,n=4，第三次需求找不到左1，清理得0；m=n=2，两轮后左右都无未标1，同样得0。每轮至少标掉右边一个1，所以不超过n轮，加上有限区间扫描与清理，总会停机。

容易漏的是输出清理：仅留下“左数还剩两个1”并没有兑现题目计算函数的接口，必须说明其他带符号如何处理，以及头最终停在哪里。

**考试角度**：（C 级 通识）常见考法是分别检查m>n、m=n、m<n，并写出有限循环的不变量与终止理由。

**考试角度**：（A 级：Final-Exam-2024T1-题目.pdf Q7；期末-2024未核-资料包.pdf Q7；Final-Exam-2025T1-题目.pdf Q6，对应截断减二函数；扫描件视觉读取。）<a name="r-a1"></a>[见附录 A1](#a1)。

### A1 作业/往年题演练（非讲义内容）：截断减二函数

<a name="a1"></a>题面块（[Final-Exam-2024T1-题目.pdf](../考试/Final-Exam-2024T1-题目.pdf) · Q7 · p.1；[期末-2024未核-资料包.pdf](../考试/期末-2024未核-资料包.pdf)同题；[Final-Exam-2025T1-题目.pdf](../考试/Final-Exam-2025T1-题目.pdf) Q6 p.3同题，扫描件视觉读取）：

> **p.1** Design a Turing machine (pseudo code) that computes the function:

公式按原图重排：

$$
f(x)=\begin{cases}x-2&x>2,\\0&x\leq2.\end{cases}
$$

原题没有指定整数编码，先明确采用一元输入1ˣ、x为非负整数、空串表示0，读头初始在最左输入格；输出同编码，非空结果头回最左格，零结果头在原输入起点空白。若老师另定编码，应调整编码层，不能默默把二进制串当一元数。

伪代码：若初始格空白，直接停机；否则向右越过全部1到第一个空白，左移。擦掉最后一个1，再左移；若当前是1，擦掉它再左移；如果当前已经空白，说明原输入只有一个1，不再擦。随后向左越过所有剩余1，到左侧空白再右移一格，停机。

x=5：11111擦成111□□，回到首1，输出111即3。x=2擦完两格，回原起点输出空串即0；x=1只擦一格；x=0走初始直接停止分支。有限扫描与至多两次擦除保证总停机，所有定义域边界均覆盖。保留最左剩余段使输出无内部空白，不能删中间两位后就声称已得到标准编码。
