## Q1

The only nullable variable is A. After eliminating λ-productions:

$$
\begin{aligned}
S&\to aaA\mid aa\mid aBB,\\
A&\to aA\mid a,\\
B&\to bB\mid bbC,\\
C&\to B.
\end{aligned}
$$

Eliminate the unit production $C\to B$ by replacing it with $C\to bB\mid bbC$. Neither B nor C can derive a terminal string: every derivation retains B or C. Remove both variables and every production containing them.

The resulting grammar is

$$
\boxed{S\to aaA\mid aa,\qquad A\to aA\mid a.}
$$

It has no λ-productions, unit-productions or useless productions, and generates

$$
\boxed{L(G)=\{a^n:n\ge2\}.}
$$

## Q2

There are no λ-productions or unit-productions. Every variable is reachable and productive; in particular, $B\Rightarrow bAC\Rightarrow bbC\Rightarrow bbc$.

Introduce $T_a\to a$ and $T_b\to b$. Replace terminals in right-hand sides of length at least two:

$$
\begin{aligned}
S&\to AB\mid a,\\
A&\to T_aAB\mid b,\\
B&\to T_bB\mid T_bAC,\\
C&\to c,\\
T_a&\to a,\qquad T_b\to b.
\end{aligned}
$$

Introduce $D\to AB$ and $E\to AC$ to split the length-three right-hand sides. The final CNF is

$$
\boxed{
\begin{aligned}
S&\to AB\mid a,\\
A&\to T_aD\mid b,\\
B&\to T_bB\mid T_bE,\\
C&\to c,\\
D&\to AB,\\
E&\to AC,\\
T_a&\to a,\\
T_b&\to b.
\end{aligned}}
$$

Every production has either two variables or one terminal on its right-hand side. Expanding the new variables recovers the original productions, so the language is unchanged.

## Q3

**(1) Deterministic.** Each transition set has one element. The a-transition requires stack top z, whereas the λ-transition requires stack top A. They cannot both be enabled in the same configuration.

**(2) Not deterministic.** With state $q_0$, stack top z and next input a, both $\delta(q_0,a,z)$ and $\delta(q_0,\lambda,z)$ are enabled. This violates the DPDA condition forbidding simultaneous input and λ moves for the same state and stack top.

## Q4

Let $M=(Q,\Sigma,\Gamma,\delta,q_0,z,F)$, where

$$
Q=\{q_0,q_1,q_f\},\quad
\Sigma=\{a,b,c\},\quad
\Gamma=\{A,z\},\quad F=\{q_f\}.
$$

The leftmost stack symbol is the top. The nonempty transitions are

$$
\begin{aligned}
\delta(q_0,a,z)&=\{(q_0,Az)\},\\
\delta(q_0,a,A)&=\{(q_0,AA)\},\\
\delta(q_0,c,z)&=\{(q_1,z)\},\\
\delta(q_0,c,A)&=\{(q_1,A)\},\\
\delta(q_1,b,A)&=\{(q_1,\lambda)\},\\
\delta(q_1,\lambda,z)&=\{(q_f,z)\}.
\end{aligned}
$$

[Open the HTML state diagram](HW04-Q4-状态图.html).

All unlisted transitions are empty. State diagram (the upper loops return to their respective states; labels are input, pop, push; `((qf))` denotes a double circle):

```text
             a,z,Az
             a,A,AA                        b,A,λ

                +-------+                   +-------+
                |       |                   |       |
                v       |    c,z,z          v       |
                |       |    c,A,A          |       |    λ,z,z
start ------> (q0) -----+----------------> (q1) ----+---------------> ((qf))
```

The machine pushes one A for each a, reads the unique c, then pops one A for each b. It enters $q_f$ when only z remains. Acceptance requires that the entire input has been consumed, so exactly the strings $a^ncb^n$ are accepted. For $n=0$:

$$
(q_0,c,z)\vdash(q_1,\lambda,z)\vdash(q_f,\lambda,z).
$$

The stack need not be empty because acceptance is by final state. This construction is also deterministic, which is permitted since every DPDA is an NPDA.
