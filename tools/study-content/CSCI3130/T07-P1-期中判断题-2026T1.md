### 模型包含、空串和接受条件（p.5）

**题面**（T07-期中试卷讲评-2026T1.pdf · Problem 1 前三项 · p.5）

> **p.5** Every DFA can be viewed as an NFA with the same set of states.

**True。** DFA 在每个“状态、输入字符”组合上指定唯一后继；NFA 允许后继集合。将 DFA 的后继 $q$ 改写为单元素集合 $\{q\}$，初态、终态和所有状态不变，每条运行路径也不变。因此这里不需要子集构造，更不需要新增状态。

> **p.5** For every language $L$, the empty string $\lambda$ belongs to $L^{\ast}$.

公式按原题重排。**True。** 星号允许连接零个、一个、两个乃至任意有限多个来自 $L$ 的串。零次连接的结果是空串，所以 $L^0=\{\lambda\}$，而 $L^{\ast}$ 含 $L^0$。即使 $L=\varnothing$，也只是没有可供“一次连接”的串；零次连接仍成立，故 $\varnothing^{\ast}=\{\lambda\}$。空语言与只含空串的语言不是同一个集合。

> **p.5** An NFA accepts a string if at least one path consumes the entire string and ends in an accepting state.

**True。** 两个条件缺一不可：“至少一条”说明其他分支失败不影响接受；“整个输入”说明不能读到一半碰到终态就停止。空转移不消耗输入。**补充（自取示例）**：输入 `ab`，某分支读完 `a` 到终态但没有读 `b` 的边，该分支仍失败；另一分支若读完 `ab` 到终态，整台 NFA 便接受。

### 上界、语言包含和封闭性（p.6）

**题面**（同原件 · Problem 1 第四至六项 · p.6）

> **p.6** An NFA with $n$ states always produces exactly $2^n$ reachable states when converted to a DFA by subset construction.

公式按原题重排。**False。** DFA 的状态是 NFA 状态的子集，全部子集数为 $2^n$；但实际构造从初始集合出发，只保留可达子集。**补充（自取反例）**：一个只有初态 $q$、在每个输入字符上都自环的 NFA，其子集只有 $\{q\}$ 可达，空集不可达。因此可达状态为 1 个，并非 $2^1=2$ 个。“最多”不能换成“恰好”。

> **p.6** Every context-free language is regular.

**False。** 原页反例是 $\{a^nb^n:n\ge0\}$。文法 $S\to aSb\mid\lambda$ 每次同时增加一个首部 `a` 和尾部 `b`，所以它是 CFL。若它正则，设泵长为 $m$，选 $a^mb^m$；任意合法泵段均为非空的 $a^k$，泵掉后 `a` 少于 `b`，矛盾。因此它不是正则语言。正确包含方向为正则语言都属于 CFL。

> **p.6** The class of regular languages is closed under union and difference.

**True。** 让两个 DFA 同时读输入，以状态对记录它们的位置。并集在“至少一台接受”时接受；差集 $L_1\setminus L_2$ 在“第一台接受且第二台不接受”时接受。第二台必须对每个输入都有转移，缺失的边先补死状态；否则简单翻转终态会漏掉原本无路可走的输入。有限状态对仍只有有限多个，因而两种结果都正则。

### 文法形式、逆命题与间接可空（p.7）

**题面**（同原件 · Problem 1 第七至九项 · p.7）

> **p.7** The grammar with productions $S\to aSb\mid ab$ is a regular grammar.

公式按原题重排。**False。** 正则文法中的变量须统一处在右端或统一处在左端；`aSb` 将变量夹在终结符中间，既不右线性也不左线性。这份文法生成 $a^nb^n$（$n\ge1$），也不能靠换一个等价正则文法挽救。本题首先检查的是“给出的文法形式”；一般而言某份文法不是正则文法，并不单凭这一点就能断言其语言非正则。

> **p.7** If $L_1\cup L_2$ is regular, then both $L_1$ and $L_2$ must be regular.

公式按原题重排。**False。** 令 $L_1$ 为非正则语言，$L_2=\Sigma^{\ast}$，则并集等于 $\Sigma^{\ast}$，仍然正则。封闭性的前提是“两项已知正则”，它不允许从结果反推两个输入都正则。

> **p.7** A variable $A$ may be nullable even if there is no production $A\to\lambda$ for that particular variable.

公式按原题重排。**True。** nullable 是“可以经若干步推出空串”，不是“有一条直接空规则”。原页给 $A\to B$、$B\to\lambda$，因此 $A\Rightarrow B\Rightarrow\lambda$。算法先标直接可空变量，再反复寻找右端全由已标变量组成的规则，直到集合不再扩大；只扫直接空规则会漏掉 $A$。

### 正则表达式漏掉末尾的一个 1（p.8）

**题面**（同原件 · Problem 1 第十项 · p.8）

> **p.8** The regular expression $(0+10)^{\ast}$ denotes the set of all binary strings that contain no substring $11$.

公式按原题重排。**False。** 每块只能是 `0` 或 `10`，故每个非空输出都以 `0` 结束。`1` 没有连续两个 `1`，却无法由这些块拼出，是最短反例。原式生成的串确实都不含 `11`，错误在于漏收合法串。

**补充（由本题条件展开）**：完整表达式可写为 $(0+10)^{\ast}(\lambda+1)$。除可选的最后一个 `1` 外，每个 `1` 后必须紧跟 `0`，将其合成 `10` 块，其余 `0` 各自成块，就得到分解；反方向，每个 `10` 块的 `1` 后有 `0` 隔开，尾部至多补一个 `1`，所以不会生成 `11`。

## 本讲核心考点

- DFA 是 NFA 特例；NFA 接受要求完整输入和存在接受路径（p.5，A 级：Problem 1）。
- 星闭包含空串，可达子集数只是上界（p.5–6，A 级：Problem 1）。
- 正则语言封闭性不能倒推，正则文法不等于任意 CFG（p.6–7，A 级：Problem 1）。
- 用遗漏串否定表达式等价性（p.8，A 级：Problem 1）。
