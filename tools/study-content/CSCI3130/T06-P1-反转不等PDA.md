### 不相等有三种可核对的原因（p.4）【已会】

题面块（T06 · Problem 1 · PDF p.4；公式按讲义重排）：

> **p.4** Find an npda on $\Sigma=\{a,b,c\}$ that accepts the language $L=\{w_1cw_2:w_1,w_2\in\{a,b\}^{\star},w_1\ne w_2^R\}$

先把c左侧逐符号压栈，c之后栈顶顺序正好是左串的反转。两串不等当且仅当某位置符号不同，或右侧较长，或右侧较短。需要恰一个c；不含c和多于一个c都拒绝。

以下给完整转移族。栈顶写在最左，底符Z；初态P，匹配态R，不等已确认态D，读完后确认左侧仍长的终态F。终态集{D,F}。记“(状态,输入,栈顶)→(新状态,替换串)”，未列者无转移。

| 条件 | 转移 |
|---|---|
| x为a/b，X为a/b/Z | (P,x,X)→(P,xX) |
| X为a/b/Z | (P,c,X)→(R,X) |
| x为a/b | (R,x,x)→(R,λ) |
| x,y为不同a/b符号 | (R,x,y)→(D,y) |
| x为a/b | (R,x,Z)→(D,Z) |
| X为a/b | (R,λ,X)→(F,X) |
| x为a/b，X为a/b/Z | (D,x,X)→(D,X) |

F无后继，只有输入已经全耗尽的分支才能在F接受，因此提前猜“右侧结束”不会误收。D只读a/b、不读c，确保第二个c无法接受。R在Z且输入空时不接受，这正是两侧相等。

**算一遍**：abcb a去空格即abcba，左侧压出baZ，右侧ba依次弹b、a，最后R/Z，拒绝。abcbb第一个b匹配，第二个b与a不同进入D，接受。abc右侧空而栈baZ，可λ到F接受；c两侧均空，不等不成立，拒绝。abcbaa在匹配ba后多一个a，R/Z读a进D，接受。

正确性：D只在已见证字符差异或右长时进入，F只在结束时栈有剩余时接受；反之每种不相等原因都对应一条上述接受路径。

### 非确定的猜测如何受完整输入约束（补充）

自取应该拒绝的 abcba，读到 c 后配置为 $(R,ba,baZ)$。此时可以沿 λ 边进入 F，但得到 $(F,ba,baZ)$，输入 ba 尚未消耗，而 F 没有后继，因此这条分支失败。另一条分支继续匹配 b、a，最终到 $(R,\lambda,Z)$，R 不是终态，所以也拒绝。这个例子说明“允许猜测结束”并不等于机器拥有读取输入结束的额外传感器；错误猜测由后续无法完成读取来淘汰。

在 D 中保留栈而不继续弹也有理由：一旦某个对应位置的字母不同，后面再出现什么 a/b 都无法修复已经发生的不相等；栈的计数任务已经结束。但语法外壳仍要检查，所以 D 没有 c 转移。若加上可读任意字母的循环，就会错误接受含两个分隔符的输入。这把“关系判定已完成”与“输入格式仍须合法”分开了。

:::hint 自检：去掉 F，只保留 D，语言会缺哪一类？

考虑左串非空而右串为空。

:::hint 展开推理与答案

会漏掉右串较短且已读部分完全匹配的情况，例如 abc。匹配阶段未遇到不同字符或右侧超长，所以不会到 D；只有栈仍有 a/b 的结束分支 F 能见证这种不等。

:::endhint
:::endhint
