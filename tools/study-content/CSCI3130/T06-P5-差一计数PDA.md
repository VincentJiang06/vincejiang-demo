### 先给一个a的免费额度（p.11–12）【已会】

p.11导航，p.12题面。

题面块（T06 · Problem 5 · PDF p.12；公式按讲义重排）：

> **p.12** Find an npda on $\Sigma=\{a,b\}$ that accepts the following language $L=\{a^n b^m:n\leq m+1\}$

把条件写成max(n−1,0)≤m：第一个a不用配b，后续每个a压X，b逐个消去X；b更多无妨。底符Z，初态q0，a阶段A，b阶段B，唯一终态F，F无任何后继。转移族如下，未列者无动作：

| 当前态/栈顶 | 输入 | 新态/替换串 |
|---|---|---|
| q0/Z | a | A/Z |
| q0/Z | b | B/Z |
| q0/Z | λ | F/Z |
| A/X或Z | a | A/在原栈顶前压X |
| A/X | b | B/λ |
| A/Z | b | B/Z |
| B/X | b | B/λ |
| B/Z | b | B/Z |
| A/Z或B/Z | λ | F/Z |

A与B在Z上的λ转移和读字符转移并存，故这是合法NPDA，不冒称此表为DPDA。只有所有输入已读完的F路径算接受。B不读a，保证顺序。

**算一遍**：aaab先免费读a，再压两个X，一个b只能弹一个，输入耗尽仍X，不能到F，拒绝，因为3>1+1。aaabb弹完两个X到Z，可λ到F接受；a免费读完后在A/Z也接受；λ从q0直接到F。bbb全部在B/Z读完后接受。

不变量是栈X数为尚待b抵消的“除首a外的a数”；最终为0恰好对应不等式，因此既不漏收也不多收。

## 本讲核心考点

- 免费额度与栈余额对应n≤m+1，b阶段不再读a（p.11–12，C 级）。
