## 1. Lec 1：数学、字符串与语言

### 1.1 集合、关系、函数与证明

| 对象 | 定义或速用公式 |
|---|---|
| 子集、真子集 | $A\subseteq B$：每个 $A$ 的元素都在 $B$；真子集再要求 $A\ne B$ |
| 并、交、差、补 | $A\cup B$ 至少属于一边；$A\cap B$ 同属两边；$A-B=A\cap\overline B$；补集相对指定全集 $U$ |
| 不相交、空集 | $A\cap B=\varnothing$；$\varnothing\subseteq A$，但 $\varnothing\in A$ 需要另行判断 |
| 基数 | $\lvert A\rvert$ 为不同元素数；有限集合满足 $\lvert A\cup B\rvert=\lvert A\rvert+\lvert B\rvert-\lvert A\cap B\rvert$ |
| 幂集 | $\mathcal P(A)=\{B:B\subseteq A\}$；若 $\lvert A\rvert=n$，则 $\lvert\mathcal P(A)\rvert=2^n$ |
| 笛卡尔积 | $A\times B=\{(a,b):a\in A,b\in B\}$；有限时基数为 $\lvert A\rvert\lvert B\rvert$；有序对不能调换 |
| 划分 | 各块非空、两两不相交、全部块的并为原集合 |
| 关系 | $R\subseteq A\times B$；同一个输入可以关联多个输出 |
| 函数 | 每个实际定义的输入恰有一个输出；全函数对整个声明域均有定义，偏函数可在部分输入上未定义 |
| 等价关系 | 自反 $xRx$；对称 $xRy\Rightarrow yRx$；传递 $xRy\land yRz\Rightarrow xRz$ |
| 等价类 | $[x]=\{y:yRx\}$；等价类或者相同，或者不相交，组成一个划分 |

德摩根律：

$$
\overline{A\cup B}=\overline A\cap\overline B,\qquad
\overline{A\cap B}=\overline A\cup\overline B.
$$

**集合恒等式的方法**：任取 $x$，把“属于左边”逐步改写为逻辑条件，最后得到“属于右边”；或分别证两边包含。反驳恒等式只需一个反例。

**例 1：证明第一条德摩根律。**
$x\in\overline{A\cup B}\iff x\notin A\cup B\iff(x\notin A\land x\notin B)\iff x\in\overline A\cap\overline B$，故两集合相等。

**例 2：按模 3 余数划分 $\{0,1,2,3,4,5,6\}$。**
三块为 $\{0,3,6\},\{1,4\},\{2,5\}$。方法是计算余数后分组；“余数相等”直接满足自反、对称、传递。

### 1.2 渐近界、图与常用证明

对充分大的 $n$，假设比较的函数非负：

$$
\begin{aligned}
f\in O(g)&\iff \exists c>0,n_0,\ \forall n\ge n_0:\ f(n)\le cg(n),\\
f\in\Omega(g)&\iff \exists c>0,n_0,\ \forall n\ge n_0:\ cg(n)\le f(n),\\
f\in\Theta(g)&\iff f\in O(g)\cap\Omega(g).
\end{aligned}
$$

**例 3：$f(n)=3n^2+2n+1$ 的紧界。**
当 $n\ge1$，$3n^2\le f(n)\le6n^2$，故 $f\in\Theta(n^2)$。证明时给出常数和起点，不能只说“忽略低次项”。

| 图论概念 | 本课用法 |
|---|---|
| 有向图、标签图 | 边有方向；标签图的边另外带字符等标签 |
| walk | 首尾相接的边序列，允许重复 |
| path | **按 Lec 1 的约定：不重复边** |
| simple path | 不重复顶点；枚举时沿出边做 DFS，只排除当前路径中已访问的点 |
| cycle / loop | cycle 回到起点；simple cycle 除首尾外无重复顶点；loop 是一条自环边 |
| Euler tour | 每条边恰好用一次并回到起点 |
| Hamiltonian cycle | 每个顶点恰好访问一次后回到起点 |
| 有根树 | 根深度为 0；高度为最深叶的深度；高度 $h$ 的二叉树叶子数至多 $2^h$ |

**证明模板**：

- 构造法：给出对象，再验证它满足全部要求。例如奇数乘积 $(2r+1)(2s+1)=2(2rs+r+s)+1$ 仍为奇数。
- 归纳法：写清基例；假设规模 $n$ 成立；推导规模 $n+1$。二叉树例：$h=0$ 时只有一片叶；$h\ge1$ 时左右子树高度至多 $h-1$，叶数总计至多 $2^{h-1}+2^{h-1}=2^h$。
- 反证法：假设结论不成立，再推出矛盾。若 $\sqrt2=p/q$ 且分数已约分，则 $p^2=2q^2$ 使 $p$ 为偶数，代回又使 $q$ 为偶数，矛盾。

**例 4：$n$ 条直线最多将平面分为几区？**
第 $n$ 条线最多被旧线切成 $n$ 段，各新增一区，故 $R_n=R_{n-1}+n,\ R_0=1$，得到 $R_n=1+n(n+1)/2$；$n=3$ 时为 7。达到最大值需要无平行线、无三线共点。

### 1.3 字符串与语言运算

字母表 $\Sigma$ 是有限非空符号集；串是符号的有限序列；语言是 $\Sigma^{\ast}$ 的任意子集。串的顺序和重复次数都有意义，集合元素的排列顺序没有意义。

| 运算 | 定义、边界条件 |
|---|---|
| 串连接 | $uv$ 先放 $u$ 再放 $v$；一般 $uv\ne vu$；$\lvert uv\rvert=\lvert u\rvert+\lvert v\rvert$ |
| 空串 | $\lvert\lambda\rvert=0$，$w\lambda=\lambda w=w$；$w^0=\lambda$ |
| 反转 | $(uv)^R=v^Ru^R$；$(w^R)^R=w$ |
| 子串、前后缀 | 子串须连续：$w=xuy$；前缀 $w=uy$；后缀 $w=xu$；允许空串和全串 |
| 串闭包 | $\Sigma^{\ast}$ 含所有有限串及空串；$\Sigma^+=\Sigma^{\ast}-\{\lambda\}$ |
| 语言连接 | $AB=\{uv:u\in A,v\in B\}$ |
| 语言幂 | $L^0=\{\lambda\}$；$L^{n+1}=L^nL$，每次独立选一个成员 |
| 星闭包、正闭包 | $L^{\ast}=\bigcup_{n\ge0}L^n$；$L^+=\bigcup_{n\ge1}L^n=LL^{\ast}$ |
| 语言反转 | $L^R=\{w^R:w\in L\}$；$(AB)^R=B^RA^R$ |
| 语言的补 | $\overline L=\Sigma^{\ast}-L$，必须固定字母表 |

必须分开记：

$$
\varnothing\ne\{\lambda\},\quad
L\varnothing=\varnothing L=\varnothing,\quad
L\{\lambda\}=\{\lambda\}L=L,\quad
\varnothing^{\ast}=\{\lambda\}.
$$

总有 $L^{\ast}=L^+\cup\{\lambda\}$。只有当 $\lambda\notin L$ 时，才能写 $L^+=L^{\ast}-\{\lambda\}$；例如 $L=\{\lambda,a\}$ 时 $\lambda$ 本来就在 $L^+$ 中。

**例 5：$L=\{a,bb\}$，求 $L^2$。**
两次独立选取，得到 $\{aa,abb,bba,bbbb\}$。方法：列出全部有序选择、连接、去重；不能只把每个成员各自平方。

### 1.4 文法与语言的定义

$G=(V,T,S,P)$：变量集、终结符集、开始变量和产生式集，$V\cap T=\varnothing$。一般产生式左侧至少含一个变量；CFG 进一步要求左侧恰为一个变量。$\alpha\Rightarrow\beta$ 是一步改写；$\Rightarrow^{\ast}$ 是零步或多步；句型可含变量，句子只含终结符。

$$
L(G)=\{w\in T^{\ast}:S\Rightarrow^{\ast}w\}.
$$

两文法等价指生成的语言完全相同，规则或树形无需相同。证明构造正确，要同时说明“不多生成”（soundness）和“不漏生成”（completeness）。

**例 6：$S\to aSb\mid\lambda$。**
$S\Rightarrow aSb\Rightarrow aaSbb\Rightarrow aabb$。每次递归左右各增加一个字符，最终恰得 $\{a^nb^n:n\ge0\}$；反过来任意 $n$ 都可递归 $n$ 次再终止。

多一个固定 $b$ 可设 $S\to Ab,\ A\to aAb\mid\lambda$，得到 $\{a^nb^{n+1}:n\ge0\}$。若只要求 $a,b$ 总数相等而不要求顺序，可用 $S\to SS\mid aSb\mid bSa\mid\lambda$；不要把它与 $a^nb^n$ 混淆。

## 2. Lec 2：DFA、NFA、子集构造与最小化

### 2.1 DFA 定义与构造方法

$$
M=(Q,\Sigma,\delta,q_0,F),\quad
\delta:Q\times\Sigma\to Q.
$$

每个“状态、字符”组合必须恰有一个后继；DFA 没有 $\lambda$ 边。缺边先补到拒绝陷阱，陷阱在每个字符上回到自己。

$$
\widehat\delta(q,\lambda)=q,\quad
\widehat\delta(q,wa)=\delta(\widehat\delta(q,w),a),\quad
L(M)=\{w:\widehat\delta(q_0,w)\in F\}.
$$

**读完全部输入**后处于终态才接受；中途到过终态不够。空串被接受当且仅当 $q_0\in F$。存在 DFA 接受的语言称为正则语言。

**构造方法**：把“读过的前缀中，哪些信息会影响未来接受”写成有限个状态含义；逐字符更新；根据完整串条件选终态；用状态含义归纳证明正确。

| 题目条件 | 状态需要记什么 |
|---|---|
| 字符个数的奇偶 | 偶/奇；只在该字符出现时翻转 |
| 长度模 $m$ | $0,\ldots,m-1$；每读一个字符余数加 1 |
| 至少 $k$ 个某字符 | 饱和计数 $0,1,\ldots,k$；到 $k$ 后不再增长 |
| 以固定串开头 | 逐个核对开头；全匹配后接受吸收，早期不匹配则陷阱 |
| 包含/不含模式 $p$ | 记“当前后缀与 $p$ 的前缀的最长匹配长度”；完整出现后分别永久接受/拒绝 |
| 以模式 $p$ 结尾 | 同样记录匹配长度，但成功态还必须继续更新，不能永久接受 |
| 多个独立条件 | 状态取条件的组合，最后只接受同时满足者 |
| 数字串模 $m$ | $b$ 进制读入数字 $d$：$r'=(br+d)\bmod m$；空串、前导零按题意处理 |

**例 7：接受所有以 $ab$ 结尾的串。**
状态 $q_0$：末尾无非空匹配；$q_1$：末尾匹配 $a$；$q_2$：末尾匹配 $ab$。初态 $q_0$，唯一终态 $q_2$。

| 状态 | 读 $a$ | 读 $b$ |
|---|---|---|
| $q_0$ | $q_1$ | $q_0$ |
| $q_1$ | $q_1$ | $q_2$ |
| $q_2$ | $q_1$ | $q_0$ |

$aab$：$q_0\to q_1\to q_1\to q_2$，接受；$aba$ 最后到 $q_1$，拒绝。

**例 8：$a$ 为偶数个，且以 $b$ 结尾。**
状态 $E_0,E_b,O_0,O_b$ 记录 $a$ 的偶/奇及是否以 $b$ 结尾；初态 $E_0$，终态只有 $E_b$。

| 状态 | $a$ | $b$ |
|---|---|---|
| $E_0$ | $O_0$ | $E_b$ |
| $E_b$ | $O_0$ | $E_b$ |
| $O_0$ | $E_0$ | $O_b$ |
| $O_b$ | $E_0$ | $O_b$ |

$aab$ 接受，$ab$ 拒绝，$b$ 接受，$\lambda$ 拒绝。构造正确后还可合并等价状态，此例 $O_0,O_b$ 可以合并。

### 2.2 NFA 与 $\lambda$ 闭包

允许 $\lambda$ 转移时，$\delta:Q\times(\Sigma\cup\{\lambda\})\to\mathcal P(Q)$。一格可有零个、一个或多个后继；$\lambda$ 边不消费输入。

**存在至少一条**路径读完输入并到达终态便接受。一条分支失败不等于拒绝；所有分支均失败才拒绝。

令 $E(S)$ 为从集合 $S$ 出发，只走零条或多条 $\lambda$ 边能到达的状态集合，包含 $S$ 自己。令 $\operatorname{move}(S,a)=\bigcup_{q\in S}\delta(q,a)$。

$$
S_0=E(\{q_0\}),\qquad
S_{i+1}=E(\operatorname{move}(S_i,w_{i+1})),\qquad
w\text{ accepted}\iff S_n\cap F\ne\varnothing.
$$

**构造技巧**：

- 猜模式起点：初态可循环跳过前缀，又可在同一字符上分出匹配路径。若要求“包含”，匹配后加任意字符循环；若要求“结尾”，匹配成功后不再允许读字符。
- 表达并：新初态用 $\lambda$ 边分别进入两台机器。
- 统一单终态：增加新终态 $f$，每个旧终态用 $\lambda$ 边到 $f$，取消旧终态标记，$f$ 无出边。

**例 9：接受以 $ab$ 结尾的 NFA。**
$q_0$ 在 $a,b$ 上循环，另有 $q_0\xrightarrow{a}q_1\xrightarrow{b}q_f$；只有 $q_f$ 接受且无出边。读 $a$ 时可以同时留在 $q_0$ 和进入 $q_1$；$aab$ 有成功路径，$aba$ 到过 $q_f$ 后仍剩字符，故不接受。

### 2.3 NFA 转 DFA：子集构造

**算法**：初态为 $E(\{q_0\})$；对每个已发现的集合和每个字符计算 $E(\operatorname{move}(S,a))$；新集合加入待处理表；直到无新集合。任何含原 NFA 终态的集合均为 DFA 终态。

空集合也是一个状态，所有字符都转向自己。$k$ 个 NFA 状态至多产生 $2^k$ 个 DFA 状态，通常只保留可达子集；若题目明确要求核对已给的每一行，则不可跳过不可达行。

**例 10：一份带 $\lambda$ 的完整转换。**
NFA 初态 $0$、终态 $2$，非空转移只有 $0\xrightarrow{\lambda}1$、$1\xrightarrow a1$、$1\xrightarrow b2$、$2\xrightarrow{\lambda}1$。

| DFA 名称 | NFA 子集 | $a$ | $b$ | 接受？ |
|---|---|---|---|---|
| $A$（初态） | $\{0,1\}$ | $B$ | $C$ | 否 |
| $B$ | $\{1\}$ | $B$ | $C$ | 否 |
| $C$ | $\{1,2\}$ | $B$ | $C$ | 是 |

例如 $E(\operatorname{move}(\{1,2\},b))=E(\{2\})=\{1,2\}$，所以 $C$ 读 $b$ 仍到 $C$。语言是所有以 $b$ 结尾的串；$A,B$ 还可合并。此例空集合不可达，因此表中无需增加它。

DFA、NFA 接受能力相同，均恰为正则语言。**机器等价比较的是语言，不是图形是否相似。**

### 2.4 DFA 最小化与区分串

状态等价：

$$
p\sim q\iff\forall z\in\Sigma^{\ast},\
\bigl(\widehat\delta(p,z)\in F\iff\widehat\delta(q,z)\in F\bigr).
$$

**划分法**：

1. 删除从初态不可达的状态；必要时先补全转移。
2. 按终态/非终态分组，忽略空组。
3. 比较组内状态在各字符上的“目标组编号”；编号向量不同就拆组。
4. 重复直到稳定；每组变成新状态，初态及终态随组继承。

**填表法**：先标记一个终态、一个非终态的状态对；若某字符使一对转移到已标记的状态对，则也标记；反复到稳定。未标记的对可合并。保存触发字符可以回溯区分后缀。

**例 11：最小化下表，初态 $A$，终态 $D$。**

| 状态 | $a$ | $b$ |
|---|---|---|
| $A$ | $B$ | $C$ |
| $B$ | $D$ | $C$ |
| $C$ | $B$ | $C$ |
| $D$ | $D$ | $D$ |

先分 $\{A,B,C\},\{D\}$。$B$ 读 $a$ 到终态组，$A,C$ 不到，因此变为 $\{A,C\},\{B\},\{D\}$，已稳定。合并 $A,C$ 后得到三状态 DFA，语言为“包含 $aa$”。$A$ 与 $B$ 的区分后缀是 $a$；任一非终态与 $D$ 的区分后缀可取 $\lambda$。

## 3. Lec 3：正则表达式与正则文法

### 3.1 RE 的语法、语义与常见表达式

基本表达式为 $\varnothing,\lambda,a$（$a\in\Sigma$）；用并、连接、星闭包和括号递归组合。表达式是描述形式，$L(r)$ 才是语言集合。

$$
\begin{aligned}
L(\varnothing)&=\varnothing,&L(\lambda)&=\{\lambda\},&L(a)&=\{a\},\\
L(r+s)&=L(r)\cup L(s),&L(rs)&=L(r)L(s),&L(r^{\ast})&=L(r)^{\ast}.
\end{aligned}
$$

优先级：星闭包 > 连接 > 并。$ab^{\ast}+c$ 表示 $a(b^{\ast})+c$。

| 语言（字母表见式中） | 一个 RE |
|---|---|
| 以 $ab$ 开头 / 结尾 / 包含 $ab$ | $ab(a+b)^{\ast}$ / $(a+b)^{\ast}ab$ / $(a+b)^{\ast}ab(a+b)^{\ast}$ |
| 恰好两个 $a$，其余全为 $b$ | $b^{\ast}ab^{\ast}ab^{\ast}$ |
| 偶数个 $a$，其余任意 $b$ | $b^{\ast}(ab^{\ast}ab^{\ast})^{\ast}$ |
| 不含 $00$ 的二进制串 | $(1+01)^{\ast}(\lambda+0)$ |
| 每两个字符成一组 $ab$ 或 $ba$ | $(ab+ba)^{\ast}$；这不等于所有 $a,b$ 个数相等的串 |

**例 12：解释“不含 $00$”的表达式。**
把每个非末尾的 $0$ 连同其后的 $1$ 组成块 $01$；其余 $1$ 单独成块；末尾允许多一个 $0$。例如 $01010=(01)(01)0$，符合表达式；任何一个块及块的连接处都不产生 $00$。

常用等价式：$r+\varnothing\equiv r$，$r\lambda\equiv\lambda r\equiv r$，$r\varnothing\equiv\varnothing r\equiv\varnothing$，$r+r\equiv r$，$r^{\ast}\equiv\lambda+rr^{\ast}$，连接对并分配。

常见错误：$rs$ 不一定等于 $sr$；$(r+s)^{\ast}$ 不一定等于 $r^{\ast}+s^{\ast}$，因为左边允许混合选取，例如 $ab\in L((a+b)^{\ast})$，却不在 $L(a^{\ast}+b^{\ast})$ 中。

### 3.2 RE 与自动机互转

**Kleene 定理**：DFA、NFA、RE、正则文法表示同一类语言。

**RE → NFA（按表达式结构递归）**：

- $\varnothing$：开始点到终点无路；$\lambda$：一条 $\lambda$ 边；$a$：一条 $a$ 边。
- $r+s$：新开始点分两条 $\lambda$ 边进入两子机；两旧终点用 $\lambda$ 边连新终点。
- $rs$：$r$ 的终点以 $\lambda$ 边接 $s$ 的开始点；整体从 $r$ 开始、在 $s$ 结束。
- $r^{\ast}$：新开始点可直接 $\lambda$ 到新终点，也可进入 $r$；$r$ 的终点既能回到其开始点，也能到新终点。
- 连接时取消不再是整体终态的旧终态标记；零次重复必须接受空串。

**NFA/DFA → RE（状态消元）**：

1. 增加无入边的新开始点、无出边的新终点，用 $\lambda$ 接原开始点和原终态。
2. 所有边用 RE 标记，平行边取并，无边为 $\varnothing$；有 $\lambda$ 边才记 $\lambda$。
3. 删除中间状态 $k$ 时，对每对保留状态 $i,j$ 更新：

$$
R'_{ij}=R_{ij}+R_{ik}(R_{kk})^{\ast}R_{kj}.
$$

4. 同一次消元全部使用更新前的标签；删除 $k$；直到只剩新开始和新终点，二者间标签即答案。

**例 13：**$s\xrightarrow a k$，$k\xrightarrow b k$，$k\xrightarrow c f$，另有 $s\xrightarrow d f$。消去 $k$ 后答案为 $d+ab^{\ast}c$：可直接走 $d$，或先 $a$、任意多个 $b$、最后 $c$。若 $k$ 没有自环，因 $\varnothing^{\ast}=\lambda$，仍允许经过它零次循环。

### 3.3 正则文法、左/右线性与转换

| 文法类型 | 规则形式 |
|---|---|
| 线性文法 | 每条右侧至多一个变量，允许在中间，如 $A\to uBv$ |
| 右线性 | 整套规则均为 $A\to uB$ 或 $A\to u$，$u\in T^{\ast}$ |
| 左线性 | 整套规则均为 $A\to Bu$ 或 $A\to u$ |
| 正则文法 RG | 统一右线性或统一左线性；不能把“每条看起来像其中一种”当作整套正则 |

线性不保证正则：$S\to aSb\mid\lambda$ 是线性文法，却生成非正则语言。混合方向也不保证正则：$S\to aA\mid\lambda,\ A\to Sb$ 的两步递归等效于 $S\Rightarrow aSb$。

**右线性文法 → NFA**：变量作状态，开始变量作初态，另加终态 $f$。$A\to uB$ 变为读 $u$ 到 $B$ 的路径；$A\to u$ 变为读 $u$ 到 $f$ 的路径。$u$ 长于一字时加入中间状态；$u=\lambda$ 用 $\lambda$ 边。

**NFA → 右线性文法**：每条 $p\xrightarrow a q$ 对应 $P\to aQ$；$\lambda$ 边对应 $P\to Q$；每个终态 $P$ 加 $P\to\lambda$。初态对应开始变量。

**左线性 → 自动机**：把 $A\to Bu$ 改为 $A\to u^RB$，把 $A\to u$ 改为 $A\to u^R$，得到生成 $L^R$ 的右线性文法；转 NFA 后反转所有边，以新初态 $\lambda$ 连旧终态、以旧初态为唯一终态，得到 $L$。

**例 14：**$S\to aS\mid b$ 生成 $a^{\ast}b$；NFA 为 $S$ 上 $a$ 自环、$S\xrightarrow b f$。左线性 $S\to Sa\mid b$ 生成的是 $ba^{\ast}$，不是 $a^{\ast}b$。

**计数文法的方法**：先造有限状态机，再把每条边改写成规则。例如要求 $a,b$ 都为偶数，变量 $E_E,E_O,O_E,O_O$ 记录两种奇偶；读 $a$ 翻第一位，读 $b$ 翻第二位；仅 $E_E$ 允许 $\lambda$。若要求 $a$ 偶数且 $b$ 至少四个，用“2 种奇偶 × 5 种饱和计数”共至多 10 个变量即可。

## 4. Lec 4：封闭性、判定与非正则证明

### 4.1 正则语言封闭性与乘积自动机

正则语言对有限次的并、交、差、补、连接、星闭包、反转、同态封闭。“封闭”指输入语言正则时，运算结果也正则；不能反过来推每个输入正则。

| 运算 | 构造方法 |
|---|---|
| 并、连接、星闭包 | 按 NFA 的 $\lambda$ 接线构造 |
| 补 | 先得到完整 DFA，再把 $F$ 换成 $Q-F$；NFA 不能直接交换终态求补 |
| 反转 | 反转所有边；新初态 $\lambda$ 连旧终态；旧初态变为唯一终态 |
| 同态 $h$ | 每个字母替换为固定串；$h(uv)=h(u)h(v)$，$h(\lambda)=\lambda$；边标签替换为相应字符链 |

两台完整 DFA 的乘积状态为 $(p,q)$，同时读同一个字符：

$$
\delta((p,q),a)=(\delta_1(p,a),\delta_2(q,a)).
$$

初态为 $(q_{01},q_{02})$，至多 $\lvert Q_1\rvert\lvert Q_2\rvert$ 个状态。终态条件按运算选择：

| 目标语言 | 状态 $(p,q)$ 接受的条件 |
|---|---|
| $L_1\cap L_2$ | $p\in F_1$ 且 $q\in F_2$ |
| $L_1\cup L_2$ | $p\in F_1$ 或 $q\in F_2$ |
| $L_1-L_2$ | $p\in F_1$ 且 $q\notin F_2$ |
| 对称差 $L_1\triangle L_2$ | 两台机器恰有一台接受 |

**例 15：**$L=a^{\ast}b$，$h(a)=01,h(b)=\lambda$，则 $h(L)=(01)^{\ast}$。同态可删除字符，但对同一个字母的替换必须固定。

### 4.2 判定问题及最短反例

| 问题 | 做法 |
|---|---|
| $w\in L$？ | DFA 顺序运行；固定机器时间 $O(\lvert w\rvert)$。NFA 维护全部当前状态及闭包 |
| $L=\varnothing$？ | 从初态搜图；没有任何终态可达才为空，$\lambda$ 边也要考虑 |
| $L$ 是否无限？ | DFA 中是否存在同时“从初态可达”且“能到某终态”的有向环；环必须能重复消费字符 |
| $L_1=L_2$？ | 构造对称差乘积，检查其语言是否为空 |
| $L_1\subseteq L_2$？ | 检查 $L_1-L_2$ 是否为空 |
| 找最短不一致输入 | 在对称差乘积上 BFS，第一条到接受状态的路径标签即最短反例；初态即接受则答案为 $\lambda$ |

注意：死区里的环不影响接受语言是否有限；$\lambda$ 自环本身不能生成无限多个不同字符串。

**例 16：比较“一切以 $a$ 结尾的串”与“奇数个 $a$ 的串”。**
空串均拒绝；长度 1 的 $a$ 均接受、$b$ 均拒绝；$aa$ 被前者接受、后者拒绝。因此 $aa$ 是一个最短区分串。只展示不一致还不够，“最短”另需排除所有更短长度，或给 BFS 依据。

### 4.3 正则泵引理：量词与标准证明

若 $L$ 正则，则存在整数泵长 $p\ge1$，使每个 $w\in L$ 且 $\lvert w\rvert\ge p$ 都存在分解 $w=xyz$，满足：

$$
\lvert xy\rvert\le p,\qquad \lvert y\rvert\ge1,\qquad
\forall i\ge0:\ xy^iz\in L.
$$

量词顺序是“存在 $p$ → 每个长成员 $w$ → 存在一个好分解 → 所有 $i$”。原因：DFA 读前 $p$ 个字符时访问 $p+1$ 次状态，出现重复状态，中间非空段构成可重复的环。

**证明非正则的模板**：

1. 假设 $L$ 正则，设其泵长为任意的 $p$。
2. 你选择 $w\in L$，验证 $\lvert w\rvert\ge p$。
3. 对**任意**满足 $\lvert xy\rvert\le p,\ \lvert y\rvert\ge1$ 的分解，限制 $y$ 所在位置，通常写 $y=a^d,\ 1\le d\le p$。
4. 选一个 $i\ge0$（可依赖分解），证明 $xy^iz\notin L$。
5. 与泵引理矛盾，所以 $L$ 非正则。

你能选择见证串和泵次数，不能替对方指定方便的分解。该引理是正则性的必要条件，不能拿“能泵”直接证明正则。

**例 17：$\{a^nb^n:n\ge0\}$ 非正则。**
取 $w=a^pb^p$。任意合法分解中 $y=a^d,\ 1\le d\le p$。取 $i=0$，得到 $a^{p-d}b^p$，两段数量不相等，矛盾。

**例 18：$\{a^{n^2}:n\ge0\}$ 非正则。**
取 $w=a^{p^2}$。任意分解令 $d=\lvert y\rvert\in[1,p]$。取 $i=2$，新长度为 $p^2+d$，而

$$
p^2<p^2+d\le p^2+p<(p+1)^2.
$$

处在相邻平方之间，故不在语言中。

**例 19：$\{a^{2^n}:n\ge0\}$ 非正则。**
取 $k$ 使 $2^k>p$，令 $w=a^{2^k}$。泵一次新增 $d\in[1,p]$，有 $2^k<2^k+d<2^{k+1}$，不可能仍是 2 的幂。

**其他长度题的方法**：泵后长度恒为 $\lvert w\rvert+(i-1)d$。阶乘长度可选 $w=a^{m!}$，令 $m\ge3$ 且 $m!>p$，取 $i=2$，新长度落在 $m!$ 与 $(m+1)!$ 之间。质数长度不能假定固定小间隔：选质数长度 $q\ge p$，取 $i=q+1$，新长度 $q+qd=q(1+d)$ 为合数。

### 4.4 另外两种非正则证明

**封闭性反证**：假设目标语言正则，与一个已知正则语言做封闭运算，若结果恰是已知非正则语言则矛盾；必须证明运算结果确实相等。

**例 20：$L=\{w\in\{a,b\}^{\ast}:\#_a(w)=\#_b(w)\}$ 非正则。**
若 $L$ 正则，则 $L\cap a^{\ast}b^{\ast}$ 正则；但交集恰为 $\{a^nb^n:n\ge0\}$，与例 17 矛盾。

**无限多个可区分前缀**：找无限前缀集合，使任意两个不同前缀均有某个共同后缀让接受结果不同，则它们必须到不同 DFA 状态，有限状态不可能做到。

例如对 $a^nb^n$，前缀 $a^i,a^j$（$i\ne j$）用后缀 $b^i$ 区分：$a^ib^i$ 属于语言，$a^jb^i$ 不属于语言。

## 5. Lec 5：CFG、推导树、歧义与解析

### 5.1 CFG 定义与构造模板

CFG 的每条产生式必须为 $A\to\alpha$，$A\in V,\ \alpha\in(V\cup T)^{\ast}$；左边恰好一个变量。存在 CFG 生成的语言称 CFL。正则语言都是 CFL，反向不成立。

| 目标结构 | 文法模板 |
|---|---|
| 两侧同步计数 $a^nb^n,\ n\ge0$ | $S\to aSb\mid\lambda$ |
| 同步比例 $a^{2n}b^n,\ n\ge0$ | $S\to aaSb\mid\lambda$ |
| 必须至少一组 | 将上例的空串基例改成最小合法串，如 $S\to aaSb\mid aab$ |
| 相等两段后接独立后缀 | $S\to AB$，让 $A$ 管配对、$B$ 管后缀；变量改名避免相互干扰 |
| 偶数长度回文 | $S\to aSa\mid bSb\mid\lambda$ |
| 任意长度回文 | 在偶数回文模板中增加 $S\to a\mid b$ |
| 合法括号串 | $S\to (S)S\mid\lambda$ |
| 两种语言取并 | 新开始变量 $S\to S_1\mid S_2$；两套变量先改成不相交 |
| 连接两种语言 | $S\to S_1S_2$；两套变量先改成不相交 |

**例 21：生成 $\{a^{2n}b^n:n\ge1\}$。**
用 $S\to aaSb\mid aab$。每次递归增加两个 $a$、一个 $b$；例如 $S\Rightarrow aaSb\Rightarrow aaaabb$，对应 $n=2$。一般递归 $n-1$ 次再用基例，得到所有目标串，且不会产生别的形式。

**例 22：括号串与数量相等的区别。**
合法括号必须总数相等，并且任意前缀的左括号数不少于右括号数；因此串“)(”不合法。模板 $S\to(S)S\mid\lambda$ 可生成 $()()$：先取外层规则，再令内部 $S$ 为空，后面的 $S$ 生成另一对。其完整性来自非空合法串必能分解为 $(u)v$，其中 $u,v$ 仍合法。

写 CFG 答案时，应说明递归次数如何对应参数，检查零值/正值边界，并分别证明不多生、不漏生。仅生成几个样例不构成完整证明。

### 5.2 最左/最右推导与推导树

最左推导每次替换最左变量；最右推导每次替换最右变量。树的根是开始变量；每个变量节点的有序孩子对应其选用规则；叶子从左到右读取为生成串，$\lambda$ 叶不贡献字符。部分树仍可有变量叶子。

**例 23：**$S\to AB,\ A\to a,\ B\to b$。

- 最左：$S\Rightarrow AB\Rightarrow aB\Rightarrow ab$。
- 最右：$S\Rightarrow AB\Rightarrow Ab\Rightarrow ab$。

二者是同一棵树，只是展开顺序不同。固定一棵树时，最左推导唯一、最右推导也唯一。

### 5.3 证明歧义与去歧义

**有歧义**：存在同一个终结符串有两棵不同推导树；等价地，存在两份不同的最左推导，或两份不同的最右推导。

**方法**：找能有不同分组的小串；写出两份最左推导，并标明结构区别。两份任意顺序的推导不足以证明歧义。

**例 24：$S\to SS\mid a$ 有歧义。**
同一串 $aaa$：

$$
\begin{aligned}
S&\Rightarrow SS\Rightarrow SSS\Rightarrow aSS\Rightarrow aaS\Rightarrow aaa,\\
S&\Rightarrow SS\Rightarrow aS\Rightarrow aSS\Rightarrow aaS\Rightarrow aaa.
\end{aligned}
$$

两行每一步都替换最左变量；第一棵树按 $(aa)a$ 分组，第二棵按 $a(aa)$ 分组，故有歧义。

**表达式去歧义**：为不同优先级分层，并把结合性写进递归方向。例如以下 $\cdot$ 代表乘号终结符：

$$
E\to E+T\mid T,\qquad
T\to T\cdot F\mid F,\qquad
F\to(E)\mid a.
$$

$a+a\cdot a$ 只能按 $a+(a\cdot a)$ 解释；同级运算用左递归得到左结合。括号可改变优先级。dangling else 同样需要规定 else 绑定哪个 if，并通过文法或解析规则实现。

**固有歧义**是语言的性质：它的每份 CFG 都有歧义。证明一份文法有歧义，不等于证明语言固有歧义。

### 5.4 s-grammar 与一般穷举解析

s-grammar 的规则均为 $A\to a\alpha$，其中 $a\in T,\alpha\in V^{\ast}$，且对每个组合 $(A,a)$ **最多一条规则**。按此定义不含空规则。首字符之后只能是变量；如 $S\to aSb$ 必须将末尾 $b$ 代理为变量后才满足形式。

**解析方法**：栈初始为 $S$；取栈顶变量 $A$ 和下一输入字符 $a$，选唯一对应规则，消费 $a$，将右侧变量从右到左压栈。无规则则拒绝；输入与栈同时耗尽才接受。固定文法时间 $O(n)$。

**例 25：**$S\to aSB\mid c,\ B\to b$ 是 s-grammar，生成 $\{a^ncb^n:n\ge0\}$。
解析 $aacbb$，用左端表示栈顶：

| 消费的字符 | 剩余输入 | 栈 |
|---|---|---|
| 尚未消费 | $aacbb$ | $S$ |
| $a$ | $acbb$ | $SB$ |
| $a$ | $cbb$ | $SBB$ |
| $c$ | $bb$ | $BB$ |
| $b$ | $b$ | $B$ |
| $b$ | $\lambda$ | 空 |

两者同时空，接受；$aacb$ 输入耗尽后还剩一个 $B$，拒绝。

**穷举解析**：按层枚举最左推导。若没有空规则和单位规则，生成长度 $n\ge1$ 的成功推导最多 $2n-1$ 步：增加句型长度的步骤至多 $n-1$，单变量变单终结符的步骤至多 $n$。可用此界截断搜索；一般 CFG 若带空规则/单位环，不能直接套此界。穷举虽可停机，分支数仍可能指数增长。

### 5.5 编译中的位置

字符 → 词法分析 → token → 语法分析 → 语法树 → 语义检查与代码生成。

词法常用 RE/FA；语法结构常用 CFG。语法正确不代表类型或语义正确。BNF 用产生式表达语法，通常用 ::= 表示定义、竖线表示备选。LL/LR 是适合特定高效解析算法的文法类别，不代表所有 CFG 都可按同一方式线性解析。

## 6. Lec 6：文法清理、CNF、GNF、CYK

### 6.1 代入与清理顺序

**代入定理**：若 $A\ne B$，存在 $A\to uBv$，而 $B\to\beta_1\mid\cdots\mid\beta_k$ 是 $B$ 的全部规则，可用所有 $A\to u\beta_i v$ 替换该规则，保持语言。只代一个候选就删旧规则会丢失语言；自递归不能当作普通一步代入无限展开。

顺序：保护空串 → 消空规则 → 消单位规则 → 去无用符号（先 generating，后 reachable）→ 所需范式。消空可能制造单位规则，所以两步不能随意颠倒。

若原语言含 $\lambda$，引入不出现在任何右侧的新开始变量 $S_0$；在后续变换中保留唯一空规则 $S_0\to\lambda$，最终消掉 $S_0\to S$ 的单位规则。若题目明确只要求 $L-\{\lambda\}$，则不保留空串。

### 6.2 消除 $\lambda$ 规则

1. 找 nullable 集：先收集直接推出 $\lambda$ 的变量；反复加入“某条右侧全由已 nullable 变量组成”的左变量，直到不变。
2. 对每条右侧，枚举每个 nullable **出现位置**的保留/删除，加入所有不同的非空结果。
3. 删除旧空规则；按前节约定处理开始变量的空串例外。

**例 26：**若 $A,B$ 都 nullable，则 $S\to ABA$ 可产生的不同右侧为

$$
ABA,\ BA,\ AA,\ AB,\ A,\ B,\ \lambda.
$$

两个 $A$ 的位置要独立选择；删左 $A$ 得 $BA$，删右 $A$ 得 $AB$。非空结果加入规则，$\lambda$ 仅在受保护的开始变量处保留。$r$ 个 nullable 位置最多有 $2^r$ 种删留组合，去重后可能更少。

### 6.3 单位规则与无用符号

**单位规则**形如 $A\to B$，右边恰一个变量；$A\to a$ 不是单位规则。

**消单位方法**：为每个 $A$ 求单位边可达闭包 $U(A)$，包含 $A$ 自己。对每个 $B\in U(A)$，把 $B$ 的全部非单位出口复制给 $A$；最后统一删单位规则。遇到单位环用访问集合防止重复。

**例 27：**$S\to A,\ A\to B\mid a,\ B\to A\mid b$。
$U(S)=\{S,A,B\}$，$U(A)=U(B)=\{A,B\}$。消单位后 $S,A,B$ 都有 $a,b$ 两个出口；再删不可达的 $A,B$，最终为 $S\to a\mid b$。

**去无用符号**：

1. generating：从能直接生成纯终结符串的变量起，反复加入右侧只含终结符和已 generating 变量的左变量。删非 generating 变量及涉及它们的规则。
2. 在**删过规则的新文法上**，从开始变量找 reachable；删除不可达变量及其规则。
3. 若开始变量也非 generating，则语言为空，不能凭空给它增加终止规则。

**例 28：**$S\to AB\mid a,\ A\to a,\ B\to B,\ C\to c$。
$B$ 不 generating，先删 $B$ 及 $S\to AB$；此时 $A,C$ 都不可达，继续删除，最终 $S\to a$。若先算旧文法可达性，容易错误地留下 $A$。

### 6.4 Chomsky Normal Form（CNF）

非空规则只能为 $A\to BC$ 或 $A\to a$；允许受保护开始变量的空串例外。不能有 $A\to B$、$A\to aB$、$A\to BCD$。

**转换方法**：先完成清理；对长度至少 2 的右侧，把终结符 $a$ 替换成代理 $T_a$，增加 $T_a\to a$；再把长度超过 2 的变量串逐步二叉化。如

$$
A\to BCD\quad\leadsto\quad A\to BX,\ X\to CD
$$

其中 $X$ 为新变量；原来的一字符终结规则无需替换。最终检查所有右侧形状，并再次去除新产生的无用部分。

**例 29：把 $S\to AB\mid a,\ A\to aA\mid\lambda,\ B\to b$ 转成 CNF。**

- nullable 只有 $A$，消空后：$S\to AB\mid B\mid a,\ A\to aA\mid a,\ B\to b$。
- 消单位 $S\to B$：$S\to AB\mid b\mid a,\ A\to aA\mid a,\ B\to b$。
- 给混合右侧中的 $a$ 加代理，最终：

$$
S\to AB\mid b\mid a,\qquad
A\to T_aA\mid a,\qquad
T_a\to a,\qquad B\to b.
$$

四条类型均合法，语言仍为 $\{a\}\cup\{a^nb:n\ge0\}$。注意 $S$ 原本不可空，不应添加 $S\to\lambda$。

CNF 生成长度 $n\ge1$ 的串时，每棵完整推导树恰有 $n-1$ 次二叉规则和 $n$ 次终结规则，总计 **$2n-1$ 步**。

### 6.5 Greibach Normal Form（GNF）

每条非空规则形如 $A\to aA_1\cdots A_k$，$a\in T,\ k\ge0$；第一个符号是终结符，其余全是变量。允许受保护开始变量的空串例外。

**转换思路**：先清理文法；给变量编号；通过代入消去规则首部的较小编号变量并消除直接左递归，再按逆序展开首部变量，直到所有规则以终结符开头；最后把首字符之后的终结符换成代理变量。含相互递归时须按编号系统处理，不能随意反复代入。

**直接左递归的常用消法**：若

$$
A\to A\alpha_1\mid\cdots\mid A\alpha_m\mid\beta_1\mid\cdots\mid\beta_r,
$$

其中每个 $\alpha_i\ne\lambda$、$\beta_j$ 不以 $A$ 开头，且存在非递归出口，则引入新变量 $R$，替换为

$$
A\to\beta_j\mid\beta_jR,\qquad
R\to\alpha_i\mid\alpha_iR
$$

（对全部 $i,j$ 加规则）。这一步去除直接左递归，但右侧是否已符合 GNF 还需继续检查。

**例 30：$A\to Aa\mid b$。**
改为 $A\to b\mid bR,\ R\to a\mid aR$，已经是 GNF，语言仍为 $ba^{\ast}$。例如 $A\Rightarrow bR\Rightarrow baR\Rightarrow baa$，三字符恰好三步。

GNF 中每一步最左推导恰产生一个新的最左终结符，所以非空长度 $n$ 的串恰需 $n$ 步。GNF **不保证**同一 $(A,a)$ 仅有一个候选；因此不自动是 s-grammar，也不自动无歧义。

### 6.6 CYK：从短子串向长子串填表

输入为 CNF 文法和串 $w=w_1\cdots w_n$。定义

$$
V[i,j]=\{A:A\Rightarrow^{\ast}w_i\cdots w_j\}.
$$

**算法**：

1. 长度 1：$V[i,i]=\{A:A\to w_i\in P\}$，同一个字符可对应多个变量。
2. 按区间长度 $2,3,\ldots,n$ 填表。对每个 $[i,j]$ 枚举所有切口 $k=i,\ldots,j-1$：

$$
V[i,j]=
\bigcup_{k=i}^{j-1}
\{A:\exists A\to BC\in P,\ B\in V[i,k],\ C\in V[k+1,j]\}.
$$

3. $S\in V[1,n]$ 则接受；否则拒绝。空串单独检查受保护开始变量能否生成 $\lambda$。
4. 要输出推导树，记录每次加入变量时使用的规则和切口，再从顶格的 $S$ 回溯。

**例 31：**$S\to AB,\ A\to AA\mid a,\ B\to BB\mid b$，判断 $w=aab$。

| 子串 | 计算 | 结果 |
|---|---|---|
| $w_1=a$ | $A\to a$ | $V[1,1]=\{A\}$ |
| $w_2=a$ | $A\to a$ | $V[2,2]=\{A\}$ |
| $w_3=b$ | $B\to b$ | $V[3,3]=\{B\}$ |
| $w_1w_2=aa$ | $A\to AA$ | $V[1,2]=\{A\}$ |
| $w_2w_3=ab$ | $S\to AB$ | $V[2,3]=\{S\}$ |
| $w_1w_2w_3=aab$ | 切为 $a/ab$ 得 $AS$，无匹配规则；切为 $aa/b$ 得 $AB$，用 $S\to AB$ | $V[1,3]=\{S\}$ |

所以接受。回溯可得 $S\Rightarrow AB\Rightarrow AAB\Rightarrow aAB\Rightarrow aaB\Rightarrow aab$。不能只查一个切口，也不能把格中变量随意调换左右顺序。

时间 $O(n^3\lvert P\rvert)$，固定文法时为 $O(n^3)$；存储所有集合约需 $O(n^2\lvert V\rvert)$。CYK 能对一般 CFG 使用，但须先转换成等价的 CNF，并单独照顾空串。

|---|---|
| 构造 DFA/NFA | 状态含义、初态、终态、完整转移及接受理由；NFA 无边可以省略，但不能把省略当自环 |
| 子集构造 | 初始闭包、各字符 move 后再闭包、所有接受子集、必要的空集合 |
| 最小化 | 先去不可达、展示分组细化、写合并后的转移 |
| 构造 RE | 说明每个块负责什么，核对空串、顺序、数量边界；证明两个方向 |
| 状态消元 | 正确的进入—循环—离开标签，保留原直接边；每轮用旧标签统一更新 |
| 非正则证明 | 任意泵长、合法见证、任意合法分解、明确泵次数、明确违反的条件 |
| CFG 构造 | 递归与基例、参数对应、不多生与不漏生；注意零次和至少一次 |
| 证明歧义 | 同一个终结符串、两棵不同树或两份不同最左/最右推导 |
| 文法清理/范式 | nullable 闭包、位置组合、单位闭包、先 generating 后 reachable、空串处理、最终规则形状 |
| CYK | 所有长度、所有切口、每格全部变量、顶格是否含开始变量；需要时附回溯推导 |

最容易丢分的条件：空串与空语言不同；DFA 必须读完才判接受；NFA 只需一条成功分支；求补要用完整 DFA；泵引理不能自己指定分解；文法有歧义不等于语言固有歧义；GNF 不等于 s-grammar；CNF 长度 $n$ 是 $2n-1$ 步，GNF 长度 $n$ 是 $n$ 步。
