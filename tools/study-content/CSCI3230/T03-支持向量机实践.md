### 从分类器到支持向量（p.1–3）

本辅导让我们把公式里的样本、乘子与实际程序输出对应起来。原件页脚为2025T1；文件名保留“未核”，但不能因此把它当2026新资料。PDF有33页：p.15–16是同一页脚15的动画，后面本笔记一律按PDF页号定位。

先把预测流程压到能手算的程度。一个点 $x\in\mathbb R^2$ 有两个特征；训练得到 $w\in\mathbb R^2,b\in\mathbb R$ 后，算标量 $f(x)=w^Tx+b$，大于零判+1，小于零判−1。这是预测；学习 $w,b$ 则是训练。不要因软件一行调用就把两步混为一谈。

SVM训练偏好最靠近边界的点也保有较大缓冲。规范化后，每个训练点要求 $s_i=y_if(x_i)\ge1$，并尽量减小 $\lVert w\rVert^2/2$。$y_i$是真实标签，$s_i$是标签乘分数，均为数；$w$则是向量。总间隔宽度为 $2/\lVert w\rVert$，来源见 [L04 Part 2](L04-P2-最大间隔SVM.md)。还不熟时先画下一节三条竖线，比直接背对偶式有效。

### 例 1：由乘子恢复直线（p.4–6）

**题面数据（T03 p.4–5）**：正类 $(3,1),(3,-1),(6,1),(6,-1)$，负类 $(1,0),(0,1),(-1,0),(0,-1)$；乘子只有1、2、5号非零，依次为0.25、0.25、0.5。这是讲义给出的求解器结果，不是我们从图上估出来的。

恢复公式 $w=\sum_i\alpha_i y_ix_i$ 可以读成：把每条样本乘自己的乘子和标签，再逐坐标相加。前两点各贡献 $(0.75,0.25)$ 和 $(0.75,-0.25)$；5号标签为−1，贡献 $(-0.5,0)$。总和第一坐标1、第二坐标0，所以 $w=(1,0)^T$。

非零乘子点应压在相应支撑线上。对正类 $(3,1)$，$w^Tx+b=1$，得到 $3+b=1$，故 $b=-2$。对负类 $(1,0)$，应有 $1+b=-1$，也得到−2。于是分数 $x_1-2$：中线在横坐标2，正支撑线在3，负支撑线在1，总宽2。纵坐标怎么变都不改变这个**已训练模型**的分数。

再验两个容易漏掉的条件：乘子加权标签和 $0.25+0.25-0.5=0$；对远处正点 $(6,1)$，功能间隔为4，确实比1大。它不贴线所以可取零乘子。最优性还可由原目标 $1/2$ 与对偶目标 $1-1/2=1/2$ 相等检查，完整理由属于对偶拓展。

### 数据与拟合接口（p.7–9）

p.7介绍scikit-learn库，p.8导入工具，p.9把数据交给 `svm.SVC(kernel='linear')`。先关注数据形状：`X` 的每一行是一条样本，每列是一种特征，所以八点例为8行2列；`y`是长度8的标签数组，同一行必须配同一个标签。转置成2行8列会把“两个特征”误当“两个样本”。

p.9的 `fit(X,y)` 用训练数据求模型参数，返回后才可以预测新点。下面是**接口理解用的最小示例**，复现课件的数据形状，本篇没有实际运行它，也不声称得到某个版本完全一致的数值：

```python
import numpy as np
from sklearn import svm
X = np.array([[3, 1], [3, -1], [6, 1], [6, -1],
              [1, 0], [0, 1], [0, -1], [-1, 0]])
y = np.array([1, 1, 1, 1, -1, -1, -1, -1])
model = svm.SVC(kernel="linear", C=1.0)
model.fit(X, y)
```

这里保留p.9代码的后两个负点顺序，它与p.4列表顺序相反。两点在此例的乘子都为零，所以边界不变；但对照样本编号时必须以实际输入数组为准。`C=1.0` 是显式教学设置，也让你看到SVC是带惩罚参数的模型；`kernel="linear"`并不自动表示“严格硬间隔求解器”。在此数据与设置下，课件数值接近前述硬间隔解。

**补充 · 模型保存的带符号系数，不要再乘一次标签**（通识讲解；演示数据不属于原题）。

理论式使用非负乘子 $\alpha_i$，预测贡献是 $\alpha_i y_iK(x_i,x)$。有些接口直接保存这个带符号乘积，而不是单独保存 $\alpha_i$。读输出时先辨认对象，否则将保存值再乘一次 $y_i$，负类贡献会被错误翻正。

演示两个支持点标签为−1、+1，乘子均为0.5，保存的带符号系数应为−0.5、+0.5。若新点与它们的核值为2、4，偏置为0，正确分数是 $-0.5\times2+0.5\times4=1$；错误地再乘标签得到3。两者可能碰巧预测同一类别，所以只检查类别还发现不了错误；应先逐项核对决策分数，再比较符号。

### 输出符号与等高线（p.10–12）

p.10显示 `dual_coef_`、`coef_` 与 `support_vectors_`。数组不是按所有训练点逐行列出：非零系数对应保留下来的支持向量，顺序也可能先负类后正类。必须把**同一输出顺序**的系数与支持向量成对解释。

原页带符号系数约为 `[-0.50024083, 0.25012042, 0.25012042]`，对应点 $(1,0),(3,1),(3,-1)$。数学里的 $\alpha_i$非负，但这个二分类输出是 $y_i\alpha_i$，所以负类条目为负不违反约束。乘回支持点：横坐标约为 $-0.50024083+3(0.25012042)+3(0.25012042)=1.00048169$；纵坐标约为 $0.25012042-0.25012042=0$。这对应原页 `coef_` 中约1.00048166与近零的数，微小差值来自显示舍入与求解容差。

p.11先在二维平面密集放一张网格，再对每个网格点算 `decision_function`。p.12画值为−1、0、1的等高线：中间是决策边界，两侧是功能分数支撑线；空心圆圈出支持向量。图中中线约在2、两侧约在1与3，与手算相符。这里的“等高”是分数一样，不是真把样本升到三维。

**小检查（补充）**：看到分数2，能否把它读成概率200%？

:::hint 参考答案
不能。`decision_function`给判别分数，未限制在0到1。它的符号可用于分类，数值大小还与参数尺度有关；概率估计是另外的校准任务。
:::endhint

### 例 2：为什么一条直线不够（p.13–15）

p.13的图把棕色正点放在近原点的一圈，蓝色负点放在更大的外圈。p.14的代码具体为六个内点 $(0.1,0),(-0.05,-0.087),(-0.1,0),(0.05,0.087),(0.05,-0.087),(-0.05,0.087)$；外点为 $(-0.5,-0.87),(1,0),(0.5,-0.86),(-0.5,0.87),(0.5,0.87),(-1,0)$。近似小数让半径略有差异，不应把所有点强称为精确同圆。

先用结构判断：一条直线的一侧是半平面，它不能完整围住中间一团而把周围各方向都排除。p.14线性模型的图确实没把内圈隔开，p.15提问如何处理。此处首先遇到的是表示能力限制；调大迭代次数并不能让一条直线变成封闭圆。

**补充数值直觉**：内点 $(0.1,0)$ 的半径平方为0.01，外点 $(1,0)$为1。若新增特征“到原点的半径平方”，一条关于该特征的阈值就有机会分开内外。这是从数据结构想到特征，而不是先盲目背某种核名称。

### 核映射的几何与计算（p.16–18）

p.16是上一张“Kernel function!”的动画揭示页；p.17示意图左侧红方块在中间、绿圆点在外，右侧将中央点抬高到曲面上，水平分割面把高低两类分开。它说明**坐标经非线性变换**后可能线性可分，不是把原平面刚性旋转了一下。p.18接着谈节省映射计算成本。

把图变为能算的补充例子：新增 $r^2=x_1^2+x_2^2$，内点0.01，外点1；在这个新坐标上选阈值0.5便区分这两个代表点。这个阈值是教学自取，不是课件训练器输出。真实模型还要处理全部样本并学出分界。

映射 $\phi(x)$ 输出特征向量；核 $K(x,z)=\phi(x)^T\phi(z)$ 接收两个样本并输出标量内积。原页把核描述为转换，初学时容易因此混淆这两个对象。以 [L04 Part 3](L04-P3-核方法.md) 的二次映射为例，$x=(1,2),z=(2,1)$ 原内积4，平方16，恰等于显式三维映射后的内积16。只算这16，便无需先存储那两个映射向量。

节约的是特征展开成本。若训练样本有 $m$ 条，成对核值仍可能需要 $m^2$ 的存储，不能从“kernel trick”推断样本量再大也不占内存。

### 多项式、sigmoid 与次数（p.19–21）

p.19回顾多项式、sigmoid与高斯核。多项式按课件写作 $(x^Tz)^d$，次数 $d$ 是选择的正整数；sigmoid使用双曲正切；RBF由距离决定相似性。实际库参数化可能带额外缩放与偏移，纸面公式与API参数不能仅凭名字等同。

p.20用 `kernel='poly'` 的课件运行图尚未圈住内点；p.21显式设 `degree=4`，图中出现包围内圈的曲线。原页p.20没有显式打印次数，不能把“本地现在某版本默认值”假装成该页的直接证据。应先记录课件代码实际给出的参数，再查询自己安装版本的文档与 `get_params()`。

**补充手算看次数**：若两点内积为2，齐次二次核为4，四次核为16；若内积为0.5，则分别为0.25和0.0625。升次数对大、小内积产生不同放大/压缩，而不只是把整条边界 统一放大。若内积为−2，奇次结果负、偶次结果正，确实可能影响对称数据；但不能因此概括“偶数次数总好、奇数总坏”。应以独立验证表现选择模型。

### 核边界与测试点（p.22–24）

p.22的sigmoid示例未理想圈出内圈；p.23换RBF后出现包围内点的边界。图上的曲线是**训练后的零分数集合**，不是高斯函数那条钟形曲线直接搬到了平面上。每个支持样本对新点贡献一个核值，带标签加权相加再加偏移，最终零集合才形成边界。

**补充·理解RBF的旋钮**：$K(x,z)=\exp(-\gamma\lVert x-z\rVert^2)$，$\gamma>0$。距离1时，$\gamma=1$给 $e^{-1}\approx0.368$，$\gamma=4$给 $e^{-4}\approx0.018$；更大的gamma使影响更局部。它与控制违约代价的 $C$ 不是同一参数，选择RBF并不意味着这两个参数已经最合适。

### 十点结果与重叠类别（p.25–27）

p.25打印 `predict(X_test)`，与真实标签逐项一致。准确率定义为正确条数除总条数，因此该页记录为 $10/10=100\%$。这是**课件保存的运行结果**，不是本篇重新执行所得；也不是未来数据不会出错的证明。十条测试很少，反复用它们挑超参数还会让结果偏乐观。

为什么前一个漂亮例子不够？p.26用 `make_blobs` 生成30条二维数据，设置两个中心与标准差1.2；p.27散点图中两类相互靠近、部分混杂。标准差控制围绕中心的扩散尺度，不是分类器参数。更分散的数据更容易重叠，但一次随机抽样不能精确代表所有未来样本。

想象两个同位置样本标签相反：任何只依赖输入坐标的确定分类器都无法把二者同时判对。这个补充极端例子说明完全可分不是天经地义的前提。软间隔因此允许违反要求，并在训练中对它付费。

### 软间隔到底容许了什么（p.28–30）

p.28提出软间隔动机，p.29原页写的是带 $\ell_{0/1}$ 的离散间隔违约惩罚，**没有写出hinge的max公式**。旧笔记把它直接引成hinge，现按原件纠正。当前L04 p.45也先讲离散计数，p.46再用hinge替代；以下连续目标是承接L04的讲解，不冒充T03 p.29逐字公式。

令功能间隔 $s_i=y_i(w^Tx_i+b)$。hinge损失为 $\max(0,1-s_i)$。它问“离要求的1还差多少”，不是只问分类正负是否对。例子是补充自取：$s=1.4$损失0；$s=0.4$损失0.6（判对但不够远）；$s=-0.2$损失1.2（已经错分）。

相应的训练目标是

$$
\frac12\lVert w\rVert^2+C\sum_i\max(0,1-s_i).
$$

范数项鼓励较宽缓冲；$C$把违约损失换算成目标中的代价。$C$大时违约贵，$C$小时更可能接受违约以减小权重。所谓“give up noisy examples”应理解为容许付费违约，不是软件把那些行从数组里删除，也不是已经证明它们的标签错误。

p.30示例显式或默认使用 $C=1$；这只是那次模型设置，不能作为每个数据集的最佳值。比较不同 $C$ 时保持数据、特征尺度及划分一致，才能知道改变来自哪个旋钮。

### 比较与进一步练习（p.31–33）

p.31并排展示 $C=10$ 与 $C=0.1$ 的线性模型。中间实线是零分数边界，两条虚线标±1，空心圈是输出的支持向量。右侧小C图的虚线间带更宽，也容许更多点进入带中。不能只数训练错误就判它更差，目标本来就在用拟合换缓冲。

一个适合初学者的小实验流程（补充）是：先固定一份训练/验证划分；选两三个C，分别拟合；记录训练与验证准确率、支持向量数、边界图；最后用先前没参与选择的测试集评价。若训练更好而验证更差，首先怀疑拟合噪声，别立即把迭代次数无限加大。特征尺度也会影响距离与核，所以任何标准化参数都只能从训练集估计，再应用到验证/测试。

p.32列Python学习资源，p.33鼓励查API与用测试数据评价。实际操作时把 `fit`、`predict`、`decision_function` 的职责写在纸上：第一个学习参数，第二个给标签，第三个给分数。先能解释输出，再增加参数组合；无需第一次就实现SMO。

**小检查（补充）**：把 $C$ 从0.1改成10，测试准确率一定提高吗？若只有训练准确率提高，你还缺什么信息？

:::hint 参考答案
不一定。C提高的是训练目标中违约的相对代价，不是对未来标签作保证。还需要固定且未被用于拟合的验证/测试评价，并检查是否反复用测试集选参数。本文只读原件记录，没有安装或重新运行这些实验。
:::endhint
