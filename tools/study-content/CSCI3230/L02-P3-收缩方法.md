### 预测误差为何分成三项（p.30–31）【新】

p.30 写真实观察 $y=f(x)+\epsilon$，噪声均值零、方差 $\sigma^2$。固定一个输入 x 后，重复抽取训练集会得到不同的 $\hat f(x)$：其平均值偏离 $f(x)$ 的量是 bias，预测围绕自身均值的波动是 variance。

$$
\mathrm{EPE}(x)=\mathrm{Bias}(\hat f(x))^2+\mathrm{Var}(\hat f(x))+\sigma^2.
$$

公式按讲义重排。Bias 要平方后才与另外两项保持同一量纲；噪声项表示目标本身的不可预测波动。推导中交叉项为什么消失<a name="r-a1"></a>[见附录 A1](#a1)。

图（p.31）：四种射靶图。  
元素：靶心、每次训练的预测点、低/高 bias 与低/高 variance 的组合。  
看什么：点团中心偏离靶心是偏差，点团散开是方差；一团很集中的错误预测仍可能高偏差。

**补充·算一遍**（数字是我为演示取的，讲义没给）：真值 10，两次模型预测 8、12，平均 10，偏差平方 0，方差 $((8-10)^2+(12-10)^2)/2=4$；若噪声方差 1，EPE=5。另一模型总预测 9，偏差平方 1、方差 0，EPE=2。这个对照解释了为何允许一点偏差有时更好。

**补充：方差不是一份测试集里预测值的分散。** 固定同一个输入，例如同一面积的房屋，想象重新收集训练集、重新拟合，再观察这套训练流程会给出哪些预测。不同房屋的租金预测差得很大，可能只是房屋本来不同，并不能据此说模型方差高。相反，同一套房在训练数据稍变后就从低价变成高价，才对应这里的估计不稳定。噪声项又是另一层：即使知道真实函数，同面积房屋也可能因未观察因素而有不同租金。

附录分解中的期望是在这个重复采样设定下计算；单次训练、测试实验只能提供泛化表现的观察，不能把三项逐一直接读出来。

### 复杂度、欠拟合与过拟合（p.32–34）【新】

p.32 用重复抽样的实验解释 tradeoff；p.33 把过高复杂度与低偏差高方差联系，过低复杂度与高偏差低方差联系；p.34 因而提出用 shrinkage 调整模型。

> **p.34** To improve the EPE, sometimes we would like to sacrifice some bias to reduce the variance.

“sacrifice some bias”在上下文中是容忍偏差上升以换取方差下降。**补充**：p.32 的“恒定模型 definitely 高 bias”是教学直觉，不是无条件定理；若真实函数恰好是同一常数，恒定预测也可零偏差。同样，训练零误差本身不能证明测试偏差小。

**考试角度**：（A 级：HW01 Q1(d)，p.2；扫描件 2023 卷 Part I Q10，p.3）前者考过比较不同次数拟合，后者考过识别训练误差下降而验证误差回升。分别<a name="r-a2"></a>[见附录 A2](#a2)、<a name="r-a3"></a>[见附录 A3](#a3)。

### Ridge 为什么压制相互抵消的大系数（p.35–37）【新】

> **p.35** Note that θ0 is not included in the penalty term.

p.35 在 RSS 后加 $\lambda\sum_j\theta_j^2$，$\lambda\ge0$ 是超参数，截距不受罚。这里惩罚是 **L2 范数的平方**；课件括注 L2 Norm，计算时应以显示的平方和为准。

p.36 解释相关特征：若两列几乎一样，一个巨大正系数可被另一巨大负系数抵消，预测近似不变但系数很不稳定。加惩罚后，这种“用两个大数抵消”会付出代价。

**补充·算一遍**（数字是我为演示取的，讲义没给）：相同特征列的系数取 100 和 −99，与取 0.5 和 0.5 都形成同样总系数 1；平方和分别为 19801 与 0.5。相同 RSS 下 Ridge 偏好后者。另取中心化单特征的平方和为 2、与标签乘积和为 4、$\lambda=2$，OLS 系数 $4/2=2$，Ridge 系数 $4/(2+2)=1$；解析式和未罚截距的推导<a name="r-a4"></a>[见附录 A4](#a4)。

图（p.37）：六次重抽噪声后的 OLS/Ridge 对比。  
元素：蓝色真实关系、红色真实值、绿色带噪样本、灰色各次拟合直线。  
看什么：OLS 更贴当次数据，但斜率差别大；Ridge 不追求穿过每次两点，换来跨训练集更小波动。

**考试角度**：（A 级：HW01 Q2(a)–(c)，p.2–3）考过中心化、截距及 Ridge 解析解，演练就在附录 A4。

**补充：为什么不一起压截距？** 截距负责整体基准水平。只给所有租金加同一常数，趋势斜率不该因此更复杂；中心化以后，截距恰好吸收标签均值与特征均值的差。若盲目给增广参数使用 $\lambda I$，连常数列也会受罚，便改变了课件约定。写增广矩阵时应使用首个对角元素为 0、其余为 1 的惩罚矩阵。

系数大小也依赖单位：同一面积以平方米或另一种面积单位表示，数值和斜率会反向变化，但预测可完全相同。直接比较未处理的不同特征系数大小可能误导；使用特征标准化时，均值和尺度必须从训练集估计，再应用到验证、测试集。这是建模补充，不是本页新增考试结论。

### Lasso 如何鼓励少用特征（p.38–39）【新】

p.38 将惩罚换成 $\lambda\sum_j\lvert\theta_j\rvert$。L1 的重点不只是让数值小，而是允许某些系数恰为零，零系数对应不使用那个特征。**补充·算一遍**（数字是我为演示取的，讲义没给）：对中心化单参数目标 $(\theta-1)^2+3\lvert\theta\rvert$，正半轴导数 $2\theta+1>0$，负半轴导数 $2\theta-5<0$；从左右都向零点下降，因此最优为零。相同系数的 Ridge 目标 $(\theta-1)^2+3\theta^2$ 导数为 $8\theta-2$，最优为 0.25。二者一个置零、一个收缩，差别已经可见。

图（p.39）：与 p.37 相同采样设置的 OLS/Lasso 对比。  
元素：真实线、噪声点、六次拟合线；Lasso 图中有近水平直线。  
看什么：系数可缩到零，所以有些拟合几乎不随输入变化。正则化过强也会欠拟合，不能说“越稀疏越准确”。

**考试角度**：（A 级，扫描件，视觉读取：2023 卷 Part I Q1，p.2）考过收缩与偏差方差、OLS 训练误差的辨析；<a name="r-a5"></a>[见附录 A5](#a5)。

**补充：把两个惩罚放在同一条数轴上看。** Ridge 在零附近的惩罚斜率也接近零，因此常把小系数继续缩小而不恰好置零；Lasso 的绝对值在零点有尖角，左右斜率分别为负和正，小的拟合收益可能不足以跨过这个尖角。上面的 Lasso 例子不能在零点直接套“导数等于零”，因为那里不可微；检查左右方向都不能下降才是正确论证。

$\lambda$ 是训练前选定的超参数，$\theta$ 是给定 $\lambda$ 后优化出来的模型参数。比较不同 $\lambda$ 应用验证集或交叉验证；如果反复用最终测试集挑 $\lambda$，测试集就参与了模型选择，失去独立评估的用途。

## 本讲核心考点

- EPE 包含偏差平方、方差和噪声方差（p.30–32，C 级）。
- 泛化比较不能只看训练 RSS（p.33–34，A 级：HW01 Q1(d)）。
- Ridge 惩罚系数平方和且不惩罚截距（p.35，A 级：HW01 Q2）。
- Lasso 的 L1 惩罚鼓励稀疏（p.38，A 级：2023 Part I Q1）。

### A1 偏差方差分解的交叉项

<a name="a1"></a>令 $\mu=E[\hat f(x)]$。把误差拆成 $f(x)-\mu+\mu-\hat f(x)+\epsilon$。平方展开后，第一项的平方是 bias 平方，第二项平方的期望是模型方差，第三项平方的期望是噪声方差。含第一项的交叉项消失，因为 $E[\mu-\hat f]=0$、$E[\epsilon]=0$。**补充（所需假设）**：新测试噪声与训练得到的预测误差独立或不相关，因此最后一个交叉项也为零。若不满足这点，不能直接丢掉该项。于是得到正文三项和。

### A4 作业/往年题演练（非讲义内容）：HW01 Ridge 解析解

<a name="a4"></a>**题面**（HW01-2025T1-题目.pdf · Q2(a)–(c) · p.2–3）

> **p.2** 2. Recall that we have learned ridge regression which is a shrinkage method to regularize the coefficients in linear models.
>
> The ridge regression penalizes L2 norm of the model parameters: $\hat\Theta_{\mathrm{ridge}}=\arg\min_{\Theta}\lVert X\Theta+\theta_0-Y\rVert_2^2+\lambda\lVert\Theta\rVert_2^2$, with $\lambda$ as a positive scalar $\lambda>0$.
>
> (a) First of all, in order to be more convenient for the derivation, we rewrite the error function as: $J(\Theta,\theta_0)=\sum_{i=1}^{M}(X^{(i)}\Theta+\theta_0-Y^{(i)})^2+\lambda\lVert\Theta\rVert_2^2$.
>
> Set $\bar X$ be the mean vector of all the raw vectors of X, then, if we change the form of $J(\Theta,\theta_0)$ into the following rewritten function: $J(\Theta,\theta_0)=\sum_{i=1}^{M}((X^{(i)}-\bar X)\Theta+\theta_0+\bar X\Theta-Y^{(i)})^2+\lambda\lVert\Theta\rVert_2^2$.
>
> Prove that, when $\theta_0=\bar Y-\bar X\Theta$, we can get the minimal value for $J(\Theta,\theta_0)$. (10%)
>
> (b) Next, let’s define the centered input as $X_c^{(i)}=X^{(i)}-\bar X$, and the corresponding centered label as $Y_c^{(i)}=Y^{(i)}-\bar Y$. Plug the above $\theta_0$ into the loss function, try to derive that: $J(\Theta,\theta_0)=J_c(\Theta)=\sum_{i=1}^{M}(X_c^{(i)}\Theta-Y_c^{(i)})^2+\lambda\lVert\Theta\rVert_2^2$. (5%)

> **p.3** (c) Finally, with calculating the first-order derivatives of $J_c(\Theta)$, try to find the analytic solution $\hat\Theta$ for the ridge regression. (10%)

公式按原题重排；这里 $X^{(i)}$ 是行向量。(a) 固定斜率向量，对截距求导：

$$
\frac{\partial J}{\partial\theta_0}=2\sum_i(X^{(i)}\Theta+\theta_0-Y^{(i)})
=2M(\bar X\Theta+\theta_0-\bar Y).
$$

令其为零得所要求截距；二阶导为 $2M>0$，故对固定斜率确实最小。(b) 将此截距代入每条残差，得 $(X^{(i)}-\bar X)\Theta-(Y^{(i)}-\bar Y)$，平方求和后正好是中心化损失，惩罚项未动。

(c) 对中心化损失求导：

$$
\begin{aligned}
\nabla J_c&=2X_c^{T}(X_c\Theta-Y_c)+2\lambda\Theta,\\
(X_c^{T}X_c+\lambda I)\hat\Theta&=X_c^{T}Y_c,\\
\hat\Theta&=(X_c^{T}X_c+\lambda I)^{-1}X_c^{T}Y_c.
\end{aligned}
$$

对任意非零 v，二次型为 $\lVert X_cv\rVert_2^2+\lambda\lVert v\rVert_2^2>0$，所以正的 $\lambda$ 保证斜率部分可逆。最后按 (a) 恢复截距，不能在常数列上也加同样惩罚。验算：令 $\lambda\to0$ 且中心化矩阵列满秩，就回到 OLS。
