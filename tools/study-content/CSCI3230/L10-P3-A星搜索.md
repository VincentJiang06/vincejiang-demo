## A*的计算与保证

### 评估函数（p.26–28）【新】

p.26为Part页，p.27定义f=g+h，表示经当前路径到该节点再到目标的估计总代价。p.28对照UCS只用g、Greedy只用h。h=0时A*退化为UCS，不是自动退化BFS，后者还需等步成本。

### 小图逐步追踪（p.29–31）

图S→a成本1，h(S)=6,h(a)=5；a→b成本1,h(b)=6，a→d成本3,h(d)=2，a→e成本8,h(e)=1。先S(g0,f6)，再a(g1,f6)；候选b(g2,f8)、d(g4,f6)、e(g9,f10)，故取d。p.31文字把h(d)与g(d)的数字顺序写反，但两数相加仍6；这里按图明确g4、h2。

### 到目标与可采纳性（p.32–34）

d→G成本2，所以G(g6,h0,f6)先于b8、e10取出，解S-a-d-G，成本6。h admissible要求0≤h(n)≤h*(n)，h*是真正最便宜剩余成本。此时f是“沿这条已走路径继续到目标”的下界，不是说当前g必为到该状态的全局最小值。道路直线距离在成本为道路长度时是典型下界；p.33煎饼图的条件问题见Part 1。

### 多个启发取最大（p.35）

若两个h均≤h*，则max(h1,h2)仍≤h*且分别≥两者，所以不牺牲可采纳性而使下界更紧。**补充·算一遍**：真实剩余10，两下界6与8，max8仍安全；sum14却高估。因此不能将安全组合记成相加。更强启发通常减少扩展，但计算h本身也有成本，平局处理还影响边界f=C*上的节点。

### 完备性需要避免无限廉价前缀（p.36–37）

链0→1→2→…边权1,1/2,1/4,…，另0→G成本2，h都0。任意有限前缀和<2，于是不断取链节点而不取G。p.36结尾“0 to S”应为0到G。有限分支再加统一正下界ε>0排除这种无限廉价链，是p.37给出的充分条件。

### 最优性证明的主线（p.38–40）

设最优目标A成本C*，次优目标B成本更大，h目标0。当B在frontier，最优路径上还有某未扩展前沿n，且其路径g正确，则

$$
f(n)=g(n)+h(n)\le g(n)+h^*(n)=C^*<g(B)=f(B).
$$

所以算法不会跳过这个更小f候选而先取B。要点是最优路径前沿始终没有被错误丢弃，不能仅背“不高估所以最优”而忽略图搜索去重策略。

### 证明完成及图搜索补充（p.41）

p.41沿前述不等式逐步推进直至A先被取出。对tree search，可采纳性支持此证明；对graph search，若关闭后不再打开，常需要一致性h(n)≤c(n,n′)+h(n′)。若只有可采纳而不一致，则发现更低g时应重新打开节点，才能保护更优路径。这是实现条件补充，课件本页未展开。

### 成本与形状（p.42–44）

最坏时间和内存仍可指数；课件用O(b^m)表示有限最大深度树的粗上界。h无信息且等成本时退化BFS；h好时较集中向目标探索。p.44三策略对照应读为排序方式导致的探索形状，A*并非只走一条直线，更不是无需维护备选节点。

### 课堂题答案及需处理的平局（p.45）

**题面**（L10-Informed-Search-2025T1.pdf · Quiz · p.45）

> **p.45** The value at each node represents the heuristic cost from that node to the
> goal node (G). The value at each arcs represents the path cost between
> two nodes. If the initial node is node B, what is the solution if use A∗
> search?
> 
> A. BEFHG
> B. BCFHG
> C. BCDHG
> D. BADHG

同p.25图，A*得到B→C→D→H→G，成本5+6+4+3=18，课件答案C；若只按h会得25。此图h(B)=19大于实际18，h(C)=13也不满足到D的一致性13≤6+6，因此不能直接把整张h表称为一致且可采纳。计算题仍可按完整frontier松弛求得18，尤其需要正确处理更低g更新。
