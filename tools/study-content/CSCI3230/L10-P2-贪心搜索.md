## Greedy best-first

### 取最小h（p.12–14）【新】

p.12为Part页；p.13定义f=h，从全体frontier中取估计最接近目标者；p.14 Arad初始h366。它不是每次只在当前节点邻居中作不可回退选择，仍维护候选集合。

> **p.13** “f(n) = h(n)”

### 罗马尼亚前三步（p.15–17）

Arad邻居Sibiu253、Timisoara329、Zerind374，选Sibiu；Sibiu的新邻居Fagaras176、Rimnicu193、Oradea380，连同旧frontier比较后选Fagaras。忽略已付的路程正是该选择标准。

### 到达与循环反例（p.18–20）

p.18 Fagaras生成Bucharest，h0最小，返回Arad→Sibiu→Fagaras→Bucharest。p.19–20另图从S在A(h1)与B(h3)间选A；该图用来说明启发方向可能误导，不能拿“朝目标”替代完备性证明。

### 为什么会困在假起点（p.21–22）

A再生成S(h2)，比仍等待的B(h3)低，若不检测重复，便S,A,S,A循环。有限图配合全局去重可消除此类循环且最终穷尽可达状态；所以课件“not complete”针对一般树搜索/无限空间，而非任何有限图去重实现都不完备。

### 非最优、复杂度与课堂题（p.23–25）

p.23已得路线140+99+211=450；经Rimnicu、Pitesti是140+80+97+101=418，差32（地图为公里，页文miles不应覆盖原单位）。h较近不保证g+h较小。

p.24最坏有限深m树时间/空间O(b^m)，启发质量改善实际扩展，但没有普遍固定加速比。

**题面**（L10-Informed-Search-2025T1.pdf · Quiz · p.25）

> **p.25** The value at each node represents the heuristic cost from that node to the
> goal node (G). The value at each arcs represents the path cost between
> two nodes. If the initial node is node B, what is the solution if use greedy
> best-first search?
> 
> A. BEFHG
> B. BCFHG
> C. BCDHG
> D. BADHG

p.25图初B，邻居A h12、C h13、E h6，选E；随后F h4、H h3、G h0，解BEFHG，答案A，总成本10+6+6+3=25。它没有选实际更短的BCD路径，因为不看g。

## 本讲核心考点

- 按整个frontier的h排序（p.13–18，C 级）。
- Greedy一般不最优，去重条件影响完备性（p.19–24，C 级）。
- 能对同图比较Greedy与A*（p.25，C 级；2023 卷 Part I Q6直接考的是A*，演练在下一 Part）。
