## 读懂每个空间轴和通道轴

### 封面与路线（p.1–3）

本讲按基础、分类架构、训练技巧、小结展开。理解架构前先会算单层输入输出，否则多层图只剩名字。

### 两个里程碑（p.4–6）

p.4并列LeNet与AlexNet，展示从较小数据/算力到大图像数据/GPU的变化；p.5用卷积、非线性、池化介绍LeNet式流程。该页把ReLU列为教学示意，不应据此写成原始1998 LeNet-5必用ReLU的历史结论。p.6列AlexNet与2012竞赛；37.5%/17.0%在后文p.52表中对应ILSVRC2010测试，课件此处年份叙述与表格不一致，具体数据以表格列标题辨别。

### ImageNet图应该怎样读（p.7–9）

p.7历史概览写22K类别、14M图像，p.8从mammal到husky、vehicle到trimaran展示标签层级，不能把全库22K与常见竞赛1000类混为一谈。p.9横轴2010–2021年份、纵轴Top-1 accuracy，青线是图中当时领先结果，灰点其他模型。这里学习数据规模与模型进步的背景，不把旧曲线当2026排行榜。

### 视觉任务改变输出对象（p.10–12）【新】

**图：猫狗鸭与框/轮廓。** 分类给整图类别，分类加定位还给一个目标框；检测可给多个框及类别；实例分割为各个对象输出像素掩码。p.11是真实图像上的多个检测框，p.12多个person用不同颜色，说明同类不同实例仍需区分。

### COCO与从向量到张量（p.13–15）

p.13展示COCO日常场景及掩码；p.14的2016–2021曲线纵轴box AP，不是分类accuracy，不能与p.9直接比百分数。p.15从普通全连接网络过渡到具有宽、高、通道的激活张量；保留空间轴使相邻位置的结构可被局部窗口利用。

### 一个卷积输出是一次内积（p.16–18）【新】

图给32×32×3输入、5×5×3滤波器。滤波器空间5×5且贯穿全部3输入通道，覆盖75个数，乘权重求和再加一个偏置得到一个标量。

$$
y_{u,v,k}=b_k+\sum_{c=1}^{C_{\rm in}}\sum_{i=0}^{F-1}\sum_{j=0}^{F-1}W_{i,j,c,k}X_{uS+i-P,vS+j-P,c}.
$$

越界输入按padding规则处理。式中k选输出通道，c求和消去输入通道；不要把每个RGB通道分别产生一张图后不相加。深度学习常称卷积的这个滑窗计算形式是未翻核的互相关。

### 滑动而不重新造参数（p.19–21）

连续三图将同一滤波器移到相邻位置，每次读取不同输入块，重复使用同一75个权重与偏置。输出激活随图像变化，滤波器参数则在一次前向中固定。共享使识别同一局部模式不需在每个位置单独学习一套参数。

### 一张特征图、多个滤波器（p.22–24）

p.22继续铺满滑动位置；p.23将结果命名activation/feature map；p.24用第二个滤波器产生第二张28×28图。空间宽度32−5+1=28，两个滤波器权重通常不同，每个输出通道对应一种学得的响应。

### 层间通道如何接（p.25–27）

p.25把输出深度称channel；p.26六个5×5×3核得到28×28×6；p.27下层十个5×5×6核得到24×24×10。第二层核深度必须6以匹配上一层输入，不再是原图RGB的3。首层参数(75+1)×6=456；第二层(150+1)×10=1510，均含偏置。

### 层次特征与尺寸问题（p.28–30）

p.28由低层边纹到高层复杂模式的可视化承接L06迁移学习；p.29车图依次经过CONV、ReLU、POOL、FC，最终类别分数偏向car。亮的中间响应不是独立参数表。p.30重现32到28的空间变化，引出接下来只看二维网格的计算。

### 7×7网格上的合法位置（p.31–33）

3×3窗口每次要完整落在输入内；步长1时左上角可沿一轴取0到4五个位置。p.33的“common to zero pad”是提示，具体网格是否有额外边框须与p.40例子区分，不能看到文字就擅自在无padding算式中加2。

### 步长1的输出与步长2的移动（p.34–36）

p.34–35完成横纵滑动，得到5×5。p.36改为stride2，左上角位置改为0,2,4，而不是仍移动五次。步长影响采样位置数量，不会把核中相邻权重间距改成2（那是另一种dilation概念）。

### 通式与向下取整（p.37–39）

p.37–38得到3×3；p.39列(N−F)/S+1，示例均整除。普通向下取整输出规则更完整为

$$
N_{\rm out}=\left\lfloor\frac{N+2P-F}{S}\right\rfloor+1.
$$

高度与宽度分别算；此处默认dilation1。不能在结果非整数时报告半个像素。

### Padding与两道课堂题（p.40–42）

p.40 输入 $7\times7$、核宽 3、stride 1、padding 1，输出 $(7+2-3)+1=7$。奇数核取 $P=(F-1)/2$ 且 $S=1$ 可保持空间尺寸。

**题面**（L07-Convolutional-Neural-Networks-2025T1.pdf · Quiz · p.41）

> **p.41** For a convolutional layer:
> Input volume: $224\times224\times3$
> Use 50 $8\times8$ filters with stride 2, pad 3
> 
> What is the output feature map size?
> A $112\times112\times3$
> B $112\times112\times50$
> C $111\times111\times50$
> D $223\times223\times50$

尺寸记号按讲义重排。空间 $(224+6-8)/2+1=112$，通道数由 50 个滤波器决定，所以选 B：$112\times112\times50$。

**题面**（L07-Convolutional-Neural-Networks-2025T1.pdf · Quiz · p.42）

> **p.42** For a convolutional layer:
> Input volume: $224\times224\times3$
> 50 $8\times8$ filters with stride 2, pad 3
> 
> Number of parameters in this layer?
> A 9, 550
> B 9, 700
> C 9, 600
> D 9, 650

每核 $8\times8\times3+1=193$ 个参数，总计 $193\times50=9650$，选 D。参数数量不乘 $112^2$，因为不同空间位置共享权重。

### 卷积总结与池化入口（p.43–44）

p.43把超参数列为K,F,S,P，输出通道K，权重F²CinK、偏置K。p.44池化在每张特征图独立操作，以缩小空间表示；通常不混合通道，也没有可学习滤波器。

### 最大池化的完整数值（p.45–47）

p.45输入单通道四行依次为(1,1,2,4),(5,6,7,8),(3,2,1,0),(1,2,3,4)。2×2、stride2四窗口最大值6,8,3,4，输出两行(6,8),(3,4)。体积224×224×64因此变112×112×64。p.46池化参数数0；该页“Conv layer”应读为Pooling layer。p.47全连接把全部上一层激活连到每个目标单元，展平后的长度是高×宽×通道。

## 本讲核心考点

- 输出尺寸与参数数独立计算（p.39–43，A 级：2023 卷 Part I Q8）。
- 特征图是激活，核和偏置才是参数（p.23–27，A 级：2023 卷 Part I Q7）。
- 池化保通道、无学习参数（p.44–46，C 级）。

### A1 作业/往年题演练（非讲义内容）：数值与概念题

**题面**（ESTR-Final-Exam-2023T1.pdf · Part I Q8 · p.3；扫描件，视觉读取）

> **p.3** 8. (3%) For a convolutional layer, we use 128 filters with kernel size $3\times3$, stride 2 and padding 1 (each side). Suppose the input data to this convolutional layer is an RGB image with size $255\times255$, what are the output feature map size and the number of trainable parameters in this layer?
>
> A. $126\times126\times128$; 3456
>
> B. $126\times126\times128$; 3584
>
> C. $128\times128\times128$; 3456
>
> D. $128\times128\times128$; 3584

尺寸记号按原题重排。

**2023卷 p.3 Part I Q8，A 级。题面：** 255×255 RGB图像，128个3×3卷积核，stride2,pad1，求输出尺寸和参数数。空间floor((255+2−3)/2)+1=128，输出128×128×128；参数(3×3×3+1)×128=3584。对应原题D。核验偏置128个、不是每像素一个。

**HW03-2025T1-题目.pdf p.1 Q1(3)，A 级。题面：** “1×1 convolution enables nonlinear feature fusion without changing spatial dimensions”判断并解释。整体为假：stride1,pad0时它保持空间，但单独卷积只是每位置跨通道的线性/仿射组合，非线性需另加激活；stride改变时也不必保尺寸。**补充·算一遍**：一个像素两通道(2,3)，核权重(1,−1)、偏置0，输出−1；加ReLU才变0，新增的非线性来自ReLU。

**题面**（ESTR-Final-Exam-2023T1.pdf · Part I Q7 · p.3；扫描件，视觉读取）

> **p.3** 7. (3%) Which of the following statement about CNN is not true?
>
> A. Data augmentation and dropout are common tricks to alleviate overfitting.
>
> B. The values in the activation maps are trainable parameters of the model.
>
> C. Residual neural networks use skip connections to alleviate gradient vanishing.
>
> D. Low-level features usually represent image characteristics of edges, shapes and colors.

选 B。A 的两种方法改变训练暴露的数据或激活，常用于减轻过拟合；C 提供额外梯度路径；D 描述低层局部特征。B 混淆了随输入变化的响应与优化器直接更新的权重。

**2023卷 p.3 Part I Q7，A 级。题面辨析：** “activation maps are trainable parameters”是否正确？不正确。激活图是输入与参数计算得到的中间结果；参数通过训练更新，而换输入就能改变激活图。卷积核权重和偏置才属于此层训练参数。
