## 深度优先

### 栈、递归与课件路径（p.41–43）【新】

p.41为Part页；p.42优先最深frontier节点，通常LIFO或递归调用栈。p.43图从S选d，再探b到a死端、回退探c，再探e相关分支，最终解S→d→e→r→f→G。访问了a不表示a在最终解中。返回父指针链或递归成功的动作链，回溯失败分支应弹出动作。

> **p.42** “hits a dead end”

### 防环仍需空间条件（p.44–45）

p.44图A→B→D→A会无限循环；路径防环解决这个环。更一般无限深无环分支也可使DFS永不到另一侧目标，所以“防环就完备”只在有限可达图等条件下成立。p.45结果经过d，而S→e→r→f→G更短，说明DFS不保证最浅或最便宜。

### 时间、空间与课堂题（p.46–48）

最大深m的树最坏探索O(b^m)，只保当前路径与未探兄弟约O(bm)，远小于BFS整层。若维护全局visited还需额外O(|V|)，不能仍把总内存一概写成仅O(bm)。

**题面**（L09-Uninformed-Search-2025T1.pdf · Quiz · p.48）

> **p.48** If node G is a goal node, what is the solution if use depth-first search?
> A ABDG
> B ABDHG
> C ABEG
> D ACG

p.48按图从左到右优先，首次G在A→B→D→G，答案A；若栈把B再C依次压入却不反转，则实际先探C，与图顺序不同。

**来源：HW04-2025T1-题目.pdf Q1（64%），A 级。题面要求：** 在Pac-Man框架实现递归和非递归DFS；迭代版用提供的Stack，graph search避免重复探索；返回动作路径，并使用题面maze测试。题面指出同一mediumMaze可能因后继压栈顺序得到130或246长度，要求注意顺序。

递归版：先判目标；标访问；遍历后继，对未访问者递归，成功就返回[action]+后续成功路径；所有后继失败才回退失败。迭代版：栈存(state,path)或父指针节点，弹出未处理状态，判目标后标访问并压入后继；跳过重复弹出。若要与递归的从左到右一致，通常把后继逆序压栈，还需保持一致的标记时机。

130与246是题面示例，不是本次运行结果。DFS两种合法路径长度不同不自动说明某一版错误；要核对起终点、动作合法、顺序约定与重复处理。这里没有改写作业原件、读取同学代码或提交答案程序。

递归返回必须区分“成功但动作列表为空”（初态已为目标）与“失败”；直接用空列表的真假值当成功标记会混淆两者。迭代版每个栈节点携带自己的路径，不可把全局访问序列直接返回。题面问 Pac-Man 是否实际走过所有红色探索格，答案是不一定：红色记录规划搜索扩展，执行只沿找到的动作路径。这也解释为什么探索多并不表示最终路径长。

本地缺少题目指定的 search.zip、迷宫与评分脚本，所以 130、246 只作原题条件下的参照。本次不声称运行这两种 DFS 或通过 autograder。
