## 深度优先

<a name="栈递归与课件路径p4143新"></a>

### 先把一条路试到底，为什么能省记忆（p.41–42）

p.41是分节页。BFS要同时记住一整层候选；DFS（深度优先搜索）换一种探索习惯：先沿当前分支往下走，走不通再回到岔路口试另一个。它像逐条检查迷宫通道，但这是帮助理解的类比，程序实际上仍在操作搜索节点，不一定真的移动机器人。

**栈（stack）**最后放进去的先取出，叫LIFO。递归也可以实现同样的行为：每次调用记住“这一层还有哪些兄弟没试”，子调用失败后回到上一层。这不是把所有搜索历史永久保存。

### 先用已经认识的小树练栈（补充，沿用p.28树）

沿用A的孩子B/C，B的孩子D/E，C的孩子F/G，目标G。约定左边孩子优先，栈的**左端是下一次取出的顶端**。一次生成一组后继时，要使B最终位于C前面；若程序按右端作栈顶，就应先压C后压B。约定不同没关系，实际取出顺序必须对应。

|取出|理由与操作|之后frontier，左端先取|
|---|---|---|
|—|先放起点|[A]|
|A|把B/C放在已有候选前面，B先|[B,C]|
|B|D/E抢在等待的C前面|[D,E,C]|
|D|叶子失败，转向兄弟|[E,C]|
|E|叶子失败，B分支已完|[C]|
|C|继续沿C分支|[F,G]|
|F|叶子失败|[G]|
|G|目标，停止|[]|

访问次序是A,B,D,E,C,F,G，解仍然是A→C→G。**回溯**表示放弃失败子树、继续尝试；不表示最终动作列表必须包含先前所有尝试。父指针只记录当前路线。

### 再读课件较复杂的图（p.43）

图（p.43）：左边为有向状态图，右边为展开的搜索树；起点S、目标G。
元素：图中S有后继d/e/p；d有b/c/e，b与c均可到a；e可到h/r；h可到p/q，p可到q；r到f，f可到c/G。红线标出本次DFS探索的树边。
看什么：相同状态a、e、p、q可在不同路径中重复出现在搜索树，红色探索过的节点也未必在答案里。

按课件左到右顺序，先S→d→b→a，a是死端；退回d再试c→a，仍失败；再试e的h分支，最后进入r→f。f先试c→a，失败后才到G。最终父链为S→d→e→r→f→G。这里右侧画的是允许不同路径重复状态的搜索树演示；若实现全局去重，实际展开名单可能更短，不应强行逐节点照抄红色树。

为了看清大图的每次待办变化，以下直接按课件**树搜索演示**记状态标签（相同字母可对应不同路径节点）：

|取出|处理后frontier|
|---|---|
|S|[d,e,p]|
|d|[b,c,e,e,p]|
|b|[a,c,e,e,p]|
|a|[c,e,e,p]|
|c|[a,e,e,p]|
|a|[e,e,p]|
|e（经d）|[h,r,e,p]|
|h|[p,q,r,e,p]|
|p（经h）|[q,q,r,e,p]|
|q|[q,r,e,p]|
|q|[r,e,p]|
|r|[f,e,p]|
|f|[c,G,e,p]|
|c|[a,G,e,p]|
|a|[G,e,p]|
|G|停止，保留的e/p不再展开|

例如两个相邻e分别来自S→d→e和S→e，不能因为标签一样就把父链混在一起。

<a name="防环仍需空间条件p4445"></a>

### 防环究竟保证什么（p.44）

p.44有A→B→D→A的环。若每次回到A都像第一次一样继续下探，永远不会回头试另一支。最简单的路径防环，是拒绝进入当前祖先链中已有的状态；全局visited则更强，连其他分支已处理的状态也跳过。

但“不绕圈”不等于一般空间里一定找到目标：补充设左边是永远向前的0→1→2→3→…，右边一步就是目标。左边没有重复状态，DFS仍可能一直深入。因此完备性要说条件：有限可达图且适当避免重复，可穷尽状态；无限深树上一般不完备。

### 找到的第一条路为什么未必最好（p.45）

课件DFS返回S→d→e→r→f→G，5条边；同图S→e→r→f→G只有4条边。若每条边成本1，前者5、后者4。DFS只是先试左分支，没有机制保证“第一条成功路径最短”。改变后继顺序甚至会改变答案，不能用一次运行很快找到好路线当作最优性证明。

<a name="时间空间与课堂题p4648"></a>

**补充 · 显式栈里不只有状态，还可能需要执行进度**（通识讲解；演示数据不属于原题）。

递归DFS进入一个节点后，会记住“下一个还没尝试的后继是哪一个”；子调用返回时从那里继续。这份进度由调用栈隐式保存。若改写成迭代版但只保存一个状态，必须另行决定一次推入全部后继，还是保存后继迭代位置；两者都能实现DFS，但压栈顺序和内存账不同。

演示后继按A、B、C顺序访问：若一次全部入栈，为了让A先弹出，应按C、B、A压入。写成A、B、C压入却声称访问A在先，就是把容器里的排列与下一次取出顺序混淆。回溯时删除当前路径标记，也不等于删除一个用于全局图去重的visited集合；要先说集合承担哪种职责。

### 时间看最深处，空间看同时压住多少（p.46–47）

$b$ 是最大分支数，$m$ 是搜索树最大深度。最坏要试完整树，所以时间 $O(b^m)$；它用的是 $m$，不是最浅目标深度 $d$，因为DFS可能先去比目标深得多的地方。

每深入一层，至多记住当前节点和若干尚未尝试的兄弟。深度 $m$，每层约 $b$ 条记录，路径式空间是 $O(bm)$。补充二叉树深10，完整叶层可有1024个节点，而沿一条路径主要只需约10层祖先/待办兄弟；数量级差异来自“同时保留”，不是DFS从不访问其他节点。

如果另保存全局visited，它还要随可达状态数增长；不能一边保存所有访问过的状态，一边说程序总空间必定只有 $O(bm)$。上述线性深度空间适用于路径式DFS记账。

### 课堂题按约定找第一个目标（p.48）

> **p.48** If node G is a goal node, what is the solution if use depth-first search?

原选项A.ABDG、B.ABDHG、C.ABEG、D.ACG。图中D的左孩子就是G，右孩子H再接一个G。按左到右DFS，不需要走到整棵树“最深的G”才停。

:::hint 参考答案
A→B→D→G是第一次碰到的目标，选A。DFS的“深度优先”指继续处理当前分支，不是预先知道所有节点后挑最深目标；同理也不保证最浅目标。
:::endhint

## 本讲核心考点

- 栈顶约定与后继压入顺序共同决定访问次序（p.42–43，C级）。
- 防环解决重复循环，不能消除无限无环深支（p.44，C级）。
- 解路径来自成功父链；时间深度与空间记账要分清（p.45–47，C级）。

:::hint 参考答案
下一条候选是A→B→E，所以要撤去失败分支的B→D，保留共同前缀A→B。visited可以另外记录D已处理过，但不能把这个搜索知识当作未来要执行的动作。递归实现中，一份是调用栈/当前路线，一份是可选的全局去重集合；职责不同。
