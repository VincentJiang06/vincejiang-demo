### 在原空间分不开，换什么（p.33–35）【新】

p.33 提出原空间可能线性不可分；p.34 考虑升维后用平面分开；p.35 举映射 $\phi(x)=(x_1^2,x_2^2,\sqrt2x_1x_2)$。映射改变特征表示，分类器在新空间仍线性，在原空间却可以有弯曲边界。升维只是创造可能，不保证任何映射都能把任意数据分开。

**补充·算一遍**（数字是我为演示取的，讲义没给）：x=(1,2) 映成 $(1,4,2\sqrt2)$；若高维法向量为(1,1,0)、b=−3，分数为 $x_1^2+x_2^2-3=2$。其原空间零分数边界是半径 $\sqrt3$ 的圆，而在三维映射空间是一个平面。

**补充：映射必须对训练与新样本使用同一规则。** 不能为了让训练点分开而临时给每个点任意坐标，再没有办法映射新输入。这里的 $\phi$ 是一个事先明确的函数，任意新点都能按相同平方、乘积规则得到特征。所谓“在高维线性”仍是学习一个可用于新样本的统一分数，而不是给训练点重新命名。

### 核函数计算的是内积（p.36–38）

p.36 把硬间隔约束中的 x 换成 φ(x)；p.37 观察对偶只用内积，所以定义 $K(x,z)=\phi(x)^{T}\phi(z)$；p.38 的预测成为

$$
f(x)=\sum_i\alpha_i y_iK(x_i,x)+b.
$$

核函数不是“把一个输入直接输出高维向量”的同义词：它接收两个输入，直接给高维内积这个标量。**补充·算一遍**：继续取x=(1,2)，z=(2,1)（演示自取），原内积4，平方16；显式映射内积 $1\times4+4\times1+(2\sqrt2)(2\sqrt2)=16$。二者相等才可以替换。

**补充：把训练和预测两处替换分开。** 训练时，二次项里每个 $x_i^Tx_j$ 换为 $K(x_i,x_j)$；求出的仍是 $\alpha$。预测新点 $x$ 时，则计算它与各个非零乘子训练样本的 $K(x_i,x)$，乘上 $\alpha_i y_i$ 再求和加 $b$。核不直接给类别，类别仍取最终分数的符号。

核技巧避免显式存储巨大映射向量，但不是所有成本都消失：若有 $m$ 个训练样本，完整核矩阵有 $m\times m$ 个位置。它解决的是特征展开的一类成本，样本数很大时仍需考虑训练规模。

### 讲义核函数小测（p.39–40）

**题面**（L04-Support-Vector-Machine-2026T1.pdf · Quiz · p.39）

> **p.39** Which of the following function $\kappa(x_i,x_j)$ can be the kernel function of the transformation:
>
> $x=(x^{(1)},x^{(2)})\Rightarrow\phi(x)=((x^{(1)})^2,(x^{(2)})^2,\sqrt2x^{(1)}x^{(2)})$
>
> In other words, which one can make $\kappa(x_i,x_j)=\phi(x_i)^{T}\phi(x_j)$?
>
> A $\kappa(x_i,x_j)=x_i^{T}x_j$
>
> B $\kappa(x_i,x_j)=(x_i^{T}x_j)^2$
>
> C $\kappa(x_i,x_j)=x_i^{T}+x_j$
>
> D $\kappa(x_i,x_j)=x_i^{T}/x_j$
>
> E $\kappa(x_i,x_j)=\sqrt2x_i^{T}x_j$

公式按讲义重排；D 照原件写法，不把未定义的向量除法补成另一种运算。p.40 展开映射内积：$x_{i1}^2x_{j1}^2+x_{i2}^2x_{j2}^2+2x_{i1}x_{i2}x_{j1}x_{j2}$，正好是 $(x_{i1}x_{j1}+x_{i2}x_{j2})^2$，选B。交叉特征前的 $\sqrt2$ 正是为了乘起来给系数2，不能随意删去。

### 常见核与不同任务（p.41）

表（p.41，原页为图片）：三个核表达式

| 名称 | 公式 |
|---|---|
| Polynomial | $K(x_i,x_j)=(x_i^{T}x_j)^d$ |
| Sigmoid | $K(x_i,x_j)=\tanh(\beta x_i^{T}x_j+\theta)$ |
| Gaussian | $K(x_i,x_j)=\exp(-\lVert x_i-x_j\rVert_2^2/(2\sigma^2))$ |

图（p.41）：三类核的直观曲线。  
元素：多项式曲线、S形曲线、高斯钟形曲线。  
看什么：核规定如何比较样本，不等于分类模型已经训练完成。**补充**：sigmoid 核需注意参数与正定条件，不能说任意参数总构成有效内积核。

**补充·算一遍**（数字是我为演示取的，讲义没给）：高斯核 σ=1，两点距离0时K=1，距离2时K=$e^{-2}\approx0.1353$。距离越大相似度越低；这是核值，不是某个类别的概率。

**考试角度**：（A 级，扫描件，视觉读取：2023/2024 卷 Part III Q1、2025 官方节选 Part III Q1）考过一维点映到二维后求最大间隔边界；统一几何过程<a name="r-a1"></a>[见附录 A1](#a1)。

**补充：核参数与软间隔参数不是同一个旋钮。** 高斯核的 $\sigma$ 控制多远的点仍被看作相似：同样距离下，$\sigma$ 越小，核值衰减越快。下一 Part 的 $C$ 则控制违反间隔的代价。前者改变比较样本的方式，后者改变拟合与范数的权衡；即使同时调节，也应能说明各自作用。两个参数都不能从某个训练样本的标签直接“算出来”，需要训练流程中的模型选择。

### A1 作业/往年题演练（非讲义内容）：一维传感器点的二维映射

<a name="a1"></a>**题面**（Final-Exam-CSCI3230-Record-2025T1-官方节选.pdf · Part III Q1 · PDF p.3；扫描件，视觉读取）

> **p.3** 1. (5%) A robot is using a SVM classifier for 1D sensor. The data $X\in\mathbb{R}$ is found to be not linearly separable. The training data points are:
>
> Positive (+): $x_1=0,x_3=3,x_4=4$
>
> Negative (-): $x_2=1$
>
> To solve this, a feature mapping function $\Phi(X)=(X,(X-1)^2)$ is used to project the data into a 2D space.
>
> (a) Calculate the 2D coordinates for all four data points $(x_1,x_2,x_3,x_4)$ after applying the mapping $\Phi(X)$. Then, draw these 4 points in the 2D space and write the function of the line of decision boundary. (2%)
>
> (b) In this new 2D space, which of the points $(x_1,x_2,x_3,x_4)$ are the support vectors? (2%)
>
> (c) If the robot collects one more negative data point at $x_5=1.5$, would its mapped position in the 2D space affect the decision boundary (margin) you drew in (a)? Justify your answer. (1%)

公式按原题重排。2023 卷 p.6 和2024 卷 p.7 的 Part III Q1 使用相同数据、映射与新增点（各小问分值不同）；以下逐项几何计算适用于三份中的同一问题，ESTR 2025 节选是相同页面。

(a) 记映射后的坐标为(u,v)，四点依次是(0,1)、(1,0)、(3,4)、(4,9)。正类前三个中的1、3号在v=u+1线上，负类2号在v=u−1线上，取中央边界 **v=u**。规范参数w=(−1,1)、b=0；功能间隔依次1、1、1、5（已乘各自标签）。两侧总间隔 $2/\sqrt2=\sqrt2$。

为什么不是随便取一条分开的线：正类1号与负类2号距离 $\sqrt2$，任何平行支撑面间距都不能超过这两个异类点的距离；上面达到该上界，故是最大间隔。若取水平线v=0.5，虽可分但总间隔只有1，并非SVM最优。

(b) 按“位于支撑面”的几何定义，正类1、3号与负类2号在支撑面上；4号严格在外。这里出现退化：对偶可取α1=α2=1、α3=α4=0，恢复w=(−1,1)。因此按“非零对偶系数”的计算定义，只有1、2号承担权重；3号虽在支撑面却可零系数。本讲 p.24 将两定义视作等价的简化在这里需要说明，答题时应同时写清几何位置与α，不能虚构唯一的官方答案。

(c) 新点映成(1.5,0.25)，分数−1.25，负类功能间隔1.25≥1，位于原负侧支撑面之外。原分界保持可行，且1、2号给出的最大间隔上界没有改变，因此边界与间隔均不变。新增点在原一维坐标上更靠右，并不意味着映射空间里更靠近边界。
