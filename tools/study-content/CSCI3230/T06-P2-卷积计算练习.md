### Quiz 1：共享到哪一层（p.9–10）

> **p.10** In CNN, 'weight sharing' refers to 'all convolutional layers having completely identical convolution kernel weights'. Is this statement correct?

尺寸/公式记号按原题重排。

先不要被“共享”两个字带走，指出到底哪两个对象共用哪组数。普通卷积中，是**同一层、同一输出核在不同空间位置**共享权重；不同核需要学不同模式，不同层的输入通道数甚至可能不同，不能要求全部权重形状都一样。

所以题目把共享扩大到“all convolutional layers”，命题为False。补充自取：第一层是3×3×1核，第二层输入32通道，核变3×3×32，这两层连参数个数都不同，更不可能按普通定义完全相同。

自查时把一句模糊定义改成完整句：“谁在什么范围内共享什么？”这比只记True/False更能避免换题就错。

### Quiz 2：28 像素输入（p.11–12）

> **p.11** Given the input image size of $28\times28\times1$ (MNIST data), using a $3\times3$ convolution kernel, stride = 1, no padding (Padding=0), find the size of the feature map after convolution ($H\times W\times C$).

尺寸/公式记号按原题重排。

先把给定条件摆好：输入边长28，核宽3，步长1，每边填充0。空间计算与通道计算分两步。

1. 不填充，所以可用长度还是28。
2. 核左上角从0开始，最远到25，覆盖25、26、27，仍在范围内。
3. 起点0到25一共26个，不是25个。
4. 高宽相同，因此空间为26×26。

公式也给同样结果：

$$
\left\lfloor\frac{28+2\cdot0-3}{1}\right\rfloor+1=26.
$$

原题只说“a kernel”，p.12按一个输出滤波器给 $26\times26\times1$。最后的1来自单核这个读法，不能只因输入单通道就断言输出单通道。若改用8个核，空间不变，输出会是26×26×8。

检查：kernel3为什么不是让长度28直接除3？因为窗口重叠、每次只走1，不是在把图切成不重叠三格块。

### Quiz 3：偶数核与填充（p.13–15）

> **p.13** For a certain CNN’s Conv layer, the input is $16\times16\times8$ (8 channels), kernel size $4\times4$, stride = 1, Padding=2, number of kernels 16, find:
>
> 1. the size of the feature map after convolution;
>
> 2. the total number of parameters in this layer.

尺寸/公式记号按原题重排。

这题同时问形状和参数，分两张账来做。形状先只看空间：输入16，左右各补2后变20，核宽4，合法起点从0到16，计17次。

$$
H_{\rm out}=W_{\rm out}=\frac{16+2\cdot2-4}{1}+1=17.
$$

16个核产生16张图，所以完整输出为17×17×16。输出比输入大1并非一定算错：偶数核4配对称padding2，本来就不是恰好same。核4在stride1要总填充3才保持长度16，左右对称整数填充无法各给1.5。

再数参数。一个核覆盖4×4空间和8个输入通道，共 $4\cdot4\cdot8=128$ 个权重；每核另有1偏置；16核共 $128\cdot16=2048$ 权重加16偏置，得到2064。

输出有 $17\cdot17\cdot16=4624$ 个激活，不能拿这个数当参数，因为同一核在289个空间位置重复用。增加padding让输出位置变多，却没增加核内可学习数。

小检查：若题目明确 `bias=False`，哪一步变化？

:::hint 参考答案
只去掉每核的1个偏置，总参数变2048；输出形状仍17×17×16。
:::endhint

### Quiz 4：一路追踪到展平（p.16–17）

> **p.16** Suppose we have a CNN with hierachy structure [Conv1($5\times5\times6$), MaxPool1($2\times2$), Conv2($5\times5\times16$), MaxPool2($2\times2$)], padding=0, stride=1(stride=2 for maxpool). Given an input image with shape ($28\times28\times1$), find the shape of output feature.

尺寸/公式记号按原题重排。

长链最常见的错误是第二层还用原输入28。正确做法：每算完一层，把输出写在纸上，它就是下一层的输入。题中Conv1的6、Conv2的16是输出核个数。

|步骤|本层读取什么|空间计算|输出|
|---|---|---|---|
|Conv1|28×28×1|$28-5+1=24$|24×24×6|
|MaxPool1|24×24×6|$(24-2)/2+1=12$|12×12×6|
|Conv2|12×12×6|$12-5+1=8$|8×8×16|
|MaxPool2|8×8×16|$(8-2)/2+1=4$|4×4×16|

为什么第一池化通道仍6？因为每张图各自取窗口最大值，没有把六张图合为一张。为什么第二卷积变16？因为第二层用了16个不同核，每核都跨上层六个输入通道。

原题所问最终特征形状是4×4×16。若后接全连接，才再展平成 $4\cdot4\cdot16=256$ 个特征。展平不是把各格相加，它只是按固定顺序排成一条，所以信息个数不变、参数数为0。

自己核验时，可把每次池化前空间圈起来：24到12、8到4确实各减半；卷积的24到8不是直接一次减到8，而是先池化成12再卷积。
