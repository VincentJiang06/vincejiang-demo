### Quiz 1：共享到哪一层（p.9–10）

> **p.10** In CNN, 'weight sharing' refers to 'all convolutional layers having completely identical convolution kernel weights'. Is this statement correct?

**题面：** 卷积的权重共享是否意味着所有层有相同权重？答案 False。同一层同一个滤波器在不同空间位置共享；不同输出滤波器以及不同层通常各有自己的参数。若第一层学边缘、下一层组合纹理，让它们强制相同会改变网络架构，不是普通 CNN 的定义。

### Quiz 2：28 像素输入（p.11–12）

> **p.11** Given the input image size of $28\times28\times1$ (MNIST data), using a $3\times3$ convolution kernel, stride = 1, no padding (Padding=0), find the size of the feature map after convolution ($H\times W\times C$).

公式与尺寸记号按讲义重排。

**题面：** 输入 $28\times28\times1$，核 $3\times3$，步长 1，填充 0，求输出。每边 $28-3+1=26$，所以空间尺寸为 $26\times26$。按课件单滤波器图，完整输出 $26\times26\times1$；若题目另给 $C_{out}$ 个滤波器，则最后一维应是 $C_{out}$，不能由输入通道 1 自动推出输出通道 1。

验算：核左上角可从位置 0 走到 25，共 26 个位置。若数成 25，是漏掉起始位置。

### Quiz 3：偶数核与填充（p.13–15）

> **p.13** For a certain CNN’s Conv layer, the input is $16\times16\times8$ (8 channels), kernel size $4\times4$, stride = 1, Padding=2, number of kernels 16, find:
>
> 1. the size of the feature map after convolution;
>
> 2. the total number of parameters in this layer.

公式与尺寸记号按讲义重排。

**题面：** 输入 $16\times16\times8$，16 个 $4\times4$ 滤波器，步长 1、填充 2；求输出尺寸与含偏置参数数。

每边 $(16-4+4)/1+1=17$，因此输出 $17\times17\times16$。一个滤波器跨 8 个输入通道，含 $4\cdot4\cdot8=128$ 个权重，再加一个偏置；16 个滤波器共 $129\cdot16=2064$ 个参数。

这里填充后输出比输入大 1，并非计算错误；偶数核配左右各 2 的对称填充没有恰好保持尺寸。输出元素数 $17^2\cdot16=4624$ 也不等于参数数 2064，因为每组参数在空间复用。

### Quiz 4：一路追踪到展平（p.16–17）

> **p.16** Suppose we have a CNN with hierachy structure [Conv1($5\times5\times6$), MaxPool1($2\times2$), Conv2($5\times5\times16$), MaxPool2($2\times2$)], padding=0, stride=1(stride=2 for maxpool). Given an input image with shape ($28\times28\times1$), find the shape of output feature.

公式与尺寸记号按讲义重排。

**题面：** 输入 $28\times28\times1$，依次卷积 $5\times5$、6 通道，$2\times2$ 最大池化，卷积 $5\times5$、16 通道，$2\times2$ 最大池化。卷积无填充、步长 1，池化步长 2。

|步骤|计算|输出|
|---|---|---|
|第一卷积|$28-5+1=24$|$24\times24\times6$|
|第一次池化|$(24-2)/2+1=12$|$12\times12\times6$|
|第二卷积|$12-5+1=8$|$8\times8\times16$|
|第二次池化|$(8-2)/2+1=4$|$4\times4\times16$|
|展平|$4\cdot4\cdot16$|256 个特征|

池化逐通道处理，空间缩小，通道数保留；展平只改形状，不引入参数。这也是检查后续全连接层输入维度的方法。
