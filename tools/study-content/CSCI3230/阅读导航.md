# CSCI3230 阅读导航

这套笔记按第一次学习的速度展开：先说明要解决什么问题，再看小例子，然后逐步写符号和计算。共 **64 篇学习笔记**，包括主课 50 篇、辅导/代码实践 9 篇、ESTR 独立阅读 3 篇，以及 HW01 的详细解析与分级提示各 1 篇。本页是第 65 个导航文档。

不需要一次读完。每次选一个小节，先自己算正文的小例子；能解释每个量的含义再往下走。标为“补充自取”的数字用于教学，不是老师原题。小检查的参考答案默认收起，先停下来想一下再展开。

## 建议阅读顺序

### 如果觉得讲义太快

先只走基础主线：

1. [L01-P4 学习与评价](L01-P4-学习与评价.md)：分清输入、标签、参数与评价数据。
2. [L02-P1 回归建模](L02-P1-回归建模.md) → [P2 最小二乘](L02-P2-最小二乘.md)：把一条预测扩成矩阵，再自己算平方误差。先读正文，旧题大表可以第二遍再做。
3. [L02-P3 收缩方法](L02-P3-收缩方法.md)：理解为什么训练误差低还不够，再看两种惩罚。
4. [L03-P1](L03-P1-分类问题.md) → [P2](L03-P2-逻辑回归模型.md) → [P3](L03-P3-交叉熵与梯度下降.md)：分数、概率、损失和参数更新逐层接起来。
5. [L04-P1](L04-P1-线性分类器.md) → [P2](L04-P2-最大间隔SVM.md) → [P3](L04-P3-核方法.md) → [P4](L04-P4-软间隔.md)：先画边界与距离，再看优化问题。
6. [L05-P1](L05-P1-聚类基础.md) → [K均值](L05-P2-K均值.md) → [密度聚类](L05-P3-密度聚类.md) → [层次聚类](L05-P4-层次聚类.md)：每次只跟一个算法的完整小例。

进入旧课件预习后，按 [L06 网络](L06-P1-网络结构.md) → [反传](L06-P2-反向传播.md) → [L07 卷积](L07-P1-卷积基础.md) → [L08 注意力](L08-P1-注意力基础.md) 的顺序。遇到矩阵尺寸卡住，先数输入输出，不急着背网络名称。

[L09 搜索建模](L09-P1-搜索建模.md) 开始的是另一条主线。先分清状态、路径和frontier，再按各篇队列表手跑；到 [L10 A*](L10-P3-A星搜索.md) 时，先写明g/h/f各自是什么，才讨论最优性条件。

### 如果正在做 HW01

先打开 [2026T1 分级提示](HW01-2026T1-分级提示.md)，只展开卡住的小问与必要层级。想核对整条推导时再进入 [2026T1 详细解析](HW01-2026T1-详细解析.md)。后者包含答案和完整数值；它不是提示模式。

### 如果需要实际代码或 ESTR 拓展

梯度下降搭配 T02；SVM搭配 T03；卷积搭配 T06和T07CNN；Transformer搭配T07Transformer。代码篇会区分“原件保存输出”“按代码能推出的形状”和“确实运行过的核验”，不把它们混在一起。

ESTR扩展先读相应基础 Part，再读该讲最后的扩展 Part。独立阅读项目另从 [选题导引](ESTRTopics-阅读与项目选题.md) 进入，历史展示时间和评分仅作版本明确的参考。
