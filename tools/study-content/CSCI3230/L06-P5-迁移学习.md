## 从已有模型开始

### 扩展范围与动机（p.74–76）

**这是旧版讲义的 ESTR3108 扩展。** p.74 单独写 ESTR3108，p.75 的 Outline 只有 Transfer learning。它不应被当作 CSCI3230 本学期已确认必需的内容；前面网络基础还没稳固时，先完成[结构](L06-P1-网络结构.md)、[反传](L06-P2-反向传播.md)与[训练](L06-P3-训练与验证.md)。

p.76 的问题很实际：训练大网络很费时间和数据，已有模型已经学过一些模式，能否保留有用部分，避免每个新任务都从零开始？这就是**迁移学习（transfer learning）**的动机。

> **p.76** Can we reuse them?

类比是已经会骑自行车的人学另一辆车，不从“怎样保持平衡”全部重学。但这只是直觉：模型没有人的理解，它复用的是参数和由这些参数计算出来的表示。迁移是否有用，要看新任务的数据与目标，不能由类比保证。

### 什么会迁移（p.77–79）【新】

p.77 描述从相关问题中转用知识。具体到网络，前面若干层把原始输入变成一组特征，后面层用特征做最终判断。我们可能保留前面的计算，改后面的判断。

p.78 以 CNN 为例：早层往往对边缘、方向和颜色等局部模式有响应；后层更贴近原任务的物体部件或类别。这是理解可迁移性的常见趋势，不是保证某一层“只懂边缘”、另一层“只懂猫”的严格分工。

图（p.79）：AlexNet 首层过滤器的彩色小块。
元素：标注 $64\times3\times11\times11$，表示 64 个过滤器，每个有 3 个通道、空间大小 11×11；不是 64 张训练图片。
看什么：已经学到的权重呈现方向边缘、颜色等结构，说明从训练中得到的参数并非只能作为随机数重新扔掉。

**补充自取一个很小的表示例子。** 设特征提取器 $F_{\theta}$ 将原始输入 x 变成两个数 $h=(2,1)$。下标 $\theta$ 表示它内部的旧参数；我们暂时不管原始 x 有多少维，只知道输出 h 是 2 维。新任务的线性头使用 $w=(1,-1)$、偏置 0，分数为 $2-1=1$。如果前两维特征对新任务仍有用，只学习这个新 w 就可能比重新学习全部特征省数据。

这里 2、1 只是演示数值，不代表可以把真实网络隐藏维度直接命名成两个可解释的人类概念。

### 顶层特征与冻结（p.80–82）

p.80 用网络高层表示做 L2 最近邻检索：每行左侧是测试花、象、船、南瓜或奶牛，右侧是特征空间中接近的图像。**相近的是网络表示，不一定是原始像素逐个相近**；同一物体可能换背景仍靠近。

p.81 展示将 ImageNet 的 1000 类输出层换成新任务 C 类的输出层，其余层冻结。若保留的特征维度为 d，新分类头的矩阵在行向量约定下是 $d\times C$，偏置长 C；它必须适配新类别数，不能直接保留旧 1000 类名字。

**冻结（freeze）**表示训练时不更新某些参数，**不表示跳过它们的前向计算**。新图像仍必须经过旧特征提取器，才能得到 h；只是优化器不修改旧的 $\theta$。

继续补充小例：h=(2,1)、w=(1,−1)、目标实数为 2，暂用半平方损失帮助看更新对象。预测为 1，残差 −1，头部梯度为 $(-2,-1)$，偏置梯度 −1。学习率 0.1 后，新头部权重为 (1.2,−0.9)、偏置 0.1，新预测为 $2\times1.2-0.9+0.1=1.6$。**特征 h 保持 (2,1)**，因为提取器被冻结。

这个演示是回归头，不是 p.81 的分类实验。分类时会把 C 个分数变成 softmax 概率，损失也相应换成交叉熵；“只更新新头部”这一原则相同。

p.82 在新数据更多时训练更多高层，而底层继续冻结。更多可调参数提供适应能力，也需要更多数据约束，避免仅记住少量新样本。

### 操作顺序与任务差异（p.83–85）

p.83–84 的路线可以慢慢分成几个决定，而不是一条“下载模型后训练”的口号：

1. 明确新输入的表示、标签与输出维数；确认旧特征适不适合。
2. 保留预训练参数作为起点，将不匹配的旧分类头换掉。
3. 冻结特征部分，先训练新头，让它学会使用现有表示。
4. 若验证效果不足，再尝试解冻靠后的层，用较小步长适配。
5. 比较新方案与前一个方案的独立验证表现，而不是只看训练 loss 更低。

第 4 步的“微调（fine-tuning）”是继续更新已有参数；从头训练则从随机初始化开始。只训练新头与微调旧层不是完全相同的操作。

表（p.85）：新数据量与域相似度的四格建议。

|新数据量|与旧数据很相似|与旧数据很不同|
|---|---|---|
|很少|在顶层特征上训练线性分类器|较困难；可尝试不同深度的特征加线性分类器|
|较多|微调少数层|微调更多层|

为什么是这四格？数据少，调整太多参数容易被少数样本牵着走；数据多，才有更多证据支持调整。任务相似，旧高层表示可能直接有用；差异大，高层可能过度专门化，甚至早层假设也未必适合。表格是课件的策略建议，不是保证收益的定理。

**补充：负迁移**指复用旧知识反而损害新任务。如果旧模型强调与新目标无关的模式，保留它也可能是限制。所以应与合理的基线比较，不能把“预训练过”当质量证明。

### 步长和模型来源（p.86–88）

p.86 建议微调时从原学习率的约十分之一尝试。假设是旧权重已经处于有用位置，大步可能破坏它。这个比例是起点，不是必须遵守的常数；新随机头与旧层也可能需要不同的更新幅度（补充策略）。

看一个**补充自取的单参数比较**：某旧参数为 0.50，本次梯度为 2。学习率 0.1 改到 0.30，学习率 0.01 改到 0.48。较小步长保留更多原值，但如果旧特征并不适合，保留它也未必更好。要把“少破坏”和“更适合新任务”分开评估。

p.87 列 model zoo 作为已发布模型入口，这只是说明可以寻找预训练权重，不表示每个下载项都符合新任务。使用时还要核对模型架构、输入尺寸、归一化方式、类别头和权重版本；相同模型名称也不能代替这些具体条件。

图（p.88）：上方从图像训练 CNN 后分类，下方从预训练 CNN 接新任务并微调。
看什么：新任务训练的是新标签对应的映射，不能只换页面上显示的类名却继续使用原分类头解释输出。

### 医疗、文本与语音（p.89–91）

图（p.89）把自然图像预训练与医学影像任务之间画上迁移箭头及问号。它提出“是否能迁移”的问题，不给临床有效性结论。自然照片与特定医学图像的数据分布、纹理、灰度和目标均可能不同，必须在相应任务上验证；本篇不据图推断医疗能力。

p.90 的文本例用预训练语言模型再接情感分类器：句子 “The movie was good” 标 1，“The movie was horrible” 标 0。共享表示可用来识别词语与上下文，但新分类头仍需要学习这些表示如何对应情感标签。图里的预训练目标与下游标签目标不同，迁移不等于将旧输出直接当新答案。

p.91 的语音图展示三条路线：设备端个性化、用大模型表示训练小模型、用下游数据微调整体。它们共享“复用已有表示”，但更新哪些参数、需要多少计算以及部署位置不同。不能仅因都叫 transfer learning 就认定实现完全一样。

#### 小检查：冻结以后还能学习吗

设整个特征提取器被冻结，只有新头部可训练。训练若改善，是不是说明被冻结的权重也变了？若全部层都被冻结、也没有新可训练参数，优化器还能通过更新参数适应新任务吗？

:::hint 参考答案
第一问不是：改善可以完全来自新头学习如何组合固定特征，旧提取器仍不变。第二问没有可更新参数，便不存在通常意义上的参数训练；只能使用固定模型做推断或另外引入可学习部分。冻结的对象和可训练参数清单必须先明确。
:::endhint

这篇的核心是做出明确选择：哪些表示保留、哪些参数允许改、用什么新数据与验证方法判断适配是否有效。它是 ESTR 旧版扩展学习路线，不将其写成 CSCI3230 当前必考要求。

## 本讲核心考点

- 区分从头训练、冻结特征训练新头、微调旧层（p.81–86）。
- 冻结禁止更新，不禁止前向计算；输出头维数应符合新任务（p.81–83）。
- 数据量和域差异共同影响调整范围，四格表是建议不是保证（p.85）。
- 明确这是 2025T1 ESTR3108 扩展，不能据此声明当前 CSCI3230 教学或考试要求。
