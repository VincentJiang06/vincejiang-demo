### 为什么不能永远追求完全可分（p.43–45）【新】

p.43 指出即使有核映射，噪声也可能使完全可分困难或带来过拟合。p.44 提议允许个别样本违反间隔；p.45 用离散惩罚计数违反程度：先定义 z=标签乘分数−1，z<0记1，否则记0。

注意此处惩罚的是“未达到单位间隔”，不只“分类错了”。**补充·算一遍**（数字是我为演示取的，讲义没给）：标签+1、分数0.4，符号判类正确，但功能间隔0.4<1，仍付出惩罚。标签+1、分数−0.4才是错分；两者不能合称同一种状态。

**补充：所谓容忍并不是先挑几条数据删除。** 模型仍把所有样本写入目标，让优化权衡“增加间隔带来的好处”与“某些点受罚的代价”。若事先把所有难分点删掉，改变的是训练数据；软间隔则是在固定数据上改变优化规则。课件中的 noisy examples 是动机，不是已经知道哪些标签一定错误。

### Hinge loss 的折点在间隔1（p.46）

p.46 将不连续的计数惩罚换成凸的 hinge：

$$
\min_{w,b}\frac{1}{2}\lVert w\rVert_2^2+C\sum_i\max(0,1-y_i(w^{T}x_i+b)).
$$

公式按讲义重排。C 控制每单位违反间隔的代价；更大 C 更重视训练间隔错误，较小 C 更允许违反，以争取小范数。不要把这里 C 与 Ridge 的 λ 方向直接等同。

图（p.46）：0/1 与 hinge、指数、log 损失的比较。  
元素：横轴分类分数式变量、阶跃损失及连续替代曲线。  
看什么：正文 hinge 为 max(0,1−功能间隔)，零损失区从功能间隔1开始，不是从0开始。

**补充·算一遍**（数字是我为演示取的，讲义没给）：三个样本功能间隔为1.2、0.4、−0.5，hinge分别0、0.6、1.5，总和2.1；若范数平方4、C=2，总目标 $4/2+2\times2.1=6.2$。中间那个分类正确仍有0.6损失。

**考试角度**：（A 级：HW02 Q2，p.2）要求比较不同核和软间隔参数；演练<a name="r-a1"></a>[见附录 A1](#a1)。

**补充：逐段读 hinge。** 令 $s=y(w^Tx+b)$。当 $s\ge1$，已达单位间隔，损失为 0；当 $0<s<1$，判对但离边界不够远，损失 $1-s$ 介于 0 与 1；当 $s<0$，判错，损失大于 1。$s=0$ 是分类边界，$s=1$ 才是损失折点。不要把这两个位置记成一个。

也可引入松弛量 $\xi_i\ge0$，写约束 $y_i(w^Tx_i+b)\ge1-\xi_i$，目标 $\tfrac12\lVert w\rVert^2+C\sum_i\xi_i$。给定 $w,b$ 后，使惩罚最小的松弛量正是 $\xi_i=\max(0,1-s_i)$，所以得到同一个 hinge 目标。这是辅助理解的等价写法：松弛量量化违反程度，不是非正即负的标签。

对 $C>0$，把整个目标除以 $C$ 可得 $\frac{1}{2C}\lVert w\rVert^2+\sum_i\mathrm{hinge}_i$；这就看出较大 $C$ 对应相对较弱的范数约束。它可能更贴训练数据，但不能保证测试准确率提高。

## 本讲核心考点

- 正确分类仍可能落入间隔、产生hinge损失（p.45–46，C 级）。
- C 越大，违反间隔越贵（p.46，A 级：HW02 Q2）。
