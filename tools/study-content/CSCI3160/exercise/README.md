## 如何使用

- Regular按题号阅读，重点看正确性证明与复杂度中每一步的条件。
- Special先读“题解”得到完整结论或算法，再读“具体解析”理解推导、表格、证明与边界。
- 图形题已核对箭头、权重、坐标；顺序不唯一的题明确指定平局或松弛顺序。
- 异常题先读[勘误与阅读说明](勘误与阅读说明.md)，尤其Regular6 Q3、Regular9 Q6、Special6 Q2。

**按错误类型挑练习。** 若看懂结论却不会独立做，先遮住答案写输入、状态和第一步，再对照：

| 卡点 | 推荐练习 | 应留下的结果 |
|---|---|---|
| 目标秩或阈值更新 | [Sp01 Q2、Q5](Sp01-选择与加权中位数.md) | 每次保留集合及新的 k 或 H |
| DP 边界、费用与回溯 | [Sp06 Q2、Q5](Sp06-DP表格与切割费用.md) | 空切点处理、最后一格所有候选、实际切法 |
| 图的顺序影响中间状态 | [Sp10 Q1、Q4、Q5](Sp10-Dijkstra与BellmanFord演算.md) | 提取或松弛顺序、距离表、树边 |
| 近似保证的不等号 | [Sp13 Q3](Sp13-集合覆盖贪心与困难性.md)、[Sp14 Q3–4](Sp14-HittingSet与最远点中心.md) | 可行解、OPT 的界及每个不等式的理由 |

做完手算后再改一项条件，例如允许重复值、把边权改负、把严格递增改为非递减；指出哪一步证明失效。反例只需击破一个必要步骤，不能凭一次成功的小例子证明算法普遍正确。
