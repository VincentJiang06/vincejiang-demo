# CSCI3160 L12 强连通分量与两遍DFS

> 课程：CSCI3160 Design and Analysis of Algorithms
> 本讲：L12 强连通分量与两遍DFS · 原件 [L12-Graph-02-Strongly-Connected-Compon-未核-隐藏.pdf](../课件/L12-Graph-02-Strongly-Connected-Compon-未核-隐藏.pdf) p.1–18
> 定位：通过两遍 DFS 划分有向图，并解释为什么必须反转边、按完成次序启动。
> 承接：[#L11-02 白路径定理](local:course-index)

### p.1–3：强连通还要求极大【新】

p.1 为标题。

> **p.2** “cannot add any more vertex”

强连通分量 SCC 是极大的顶点集合：任意两点互相可达，而且不能再加入其他顶点保持这个性质。“极大”不是全图中点数最多，而是不能扩张。p.3 的 {a,b,c} 是 SCC；{a,b,c,d} 不是，因为引入 d 后不再互相可达；{d,e,f,k,l} 虽内部强连通却可再加入 g，故也不是完整 SCC。

### p.4–5：分量确实形成划分

> **p.4** “Any two distinct SCCs are disjoint.”

若两个强连通集合共享 x，则前者任意 u 可经 x 到后者任意 v，反向亦然；并集仍强连通，因此两个不同的极大集合不可能重叠。p.5 的目标划分是 {a,b,c}、{d,e,f,g,k,l}、{h,i}、{j}。一个孤点集合也可构成 SCC，这不要求它具有自环。

图（p.3、5）：12 个顶点的有向图。元素：a→c→b→a 是一个环；d,e,f,g,k,l 通过多条内部路径互达；h 与 i 双向相连；j 可走向其他区域但不能从这些区域返回。看什么：仅有“向外可达”不会把分量合并。

### p.6–8：第一次记录完成，随后反转全部边

> **p.6** “when it turns black”

标签按第一次 DFS 的完成顺序从 1 增加，不是发现顺序。p.7 给出的完成顺序为 h,b,c,a,l,k,f,e,d,g,i,j，所以 h 的标签是1，a 是4，g 是10，i 是11，j 是12。第一次从 i 启动，最后另起根 j。

图（p.7–8）：原图及反转图。元素：第一次树包含 i→g→d→e，再分别向 a 和 f 深入；p.8 每条箭头反向，标签不变。看什么：反转的是整个原图，不能只反转 DFS 树边。实现时一次扫描原图边 (u,v)，向反向邻接表 v 中加入 u。

### p.9–11：第二遍每棵树输出一个分量

> **p.9** “largest label”

第二遍先把颜色重置为白，在反转图上从标签最大的白点启动，栈空后仍这样选根。p.10 的根依次是 j、i、g、a，输出的四棵树分别就是上面的四个 SCC。树内部的访问次序可以有差异，分量划分不会改变。

p.11 总时间 $O(V+E)$：两次 DFS 加构造反向邻接表都是线性。无需比较排序标签；第一次每完成一个点就压入列表，第二次倒序遍历该列表，遇黑跳过即可。若每次线性扫描寻找最大白点，反而可能引入平方时间。

**补充：最小反例说明两项操作都不能少。** 自取图仅有 `a→b`。第一次从 a 开始，先完成 b 后完成 a，标签分别 1、2。正确的第二遍反图只有 `b→a`，先从 a 开始只能收集 a，再从 b 收集 b，得到两个单点 SCC。

若不反图而仍从 a 开始，就会沿 a→b 把两个点放进同一树，错误合并。若已经反图却按标签从小到大，先从 b 开始也会走到 a，同样错误。不是“反图”和“排序”分别神奇地有效，而是反向边与递减完成次序共同保证不进入尚未处理的其他分量。

:::hint 自测：只对第一次 DFS 的树边反向，为何不足？

SCC 由原图全部可达关系决定。原图中被略过的灰边、黑边也可能提供回程，删掉它们会把本来互达的点拆开。构造反图应遍历每条原边，并保留全部顶点；第一次森林仅用于取得完成顺序，不能替代输入图。

:::endhint

### p.12–14：把整个分量压成一个点

> **p.12** “SCC graph”

分量图的每个点是一个 SCC，跨分量的原图边变成分量间的边。它一定无有向环；否则环上的分量互相可达，应合并为一个 SCC。

图（p.13–14）：四个压缩点 S1={j}、S2={h,i}、S3={d,e,f,g,k,l}、S4={a,b,c}。元素：边为 S1→S2、S1→S3、S2→S3、S3→S4；分量标签取内部顶点完成标签的最大值。看什么：四个分量标签分别12、11、10、4，跨分量的箭头总从大标签指向小标签。

这里取最大值很关键：不必断言一个 SCC 的所有完成事件在时间上连续，也不必断言该分量每个点的标签都大于后继分量的每个点。

### p.15–16：下降标签是证明的关键

> **p.15** $\mathrm{label}(S_i)>\mathrm{label}(S_j)$

若原图有跨分量边 Si→Sj，考察两者中最先发现的点。若它在 Si，则可到 Si 和 Sj 的所有尚白顶点，它完成时 Sj 已完成，所以 Si 的最大标签更大。若最先发现的点在 Sj，则 Sj 不可能到 Si，否则两者互达属于同一 SCC；因此 Sj 会先处理完，再轮到 Si，结论仍成立。

p.16 将分量按最大标签递减排列。反转后，某个分量的出边只通向序列中更早、已经处理的分量。这正是第二遍不会“走出自己分量”的原因。只记“做两遍 DFS”而漏掉顺序或反转步骤，不能得到这个保证。

### p.17–18：从第一棵树推广到全部

第一次选最大标签的 SCC：在反转图内部仍然互相可达，其外部出邻居均不存在于尚白分量，因此 DFS 恰好覆盖它。p.18 归纳：假设之前的 SCC 已全黑，下一最大标签白点所在分量内部全白、互达；能向外走到的较早分量已黑，故本棵树仍恰好是一个 SCC。

这也给出实现检验：每个点输出一次；树内任意两点互达；压缩图无环。三者帮助理解，不应拿实际运行的检查代替上述正确性证明。

> **p.2** “(h) (2 points) If S1 and S2 are two distinct strongly connected components in a directed graph, we cannot have a path from a vertex in S1 to a vertex in S2 and a path from a vertex in S2 to a vertex in S1 simultaneously.”

题源：[Final-2025T1-题目.pdf](../考试/Final-2025T1-题目.pdf) p.2 Q1(h)。判断：两个不同 SCC 之间，不能既有从第一个到第二个的有向路径，又有从第二个到第一个的有向路径。

正确。假设双向路径均存在，利用两个分量内部的互相可达，就能把任意 u、v（分别属于两个分量）双向连接起来。并集仍强连通，与两个分量分别极大矛盾。注意允许单方向跨分量路径；禁止的是双向同时存在。

### A2 作业/往年题演练（非讲义内容）：完成标签与分量方向

<a name="a2"></a>**题面**（Final-2021T1-题解.pdf · Part I Q3 · PDF p.2 左栏，印刷 p.3；扫描件，视觉读取；公式按原题重排）

> **p.2** “3. Determine true statements for an arbitrary DFS on a digraph G:”
>
> (a) $post(u)>post(v)$ if there is a (u,v)-path in G.
>
> (b) $post(u)>post(v)$ if G contains a (u,v)-path but no (v,u)-path.
>
> (c) The vertex of maximum post number belongs to a source strongly connected component.
>
> (d) The vertex of minimum pre number belongs to a sink strongly connected component.

(a)错：两点双向边图，DFS先发现v再发现u，u→v路径存在，但u先完成，所以post(u)<post(v)。(b)对：u、v不在同一SCC，存在从u到v的单向可达。若u先发现，会在u完成前把v完成；若v先发现，因为v不能到u，它会先完成，再在以后发现u。两种情况都得所述次序。

(c)对：若最大完成编号所在SCC有别的SCC指向它，前者的分量最大完成编号必更大，矛盾。因此它在源SCC中。(d)错：最先发现的点由DFS启动选择，可任意选；图a→b先从a启动，a的pre最小，却处于源分量而不是汇分量。结论为(b)、(c)，不是笼统说“所有有向路径都让post递减”。
