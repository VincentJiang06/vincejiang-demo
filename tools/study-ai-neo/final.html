先建立三个能解释失败原因的小实验。① 将一幅图单独输入，再把它和另一幅无关图拼成一批；取出同一幅的 10 个分数逐项比，可检验预测是否依赖批内同伴。② 用随机权重、非对称图案、水平和竖直不同的循环位移，比较 f(x)f(x)f(x) 与 f(Tx)f(Tx)f(Tx)；对称图或全零图可能让有缺陷的网络碰巧通过。③ 切换到训练好的权重，在与训练分开的验证数据上评估识别。把所有样本都预测成相同分数的模型可以严格不变，却没有区分类别的能力。

原题要求输入 [B,1,28,28][B,1,28,28][B,1,28,28]，输出浮点原始分数 [B,10][B,10][B,10]，各图可独立移动。数值检查比较原分数，也比较中心化再按长度归一化的向量；还单独核对类别。给每行 logit 减去该行均值会去除公共偏移，除以范数会去除公共比例，所以只把原分数压得很小无法说明结构正确。对近似相等的两个最高分，还应检查浮点误差是否会让 argmax 换位。

模型大小也能纸算。若 3×33\times33×3 卷积从 1 通道到 8、带偏置，参数是 8(9+1)=808(9+1)=808(9+1)=80；随后 8 到 16 是 16(72+1)=116816(72+1)=116816(72+1)=1168；若池化后 16 维接 10 类，线性层有 16×10+10=17016\times10+10=17016×10+10=170，三层合计 1418。这个数不随输入空间尺寸变化，乘加计算量却随尺寸变化。训练时按验证集挑 checkpoint，之后锁定模型再评估。题目限制未平移训练图、无增强、固定优化日程、至多 10 epoch；用平移增强得到的经验稳健性，不能回答“结构是否保证”这一问。

§2.1–2.2A · 用一行数字检查缩放、遮罩和梯度

要点屏蔽位置要在归一化前排除。这样合法位置分到的概率之和才是 1，被屏蔽的值也不会影响结果。

字典在每个样本里都可能变化。给定“蓝签→甲、红签→乙”，问题依次问“红签、蓝签”，输出必须按提问顺序。若下一例把红签改成甲，固定背诵“红签总是乙”就错了。需要的是对当前上下文的检索。查询 QQQ 决定读什么，键 KKK 提供匹配依据，值 VVV 携带要取回的内容。

自编一个头，键深度 D=4D=4D=4。设某个查询与三个键的内积为 (0,2log⁡3,8)(0,2\log3,8)(0,2log3,8)，第三个位置属于未来。先除以 4=2\sqrt4=24​=2，得到 (0,log⁡3,4)(0,\log3,4)(0,log3,4)；在 softmax 之前将第三个分数屏蔽，归一化后权重为 (1/4,3/4,0)(1/4,3/4,0)(1/4,3/4,0)。若值向量分别为 (2,0),(0,4),(9,9)(2,0),(0,4),(9,9)(2,0),(0,4),(9,9)，上下文为 (0.5,3)(0.5,3)(0.5,3)。若先用三个位置做 softmax 再把第三项清零，前两项的和会小于 1，未来键即使不直接贡献值，仍会通过分母改变结果。

张量版对每一批、每个头分别做同一件事。Q,K,VQ,K,VQ,K,V 为 [B,H,T,D][B,H,T,D][B,H,T,D]，只交换 KKK 的最后两轴，QK⊤QK^\topQK⊤ 才会得到每个 query 对每个 key 的 [B,H,T,T][B,H,T,T][B,H,T,T]。沿最后的 key 轴做 softmax，乘 VVV 才回到 [B,H,T,D][B,H,T,D][B,H,T,D]。不能交换批或头的轴。若只盯住输出形状，一条被错误归一化的行仍可能长得完全正确。

为什么还要测梯度？ 只看上下文第一维 c=∑jajvjc=\sum_j a_j v_jc=∑j​aj​vj​，对第 jjj 个已缩放分数的偏导是 aj(vj−c)a_j(v_j-c)aj​(vj​−c)。本例 c=0.5c=0.5c=0.5，两项分别为 0.25(2−0.5)=0.3750.25(2-0.5)=0.3750.25(2−0.5)=0.375 和 0.75(0−0.5)=−0.3750.75(0-0.5)=-0.3750.75(0−0.5)=−0.375，被屏蔽项为零。两者相加为零，符合“整行加常数不改变 softmax”。对 VVV 第一维的梯度正好是对应权重。再沿点积往回传才能更新 Q,KQ,KQ,K。若把权重转到不追踪梯度的数组再转回，前向数字可以正确，训练信号却可能消失。

§2.2B–C · 画出两个不同的掩码

要点因果掩码管「这一步能读哪些词」，损失掩码管「哪些位置答错了要扣分」。两张表分别画，才不容易混。

因果遮罩控制读权限。 当 T=3T=3T=3 时，第 0 行能读 {0}\{0\}{0}，第 1 行能读 {0,1}\{0,1\}{0,1}，第 2 行能读 {0,1,2}\{0,1,2\}{0,1,2}。本题布尔真表示允许，对角线可见。把同一前缀各接两个不同后缀，保持权重不变，比较共同前缀各位置的 logits；它们应一致。若第 0 行会随最后一个词变化，优先检查三角方向和 softmax 之前是否屏蔽。

损失掩码控制哪些预测计分。 为单独看清对齐，缩短提示部分，写一条自编示意序列。真实任务的完整字典和查询均位于 SEP 前。将序列首尾错开一格，对齐如下。

预测位置的输入 BOS 提示甲 SEP 答甲 答乙 EOS
下一词目标 提示甲 SEP 答甲 答乙 EOS PAD
该位置损失权重 0 0 1 1 1 0

在输入 SEP 的位置计入第一枚答案，在输入最后一枚答案的位置计入 EOS。此行最终是三项交叉熵之和除以 3。若批内另一行有不同长度的提示，必须按各行的 SEP 和 padding 决定权重。给所有行复用固定列号，短样本会多算 prompt，长样本会漏掉答案。因果遮罩随 TTT 规定哪些列可读，损失掩码随样本规定哪些行计分，形状、意义和错误现象都不同。

§2.3–2.5 · 输出格式为什么也能改变学习难度

要点多要求模型输出一个字段，就多了要学习的词元。比较模板时，还应核对相同训练步数下各自预测了多少个词。

设上下文词典是 Ka↦V2,Kb↦V1K_a\mapsto V_2,K_b\mapsto V_1Ka​↦V2​,Kb​↦V1​，依次问 Kb,KaK_b,K_aKb​,Ka​。只输出 value，目标是「V1,V2V_1,V_2V1​,V2​, EOS」；若每条记录先输出 key 再输出 value，目标是「Kb,V1,Ka,V2K_b,V_1,K_a,V_2Kb​,V1​,Ka​,V2​, EOS」。第二种在预测 value 前给出一个近邻线索，但 key 也需要模型自行生成。若第一个 key 生成错，后续上下文可能已经偏离训练时的轨迹。

训练时 teacher forcing 把真实前缀交给下一位置。推理时模型只能把自己刚生成的词放回去。即使模型用正确前缀预测每个词的表现不错，整段也可能中途失败。格式变长又会增加失败位置。在“每步正确率都恰为 .9 且独立”的自编参照下，3 步全对是 .93=.729.9^3=.729.93=.729，5 步是 .95=.59049.9^5=.59049.95=.59049。实际各步相关，额外线索还可能提高单步正确率，所以这个算式说明的是风险来源，不能预言哪种格式赢。

按本期设定，先用只含 value 的基线，再换一个合法的 1–5 字段模板，每条记录恰有一个 value。保持相同底层字典与查询、初始化、函数实现、解码方式、300 次更新和评估样本。因为输出长度变了，同时记输入词元数、参与监督的词元数和耗时。若均是两个查询，3 个目标换成 5 个，单个样本提供的监督位置增加 2/32/32/3。因此“步数相同”还不能证明收益完全来自显式 key。

§2.6–2.7 · 用三条输出读懂四个分数

要点逐字段正确、整条记录完全正确和格式能否解析，回答的是不同问题。先手算几条输出再读汇总分。

取三个两查询的示意样本，目标模板都是 key、value、key、value、EOS。第一条逐词全对；第二条输出第一枚 key 的身份错，但字段类型与位置均合法、两个 value 的顺序正确；第三条布局合法，第二枚 value 错。严格整段正确率为 1/31/31/3，格式合法率为 3/33/33/3，整段值序列正确率为 2/32/32/3，逐值正确率为 5/65/65/6。若第三条改为缺 EOS，本题解析规则会把那条响应的两个 value 都按错误计，逐值正确率变为 4/64/64/6。一定先按任务定义决定什么是“有效预测”，再算分母。

写实验解释时分成三句话。第一句写能复核的观察，包括哪两个格式、同一验证集上的分子分母、严格准确率与百分点差。第二句写可能机制，例如显式 key 缩短了取回关联值的距离；也写出另一种解释，例如每个更新看到了更多监督词元。第三句提出能区分两者的观察，如按查询个数分层，或另做长度相近但只增加固定标点的对照。基线比新设计好，也完全可以写出有价值的答案。

Assignment 3 · A3.8

合上书试一次 · 由故障现象反推最小检查

要点输出看起来整齐却答非所问时，挑一条最小样本，逐项查它能看见什么、目标有没有错位、解码读了哪一行。

现象一，训练后移位分类很准，新初始化时移一格却改变 logits。 先用单个非对称输入，列出每层特征在位移前后是否只相差循环置换。在第一处失败层检查边界填充和步幅。准确率说明经验表现，逐层对照能定位哪个假设失效。

现象二，训练损失降得很快，逐词生成却读不到问题。 选一条固定样本，写出 SEP 前后各三列的输入、目标和计分掩码，先排掉“复制当前词”和“从第二个答案开始算”；再做同前缀异后缀试验。两者都过，再逐步喂入模型自己的预测，记录第一次分叉是在格式词、值还是 EOS。这个顺序把对齐、未来信息泄漏和正常的自回归误差分开，适用于解释一个从未见过的生成任务。
