八个知识板块

从课程概览开始，也可以直接进入想弄懂的问题。八个板块连成一篇，可以按目录跳转，也可以一路向下阅读。

01 / 基础

操作系统概览

从终端启动一段 C 程序。沿着它的一条指令、一个变量和一次保存，看看运行的工作由谁承担。

7 个小课↗
02 / 接口

在用户程序中调用操作系统

亲手构造一个 shell 的工作过程，再顺着程序中的指针、文件描述符和路径，追踪每个数字究竟指向哪个对象。

13 个小课↗
03 / 持久化

文件系统如何组织磁盘

拿一块空盘，从块的编号、文件的身份和目录中的名字开始设计，最后算出一次打开、读取或扩写会触碰哪些块。

7 个小课↗
04 / 持久化

I/O 设备与存储

用一个磁盘读请求区分三件事：命令怎样到达设备，数据由谁搬运，应用怎样知道请求已经结束。

7 个小课↗
05 / 虚拟化

进程与 CPU 调度

一台单核机器一边播放声音，一边编译程序。音乐进程在什么时候停下？轮回来时，它又凭什么从同一个音符继续？先把一次暂停和恢复走通，再用同一根时间轴决定该轮到谁。

14 个小课↗
06 / 虚拟化

内存管理

同一个指针值可以在两个进程里指向两封不同的邮件。一封邮件还可能暂时只在磁盘上。沿着一次 load 从指针走到真实字节，系统怎样兼顾隔离、容量和速度，就能逐步算出来。

17 个小课↗
07 / 并发

线程

把一段录音分成两半同时处理，两份工作都要读录音，最后还得合并结果。沿着这个小程序，辨认哪些状态随线程切换，哪些对象会被另一条执行路径改动，再学会把工作交出去并安全地收回来。

7 个小课↗
08 / 并发

竞态、锁与信号量

两个售票员可以同时为不同场次工作，同一张票却只能卖一次。沿着“怎样排他”“等到什么时候”“谁能保证继续前进”三个问题，从一次加锁推到有界队列、读写锁和死锁。
